# 確認ページ — 初回と毎月の確認の HTML・名と版・貼り戻し

事務所の担当者に問いを聞く HTML は「確認ページ」の 1 つの呼び名・1 つの形にする（`docs/設計/Drive の型.md` §3）。Drive に置く写しの名は `確認事項_<会社>_<支給月>_v<版>.html`、置き場は会社の `8_確認事項/`。

- **正本は質問と回答**。確認ページは質問と回答の行から起こす、表示と配る用の写し。答えは質問と回答へ貼り戻してから使う（HTML の上の答えを直に計算に使わない）。
- **配った版の正は URL**（配る口が返す URL）。URL は管理表「確認ページ」に 1 行で載せる。
- この道具は **Drive を開かない**。問いの一覧を受けて HTML の文字列・名・置き場・管理表の行を返すだけ。置く・配る・管理表へ書くのは殻。
- 返す HTML は **外へ通信しない**自己完結の 1 枚（外の script・style・画像・fetch を持たない・`file://` で動く）。

## 置く物

| file | 中身 |
|---|---|
| `確認ページ.py` | 作る・名と版・差し替え・貼り戻し・管理表の行・問いの検査 |
| `前の答え.py` | 前の答えを照らす口（qa-html の `prior_check_cmd`＝形 qa-prior/1）。標準入力の問いを質問と回答の答え済みと照らし `{answered, checked}` を返す（同じ番号・同じ設定の項目・字の 8 割の重なり。分からない・出し直しは数えない・聞き直しは理由に「聞き直し: Q…」）。表は殻が読んで file に置き、環境 `PAYROLL_QA_ROWS`（会社は `PAYROLL_QA_COMPANY`・パックの dir は `PAYROLL_PACK_DIR`）で渡す。表が無い・読めない・見出しが無い・渡した会社の行が無くほかの会社の行がある時は何も出さず 2 で終わる（check.mjs が赤）。文面の問いは `--questions` で答え済みがあれば 2 |

## 型（qa-html の 1 つの型・答えの形 qa-html/2）

**型・検査・答えの形は repo に写さない**（前は `雛形.html` に型を丸ごと写していた）。`作る` は土台の qa-html の型を毎回直に読む（`qa_htmlの道具()`＝CI は環境の `QA_HTML_CHECK`・窓は Claude Code の台帳 `installed_plugins.json` の docs-kit の `installPath` の `check.mjs`、その `--template`）。見つからない・2 つに割れる・`--template` を知らない古い docs-kit の時は止まる（別の版の型で起こさない）。node が要る。答えの形は土台の `check.mjs --answer` で照らす（`tests/確認ページ/test_確認ページ.py`）。写しを repo に戻すと試験が赤。

形の約束の正本は qa-html の SKILL.md §型の約束。この道具が合わせる所:

- **流れ**: はじめ → 1 画面 1 問 → 送る前の確認 → 受付（受付番号・この後のこと・控え）。未回答があると送れない。
- **宛先の印** `<body data-dest>`: `send`（配る口へ素のフォームで送る・既定）／`copy`（受付の画面に貼り戻しの字が出る）／`artifact`（確認のページが `qa:submit` で答えを持つ）。宛先で変えるのは宛名と会社の色 1 つだけ（差出人・連絡先の欄は無い＝名乗りと問い合わせ先は配る人の送る文に書く）。
- **問いの鍵** `data-qkey`＝問いの番号を英数字と `_` に直した物（`Q209904-01`→`Q209904_01`）。答えの `name` も同じ。
- **版** `__版__`＝`<支給年>.<支給月>-v<n>`（`2099.04-v2`・`版の字`）。名の `_v<n>` と同じ数＝問いを直して配り直すと上がる。
- **1 枚の上限** 12 問（qa-html の `questions_per_page`）。超えたら `作る` が 1 回の呼び出しで、並びのまま **同じ版の枚** に分ける: 名 `_v<n>-<枚>.html`・版 `…-v<n>-<枚>`（枚どうしで名と版が重ならない）。`枚たち` を全部配り、管理表には枚ごとに 1 行。次の版（配り直し）は分けた枚の全部を前の版に数える（`次の版` の `前の版たち` を 1 枚ずつ `差し替え`）。殻が問いを切って `作る` を 2 回呼ばない（どちらも同じ版の名になる）。
- **並べ方（2 部）** `data-group`: 1 枚の中で **前半＝会社の決まり**（`rule`）・**後半＝原本**（`person`＝人ごとの事実 → `once`＝今回だけの事）（オーナーの決定 2026-11-16・`docs/設計/設問の作り方.md` §2・§6.1）。部の頭はまとまりの 1 行（`.glead`）の頭の字（「前半・会社の決まり: …」「後半・原本の確かめ: …」）、後半の問いの見出し `data-glabel` は「原本・人ごとの事」「原本・M 月分だけの事」（立ち上げは「原本・今回だけの事」）。まだ起きていない場面の問い（今月の原本で当たる人がいない決まり・対象の いつ が「当たる人が出た時」）は **いつも最後** の `later`（見出し「先に決めておきたい事」・まとまりの 1 行は qa-html の決まった文「今月の計算には関係しません。起きた時の決め方を先に伺います。」）に分ける（2026-11-17 オーナー）。`作る` が並べ直し（質問と回答の順は変えない）、`部`（{会社の決まり: 数, 原本: 数}）を返す。どちらの種類も事務所の窓口へ 1 枚で送る。
- **前提の 3 段**: ①はじめの画面に読んだ資料の一覧（`.docs` の `li[data-doc][data-url]`＝`d1`・`d2`…・リンクは li の中の同じ URL の `<a href>`〔別のタブで開くのは型の JS〕・リンクが無い資料は `data-url=""` と `data-no-url="訳"`）と答えるまでの扱い（`.hold`）②まとまりの最初の問いに 1 行（`.glead`）③1 問に固定の 4 欄＝何について（`.about`・問いの人は `span.who`）・見つけた事（`.known[data-docs]`）＋切り抜き（`figure.clip`・2 枚まで）・なぜ聞くか（`.why[data-why]`＝決まった 4 文）・くわしく（`details.more`・原文は `.orig`）。**前提が書けない問いは出さない**（`問いの検査` と check.mjs が赤）。
- **選択肢**: 記号（A・B）を付けず、中身の見出し `<b>`＋この答えで変わる事 1 行 `<small class="chg">`（誰の・何が・いくら）。逃げ道（`other`・`none`）は変わる事の代わりに添え書き `<small>`。値（`value`）は字から決まる鍵（`c` と 8 字・前の版の行の `見当のとおり`＝`estimate`・形が足す物＝`other`・`none`）。**おすすめの印は出さない**（`（推奨）`・`推奨: true` の行は赤。2026-11-17 オーナー: 見込みを前提にさせない）。
- **根拠と AI の読み**（2026-11-17 オーナー: どのファイルのどこをどう読んだから聞くかを見せる）: なぜ聞くかの下に AI の読み（`.reading`＝こう読んだ→ここが決まらない 1〜3 行・1 行 80 字）、見つけた事の下に根拠（`ul.evidence` の `li[data-doc][data-where]`＝`<b>資料の名</b>・場所`〔PDF はページと欄・シートはタブとセルの範囲・60 字〕＋原文の引用 `span.quote`〔80 字〕・3 つまで）。リンクははじめの画面の一覧に置く。
- **見込みの別枠**: 見当があり、見当の拠り所が見込みの拠り所（資料・過去の結果）の時だけ、選択肢の後に `p.estimate[data-basis=拠り所]`（中身は見当・40 字。「AI の今の見込み: 」と「（根拠: …）。見込みに合わせず、事実で選んでください。」は型の CSS が付ける）を置く。「見込み」「予測」の字はこの枠の外に書かない（check.mjs が赤）。既定・法の線・知らせ・無し は計算の置き値で見込みでない＝出さない。全問の最後に「または」と **「分からない・確かめてから答える」**（`value="__unknown__"`）。
- 全問にひとこと（`supp_<鍵>`）と、最後に「ほかに伝えたい事」（`__自由記入__`）。

## 呼び口

すべて `python3 確認ページ/確認ページ.py <口> < 入力.json`。赤が 1 つでもあれば終わりの値 2。

| 口 | 入力 | 出力 |
|---|---|---|
| `作る` | `組`・`支給月`（`YYYY.MM支給`）・`支給の月`（会社の `支払.支給の月`＝当月／翌月／翌々月・任意）・`用`（立ち上げ／毎月）・`問い`（下の行の list）・`今ある名`（置き場の名の並び）・`履歴にある名`（前の版の置き場 `9_履歴/` の名の並び）＝2 つは必ず渡す（前の版が無ければ `[]`・省く・`null`・1 つの字は止まる＝版は前の版の最大の次）・`宛先`（`send`〔既定〕・`copy`・`artifact`）・`読んだ資料`（字か `{名, 期間, 受け取った日, url, no_url}` の list・問いが指すのに無い名は足して知らせ・url か no_url が要る）・`答えるまでの扱い`・`まとまりの1行`（`{rule|person|once|later: 1 行}`・渡すと部の頭の字ごと替わる）・`宛名`・`期限`・`この後のこと`・`会社の色`（`#rrggbb`）・`内部の言葉`（どれも任意） | `赤`・`知らせ`・`版`・`版の字`・`名`・`下書きの名`・`置き場`・`前の版`・`前の版たち`・`問いの数`・`部`（{会社の決まり: 数, 原本: 数}・赤の無い時）・`html`（赤があれば `null`）・`枚たち`（`[{枚, 名, 下書きの名, 版の字, 問いの数, 問いの番号, 部, html}]`・12 問を超えて分けた時は上の段の `名`・`下書きの名`・`版の字`・`html` が `null`） |
| `検査` | `問い`・`内部の言葉` | `赤` |
| `貼り戻し` | `問い`（その確認ページの問いの質問と回答の今の行・送り直しで足した行も）・`答え`（1 送信か送信の並び〔古い順〕）・`回答日`・`版`（今配っている `版の字`・必ず渡す＝省く・空・形の違う時は赤。分けた枚の答えはその枚の `版の字`〔`…-v<n>-<枚>`〕を渡す＝ほかの枚の版・今より前の版は「古い版」の印が付き、今より新しい版・別の支給月の版の答えは赤） | `受付たち`・`行たち`・`全体の補足`・`知らせ`・`赤` |
| `管理表の行` | `会社`・`支給月`（月に紐づかない物は `null`＝全社の決まり）・`支給の月`（任意）・`用`・`何のための質問か`・`問いの数`・`URL`・`載せた日` | 管理表「確認ページ」の 1 行（`管理表/` の `書く` の `行たち` にそのまま渡す） |

- `差出人`・`連絡先` は型から外した欄（2026-11-14）。渡されても使わず `知らせ` に 1 行ずつ出す（呼ぶ側から外す）。
- Python から呼ぶ時は、ほかに `次の版`・`版の字`・`差し替え`・`差し替えの行`・`お答えの行`・`名`・`名を読む`・`置き場` がある。

## 貼り戻し（答え → 質問と回答の行）

1 送信は次のどれでも読む（中身は同じ qa-html/2 の形）:

| 来る形 | 宛先 | 読む所 |
|---|---|---|
| 答えの JSON `{"form": "qa-html/2", "version", "receipt", "answers": {鍵: [選択肢の鍵]}, "labels", "supp", "free"}` | artifact（`qa:submit`）・配る口が JSON で受けた時 | そのまま |
| 貼り戻しの字（1 行目 `# <件名> — 回答`・2 行目 `版: … ／ 受付番号: …`・`■ 問N [鍵]: …`・最後に `qa-json: {…}`） | copy | 最後の `qa-json:` の行 |
| フォームの値 `{鍵: 選択肢の鍵, supp_鍵: 文, __自由記入__, __版__, __受付番号__}` | send | 項目の名 |

- **鍵で戻す**: 答えの問いの鍵を、渡した行の問いの番号（を鍵に直した物）に当てる。選択肢の鍵は今の行の選択肢から 回答 に書く語へ戻す（`estimate`＝`見当のとおり`・`__unknown__`＝`分からない`・`none`＝`当てはまらない`）。今の行に無い選択肢の鍵は答えに付いた見出しで書いて `知らせ`。配った問いに無い問いの鍵は赤。
- **回答 の字**: `<答え>[ ／ 補足: …] ／ 受付: <受付番号>（版 <版>[・古い版]）`。版が `版` と違えば「古い版」の印（`受付たち` の `古い版` も true）。受付番号が空で届いた時（JS が切られた端末）は同じ形 `R<YYMMDD>-<英数 4 字>` を中身から出す。
- **送り直しは新しい行**: 問いの今の行（同じ番号が幾つもあれば一番下）の 回答 が空なら `{する: 書く, 問いの番号, 回答, 回答日}`、答えが既にあれば `{する: 足す, 行: 今の行の写しに新しい 回答・回答日}`（前の答えの行は消さない）。同じ受付番号を既に持つ問いは飛ばす（2 回貼っても増えない）。表として読む時は問いの番号ごとに一番下の行が正（`初期設定/設問.py` の `反映の照らし` もそう読む・答えが「分からない」の問いはまだ答えの無い問いと同じ）。
- `受付たち` は 1 送信 1 行（受付番号・版・古い版・回答日）。管理表は今のまま `お答えの行` で 答えていただいた日・答えた方 を書く。
- 前の形の写し（`qa-json:` の行が無い・`■ 問N: 見出し` だけの字）は読まない（赤）。前の形の確認ページに答えが来たら、今の版で配り直して答えていただく。

## 名の（M月分）

名は `確認事項_<組>_<YYYY.MM支給（M月分）>_v<n>`。M は締めた期間の終わりの月で、会社の `支払.支給の月` から `支給月の名`（1 か所・`初期設定/始める.py` も使う）が出す: 当月＝支給月・翌月＝前の月・翌々月＝2 つ前の月（`芯/計算/暦.期間` と同じ式・字のそろえ方は `初期設定/段の解決.py` と同じ）。

- `支給の月` が渡されない・読めない時は拒まず `知らせ` に 1 行出し、`支給月` に（M月分）が書いてあって当月〜翌々月のどれかに当たればそれを、無ければ既定の 翌月 で出す。
- `支給の月` が分かっていて、書いてある（M月分）が合わない時は誤り（ValueError）。

## 問いの行（質問と回答の行の形）

質問と回答の行（`初期設定/型.json` の「質問と回答」の見出し・型の版 10 から前提の列 対象・理由・分かっている事・資料・探した資料・くわしく・変わる事 を持つ）をそのまま渡す（シートから読み直した字のままでよい）。使う列と、行に足してよい鍵:

| 鍵 | 使い方 |
|---|---|
| `問いの番号` | 要る。問いの鍵（英数字と `_` に直した物）。重ならない |
| `質問` | 要る。1 行の問い（改行があれば赤）。頭に番号を付けない（進み具合は型が出す） |
| `見当`・`見当の拠り所` | 拠り所が見込みの拠り所（既定・法の線…・知らせ…・無し・空 でない）の時だけ選択肢の後の別枠（`.estimate`）に出す。前の版の行の選択肢 `見当のとおり` は「下の灰色の枠のとおり」と見せ、別枠が無ければ赤 |
| `資料のリンク` | 資料の URL を、で並べた字（`資料`・`探した資料` と同じ順・無い物は「（リンク無し: 訳）」・型の版 16 の列）。`読んだ資料` に url が無い資料はここから引く。問いが指す資料にどちらも無ければ `作る` が赤 |
| `場所` | 根拠: 「資料の名：場所「原文」」を、で並べた字（場所は原本の場所と同じ書き方・「」の中は原文の引用）。1 つ以上・資料は 資料 か 探した資料 の名。実物（原文か `切り抜き`）が 1 つも無ければ赤 |
| `AIの読み` | こう読んだ→ここが決まらない（1 行。改行があれば 3 行まで読む）。無ければ赤 |
| `答え方の例` | `／` で区切って選択肢にする（`選択肢` が無い時）。末尾 `（推奨）` は赤（おすすめの印を付けない）・末尾 `（補足に書く）` は見出しと結果「下のひとことに書いてください」に分ける |
| `選択肢`（足してよい） | 選択肢の list。字か `{見出し, 変わる事}`（`推奨` は赤） |
| `変わる事`（足してよい） | この答えで変わる事（誰の・何が・いくら）。`{選択肢の字: 1 行}` か「字＝1 行／字＝1 行」（`設問.まとめる` が読み方の候補ごとの総支給などを入れる）。無ければ語ごとの既定（法の線に直して払う＝法の最低線に合わせて計算し直します など・`変わる事の既定`）・`見当のとおり`＝「「見当」のまま計算します」・`（補足に書く）`の語＝「ひとことに書いた事で計算します」。どれも無い選択肢は赤 |
| `対象`（要る） | 何について＝誰／いつ／何（`／` で 1〜3 つ）。問いの人は頭に `人:`（`span.who`・切り抜きに写ってよい名） |
| `理由`（足してよい） | なぜ聞くか: `mismatch`（食い違い）・`missing`（書いてない）・`law`（法の線）・`once`（今回だけ）。無ければ 形 mismatch＝mismatch・箱 法の線＝law・その月だけの物＝once・ほか missing。画面の文は qa-html の決まった 4 文を repo の根の `config/skill-values.json` の `docs-kit.qa-html.why` で給与の語に替えた物（check.mjs も同じ所を読む） |
| `資料`・`探した資料`（どちらか要る） | 見つけた事が指す読んだ資料の名（`、` で並べる）。書いてない時は `探した資料` |
| `くわしく`（要る）・`原文`（足してよい） | くわしく 3 行まで（改行で区切る）・資料の原文の抜粋 |
| `切り抜き`（足してよい） | `[{資料, 画像（data:image/…;base64）, 写っている事, 場所, 写っている人}]`・2 枚まで。写っている人は問いの人（`人:`）だけ＝ほかの人の行は塗ってから渡す |
| `形`（足してよい） | `judge`（既定・どう決めますか）・`choose`（どちらが正しいですか）・`mismatch`（資料どうしが食い違う）・`fact`（資料の外の事実） |
| `まとまり`（足してよい） | `rule`・`person`・`once`・`later`。無ければ 対象 の いつ が「当たる人が出た時」なら `later`・ほかは箱から（下） |
| `種類`（足してよい） | `会社の決まり`・`原本`。無ければまとまりから（rule＝会社の決まり・person と once＝原本・later は箱と反映先から＝`初期設定/設問.py` の `種類` と同じ決まり）。まとまりと食い違うと赤（later はどちらの種類とも合う） |
| `分かっている事`（足してよい） | 見つけた事（資料名・場所・値）2 行まで（list か改行区切り）。無ければ探した資料と見当から起こす |
| `表`（足してよい） | 分かっている事の下の小さな数字の表（行の list・1 行目が見出し） |
| `くわしく`（足してよい） | たたむ説明 1 つ |
| `見出し`（足してよい） | 送る前の確認と貼り戻しの字に出す一言（無ければ 質問） |

ひとことに書かせる選択肢（末尾 `（補足に…）` の字・形が足す「ほかの答え」「別の決め方」・見出し／添え書き／変わる事に「ひとこと」「補足に書」「補足欄」「下の欄」がある物）は、`input` に印 `data-supp="need"` を付け、見出しから `（補足に…）` を外す（qa-html の型が、選ぶと欄の名を「ひとこと（この答えでは書いてください）」に替え、空では次へ進めない。印の無い物は qa-html の `check.mjs`〔v0.4.7 から〕が赤）。

形ごとに道具が選択肢を後ろへ足す: `judge`＝「別の決め方」・`choose`／`mismatch`＝「ほかの答え」（どちらもひとことに書かせる選択肢〔`（補足に…）`〕がもうあれば足さない）・`fact`＝「当てはまらない」（その月だけの物の問いは結果「この月は払う物・引く物・人の変わりが 1 つも無い」）。その後に全問「または」と「分からない」。

`形`・`まとまり` の無い行は、`何が無いか` の頭の字（問いの箱・`docs/設計/設問の作り方.md` §2）で決める:

| 箱 | 形 | まとまり |
|---|---|---|
| 読み方（`読み方: …`） | choose | rule |
| 法の線（`法の線: …`） | choose | rule |
| 足りない値（頭なし） | judge | 反映先が全部 会社の決まりの先（`2_マスタ/会社`・`勤務の型`・`支給控除の項目`・`給与のルール.md`）＝rule・ほかの先がある＝項目なら person・項目でなければ once。反映先が空なら 項目の段に会社・勤務の型・事務所がある＝rule・人だけ＝person・項目でない（原本の名）＝once・空＝rule |
| その月だけの物 | fact | once |

初期設定/ の「見当つきの 1 問」（`始める.py` の `問い`）と、芯/計算/ の確認の問いの種（`docs/設計/確かめと仮.md` §3 の問いの形）は、どちらもこの行の形で渡す。

## 問いの検査（赤にする物）

qa-html の決まりのうち機械で見られる物。`作る` は赤があれば HTML を返さない。

- 1 問 1 行（質問に改行が無い）・分かっている事 2 行まで
- 形が 4 つ・まとまりが 4 つのどれか・種類が 2 つのどれかでまとまりとそろう（会社の決まり＝rule か later・原本＝person・once か later）・選択肢 2 つ以上（`fact` は道具が足すので除く）・選択肢が 3 つ以上の `choose`／`mismatch` で質問が「どちら」と聞いていない
- 用＝毎月 の 1 枚に「その月だけの物」の問い（`何が無いか`＝その月だけの物・`初期設定/設問.py` の `その月だけの物の問い`）が在る（その組×支給月の最初の版だけ。同じ月の次の版＝配り直しは前の版が持つので見ない）
- おすすめの印が無い・`見当のとおり` があれば見込みの別枠がある
- 根拠の場所（`場所`）・実物（原文か切り抜き）・AI の読み（`AIの読み`・3 行まで・1 行 80 字）がある・根拠の資料が 資料 か 探した資料 にある・根拠 3 つ・場所 60 字・引用 80 字まで・見込みの別枠は見当 40 字・拠り所 60 字まで
- 前の問いの答えに寄りかからない（「前の問い」「前の答え」など）・道具やシステムの都合（文字の種類・番号の付け方・置き場など）を聞かない
- （`作る`）問いが指す資料にリンク（https の URL）か無い訳がある
- 選択肢の頭に記号（A・B・①・1. など）を付けない・問いと分かっている事で記号で選択肢を指さない（「A なら」）
- 前提: 人ごとの事実（person）の問いに問いの人（`人:`）・食い違いの問いの切り抜きは 0 枚か 2 枚・何について 1〜3 つ・なぜ聞くかが 4 つのどれか（mismatch の形は mismatch）・見つけた事 1〜2 行と読んだ資料の名・くわしく 1〜3 行・逃げ道の外の選択肢に変わる事・切り抜きは 2 枚まで・画像は data URI・写っている人は問いの人だけ
- 内部の言葉を含まない（質問・何について・見つけた事・くわしく・選択肢の見出しと変わる事と添え書きを見る）。既定の束（立ち上げ・照合・逆算・道具・部品・質問と回答・2_マスタ・台帳_・1_決まり・.md＝`確認ページ.py` の `既定の内部の言葉`）に、呼ぶ側が `内部の言葉` で足す（顧客の語は repo に置かないので、呼ぶ側が Drive の側から渡す）
- 問いの番号が在って重ならない

長さ（問い 40 字・選択肢の見出し 30 字・結果 40 字など）・1 問に 2 つ・数を書かせる形・型の動かない所は、配る前に qa-html の `check.mjs`（`node check.mjs <file.html>`）で見る。緑でなければ配らない。この repo の試験は、環境に `QA_HTML_CHECK`（check.mjs の path）と node があれば作った HTML に当てる（無ければ skip）。

## 名と置き場と版

| 物 | 形 |
|---|---|
| 置き場 | 正本は `docs/設計/Drive の型.md` §3「確認事項の置き場の表」（道具が読み込みの時に直に読む・表が読めなければ止まる）。会社は表の `<会社>` の行・事務所全体の問いは組を `事務所` にして表の「事務所」の行（給与エージェントの見張りは `置き場の名たち` を読み、組に合うフォルダにだけ置かせる）（月のフォルダは切らない・支給月は名が持つ。立ち上げは最初に計算する支給月の名）。事務所の置き場は事務所のルール.md などと同じフォルダ＝`次の版` は確認事項の頭の無い名を数えない |
| 名（配った版） | `確認事項_<組>_<YYYY.MM支給（M月分）>_v<n>.html`（分けた枚は `_v<n>-<枚>.html`） |
| 名（配る前） | `下書き_確認事項_<組>_<YYYY.MM支給（M月分）>_v<n>.html` |
| 版 | 置き場の名の一覧から、その組×支給月の配った版の最大 +1（無ければ 1・下書きとほかの月は数えない）。一覧に前の形の名（`確認ページ_…`）・形の読めない名・ほかの組の名があれば数えずに止める（ValueError＝版を 1 から数え直さない・置き違いを通さない） |
| 版の字（答えに付く `__版__`） | `<支給年>.<支給月>-v<n>`（例 `2099.04-v2`・n は名の版と同じ） |

宛先はいつも事務所の担当者 1 人（2026-11-18 の設計の決定 19）。宛名の既定は「ご担当者様」。

## 毎月の流れでの使い方

1. 殻が `初期設定/設問.py` の `まとめる` で 1 枚の問いを作り（種の集め方は `docs/設計/設問の作り方.md` §6）、質問と回答に書く。まだ答えの無い行を拾う。
2. `作る` → 赤なら問いを直す。緑なら qa-html の `check.mjs` を当て（緑でなければ問いを直す）、`下書きの名` で置き、見てから配る口で配って URL を受ける。
3. 配った物を `名` で置き、前の版があれば `差し替え` で移す。`管理表の行` を管理表の書く口で書く（前の版の行は `差し替えの行`）。
4. 答えが来たら `貼り戻し`（`版` に今の `版の字`）で、返った `行たち` を質問と回答へ当てる（`書く`＝今の行の 回答・回答日・`足す`＝新しい行）。管理表は `お答えの行`。答えを出所としてマスタ・決まりの md を直すのは各々の口。

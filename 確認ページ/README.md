# 確認ページ — 初回と毎月の確認の HTML・名と版・貼り戻し

先方・事務所に問いを聞く HTML は「確認ページ」の 1 つの呼び名・1 つの形にする（`docs/設計/Drive の型.md` §3）。

- **正本は質問と回答**。確認ページは質問と回答の行から起こす、表示と配る用の写し。答えは質問と回答へ貼り戻してから使う（HTML の上の答えを直に計算に使わない）。
- **配った版の正は URL**（配る口が返す URL）。URL は管理表「確認ページ」に 1 行で載せる。
- この道具は **Drive を開かない**。問いの一覧を受けて HTML の文字列・名・置き場・管理表の行を返すだけ。置く・配る・管理表へ書くのは殻。
- 返す HTML は **外へ通信しない**自己完結の 1 枚（外の script・style・画像・fetch を持たない・`file://` で動く）。

## 置く物

| file | 中身 |
|---|---|
| `確認ページ.py` | 作る・名と版・差し替え・貼り戻し・管理表の行・問いの検査 |
| `雛形.html` | 1 枚の形。qa-html の 1 つの形の `qa:css`・`qa:toc`・`qa:foot`・`qa:js` の 4 か所をそのまま写した物（直す時は qa-html の正本から写し直す） |

## 呼び口

すべて `python3 確認ページ/確認ページ.py <口> < 入力.json`。赤が 1 つでもあれば終わりの値 2。

| 口 | 入力 | 出力 |
|---|---|---|
| `作る` | `組`・`支給月`（`YYYY.MM支給`）・`支給の月`（会社の `支払.支給の月`＝当月／翌月／翌々月・任意）・`用`（立ち上げ／毎月）・`問い`（下の行の list）・`今ある名`（置き場の名の一覧・任意）・`宛先`（`send`＝配る口から送る〔既定〕／`copy`＝貼り戻しの字を写す）・`宛名`（任意）・`内部の言葉`（任意） | `赤`・`知らせ`・`版`・`名`・`下書きの名`・`置き場`・`前の版`・`問いの数`・`html`（赤があれば `null`） |
| `検査` | `問い`・`内部の言葉` | `赤` |
| `貼り戻し` | `問い`（配った時と同じ行と順）・`答え`（写す形の字か、送る形のフォームの値 `{鍵: 値, supp_鍵: 補足, __自由記入__: …}`）・`回答日` | `行たち`（`{問いの番号, 回答, 回答日}`・答えの無い問いは出さない）・`全体の補足`・`赤` |
| `管理表の行` | `会社`・`支給月`（月に紐づかない物は `null`＝全社の決まり）・`支給の月`（任意）・`用`・`何のための質問か`・`問いの数`・`URL`・`載せた日` | 管理表「確認ページ」の 1 行（`管理表/` の `書く` の `行たち` にそのまま渡す） |

Python から呼ぶ時は、ほかに `次の版`・`差し替え`・`差し替えの行`・`お答えの行`・`名`・`置き場` がある。

## 名の（M月分）

名は `確認ページ_<組>_<YYYY.MM支給（M月分）>_v<n>`。M は締めた期間の終わりの月で、会社の `支払.支給の月` から `支給月の名`（1 か所・`初期設定/始める.py` も使う）が出す: 当月＝支給月・翌月＝前の月・翌々月＝2 つ前の月（`芯/計算/暦.期間` と同じ式・字のそろえ方は `初期設定/段の解決.py` と同じ）。

- `支給の月` が渡されない・読めない時は拒まず `知らせ` に 1 行出し、`支給月` に（M月分）が書いてあって当月〜翌々月のどれかに当たればそれを、無ければ既定の 翌月 で出す。
- `支給の月` が分かっていて、書いてある（M月分）が合わない時は誤り（ValueError）。

## 問いの行（質問と回答の行の形）

質問と回答の行（`初期設定/型.json` の「質問と回答」の見出し）をそのまま渡す。使う列と、行に足してよい鍵:

| 鍵 | 使い方 |
|---|---|
| `問いの番号` | 要る。HTML の答えの鍵（英数字と `_` に直した物）。重ならない |
| `質問` | 要る。1 行の問い（改行があれば赤） |
| `見当` | あれば「分かっている事」に「今の見込みは「…」です。」と出し、選択肢の `見当のとおり` を「見当のとおり（…）」と見せる |
| `答え方の例` | `／` で区切って選択肢にする（`選択肢` が無い時） |
| `選択肢`（足してよい） | 選択肢の list。末尾に `（推奨）` を付けた物か `見当のとおり` が推奨（1 つ目だけ） |
| `形`（足してよい） | `judge`（既定・どう決めますか）・`choose`（どちらが正しいですか）・`mismatch`（資料どうしが食い違う）・`fact`（資料の外の事実） |
| `分かっている事`（足してよい） | 2 行まで（list か改行区切り）。無ければ見当から起こす |
| `決まる事`（足してよい） | この答えで決まる事 1 行。無ければ「給与の計算のしかた」 |

形ごとに道具が選択肢を後ろへ足す: `judge`＝「別の決め方（補足に）」・`choose`／`mismatch`＝「どちらでもない（補足に）」・`fact`＝「まだ分からない」「該当しない」。全問に補足の欄、最後に「ほかに伝えたい事」の欄を置く。

初期設定/ の「見当つきの 1 問」（`始める.py` の `問い`）と、芯/計算/ の確認の問いの種（`docs/設計/確かめと仮.md` §3 の問いの形）は、どちらもこの行の形で渡す。

## 問いの検査（赤にする物）

qa-html の決まりのうち機械で見られる物。`作る` は赤があれば HTML を返さない。

- 1 問 1 行（質問に改行が無い）・分かっている事 2 行まで
- 形が 4 つのどれか・選択肢 2 つ以上（`fact` は道具が 2 つ足すので除く）
- 推奨は 1 つだけ・1 つ目だけ・`見当のとおり` があるのに見当が空でない
- 内部の言葉を含まない（質問・分かっている事・選択肢・決まる事を見る）。既定の束（立ち上げ・照合・逆算・道具・部品・質問と回答・03_マスタ・04_台帳・01_ルール・.md）に、呼ぶ側が `内部の言葉` で足す（顧客の語は repo に置かないので、呼ぶ側が Drive の側から渡す）
- 問いの番号が在って重ならない

長さ（問い 40 字など）・1 問に 2 つ・数を書かせる形は、配る前に qa-html の `check.mjs` で見る（この道具の試験では見ない）。

## 名と置き場と版

| 物 | 形 |
|---|---|
| 置き場 | `10_会社/<組>/20_配る物/<YYYY.MM支給（M月分）>/`（立ち上げは最初に計算する支給月）。事務所全体の問いは組を `事務所` にして `20_配る物/<支給月>/` |
| 名（配った版） | `確認ページ_<組>_<YYYY.MM支給（M月分）>_v<n>.html` |
| 名（配る前） | `下書き_確認ページ_<組>_<YYYY.MM支給（M月分）>_v<n>.html` |
| 版 | 置き場の名の一覧から、その組×支給月の配った版の最大 +1（無ければ 1） |
| 配り直し | 前の版を `<組の根>/90_履歴/消す_<消す日>_<前の名>` へ移す（`差し替え`）。管理表の前の行の状況を 差し替え にする（`差し替えの行`・行は消さない） |

名の支給月は、置き場のフォルダと管理表の支給月と同じ `YYYY.MM支給（M月分）` の 1 つの形にそろえる（`YYYY.MM支給` を渡しても道具が直す）。

## 毎月の流れでの使い方

1. 殻が質問と回答から、まだ答えの無い行を拾う（初期設定/ の問い・芯の確認の問いの種）。
2. `作る` → 赤なら問いを直す。緑なら `下書きの名` で置き、見てから配る口で配って URL を受ける。
3. 配った物を `名` で置き、前の版があれば `差し替え` で移す。`管理表の行` を管理表の書く口で書く（前の版の行は `差し替えの行`）。
4. 答えが来たら `貼り戻し` で質問と回答の行の 回答・回答日 へ書き、管理表は `お答えの行`。答えを出所としてマスタ・決まりの md を直すのは各々の口。

# 法の表 — 法の表（効く月の範囲つき）を置く。形は docs/設計/法の表.md。

- 表ごとに 1 ファイル（`<表の名>.json`）。年でファイルや dir を分けず、年が替わったら同じファイルに行を足す。
- 行は「効く始め・効く終わり（表の `基準` の粒）・状態（出た｜まだ｜未起こし）・値・出典」。出典は URL・ファイル名・取った日（と sha256・照らした元）。
- 数字は国の原本からだけ。2 つの元で照らせた物だけ入れる。まだ国が出していない範囲は `まだ` の行（値 null・例年の時期）。
- 顧客ごとに違う物（健康保険組合の率・基金の掛金・住民税の特別徴収税額）は置かない。
- 国の例の試験は `tests/法の表/`。入れ直しの段取りは docs/設計/法の表.md §4。
- `祝日.json`: 国民の祝日と休日（振替休日・国民の休日）を年ごとの行で持つ。出典は内閣府の CSV（W2 が足した）。
- `法の線.json`: 労働基準法の線（法定労働時間・特例 44 時間・休憩・法定休日・深夜帯・割増の率・36 協定の上限）と社保の年齢（介護 40〜65・厚年 70・健保 75）を `線` の鍵で持つ。有給の付与の日数は `有給_付与日数.json`。
- `源泉_*.json`（月額表・日額表・賞与の算出率・電算機の特例）: 2026 年（令和 8 年分）と 2027 年（令和 9 年分）の行。出典は国税庁「源泉徴収税額表」の頁（zeigakuhyo2026・zeigakuhyo2027）の Excel と、同じ表の PDF で照らす（電算機の特例は 18.pdf と 17-18.pdf）。年の違いは各行の `注`（W7 が 2026 年を足した）。
- `子ども子育て支援金.json` の 2026-03 月分までの率 0 の行・`標準賞与額の上限.json` の 2025-04-01〜2026-03-31 の行: 出典は e-Gov 法令 API の健康保険法（第45条・第160条の2）・厚生年金保険法（第24条の4）の時点の版（W7 が足した）。
- `源泉_報酬.json`: 報酬・料金の源泉の率（所得税法 第205条第1号の 10%・100 万円を超えた分 20% に復興特別所得税〔2027 年からは防衛特別所得税も〕を足した 10.21%・20.42%）を支払日で持つ。2013〜2026 年と 2027〜2037 年（内訳が替わる）の 2 行。使うのは 芯/計算 の委託分（W15 が足した）。
- `有給_付与日数.json`: 年次有給休暇の付与日数（通常・比例）・時効の年・年 5 日（労働基準法 39 条・115 条・労基則 24 条の 3）。基準は労働した日で、付与日を渡して引く。引くのは `有給/有給.py`（前は `有給/付与の表.json` を効く範囲を見ずに 1 行目で読んでいた）。
- `源泉_賞与の月額表の月数.json`: 賞与の源泉を月額表で出す時（前月の給与なし・10 倍超）の ÷・× の月数（計算期間が 6 か月以下＝6・超える＝12）。出典は e-Gov 法令 API の所得税法 第186条、照らした元は国税庁 タックスアンサー No.2523。条文に始めの日が無いので 効く始め・効く終わり とも null の 1 行。使うのは 芯/計算 の賞与。

# 道具/答え合わせ — 初期設定の照らし（本番の 0 段の手順）

初めての会社の設定を、過去に事務所が出した給与の結果（**答え**＝給与ソフトの支給控除一覧・明細）と人×項目で照らして確かめ、
違う所を初期設定の問いにして聞き切ってから毎月の計算へ進むための道具。**本番の初期設定の手順**（0 段・会社の始めと決まりが変わった時）。
正本の設計は `docs/設計/確かめと仮.md`（§1 初期設定の照らし・§2 人×項目の突き合わせ）と `docs/毎月の流れ.md`（0 段）。

## いつ使うか・使わないか

| 使う時 | 使わない時 |
|---|---|
| **初期設定（0 段）**。会社を始める時と、会社の決まりが変わった時。過去の月を芯で法律どおりに計算し、過去の支給控除一覧と照らす | **毎月の流れ**（受け取り → 入口 → 芯 → 関所 → 出口 → 給与ソフト → 突き合わせ）。毎月の確かめは 出口/ の突き合わせ（相手は給与ソフトのその月の出力）で、照らしは入らない |

- 答えは **正しいとは限らない**。答えから読めるのは「見当」まで。違いは問いの種で、値は答え（質問と回答）で決める。
- 照らしを回したかどうかは確かめの数に入れない。差 0 の月の数も、本番の数は出口/ の突き合わせの記録から数える。

## 守る線

- **芯/・出口/・入口/ から呼ばれない**（`tests/答え合わせ/test_答え合わせ_呼ばれない.py` の grep が見張る）。この道具も 芯/ を import しない・書き換えない。芯の計算の結果（人×項目の行）を受けるだけ＝照らしは芯に混ぜない。
- **答えを見てマスタや計算を直さない**。差は **初期設定の問いの種**（`初期設定/設問.py` の 4 つの箱の形）にして返し、殻が `設問.まとめる` → `確認ページ.作る` の 1 本の道で聞く。差 0 の人×項目は聞かずに決まりへ書き、出所に過去の結果の照らしの字（書き方の正本は `月次/例の確かめ.py` の `過去の結果の書き方`）を書く（2026-11-19 オーナーの決定。`出所を見る --照らし` が差の表で一致を確かめる）。形で書かずに答えの file を出所にした値は止める。
- **照らし方を別に持たない**。照らすのは `出口/` の突き合わせ 1 本（`出口.関所.通す` → `出口.突き合わせ.突き合わせる` → `月の記録` → `続けて差0の月数`）。この道具が足すのは答えの読み口・問いの種・出所の見方だけ。
- **Drive を開かない**。立ち上げの窓（殻）が、最初の支給月の `1_届いた物/` に `書類_` で置いた過去の支給控除一覧（`確かめと仮.md` §1 の 1）を落として file・つなぎ・芯の行を渡し、出た物を受ける。
- **顧客の物を repo に置かない**。会社ごとに違う欄の名・氏名・答えの file は殻が引数で渡す。出た表は窓の作業場に置き、git に入れない。
- Python 3 の標準ライブラリだけ（xlsx は zip と xml.etree で読む）。数は `Decimal`（円は整数・時間は分）。

## 中身

| file | 中身 |
|---|---|
| `表.py` `表にする()` | 答えの file（xlsx・CSV／TSV・zip）→ タブごとの字の表。形は中身で見る。PDF は読まない（要確認＝下の「PDF の一覧表」） |
| `答えの読み口.py` `一覧表を読む()` | 人が行か列に並ぶ一覧表（支給控除一覧表・勤怠一覧表 …）→ 人×項目の縦。向きは鍵の見出しの行と列のどちらに欄が多いかで決める |
| `答えの読み口.py` `明細を読む()` | 1 人 1 枚の明細 → 人×項目の縦。見出しの値はすぐ右、無ければすぐ下 |
| `照合の段.py` `照らす()` | 芯の縦と答えの縦を 出口/ の突き合わせへ渡し、差の表・問いの種・差 0 の月を返す |
| `照合の段.py` `問いの種()` | 差の行 → 初期設定の問いの種（読み方の箱・会社×項目×向き で 1 つ・根拠つき） |
| `出所を見る.py` `見る()` | マスタ「変更の記録」・MD の［出所］・例の 確かめた人 の出所を見て、照らしで確かめていない過去の結果を出所とする値が 0 かを返す（過去の結果の照らしは 照らし＝差の表 で人×項目の差 0 を確かめる・1 つでもあれば止める） |
| `__main__.py` | 呼び口（下） |

読み口は **形ごとに 1 つ**（一覧表・明細）。会社ごと・給与ソフトごとに作らない。会社ごとに違うのは つなぎ（引数）だけ。

## 入れる物

### つなぎ（殻が Drive のマスタ「つなぎ」から渡す）

答えの見出しと芯の項目の対応。形は 出口/ の `欄の対応` と同じ `{項目, 欄, 形}`（形は `円`・`日`・`分`・`回`）。1 項目に 1 欄（1 つの欄に幾つかの項目を当てれば足す＝`出口/README.md`「欄の対応」）。
1 つの欄に幾つかの項目を当てた欄は、読み口がその欄の値を組の名（`基本給＋時給`）の行にし、照らす が芯の項目を足した 1 行と照らす（名は 出口.形.欄の組 の 1 か所）。

```json
{"欄": [{"項目": "基本給", "欄": "基本給", "形": "円"},
        {"項目": "残業時間", "欄": "残業時間", "形": "分"}],
 "読まない見出し": ["氏名", "所属"],
 "鍵の見出し": ["NO"], "氏名の見出し": ["氏名"]}
```

- 見出しは空白（全角も）を除き、全角の英数を半角にして照らす。読み用の別名・読み替えは持たない（要る欄は つなぎ に 1 行足す）。
- `読まない見出し`: 照らさない見出し（氏名・所属・表題・会社の名など）。合計（`合計`・`総合計`・`小計`・`計`）の行・列はいつも読まない。
- 鍵の見出し（既定 `NO`）の無い表は、`氏名からNO`（殻が社員マスタから渡す `{氏名: NO}`）があれば氏名で人を引く。同じ氏名が 2 人以上・引けない人は読まずに要確認。
- 時間: 芯の時間は分。答えの字は `時間の書き方`（`60進`・`時:分`・`10進`）で分へ戻す。xlsx の時刻の書式のセルは `時:分` で読む。

### 芯の行

芯/計算/ の出す人×項目の行（`確かめと仮.md` §2・§3 の列: 支給月・会社・NO・項目・値・出所・状態 …）と、人の状態（必須・仮の人が居なければ空を明示で渡す）。
仮の値が 1 つでもある人は出口の関所で外れ、照らさない（`外した人` に返す）。
初期設定の照らしで仮の人も照らす時は、`月次.月を回す` の返す `仮の人の行`（関所で外した人の人×項目の行・`出口へ出さない` の印つき）を
`照らす(…, 仮の人の行=…)`（呼び口は芯の JSON の `仮の人の行`）へ渡す。その人は外さず照らす（照らしの結果は出口へ出ない）。
部品を包んで写して照らさない（月を回す の返す行が 1 つの正本）。

## 出す物

`照合の段.照らす()` の返す `照らした物`（`出所を見る.見る()` は下の「出所を見る」）:

| 物 | 中身 |
|---|---|
| `差の表` | 出口/ の突き合わせの列 `支給月・会社・NO・項目・こちら・給与ソフト・差・差の見立て・差の出所`（給与ソフト＝答えの値）。差は 0 だけを一致・片方が空なら `片方だけ` |
| `問いの種` | 差を **初期設定の問いの種**（`設問.まとめる` の種の形）にした物。1 会社 × 項目 × 向き（値が違う・過去だけ・こちらだけ）で 1 つ（人・月・見立ては束ね、見せる値は差の一番大きい人）。箱は `読み方`（種類＝会社の決まり）・`何が無いか`＝`読み方: 照らし/「項目」/向き`。根拠（答えの file・タブ・NO の行の欄・値の字）と AI の読み（法律どおりの値と過去の値）を持つ。見当は置かない（答えまで法律どおり）。選択肢は「会社の決まりで払っていた」と「過去の支給が誤りだった」の類（おすすめの印なし）で、答えで変わる事を添える |
| `月の記録`・`差0の月数` | 照らした 1 会社 1 支給月ごとの記録と、会社ごとの続けて差 0 の月数・数えた月・まだ見ていない場面（出口/ の数え方のまま） |
| `外した人`・`照らさなかった項目`・`照らさなかった月`・`要確認` | 黙って捨てない物。照らさなかった月＝芯にあって答えの無い 支給月×会社 |

答えには何も渡していないので、つなぎ の欄は全部 `渡す=False` で突き合わせへ渡す（差の見立ては `丸め`・`決まりの違い`・`片方だけ` のどれか。`入力の違い` は出ない）。

## 呼び口

根で回す。JSON を受けて JSON を返す。出す file は scratchpad に置く。

```
python3 -m 道具.答え合わせ 読む   --形 一覧表|明細 --会社 <番号> --支給月 YYYY-MM --つなぎ つなぎ.json \
        [--時間の書き方 60進|時:分|10進] [--文字コード cp932] [--氏名からNO 氏名.json] --出す 答え.json <答えの file>...
python3 -m 道具.答え合わせ 照らす --芯 芯.json --答え 答え.json --つなぎ つなぎ.json \
        [--前の記録 記録.json] [--N <数・省くと初期設定/項目.json の既定>] --出す 差.json
python3 -m 道具.答え合わせ 出所を見る --変更の記録 記録.json --答え 答え.json [--答えの資料 名...] \
        [--質問と回答 問い.json] [--会社 <名>] [--md md.json] [--照らし 差.json] [--例 例.json] --出す 出所.json
```

- 終わりの値はどの口も 0＝通る・1＝確かめる物が在る（下の口ごと）・**2＝道具の故障**（読めない file・形の違う JSON・使い方の誤りなど。結果ではない＝出す file は書かれず毎月へ進まない。標準エラーの「道具が壊れた」の訳で直して回し直す）。2 を 1 と読まない。
- `読む`: 1 支給月 1 会社の答えの file を渡す（タブは全部読む。2 つの表で同じ人×項目の値が違えば前の値のまま要確認）。終わりの値は要確認 0 で 0・あれば 1。
- `照らす`: `芯.json` は `{"行": [...], "人の状態": [{支給月, 会社, NO, 状態}...]}`（人の状態は必須＝行の並びだけ・人の状態の無い JSON は止まる。仮の人が居なければ `"人の状態": []`）。`差.json` の `問いの種` を殻が `設問.まとめる` の種へ足す。終わりの値は差の行 0 かつ要確認 0 で 0・ほかは 1。
- `出所を見る`: `記録.json` はマスタ「変更の記録」、`問い.json` は質問と回答 の行（列名の dict の並び）。答えの file は `答え.json` の行の出所から取る（`--答えの資料` で足せる）。`--照らし` は `照らす` の出した 差.json（過去の結果の照らしを出所にした値・例があれば要る）。終わりの値は外れ 0 で 0・あれば 1（毎月へ進まない）。

Python から:

```python
from 道具.答え合わせ.表 import 表にする
from 道具.答え合わせ import 答えの読み口, 照合の段
表たち = 表にする("一覧表.xlsx", 中身)
答え = 答えの読み口.一覧表を読む(表たち, "9", "2026-10", つなぎ, "60進", 読まない見出し=("氏名",))
r = 照合の段.照らす(芯の行, 答え, つなぎ, 人の状態)   # 人の状態は必須（無い時は {}）
r.差の表, r.問いの種, r.差0の月数
from 道具.答え合わせ import 出所を見る
出所を見る.見る(変更の記録, 出所を見る.答えの資料(答え.行たち), 質問と回答, 会社,
               照らし=照らした物, 答えの行=答え.行たち, md={"給与のルール.md": 字}).止める   # 真なら毎月へ進まない
```

## 出所を見る（照らしで確かめていない過去の結果を出所とする値が 0 か）

`確かめと仮.md` §1「確かめ方」の照らし。マスタ「変更の記録」の各行（`確かめ`＝記録だけ の行は見ない）・決まりの MD の［出所: …］（`［出所］…` の前の形も）・例の 確かめた人 を見て、次を `外れ` に 1 行ずつ返す。1 つでもあれば `止める`＝毎月の計算へ進まない。

過去の結果の照らし（2026-11-19 オーナーの決定: 過去の資料で埋め切り、本当に分からない物だけ聞く）は表 `出所の種類たち` の 過去の結果 の文法で書く（書き方の正本は `月次/例の確かめ.py` の `過去の結果の書き方`・ここには写さない）。渡した照らしの差の表でその支給月・会社・人×項目の差が 0 で、答えの行のその人×項目の出所がその資料と字まで同じ名（拡張子は除いてよい）の時だけ通す。同じ人×項目の答えの行で出所が食い違えば止める。

| 訳 | 何を見るか |
|---|---|
| `過去の結果が書類` | 照らしの形で書かずに、`書類の名` が照らした答えの file（答えの行の出所か `--答えの資料`）＝どの人×項目の一致か分からない |
| `過去の結果の形が読めない` | `過去の結果` の語があるのに支給月・資料の名・人×項目・`一致` のどれかが欠けた |
| `過去の結果を確かめられない` | 過去の結果の照らしを出所にしたのに、照らし（差の表）か答えの行を渡していない |
| `過去の結果と一致していない` | 書いた人×項目が差の表に無いか、差が 0 でない（片方だけも） |
| `過去の結果の資料が違う` | 書いた資料の名が、その人×項目の答えの行の出所に当たらない |
| `答えの無い問いが出所` | `確かめ`＝確認済 なのに、`問いの番号` の問いに答えが無い |
| `出所が無い` | `書類の名` も `問いの番号` も空 |
| `問いが無い` | `問いの番号` が質問と回答に無い |
| `問いを確かめられない` | `問いの番号` を出所にした行があるのに質問と回答を渡していない（材料が無い時は止める） |

## 初期設定の照らしの手順（会社ごと・本番の 0 段）

1. 殻が最初の支給月の `1_届いた物/` の過去の支給控除一覧（`書類_`）を窓の作業場に落とす（file の名で見分けず、中身の見出しで見る）。
2. `読む` で答え.json を組む。要確認（つなぎ に無い見出し・鍵の無い行・数でない値）を先に見る。要る欄なら Drive のマスタ「つなぎ」に 1 行足す（答え.json を手で直さない）。
3. 同じ月を決まりの MD とマスタで法律どおりに計算し（入口 → 芯）、`照らす` を回す。
4. `問いの種` を `設問.まとめる` の種へ足し（ほかの種と 1 枚・根拠の無い種は差し戻し）、`確認ページ.作る` で事務所の担当者に聞く。差のある所を見てマスタ・決まりの md・計算を直さない。差 0 の人×項目で決まる所は聞かずに決まりへ書き、出所に過去の結果の照らしを書く（形で書かない逆算は見当まで）。
5. 答えを質問と回答へ貼り戻し、答えを出所に MD とマスタを直して計算し直し、もう一度照らす。違いが全部説明できるまで 3〜5 を繰り返す（パックの選べる式で表せない決まりは問いにせずパックへ式を足す PR）。
6. `出所を見る` が 0 で終わったら毎月の計算へ進む。1 社の確かめは「全員の全項目の差が 0 か、0 でない差の全部に質問と回答の答えか式を足した PR がある」かつ「照らしで確かめていない過去の結果を出所とする値が 0」（確かめと仮.md §1・§2）。`出所を見る` には `照らす` の 差.json を `--照らし` で渡す。

## 畳んだ物

前の道具の答え合わせ（読み口・試験・照合の段）をこれで置き換えた。
「開発の間だけ」の線と、差を「質問と回答へ回す行」（`出口.突き合わせ` の問いの形）で返す古い問いの形は、初期設定の照らしを本番の手順にした時（2026-11-18）に畳んだ（問いは設問の種の形 1 本）。
持ち込まなかった物: 80_答え と 照合_<支給年> への書き込み・マスタ「会社」の「答えの読み替え」・型.json「答え」の別名と欄の寄せ・「過去の支給と一致」の印・PDF の字の位置の読み（poppler に頼るため）・2_出す物 の古い形の読み分け。

## PDF の一覧表

道具は PDF を読まない（標準ライブラリだけ・数を推して読まない）。過去の支給控除一覧が PDF の時は、殻が次の手順で CSV にしてから `読む` へ渡す:

1. 殻の窓で PDF を表に起こす（土台の skill `docs-kit:pdf-read`＝数を 1 つも黙って落とさず、行と列の名まで結ぶ）。1 支給月 1 会社 1 file。
2. 起こした表を、1 行目が見出し（`NO` か `氏名` の列と、つなぎ の欄の字そのまま）・1 人 1 行の CSV（UTF-8）にする。欄の字を書き換えない（読み替えは持たない）。
3. CSV の名は元の PDF の名の拡張子を `.csv` に替えた名にする（`出所を見る` が答えの資料の名で書類を当てる）。
4. 起こせなかった・読めない升は空にせず、殻の要確認に名指しで残す（`読む` は空の升を 0 と読む＝推して埋めない）。

CSV と起こした表は窓の作業場に置き、repo と Drive の 1_届いた物 に置かない（原本は PDF のまま）。

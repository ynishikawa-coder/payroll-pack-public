# 道具/答え合わせ — 開発の間だけの答え合わせ

芯の計算を、過去に事務所が出した給与の結果（**答え**＝給与ソフトの一覧表・明細）と人×項目で照らす道具。
正本の設計は `docs/設計/確かめと仮.md`（§1 答え合わせを開発の道具へ外す・§2 人×項目の突き合わせ）。

## いつ使うか・使わないか

| 使う時 | 使わない時 |
|---|---|
| **開発の間だけ**。段階 3 で本物の会社を **1 社ずつ** 立ち上げる時の確かめ（過去の月を芯で計算し、過去の答えと照らす）。型や芯を直した時の手元の確かめ | **毎月の流れ**（受け取り → 入口 → 芯 → 関所 → 出口 → 給与ソフト → 突き合わせ）。毎月の確かめは 出口/ の突き合わせ（相手は給与ソフトのその月の出力）で、答え合わせは入らない |

- 答え合わせを回したかどうかは確かめの数に入れない（確かめと仮.md §1「確かめ方」）。差 0 の月の数も、本番の数は出口/ の突き合わせの記録から数える。
- 答えは **正しいとは限らない**。答えから読めるのは「見当」まで。

## 守る線

- **芯/・出口/・入口/ から呼ばれない**（`tests/答え合わせ/test_答え合わせ_呼ばれない.py` の grep が見張る）。この道具も 芯/ を import しない・書き換えない。芯の計算の結果（人×項目の行）を受けるだけ。
- **答えを見てマスタや計算を直さない**。差は問い（質問と回答へ回す行）にして返す。値は質問と回答の答えで決める（答えを出所にしない）。
- **照らし方を別に持たない**。照らすのは `出口/` の突き合わせ 1 本（`出口.関所.通す` → `出口.突き合わせ.突き合わせる` → `月の記録` → `続けて差0の月数`）。この道具が足すのは答えの読み口だけ。
- **Drive を開かない**。開発の窓（開発者の手元の窓）が答えの file・つなぎ・芯の行を渡し、出た物を受ける。答えの file の ID は答えの根の「答えの置き場」だけが持つ（`docs/設計/Drive の型.md` §8）。毎月の殻と芯は答えの置き場を知らない。repo にも事務所の根にも答えの置き場・欄を作らない。
- **顧客の物を repo に置かない**。会社ごとに違う欄の名・氏名・答えの file は開発の窓が引数で渡す。答えも出た表も開発者の手元（scratchpad）に置き、git に入れない。
- Python 3 の標準ライブラリだけ（xlsx は zip と xml.etree で読む）。数は `Decimal`（円は整数・時間は分）。

## 中身

| file | 中身 |
|---|---|
| `表.py` `表にする()` | 答えの file（xlsx・CSV／TSV・zip）→ タブごとの字の表。形は中身で見る。PDF は読まない（要確認） |
| `答えの読み口.py` `一覧表を読む()` | 人が行か列に並ぶ一覧表（支給控除一覧表・勤怠一覧表 …）→ 人×項目の縦。向きは鍵の見出しの行と列のどちらに欄が多いかで決める |
| `答えの読み口.py` `明細を読む()` | 1 人 1 枚の明細 → 人×項目の縦。見出しの値はすぐ右、無ければすぐ下 |
| `照合の段.py` `照らす()` | 芯の縦と答えの縦を 出口/ の突き合わせへ渡し、差の表・問い・差 0 の月を返す |
| `__main__.py` | 呼び口（下） |

読み口は **形ごとに 1 つ**（一覧表・明細）。会社ごと・給与ソフトごとに作らない。会社ごとに違うのは つなぎ（引数）だけ。

## 入れる物

### つなぎ（開発の窓が Drive のマスタ「つなぎ」から渡す）

答えの見出しと芯の項目の対応。形は 出口/ の `欄の対応` と同じ `{項目, 欄, 形}`（形は `円`・`日`・`分`・`回`）。1 項目に 1 欄・1 欄に 1 項目。

```json
{"欄": [{"項目": "基本給", "欄": "基本給", "形": "円"},
        {"項目": "残業時間", "欄": "残業時間", "形": "分"}],
 "読まない見出し": ["氏名", "所属"],
 "鍵の見出し": ["NO"], "氏名の見出し": ["氏名"]}
```

- 見出しは空白（全角も）を除き、全角の英数を半角にして照らす。読み用の別名・読み替えは持たない（要る欄は つなぎ に 1 行足す）。
- `読まない見出し`: 照らさない見出し（氏名・所属・表題・会社の名など）。合計（`合計`・`総合計`・`小計`・`計`）の行・列はいつも読まない。
- 鍵の見出し（既定 `NO`）の無い表は、`氏名からNO`（開発の窓が社員マスタから渡す `{氏名: NO}`）があれば氏名で人を引く。同じ氏名が 2 人以上・引けない人は読まずに要確認。
- 時間: 芯の時間は分。答えの字は `時間の書き方`（`60進`・`時:分`・`10進`）で分へ戻す。xlsx の時刻の書式のセルは `時:分` で読む。

### 芯の行

芯/計算/ の出す人×項目の行（`確かめと仮.md` §2・§3 の列: 支給月・会社・NO・項目・値・出所・状態 …）と、任意で人の状態。
仮の値が 1 つでもある人は出口の関所で外れ、照らさない（`外した人` に返す）。

## 出す物

`照合の段.照らす()` の返す `照らした物`:

| 物 | 中身 |
|---|---|
| `差の表` | 出口/ の突き合わせの列 `支給月・会社・NO・項目・こちら・給与ソフト・差・差の見立て・差の出所`（給与ソフト＝答えの値）。差は 0 だけを一致・片方が空なら `片方だけ` |
| `問い` | 差を **質問と回答へ回す行**（同じ見立て・同じ出所は 1 問）。開発の窓が質問と回答へ書く。答えが「こちらが違う」なら答えを出所に決まりの md・マスタを直す（ふつうの直しの道）。「答えが違う」ならこちらは何も変えない |
| `月の記録`・`差0の月数` | 照らした 1 会社 1 支給月ごとの記録と、会社ごとの続けて差 0 の月数・数えた月・まだ見ていない場面（出口/ の数え方のまま） |
| `外した人`・`照らさなかった項目`・`照らさなかった月`・`要確認` | 黙って捨てない物。照らさなかった月＝芯にあって答えの無い 支給月×会社 |

答えには何も渡していないので、つなぎ の欄は全部 `渡す=False` で突き合わせへ渡す（差の見立ては `丸め`・`決まりの違い`・`片方だけ` のどれか。`入力の違い` は出ない）。

## 呼び口

根で回す。JSON を受けて JSON を返す。出す file は scratchpad に置く。

```
python3 -m 道具.答え合わせ 読む   --形 一覧表|明細 --会社 <番号> --支給月 YYYY-MM --つなぎ つなぎ.json \
        [--時間の書き方 60進|時:分|10進] [--文字コード cp932] [--氏名からNO 氏名.json] --出す 答え.json <答えの file>...
python3 -m 道具.答え合わせ 照らす --芯 芯.json --答え 答え.json --つなぎ つなぎ.json \
        [--前の記録 記録.json] [--N 3] --出す 差.json
```

- `読む`: 1 支給月 1 会社の答えの file を渡す（タブは全部読む。2 つの表で同じ人×項目の値が違えば前の値のまま要確認）。終わりの値は要確認 0 で 0・あれば 1。
- `照らす`: `芯.json` は `{"行": [...], "人の状態": [{支給月, 会社, NO, 状態}...]}`（行の並びだけでもよい）。終わりの値は差の行 0 かつ要確認 0 で 0・ほかは 1。

Python から:

```python
from 道具.答え合わせ.表 import 表にする
from 道具.答え合わせ import 答えの読み口, 照合の段
表たち = 表にする("一覧表.xlsx", 中身)
答え = 答えの読み口.一覧表を読む(表たち, "9", "2026-10", つなぎ, "60進", 読まない見出し=("氏名",))
r = 照合の段.照らす(芯の行, 答え, つなぎ)
r.差の表, r.問い, r.差0の月数
```

## 段階 3 の 1 社ずつの確かめの手順

1. 開発の窓が答えの根の「答えの置き場」から、その会社の過去の月の答え（一覧表・明細）を scratchpad に落とす（file の名で見分けず、中身の見出しで見る）。
2. `読む` で答え.json を組む。要確認（つなぎ に無い見出し・鍵の無い行・数でない値）を先に見る。要る欄なら Drive のマスタ「つなぎ」に 1 行足す（答え.json を手で直さない）。
3. 同じ月を芯で計算し（入口 → 芯）、`照らす` を回す。
4. 差のある行は `問い` のまま質問と回答へ回す。差を見てマスタ・決まりの md・計算を直さない。答えから逆算した値を出所にしない（見当まで）。
5. 答えが来て直したら計算し直してもう一度照らす。1 社の確かめは「全員の全項目の差が 0 か、0 でない差の全部に質問と回答の答えがある」こと（確かめと仮.md §2）。

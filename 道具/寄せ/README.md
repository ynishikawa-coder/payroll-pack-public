# 道具/寄せ — 既存の Drive を今の型へ寄せる道具

仕様は `docs/設計/寄せる道具.md`（§5.2 が主）。型の中身は `docs/設計/Drive の型.md`、型の正本は `初期設定/`。

**型を直すたびに、旧_ のタブと足りない項目が生まれる散らかりを、道具で止める**ための物。
型の直しは必ず「直し」1 つ（版 N−1 → N の操作の並び）と一緒に出し、寄せも配りもその直しを会社のシートに当てる 1 つの中身（`当てる.py`）で行う。
読む側（芯・入口・出口）は今の型しか知らない。前の版の名や語は `直し/` の中にしか無い。

## 守る線
- **Drive を開かない**。殻（各エージェントの repo の Sheets・Drive の口）が読んだ値を JSON で受け、寄せた後の値・書く手順・戻す手順を返すだけ。書くのは殻。
- **何も消さない**。旧_ のタブ・99_ の中身・02_ の物・人の手が入った一点物は「消す問い」に並べるだけ。消すのはオーナーの OK の後に殻が `消す手順` を当てる。
- **値を作らない**。足すのは型の既定値か空、または事実（列「会社」＝会社の呼び名・「欄より前」）だけ。足りない値は空のまま「足りない値」として仮と 1 問の口（`確かめと仮.md`）へ。
- **1 社は全部か無し**。寄せられない物が 1 つでも残れば書く手順は空。人の答え（`人の答え`）を足してもう一度回す。
- **旧_ のタブはもう作らない**。戻すのは写し（`90_履歴/消す_<消す日>_<名>`）と戻す手順で行う。
- 顧客の物を repo に置かない。人が見る物・消す問い・寄せの記録は事務所の Drive に置く（会社の名が入るため）。

## 呼び口（3 つと自己検査）

```
python3 道具/寄せ/呼び口.py 寄せる   --会社 会社.json --型 型.json [--今日 YYYY-MM-DD] [--窓 <役>]
python3 道具/寄せ/呼び口.py 配る     --会社たち a.json b.json … --型 型.json [--今日 …]
python3 道具/寄せ/呼び口.py 見回り   --会社たち a.json … --型 型.json [--窓 <役>] [--前の答え 答え.json] [--今日 …]
python3 道具/寄せ/呼び口.py 自己検査 --型 型.json [--前の型 前の版の型.json]
```
共通: `--型` は `初期設定/型.json`（同じ置き場の `項目.json`・`雛形/` も読む）。`--直し <dir>`（既定 `道具/寄せ/直し/`）。結果は JSON を標準出力へ。終わりの値: 0＝書ける／緑、1＝寄せられない物が在る／赤。

| 呼び口 | 中身 | 返す物 |
|---|---|---|
| 寄せる | 1 社の型の版から今の版まで直しを順に当てる（版の無い会社は 0 から＝直し 1 が初めの寄せ。前の形の読み替えを人の答えで渡せば、同じ版の直しの前に当てる） | 下の「出力」全部 |
| 配る | 新しい直しを事務所の全社に当てる見通し（中は寄せると同じ） | 見通しの 1 枚（会社・今の版・当てる直し・変わるタブ・変わる列の数・寄せられない物・足りない値）・前の版のまま残る会社を頭に・消してよい直し |
| 見回り | 期限の来た 99_／90_履歴/消す_・期限の無い 99_・02_初回の書類・旧_／コピー／（1）・80_答え／照合_・旧_ のタブを並べる | 事務所ごとに 1 枚の消す問い・前の版のままの会社・消してよい直し |

### 入力（会社 1 社の JSON。殻が作る）
```json
{"会社": "作り物の会社", "型の版": 0, "選んだ部品": [],
 "シート": {"03_マスタ": {"社員": [["NO", "氏名"], ["1", "作り物 一郎"]]}, "04_台帳_2026": {}},
 "式": {"03_マスタ": {"会社": [[1, 2]]}},
 "md": {"01_ルール/給与のルール.md": "本文"},
 "置き場": ["01_ルール/", "01_ルール/給与のルール.md", "03_マスタ"],
 "初回の確認の OK の日": "YYYY-MM-DD",
 "人の答え": {"<寄せられない物の鍵>": "<選んだ答え>",
            "前の形の読み替え": [{"版": 1, "操作": [], "手がかり": {}}]}}
```
- 入力は **Drive に今在る値**（殻が読んだまま）。寄せは変わった所だけを書く（値を作らない）＝前と同じタブ・md は書かず、`書かない物` に一覧で出す。台帳の `勤怠`・`勤怠の区間`（表 A・B）は **入口が書く物**: 寄せは形をそろえるだけで、Drive に無い勤怠を寄せの入力に入れても書かない（入れた行の数を `知らせ` に出す）。勤怠を置くのは入口の口。
- `シート` はタブごとの get_values（見出しが 1 行目）。`式` は式のセル（0 始まりの行・列。任意）。`置き場` は組の根からの名（フォルダは `/` で終わる）。
- `人の答え` の `前の形の読み替え`（任意）は、その事務所の **前の道具の形** を今の型へ読み替える操作の塊（版ごと）。パックの直しはどの事務所にも当たる型の作り（タブ・列を足す・並び・md の見出しを足す）だけを持ち、1 つの事務所の前の道具に結びつく読み替え（前の列・項目・置き場・md の見出しの名・前の語・別のタブへ鍵で畳む・手がかり）は持たない（`docs/設計/入れてよい物.md` ⟦鍵:給与計算/移行だけの物はパックに入れない⟧）。読み替えはその事務所の Drive の寄せの記録に置き、殻が人の答えに入れて渡す。
  - 形: `[{"版": N, "操作": [直しと同じ閉じた一覧の操作…], "手がかり": {…}, "なぜ": "…"}]`（版は 1 以上の数・手がかりは {鍵: 字}）。版 N の塊は、この回に当てる版 N の直しの **前** に当てる（会社の版が N 以上なら当てない・同じ版の塊は 1 つ）。
  - **塊に入れる物**: 前の形の操作が頼る型の作りの操作も塊に入れる（塊はパックの型の作りより先に走る。例 人ごとの支給控除へ鍵 `会社`・`NO` で畳む前に 列「会社」を足す）。型の作りの操作は二度当てても同じなので、**便 1 までの版の直し 1・3 の全部の操作と手がかり**（v0.1.6 の `直し_0001.json`・`直し_0003.json`）をそのまま塊にしてよく、それで前と同じ寄せになる。外した読み替えの操作だけを入れると、鍵の列が無く `直しの誤り` で止まる（全部か無し＝何も書かない）。操作の形は直しと同じに確かめ、誤り・まだ無い版の塊は `直しの誤り` で止まる。当てた数は `知らせ` に出る。
  - 渡さない時、前の形の列・タブ・項目は今までどおり寄せられない物に出る（人が下の答えを選ぶ）。読み替えの塊は答えの表をまとめた物で、どちらで寄せても同じ「全部か無し」と値の保ちを通る。
- `人の答え` のほかの鍵は、前の回の「寄せられない物」の鍵と、選べる答えの 1 つ（`前を取る`・`後を取る`・`90_履歴 へ写して消す`・`md へ移す:<md>#<見出し>`・`値:<値>`・`空にする`・`値へ置く`）。
- 当てる順は **版の直し → 照らす（人の答え） → `記録.解けた`**。縦のタブの項目に `値:<今の項目>` と答えた行（`形:項目`・`項目が空`）は、直しを当てた後に今の項目になる＝そのままでは直しの「値をそろえる」（行を項目で選ぶ読み替え）が当たらない。照らすはそのタブの答えの後に、**答えで項目を変えた行にだけ** 今の版までの直し全部（この回に当てる直しだけでなく、型の版が今の版の会社でも。部品は会社が選んだ物）の「値をそろえる」を版の順に通す（答えは項目の意味を決め、値の語は直しの読み替えで今の語へ＝例 前の名「残業の数え方」＝`1日の所定時間を超えた分` に `値:割増.残業の数え方` → `1日の所定超え`。変えた所は `知らせ` に出す）。読み替えに無い語は問い（`<タブ>/そろえる:<列>/<行>`・答え `値:<今の語>`・`空にする`）。出た版の直しの中身は変えない。
- 行き先の無い列には **`今の列へ移す:<今の列>|<前の値>=<今の値>|…`**（同じタブの今の型の列へ値ごと移す。読み替えは任意）。読み替えを書いたら、読み替えに無い値は移さない（黙って捨てない）。`<前の値>=`（今の値が空）は人が捨てると決めた値（捨てた数に出る）。今の列に違う値が在る行・今の型に無い列が先の時は、何も移さず問いに残す（中身に移せない値を並べる）。全部移せれば前の列を外す＝2 回目の当ては手順 0。
- 項目の語が型に合わない行（形の合わない値・列「項目」）には、行ごと今の所へ移す答え:
  - 台帳「月の前提」: `月の前提の語へ:<語>=<値>|…`（1 行を月の前提の語の行へ分ける。例 対象期間 → 締めの始め・締めの終わり）・`月の変動へ:<項目>|<NO>=<値>|<NO>|…`（人ごとの数を 月の変動 の行へ。`=<値>` の無い NO は前の値を写す）・`入口が読み直す`（日ごとの数は 勤怠 の日の行＝入口が原本から読み直す。足りない値に 1 問を起こす）・`持たない:<なぜ>`
  - マスタ「会社」: `人の列へ:<社員の列>=<値>|<NO>|…`（例 入力しない人 → 人.区分 など人の列）・`持たない:<なぜ>`（例 地域別最低賃金 → 法の表/最低賃金.json と 会社.事業場の都道府県 で引く）。時間の書き方 は `値:出口.時間の書き方`（項目に足した）
  - 当てられない時（形が違う・同じ人の違う値が在る・社員に無い NO）は何もせず `知らせ` に出し、問いに残す。同じ名の行が支給月ごとに在る時に値を書いた答えは当てない（支給月ごとに分けて答える）。
  - 値の保ち: 外した行の値は `他の所へ移した`・足した行やセルは `足した`・`持たない` と `入口が読み直す` は `捨てた（人の答え）`（`持たない` は人が見る物の「型が持たないと決めた値」にも出る）。

### 型（初期設定/ の正本）
正本は `初期設定/型.json`（B11）。道具は `当てる.型を開く()` で 型.json と同じ置き場の `項目.json`・`雛形/` を読み、`当てる.型を読む()` の 1 か所で中の形にそろえる:
- シートの名＝`置き場`（`10_会社/<組>` を除いた残り）＋`シート`（例 `03_マスタ`・`01_ルール/質問と回答`・`00_事務所/事務所の設定`）。
- 列＝`列` の後ろに `項目の列`（その段の 1 つの値の項目＝`置く所`・`優先B` を除く）を辞書の順に（`初期設定/型の口.py` の `列()` と同じ）。
- md の見出し＝雛形の `## ` の行（`<…>` を含む見出しは人ごとの節なので照らさない）。
- 列「会社」は必須（Drive の型 §1）。台帳「月の前提」の `項目` は `語` の中だけ。マスタ「会社」の `項目` は `分野.名` の形（会社の決まり.md §1.3）。

### 出力（寄せる）
| 鍵 | 中身 |
|---|---|
| `寄せた後の値` | 今の型の形にそろえたシート・md・置き場（版も上がる）。**寄せられない物が在る時は寄せの前の値のまま**（書かない） |
| `見通しの値` | 寄せられない物が在る時だけ: 直しを当てた所までの形（人が見るだけ・書かない） |
| `書く手順` | 殻が順に当てるだけの操作: `file を写す`（`90_履歴/消す_<翌々月末>_<名>`）→ `file を移す` → `タブの名を変える` → `タブを足す`（無ければ足し、`見出し` まで 1 手で書く）→ md は `file を移す`（元を `90_履歴/消す_<翌々月末>_<名>` へ＝寄せの写しを兼ねる）と `md を作る`（同じ名で新しく。Drive の口では md の中身を直せない＝canEdit=false のため）→ `値を書く`（1 タブ 1 手。範囲は前と後の大きい方。値を他へ渡したタブを最後） |
| `戻す手順` | 全部書いた後の形に当てる逆（寄せの前の値から作る）。写しはそのまま残る |
| `寄せられない物` | 鍵・種類（行き先の無い列／タブ・一点物・ぶつかり・形の合わない値・旧_ のタブ・直しの誤り）・中身・選べる答え・手がかり |
| `足りない値` | 型が要るのに空の所（人×項目）と、「過去の支給と一致」を仮へ直した所（1 問を起こす） |
| `消す問い` | 消す候補（物・置き場・中身はどこに在るか・推奨・`消す手順`）。道具は当てない |
| `人が見る物` | 上を 1 枚にした md（置き場は Drive の確認ページの置き場） |
| `書かない物` | 入れた物（タブ・md）のうち書く手順に出ない物（所・行の数・なぜ: 前と同じ／入口が書く 勤怠・勤怠の区間／旧_ のタブ）。入れたタブは全部 `変わるタブ` か `書かない物` のどちらかに出る（黙って落とさない） |
| `値の保ち` | 前の空でない値 ＝ 後へ移った ＋ 寄せられない物に出た ＋ 捨てた（人の答え・直しの「持たない」）。合わなければ道具は止まる（`保ちの誤り`） |
| `無い値` | 寄せた後に無い値（`支払.締め日`・`支払.支給日`・`会社.事業場の都道府県`・`時間.暦`〔会社・勤務の型〕・`休日.人の休日`）: 項目・段・所・前の道具に在ったか・なぜ。書かない（寄せは値を作らない＝段の解決・芯が仮と問いにする） |

## 直し（`直し/直し_NNNN.json`）

```json
{"版": 2, "前の版": 1, "なぜ": "1 行", "部品": "共通",
 "操作": [{"する": "列の名を変える", "ファイル": "03_マスタ", "タブ": "社員", "前": "前の見出し", "後": "今の見出し"}]}
```
操作は閉じた一覧（`直し.py` の `操作の一覧`）。どれも **前の形を確かめてから当て、当たっていれば飛ばす**（何度当てても同じ・途中で止まっても頭からやり直せる）。

| する | 前の形 | 当たっている印 |
|---|---|---|
| タブを足す | タブが無い | 在る（見出しは型から） |
| タブの名を変える | 前が在り後が無い | 前が無い（両方在れば ぶつかり。人が「前を 90_履歴 へ写して消す」と答えれば今のタブを正とし、前のタブは消す問いへ） |
| 列を足す | 見出しが無い（`条件` 付きは条件に合う行の空） | 在る・埋まっている |
| 列の名を変える | 前が在り後が無い（両方在れば行ごとに重ね、値が違えば ぶつかり） | 前が無い |
| 列の並びをそろえる | 型の列が全部在る | 型の並び（型に無い列は後ろ） |
| 値の語を読み替える | 前の語が在る（`合わせ`: 全体／頭／頭で全体・`md` で md の本文） | 前の語が 0 |
| 列を md の見出しへ移す | 列が在る（`行` で縦のタブの項目の行） | 列（行）が無い |
| 列を畳む | 列が在り、先（鍵で行を合わせる表の列）が在る／先＝`持たない` | 列が無い |
| md の見出しの名を変える・md の見出しを足す | 前の見出しが在る／見出しが無い | 後だけ在る |
| file を置き場へ移す | 前が在り後が無い | 前が無い |
| 値をそろえる | 列（`行` で縦のタブの行）の値が今の形でない（`形`: 支給月・読み・都道府県・休憩の長さ・欄の名） | 全部が今の形（読めない値は問い。`先の列` は読んだ値を同じ行の別の列へ書き、元は残す） |
| 人の列へ移す | 会社の行（`行`）の前の語が `値` に在る／社員の `列の行き` の列に前の語が在る | 行と前の語が無い（人の値の在る人は人が勝つ。移る人が 0 なら問い） |

- `部品` の付いた直しは、その部品を選んだ会社にだけ当てる。
- 型・雛形・直しは同じ PR で出す。直しの無い型の直しは自己検査 1 が赤にする。
- 直し N は、両方の事務所の全社の型の版が N 以上になったら消す（配る・見回りが「消してよい直し」に並べる）。

## 型の版を上げない読み: 前の 勤務の長さの丸め（`実働の丸め.py`）
直しの鎖の後に、どの版の会社にも毎回当てる（版 5 の会社にも効く・出た版の直しの中身は変えない）。
前の道具の 勤務の長さの丸め（分）は **休憩を引いた後の日の実働を N 分で切り捨て**（意味が決まっている＝事務所に聞かない）、今の `時間.打刻の丸めの単位` は区間を **長くする向き** の丸め＝別の意味。
前の形の読み替え（版 3。便 2 までは直し 3 の中に在った）がこの列を 打刻の丸めの単位 へ名を変えて移すと、そのままでは額が変わる（10:22〜13:59・15 → 3:45／前の道具 3:30）。
`時間.打刻の丸めの単位` は今の型でも正しい項目（事務所が雇用の人のために書ける）＝**出所の分かる値だけ** 移す:
- 出所が前の道具と分かる値（寄せの入力の勤務の型に前の列 `勤務の長さの丸め（分）` が在り、その回の直し（と前の形の読み替え）が移した値）: 打刻の丸めの単位 を空にし、
  委託の人（`人.区分` 委託・委託の併用）が居て `委託.実働の丸め` が無ければ会社の行 `委託.実働の丸め`＝`N分切捨て`（N＝0 は `丸めない`）を書く（委託の人が居なければ書かない＝持たない）。
  雇用の人が居れば知らせ 1 つ（前の道具は雇用の人の日の実働も切り捨てた＝写さない〔24 条〕＝前の明細と額が変わる）。分の数でない値・型ごとに違う N は問い（種類 `読めない値`）。
- 出所の分からない値（版 3 以上の会社の 打刻の丸めの単位）: 黙って変えない。委託の人が居て `委託.実働の丸め` が無い会社だけ問い 1 つ（種類 `出所の分からない値`）。
- 問いの鍵 `03_マスタ/勤務の型/委託.実働の丸め`。答え: `前の道具の丸め`（その値 N を N分切捨て へ）・`値:<単位と向き>`・`丸めない` → `委託.実働の丸め` へ書き 打刻の丸めの単位 を空に／`打刻の丸めのまま` → 打刻の丸めの単位 は残し `委託.実働の丸め`＝丸めない。

### 途中で落ちた時
書く手順は、受け取る側（新しいタブ・md・他のタブ）を先に書き、渡す側（値を他のタブ・md へ移したタブ。値の数でなく操作で決める）を後に書く。どこで落ちても値は前か後のどちらかに在る。
md を 90_履歴 へ移した所で落ちた時は、もう一度 寄せる が写しを元の md として読み、`md を作る` だけを出す（戻す手順は実の写しの名で戻す＝寄せ直しが月をまたいでも写しの日がずれない）。
**途中で落ちたら、もう一度 寄せる**（落ちた後の値を読んで同じ手順で当て直す。当たっている所は飛ばすので、同じ寄せた後になる）。戻す手順は全部書いた後の形にだけ当てる。書く前へ戻したい時は、まず 寄せる で書き終えてから戻す手順を当てる（または最初の `file を写す` の写しから戻す）。

## 自己検査（`自己検査.py`・型を直す PR ごとに回す）

## 1 社ずつの段取り（殻と人。§1.5）
止める（管理表を「寄せ中」）→ 読む（殻）→ 寄せる（見通し・書かない）→ 人が寄せられない物に答える（0 になるまで回す）→ 書く手順を当てる（最初の `file を写す` で丸ごと写す）→ 読み直して もう一度 寄せる＝書く手順が空で寄せられない物 0 なら照らし済（管理表の型の版を上げ「寄せ中」を外す）。合わなければ戻す手順で戻す。

# 版（タグ）の出し方

## 版の名
- semver で `v<大>.<中>.<小>`（最初は `v0.1.0`）。
  - 大: 使う側が読み方を変えないと壊れる変更（入口・出口の形、マスタの型の互換が切れる）
  - 中: 互換を保った足し（新しい選択肢・新しい法の表の年）
  - 小: 直し（誤りの修正・文の直し）
- `v1.0.0` までは中の上げでも互換が切れることがある。その時は CHANGELOG の行の頭に「互換が切れる:」と書く（下の CHANGELOG）。

## CHANGELOG
- `CHANGELOG.md` の「未リリース」に、PR ごとに 1 行足す（書いた窓が足す）。
- **殻が渡す形・呼び口・型の版が変わる PR は、CHANGELOG の行の頭に `互換が切れる:` を書く**（`- 互換が切れる: …`）。殻が渡す形＝呼び口の入力・出力の鍵や値の単位（例 v0.1.2 の 有給 の `時間.週の所定` を分→時間の数・v0.1.3 の `源泉.報酬` を並び→1 つの値）、呼び口＝関数・CLI の口の名と引数、型の版＝`初期設定/型.json` の `版`。足すだけで前の渡し方がそのまま通る物（任意の鍵・出力の鍵を足す）は書かない。
- 過去の版の節は書き替えない（出した版の記録）。v0.1.3 までの節には印が無い（v0.1.2・v0.1.3 と型の版 2→5 で殻の渡す形が変わっていた）。
- 骨の自己検査（`tests/test_骨.py`）が見る: 「互換が切れる」は行の頭の形だけ・型の版が 5 より上なら「型の版 N」の行に印がある・main からの枝で `tests/` の外の `.py`・`.json`・`.html` を変えたのに CHANGELOG を変えていない（main が手元に無い時は skip）。
- 版の節の見出しは `## [vX.Y.Z] - YYYY-MM-DD` の形だけ（例 `## [v0.1.2] - 2026-11-12`）。この形でない `## ` 見出し（`## 未リリース` など）は版として読まれない。

## 版を出す
版を出す手順（Javis 側の親窓が CHANGELOG の版の節を作って main へ入れると、印は Actions が打つ）と印の決め方は、土台 agent-foundation-public の `docs/版の出し方.md`・`docs/版の印.md` に従う。
読む土台の版の名は `.github/workflows/tag.yml` の `ref` の 1 か所にだけ書く（ここや CONTRIBUTING に重ねない）。土台の版を上げる時はそこを替える。

## 使う側
- 使う側（Javis・UTC の窓）は **版の印を読む**（main の先端を直に読まない）。今は両側とも一番新しい版の印（latest）を読む。
- 新しい版を読む時は CHANGELOG のその版の節を読み、`互換が切れる:` の行があれば殻の渡し方を合わせてから回す。

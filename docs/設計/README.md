# 設計の目次

設計書と部品の置き場の目次。file や dir を足したら、同じ PR でここに行を足す（行の file・dir が無いと骨の自己検査 `tests/test_骨.py` が赤になる）。

## 設計書

| file | 書く中身 |
|---|---|
| `docs/設計/勤怠の形.md` | 表 A「日」・表 B「区間」・月の数字の口・芯の境目（入口／芯／出口） |
| `docs/設計/会社の決まり.md` | 5 分野の選べる一覧と優先 A の穴・夜勤／半休／休出の選択肢 |
| `docs/設計/Drive の型.md` | マスタ・台帳・md の雛形の 1 つの型・フォルダの 4 分け・確認の HTML の置き場・状況の正本 1 つ（管理表の型） |
| `docs/設計/法の表.md` | 1 つの形・効く月の範囲で引く・11 月に来年分を見る検査・2027 年分（表の置き場は `法の表/`） |
| `docs/設計/確かめと仮.md` | 答え合わせを開発の道具へ外す・人×項目の突き合わせ・仮の人を出さない |
| `docs/設計/寄せる道具.md` | 既存の Drive を新しい型へ寄せる道具・型を直したら雛形と既存のシートへ配る道具・移行の間だけの物を消す段取り |
| `docs/設計/入れてよい物.md` | パックに入れてよい物の線の正本（入れる物・入れない物・見分け方・足りない物の道・置き場の表・線を守る 4 段） |
| `docs/毎月の流れ.md` | 給与の窓の毎月の流れ（殻とパックの分け・殻が口へ渡す物と書く物） |

## 部品の置き場

| dir | 置く物 |
|---|---|
| `法の表/` | 法の表（効く月の範囲つき） |
| `法の表/源泉_報酬.json` | 委託の人の報酬・料金の源泉の率（所得税法 第205条第1号・支払日・2013〜2037 年） |
| `法の表/有給_付与日数.json` | 有給の付与日数（通常・比例）・時効・年 5 日（労基法 39 条・115 条・労基則 24 条の 3・労働した日＝付与日で引く） |
| `法の表/源泉_賞与の月額表の月数.json` | 賞与の源泉を月額表で出す時の ÷・× の月数（所得税法 第186条・計算期間 6 か月以下＝6・超える＝12） |
| `芯/計算/` | 芯の計算 |
| `芯/計算/法の線の読み方.py` | 芯の名 → 法の線.json の線と欄の表（芯/計算 と 芯/集計 が読む 1 か所） |
| `芯/集計/` | 芯の集計 |
| `入口/` | 勤怠などを読み、表 A・表 B の形へ直す |
| `出口/` | 明細・連携の形へ出す |
| `確認ページ/` | 確認ページ（初回と毎月の確認の HTML・名と版・貼り戻し） |
| `初期設定/` | 事務所・会社を始める時の設定 |
| `月次/` | 1 か月（と賞与の 1 回）を回す口（3 層の外の組み立て役・部品の呼び順の正本） |
| `有給/` | 有給の付与と残り |
| `管理表/` | 状況の正本（管理表） |
| `道具/寄せ/` | 既存の Drive を新しい型へ寄せる道具 |
| `道具/答え合わせ/` | 開発の間だけの答え合わせ（答えの読み口・照合の段） |
| `tests/data/` | 骨の自己検査の束（製品の名・事務所と側の名）と外しの一覧（`外し.json`） |
| `tests/作り物/` | 作り物の小さな試験 2 つ（国の率や表の例・回帰の見張り） |

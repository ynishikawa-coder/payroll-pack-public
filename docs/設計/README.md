# 設計の目次

設計書と部品の置き場の目次。file や dir を足したら、同じ PR でここに行を足す（行の file・dir が無いと骨の自己検査 `tests/test_骨.py` が赤になる）。

## 設計書

| file | 書く中身 |
|---|---|
| `docs/設計/勤怠の形.md` | 表 A「日」・表 B「区間」・月の数字の口・芯の境目（入口／芯／出口） |
| `docs/設計/会社の決まり.md` | 5 分野の選べる一覧と優先 A の穴・夜勤／半休／休出の選択肢 |
| `docs/設計/Drive の型.md` | 会社の Drive の形（1_決まり・2_マスタ・台帳_<年>・3_月ごと・8_確認事項・9_履歴）・マスタと年の台帳（読んだまま／確定した勤怠）と MD の例の表の型・確認事項の置き場・管理表の型・答えの行き先 |
| `docs/設計/法の表.md` | 1 つの形・効く月の範囲で引く・11 月に来年分を見る検査・2027 年分（表の置き場は `法の表/`） |
| `docs/設計/確かめと仮.md` | 初期設定の照らし（過去の結果と人×項目・本番の手順・芯に混ぜない）・人×項目の突き合わせ・仮の 2 種類と必ず埋める 6 欄・全員が締まるまで待つ・仮の人を出さない |
| `docs/設計/寄せる道具.md` | 既存の Drive を新しい型へ寄せる道具・型を直したら雛形と既存のシートへ配る道具・移行の間だけの物を消す段取り |
| `docs/設計/設問の作り方.md` | 問いを初期設定 1 回・毎月 1 回で聞き切る作り方（4 つの箱・問いを出す前の段・法の線の点検表・型ごとの網・その月だけの物・答えの反映の照らし） |
| `docs/設計/入れてよい物.md` | パックに入れてよい物の線の正本（入れる物・入れない物・見分け方・足りない物の道・置き場の表・線を守る 4 段） |
| `docs/毎月の流れ.md` | 月の仕事の 3 段（0 初期設定・1 材料をそろえる〔マスタの更新→その月だけの指示→勤怠の締め〕・2 給与計算）と給与エージェントとパックの分け |

## 部品の置き場

| dir | 置く物 |
|---|---|
| `法の表/` | 法の表（効く月の範囲つき） |
| `法の表/源泉_報酬.json` | 委託の人の報酬・料金の源泉の率（所得税法 第205条第1号・支払日・2013〜2037 年） |
| `法の表/有給_付与日数.json` | 有給の付与日数（通常・比例）・時効・年 5 日（労基法 39 条・115 条・労基則 24 条の 3・労働した日＝付与日で引く） |
| `法の表/源泉_賞与の月額表の月数.json` | 賞与の源泉を月額表で出す時の ÷・× の月数（所得税法 第186条・計算期間 6 か月以下＝6・超える＝12） |
| `芯/設定の表.json` | 芯が読む会社の決まりの全部の 1 枚の表（名・形・選べる値・既定・読む所）。芯はこの表に在る名だけを読み、計算の最初に全部を照らす（外の字は既定で数えて仮＋問い）。寄せ・段の解決も同じ表で照らす |
| `芯/設定.py` | 設定の表の読み口（`照らす`・`選べる値の字か`・`選べる値の一覧`〔殻のプルダウンの材料〕・`休憩の表を読む`〔時間帯・長さ・退勤の境の 3 つの形。境の（…）は 人.区分 か 人.性別〕） |
| `芯/計算/` | 芯の計算 |
| `芯/計算/法の線の読み方.py` | 芯の名 → 法の線.json の線と欄の表（芯/計算 と 芯/集計 が読む 1 か所） |
| `芯/計算/承知.py` | 承知した食い違いの印 `法の線.承知` の読み方と承知できる線（芯/計算 と 芯/集計 が読む 1 か所・会社の決まり §1.4） |
| `芯/集計/` | 芯の集計 |
| `入口/` | 勤怠などを読み、表 A・表 B の形へ直す |
| `出口/` | 明細・連携の形へ出す |
| `確認ページ/` | 確認ページ（初回と毎月の確認の HTML・qa-html の 1 つの型の写し・名と版・答え qa-html/2 の貼り戻し） |
| `config/skill-values.json` | 土台の skill に渡す給与のパックの値（qa-html の なぜ聞くか の文を給与の語に・確認ページ.py も読む） |
| `.github/workflows/土台の版.json` | 土台（agent-foundation-public）を読む版の印の正本（ci.yml・tag.yml・public-mirror.yml が直に読む・`docs/版の出し方.md`） |
| `初期設定/` | 事務所・会社を始める時の設定 |
| `初期設定/設問.py` | 問いの種の集め方とまとめ方・答えの反映の照らし（`docs/設計/設問の作り方.md`） |
| `初期設定/法の線の点検.json` | 法の線の点検表（法の線のある項目の全部に 1 行） |
| `初期設定/型ごとの網.json` | 勤務の型ごとの聞くべき決まりの網 |

| `月次/` | 1 か月（と賞与の 1 回）を回す口（3 層の外の組み立て役・部品の呼び順の正本） |
| `月次/例の確かめ.py` | 決まりの例（給与のルール.md の例の表）を毎月の計算の前に今のマスタの値で芯に通して照らす（合わない・確かめた日が無い・確かめた人に確かめの出所〔受付番号・決定DB の行・問いの番号〕が無い・書けない の例が 1 つでもあればその会社の月は出口へ出ない） |
| `月次/年の台帳を起こす.py` | 年の最初の支給月に新しい年の台帳（`台帳_<支給年>`）を起こす口: 前の年の台帳の型（`初期設定/型.json` の `台帳_<支給年>`）の全部のタブから、新しい年の同じタブの見出しと引き継ぐ行（新しい年の支給月の行）と、新しい年の 月を回す へ渡す前の年の確定した勤怠を返す（前の年の台帳が欠ける・形が違う・どの年か分からない行は止める。引き継ぎの表は `Drive の型.md` §4） |

| `有給/` | 有給の付与と残り |

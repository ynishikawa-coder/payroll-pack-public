# Drive の型

- 書く中身: 会社の Drive の形（木と名の正本は `初期設定/型.json`・ここは役目だけ）・マスタと年の台帳と MD の例の表の型・確認事項の置き場・状況の正本 1 つ（管理表の型）・確認事項の答えの行き先

各事務所の Drive に置く「会社ごとの給与の DB」（決まりの MD・質問と回答・マスタ・年の台帳・月ごとの届いた物と出す物・確認事項・状況の表）の **1 つの型** を決める（2026-11-18 オーナーと確定した設計）。
新しい会社も、作り直す今の会社も同じ型に収まり、AI が読む物・人に配る物・履歴が混ざらないことが目的。

前提（変えない物）:
- 顧客の物は各事務所の Drive にだけ置く。repo には型（名・並び・意味）だけを置き、値は置かない ⟦鍵:給与計算/エンジンの共通化⟧。
- payroll-pack は **計算のパック** と **給与エージェントの部分**（毎月の手順・決まり・照らし）の 2 つを持つ。手順は給与エージェントの部分が持つ。Drive・Notion・確認事項を配る口は各社のエージェントが持ち、この紙の形（何をどこに書くか）を守って各々作る。計算のパックは Drive と Notion を開かず、受け取った値を計算して返すだけ。
- パックが計算に読むのは **マスタの値・マスタ・確定した勤怠** の 3 つだけ。
- 仮が残る人は出す物の全部に出さない ⟦鍵:給与計算/足りない時は仮で計算し出さない⟧。過去の結果と照らすのは初期設定の照らしだけで、計算（芯）には入れない（`確かめと仮.md` §1）。
- 今の Drive は、この形で作り直す（前の置き場の物は人が今の名へ移すか 9_履歴/ へ移す。§10）。

この紙が決めるのは **置き場の名と役目と列の型** だけ。毎月の手順は `docs/毎月の流れ.md`、仮と確かめは `確かめと仮.md`、会社ごとに選ぶ決まりの選択肢は `会社の決まり.md`、勤怠の列は `勤怠の形.md` が書く。

## 1. 会社の単位

### 決めた事
- **給与の DB の単位は会社**。根は組 1 つに `10_会社/<組>/` の 1 つ（台帳 1 本〔支給年ごと〕・1_決まり 1 つ・月のフォルダ 1 列）。マスタは会社ごとに持たず、事務所の根の直下に 1 冊（全社の行を持ち、顧客ID で絞って読む＝§2・型 39）。
- 組＝同じ決まり・同じ締めと支給日で同じ担当が回す会社の束（中の言葉）。会社が 1 つなら組は会社と同じ字。束ねた時も会社ごとの値は列「会社」で分ける。フォルダの名と確認事項の名に入るのは組の名（事務所の設定「会社の一覧」の「組」）で、会社の呼び名ではない（`初期設定/型.json` の 置き場 と同じ `<組>`）。
- **全部のシートの全部のタブに列「会社」を必須で置く**（表のタブは A 列）。値は会社の呼び名（事務所の設定「会社の一覧」の「会社」と同じ字）。会社が 1 つでも空にしない。
- 台帳のタブは A 列「会社」・B 列「支給月」の順（行の鍵は「会社 × 支給月 × NO」）。マスタのタブは A 列「会社」（行の鍵は「会社 × NO」か「会社 × 項目」）。
- 束の中で会社ごとに決まりが違う所は、MD の見出しの下で会社を名指しして書く。
- 会社を指す安定した字は **顧客ID**（事務所の設定「会社の一覧」と「置き場」の頭の列）。仕組みの中の番号で、事務所の段の口が決まった形で振る（§8「顧客ID を振る」・事務所に聞かない・AI が手で書かない）。呼び名や組が変わっても顧客ID は変えない。

## 2. フォルダの形

**木の名（フォルダ・シート・md の名）と並びの正本は `初期設定/型.json` の「木」「名の形」と各シートの「シート」・md の雛形の「名」の 1 か所**。この節は役目だけを書き、Drive の名を写さない（前は この文書・型.json・道具が別々に名を持ち、台帳の名が 2 つになった）。名つきの木は `python3 初期設定/型の口.py 木` で出す。道具は `初期設定/型の口.py` の 名()・道()・物たち()・台帳の名() で引く。下の〔 〕は 型.json の役。

### 事務所の根
```
<事務所の根>/
  事務所の物（型.json の 木.事務所の物）を根の直下に置く（型 39・間にフォルダを挟まない）
  〔マスタ〕                 人・会社・項目の値（§4）。事務所に 1 冊で全社の行を持ち、顧客ID で絞って読む
  〔マスタの変更の記録〕     マスタ「変更の記録」だけを置く別の本
  〔事務所の設定〕           既定・会社の一覧・置き場（会社の物の ID の唯一の置き場＝§8）
  〔管理表〕                 状況の正本（§5）
  〔質問と回答〕             全社の問いと答えと振り分けの 1 冊（タブ 問い・答え・振り分け＝§4「質問と回答」）。人は書かない
  〔答えの原本〕/            返った答えをそのまま 1 回 1 ファイルで置く（確認ページの貼り戻し・オーナーがチャットで返した文）。手を加えない
  〔事務所のルール〕         事務所の段の決まり（給与ソフトと取り込みの形を含む・§4「製品ごとの値の置き場」）
  確認事項（名の形 確認事項・組は「事務所」）   事務所全体の問いの確認事項（§3）
  〔履歴〕/                  事務所全体の問いの確認事項の前の版（§3）
  〔会社たち〕/〔組〕        （下の「会社の根」）
```
事務所の物（上の木の物と確認事項とその前の版）は事務所の根の直下に置き、名で引く（§8）。事務所の根には上の木の物のほかに物を置かない。質問と回答は事務所に 1 冊だけ（会社ごとに持たない。行の顧客ID で会社を分ける）。

### 会社の根
```
〔会社の根〕＝〔会社たち〕/〔組〕/     会社の根の物（型.json の 木.会社の根の物）
  〔決まり〕/                 AI が読む物（木.決まりの物）
    〔給与のルール〕           会社の決まり（決まりごとに見出し・文・例の表＝§4）
    〔作業のルール〕           原本の読み方の決まり
  〔台帳〕（名の形 台帳）     年の台帳（§4）
  〔月ごと〕/（名の形 月）/   木.月の物
    〔届いた物〕/             原本（触らない・名を変えない）
    〔出す物〕/               取り込み・支給控除一覧・有給休暇管理表（§6）・確定した勤怠（確定した勤怠のシート・§4）
  〔確認事項〕/               確認事項（名の形 確認事項）＝事務所の担当者に聞くページの写し（§3）。問いと答えの正本は事務所の根の〔質問と回答〕
  〔履歴〕/                   前の版（AI の作業の物は Drive に置かない）
```

### 置き場の約束
- **1_決まり/ に置けるのは木.決まりの物だけ**（MD 2 枚〔給与のルール・作業のルール〕）。質問と回答・HTML・PDF・前の版・フォルダを置かない（質問と回答は事務所の根に 1 冊）。
- **AI の作業の物（途中の .py・.json・引き継ぎのメモ・加工の途中の表）は Drive に置かない**。窓の作業場に置く。
- **口の記録**（窓の口が戻すために残す .json）だけは置く: `事務所の根/9_履歴/置き場の登録の写し_<YYYY-MM-DD>_<HHMMSS>.json`（管理表の 置き場の登録を移す を当てる前の表・手順・戻す）と `事務所の根/9_履歴/移しを当てた記録_<YYYY-MM-DD>_<HHMMSS>.json`（道具/移しを当てる.py が当てた回ごとに 1 つ: いつ・顧客ID ごとの書いた数・消した数・止まった訳。id と値は入れない）。名の形はこの行の 1 か所。
- **「旧_」「コピー」「（1）」を名に持つ物を置かない**。前の版は 9_履歴/ へ移す。消してよい物は `9_履歴/消す_<消す日>_<元の名>`（持ち主は会社の担当＝事務所の設定「会社の一覧」の「担当」）。名に消す日の無い物は残す物。
- **初期設定の書類**（規程・契約書・過去の支給控除一覧・勤怠の原本・給与ソフトの初回出力）は、最初に計算する支給月の `3_月ごと/<月>/1_届いた物/` に頭 `書類_` を付けて置く。原本なので消さない。過去の支給控除一覧は初期設定の照らし（`確かめと仮.md` §1）にだけ使い、計算の入力にしない。
- 届いた物のファイル名は `<頭>_<受け取った日>_<元の名前>`（頭＝`勤怠_`・`変更_`・`メモ_`・`書類_`）。名を付けるのは `月次/届いた物.py`（`名を付ける`・`写す手順`）の 1 か所で、給与エージェントは受け取り口（事務所の設定「置き場」の 物＝受け取り口）の物を〔口: 届いた物を写す〕で写す（原本は動かさず名も変えない・同じ名が在れば写さない・写しの名〔旧_・コピー・（1）・Copy of〕と頭と日の付いた名は止める）。容器（zip など）は 出所 として同じ名の形で写し、中の file を 1 つずつ `<頭>_<受け取った日>_<容器名>__<中の名>`（名を組むのは `月次/台帳の形.容器の中の名` の 1 か所）で写す。原本は中の file で、台帳の 原本の名前 に容器を書かない。中身を写していない容器が在れば「容器の中身を写していない」で止める。`__` は容器と中の区切りだけに使う＝中の道の段（/ と \ で分けた物）が空・「.」「..」・前後の空白・`__` を持つ・`_` で始まるか終わる物と、中の file 名単体が写しの名の物は止める（名から出所の容器へ一意に戻す）。容器の中の容器は外の容器の名と生の中の道を `__` でつないで渡し、中の名と同じ直しを当てる（`月次/台帳の形.道の段` の 1 か所）。
- 勤怠の読み直し・確かめの結果は台帳（確定した勤怠）にだけ書く。月のフォルダに加工の途中の物を置かない。

### 窓が Drive に置く物（名と置き場の正本はこの表）
窓は名を組まない。名は右の口が返し、窓はその名のまま置く。外れた名は置き場の検査（下の 1・5・7）が赤にする。

| 物 | 置き場 | 名 | 名を返す口 |
|---|---|---|---|
| 確認事項（配った版） | §3「確認事項の置き場の表」の置き場（会社＝`8_確認事項/`・事務所＝`事務所の根/`） | `確認事項_<組>_<YYYY.MM支給（M月分）>_v<版>.html`（1 社の会社は組＝会社。1 回に配る問いが 1 枚の上限を超えて分けた時は `_v<版>-<枚>.html`＝同じ版の何枚目） | `確認ページ/確認ページ.py` の `配る手順`（1 つの版の全部の枚＝`作る` の `枚たち` の全部の名と中身を 1 度に受け、置き場に今ある名と `9_履歴/` の名から版を決め、名の並びが 1 字でも違う・枚が欠ける／多い・中身の枚の印や版の字が名と違えば止める） |
| 確認事項（配る前） | 同じ置き場 | `下書き_` + 上の名（版は次に配る版） | 同じ `配る手順`（下書き・分けた枚も全部を 1 度に） |
| 確認事項の前の版・残った下書き | §3 の表の「前の版」（`9_履歴/`） | `消す_<移した日の翌月末>_<元の名>` | 同じ `配る手順` の `移す`（全部の枚を置いた後に 1 回当てる。配る時に前の版の全部の枚と同じ組・支給月の下書きを移す。前の版の file の中身を上書きしない・移した file はリンク共有を外す） |
| 月のフォルダ | `3_月ごと/` | `YYYY.MM支給（M月分）` | `芯/支給月の字.py`（確認事項の名の支給月と同じ口） |
| 届いた物 | `3_月ごと/<月>/1_届いた物/` | `<頭>_<受け取った日 YYYY-MM-DD>_<元の名前>` | `月次/届いた物.py` の `名を付ける`（〔口: 届いた物を写す〕と同じ 1 か所） |
| 口の記録 | 「置き場の約束」の口の記録 | 「置き場の約束」の口の記録 | 「置き場の約束」の口の記録の行 |

### 照らす検査の要件（置き場の検査）
各社のエージェントが、置き場の一覧（名と種類）を照らして赤にする物:
1. 会社の根・事務所の根・3_月ごと・月のフォルダ・8_確認事項 に、上の木と「窓が Drive に置く物」の表に無い名がある（月のフォルダの名・確認事項の名と組の外れを含む。8_確認事項 に質問と回答を置かない＝事務所の根に 1 冊）。
2. 1_決まり/ に木.決まりの物のほかの物がある（質問と回答・HTML・フォルダ・前の版を含む）。
3. どこかに名が `旧_` で始まる物・`コピー`・`（1）` を含む物がある（字は `芯/字.py` でそろえて照らす＝半角の `(1)`・半角カナ・頭の `Copy of`〔大小を問わない〕の写しも同じ。並びは `芯/字.py` の `写しの名か` の 1 か所）。
4. 9_履歴/ の `消す_<日>_` の日が過ぎている（赤でなく知らせ）。
5. AI の作業の物（.py・.json・引き継ぎ）が Drive にある（口の記録は、決まった名の形でその置き場の直下に在る物だけ外す。同じ名でも置き場が違えば赤）。
6. シートのタブ・見出しが型（§4）と 1 列でも違う・列「会社」が無いか空の行がある。
7. 窓が置く物の名・版が型と違う: 届いた物の名が形に合わない・確認事項の置き場に同じ組・支給月の前の版が残る・配った版と同じか古い版の下書きが残る。

窓は検査へ、会社の根の下（3_月ごと の月のフォルダの中の名まで・8_確認事項 と 9_履歴 の中の名）と 事務所の根 の中の名（`事務所の根/<名>`）を必ず渡す（名だけ・中身は読まない）。

## 3. 確認事項の置き場

### 決めた事
- **聞く相手はいつも事務所の担当者 1 人**。問いは確認事項（1 枚の HTML のページ）で聞く。会社の担当者に直に聞く道は持たない。
- **正本は事務所の根の 質問と回答（1 冊・タブ 問い・答え・振り分け）**。確認事項は問いから道具（`確認ページ/`）が起こす **表示と配る用の写し**。返った答えはそのまま〔答えの原本〕に 1 回 1 ファイルで置き、質問と回答「答え」に 1 行足し、問いを作る時に決めておいた選ばれた選択肢の振り分けを「振り分け」に書き、反映先（§9）を書き換えてから使う（ページの上の答えを直に計算に使わない）。
- **配った版の正は URL**（配る口が返す URL）。URL は管理表「確認ページ」に 1 行で載せる（§5）。Drive の HTML は URL の中身の写し。
- 置き場と前の版の行き先は下の「確認事項の置き場の表」の 1 か所。名は `確認事項_<組>_<支給月>_v<版>.html`（初期設定の確認は最初に計算する支給月）。名・版・前の版の移しは §2「窓が Drive に置く物」の `配る手順` だけが決める。配り直したら、前の版は表の「前の版」へ `消す_<移した日の翌月末>_<元の名>` で移し（前の版の file の中身を新しい版で上書きしない）、管理表の前の行の状況を「差し替え」にする（行は消さない）。
- 事務所全体の問い（質問と回答「問い」の顧客ID が `事務所` の行）の確認事項は同じ名の形（会社の所は「事務所」）で、表の「事務所」の行の所に置く。

### 確認事項の置き場の表
置き場と前の版の正本は `初期設定/型.json` の 木.確認事項の置き場（行は `<組>` と `事務所`・道は木の役の並び）。道具（`確認ページ/確認ページ.py`）は `型の口.確認事項の置き場の表()` で読む（置き場を道具にも文書にも写さない）。形が違えば道具は読み込みで止まる。`<組>` は組の名（事務所の設定「会社の一覧」の「組」・会社が 1 つなら会社と同じ字）に置き換える。今の道は `python3 初期設定/型の口.py 木` の「確認事項の置き場」で見る。

- 確認事項の文には中の言葉（窓・段・組・つなぎ・表 A など）を使わない。

## 4. マスタ・台帳・MD の型

### 型の正本は repo の 1 か所
- タブ・列の名と並び・列の意味・選べる値・空の雛形は **repo だけ** に置く（`初期設定/型.json`）。Drive に雛形のフォルダを置かない。
- 新しい会社を始める時も、型を直した時も、Drive のシートは repo の型から起こす・直す。人が Drive の写しから写さない。
- **列の意味は 1 行**（何の値か・値の形・選べる値）。手順・経緯・日付・会社の事情を列の意味に書かない（手順は MD、変わった日は「変更の記録」）。
- シートに説明の行・メモの行を置かない。見出しは型の並びのとおり 1 列も違えない。値は 数・日付（YYYY-MM-DD）・選べる値 だけ。

### マスタ
タブ・列の名と並びの正本は `初期設定/型.json` の マスタ（`python3 初期設定/型の口.py 見出し` で出す）。下の表は役目だけを書き、列を写さない。

全タブの A 列は「会社」。マスタには金額に効く数字と、選べる式のどれを使うかを書く。金額に効く決まりは AI が MD からマスタへ写し、写す時に MD の該当の見出しとマスタの値を照らす。

| タブ | 役目 |
|---|---|
| 社員 | 人の固定の値。値の段は「人 ＞ 勤務の型 ＞ 会社 ＞ 事務所の既定」。**必ず埋める 6 欄**（人の区分・源泉の欄・保険の加入・労働時間の制度・扶養の数・保険料を引く月）が空なら計算しない（`確かめと仮.md` §3）。標準報酬は「保険料の月」で書く |
| 人ごとの支給控除 | 人ごとに決まった額の項目。氏名は人が見て確かめるための写し（計算は NO で引く） |
| 会社 | 会社の項目（会社の項目の辞書）。選べる式のどれを使うかもここ |
| 支給控除の項目 | 項目の性質（どの会社も同じ列）。使う会社の無い項目は持たない |
| 勤務の型 | 勤務の型 |
| つなぎ | 勤怠ツールと給与ソフトでの呼び名（NO が空の行は会社の行）。製品ごとの値の置き場（下） |

### 台帳（名の形 台帳）

- 勤怠の機械の照らし（時刻の抜け・区間の重なり・1 日 24 時間超え・原本に印字された合計との違い・1 次と 2 次の差の行に直した訳があるか）は、確定した勤怠と読んだままの勤怠を並べて当てる。
- 確定した勤怠のシート（人ごとの月の合計と、どう確定させたか）を毎月、事務所の担当者へ渡す。置き場はその月の `2_出す物/` の `確定した勤怠_<会社>_<支給月>_v<n>`（タブ 人ごと・直した所）。名と版は `出口/名と版.渡す名を付ける`（出す物と同じ付け方・前の版は 9_履歴/ へ）、中身と書く手順は `月次/勤怠のシート.作る`（中身は `月次/勤怠の照らし.担当者へ渡す表`）。出す命令を通らない＝出す命令が置く物（取り込み・支給控除一覧・有給休暇管理表）には混ぜない。給与エージェントは〔口: 書く手順を当てる〕で当てる。
- **年をまたぐ値**（新しい年の台帳は `月次/年の台帳を起こす.起こす` が前の年の台帳から起こす。返った `書く手順`〔`月次/台帳へ書く.py`〕を給与エージェントが〔口: 書く手順を当てる〕で当てる＝表を手で写さない。1 月支給の出す命令は新しい年の台帳が既に在るので 起こす を呼ばず、毎月と同じ `前の年の確定した勤怠`〔書く手順なし〕で前の確定した勤怠だけを読む）:

### 給与のルール.md の例の表
- 給与のルール.md は決まりごとに見出し（`### <決まりの名>`）・文・例の表を書く。例は決まりの文から作る（過去の結果からは作らない）。
- 例の表の列: 例の番号・決まり・種類（日・月・書けない）・支給月・勤務の型・人の値・日付・日の種類・区間・期待・確かめた日・確かめた人・備考。
- 例の 支給月 は、その例が当たる月（例を確かめた時の決まりの月）。例はその支給月の決まりで解いて照らす。決まりの値は、例の月も回す月も同じ `段の解決.解く`（事務所・会社・勤務の型・人の段と、変更の記録でその月へ戻した人の段）の 1 本で引く。例ごとに、例の人の決まりの値を例の支給月と回す月で、回す月の覆いが求める名と例が 決まり の欄に書いた名について比べる。比べる名・覆う名・止めの文の名は、どれもマスタの項目の名（`芯/設定の表.json` の項目の名）で数える（`段の解決.解く` が 1 つの項目を 2 つの鍵に分ける物＝時間.休憩の表 → 時間.休憩の表・時間.休憩の長さ は、`芯/設定の表.json` の `マスタの項目` で元の項目の名へ戻す＝対応の正本はその 1 か所。止めの文の値もマスタの字で出す）。`段の解決.解く` が 1 つの項目の値を別の名の鍵へ写して作る物＝時間.暦 → 時間.会社の暦 は、`芯/設定の表.json` のその鍵の行の `写す元` に元の項目の名を書く（`マスタの項目` と `写す元` は `項目の外` の行だけに付け、1 つの行に両方は付けない。値はどちらも表に在り `項目の外` でない名。`段の解決.分けて作る鍵`・`段の解決.写して作る鍵` はこの 2 つの欄から引く＝鍵の名を段の解決に字で書かない）。社員のいくつかの列を 1 つの項目にまとめて作る鍵（住民税.6月分・住民税.7月以降 → 住民税.額）は `段の解決.まとめて作る鍵` の 1 か所に置く。`解く` が出す鍵は、その人に置いた名・`マスタの項目` か `写す元` を持つ鍵・まとめて作る鍵・内の鍵（`芯/設定.py` の `内の鍵`＝勤務の型 など。`見当の値` もここ）・`見当の値` に名を出した鍵（見当で埋めたと知らせる）のどれかに限り（`見当の値` に出してよい名は芯が見当を読む名＝`芯/設定.py` の `見当を読む名`〔今は 時間.日の所定〕だけ。ほかの名を出すと `解く` は止める＝芯が読まない見当で人が仮にならず出口へ出る道を作らない）、置いた値を別の値で黙って替えない（`tests/作り物/test_作り物_例の名の空間.py` が、どの項目にも選べる値を全部・ほかの項目は形の見本を、置ける段〔会社・勤務の型・人〕ごとに置いて `解く` を回して照らす）。値の違う名は、その例ではその月の覆いと見分けに数えず、回す月にその名の値が在れば、回す月に当たる例でその名を書いた物を求め、無ければ覆いの外れとして止める。決まり の欄に書いた名がどれも違う値になる例は回す月に当たらない（まだ当たらない・もう当たらない）＝その月は数えずに外す（照らさない・返す物の `当たらない例`）。名を 1 つも書かない例は外さず、例の支給月で照らすが、覆いと見分けには数えない。支給月 が空の日の例は、どの月にも当たる例として回す月で照らす。支給月 が読めない例は止める。覆いが求める値（事務所・会社・勤務の型の段の値と、社員の列の変更の記録で戻した値）と見分けの今の値も、回す月の `段の解決.解く` から取る。回す月に当たる例が 1 つも無ければ止める（例の確かめは通らない）。決まり の欄（例の表の 決まり の升）には、マスタの項目の名（`芯/設定の表.json` の項目の名で `項目の外` でない名）だけを完全に同じ字で `・` で並べて書く（空＝名を書かない例）。見出し（`### <決まりの名>`）は例の行の 見出し に別に持ち、名としては読まない（見出しの括弧の説明を名と取り違えない）。項目の名でない字（綴りの揺れ・括弧の説明・`解く` が分けて作る鍵の名・`項目の外` の名＝時間.会社の暦・住民税.退職の時 など）は「例が読めない」で止める（綴りの揺れた名を黙って拾わない・説明は見出しか文へ書く）。
- 例の確かめは、AI が例を人の言葉にして確認事項で聞き（「8:40 出勤・18:00 退勤・休憩 1 時間なら労働 8 時間でよいですか」）、答えた人（誰でもよい。オーナーの決定なら `オーナー`）と日を、確かめた人・確かめた日に書く。確かめた人 は `<答えた人の名>（<確かめの出所>）`（出所の種類・書き方・照らしに渡す証しは `月次/例の確かめ.py` の `出所の種類たち` の表が正本＝ここに写さない。パックは 確かめた人 を照らさない＝書いた中身は人が見る）。事務所の設定に「確かめてよい人」の名簿は置かない（2026-11-19 オーナーの決定・型の版 32 で畳んだ）＝AI が自分で確かめたと書いて人が読んでいない数え方で給与が出るのを、名簿でなく例ごとの出所で防ぐ。
- 毎月の計算の前に、パックが全部の例をその月のマスタの値で計算に通す（給与エージェントが給与のルール.md の字を渡し、パックが `月次/例の確かめ.py` の `MD から例を読む` で例の表を読む）。1 つでも合わない・確かめた日が無い・確かめた人に確かめの出所が無い・`書けない` の例があれば、その会社の月は出さない。給与のルール.md の決め事とマスタの値が同じ事を言っているかを確かめる所はここ 1 か所。

### 質問と回答（事務所に 1 冊・3 タブ）
**人は 1 マスも書かない**。全部のマスをパックの 1 命令（`出口/出す.py` と同じ道の口）が書く。人が自由に書く表を機械が厳しく読む約束として使わない（2026-11-28 オーナーと合意・前の 1 タブの形は §10 で畳む）。列の名と並びの正本は `初期設定/型.json` の 質問と回答（ここは役目だけ）。

| タブ | 1 行 | 列 |
|---|---|---|
| 問い | 聞いた事 1 つ | 問いの鍵・顧客ID・聞いた支給月・聞いた日・問いの文・確認ページへのリンク・状態（聞いている／答えた／取り下げ） |
| 答え | 返った答え 1 つ（そのまま） | 問いの鍵・回答（原文のまま）・回答日・答えの原本へのリンク |
| 振り分け | 答えが効く先 1 つ（答えから書いた行）か、答えが来る前の候補の行 | 問いの鍵・顧客ID・対象（`会社` か社員ID）・反映先・何を・値・効く月・反映済み・反映した日・選択肢（型 44） |

- **問いの鍵** はパックが中で振る。形を検査しない（番号の形では止めない）。
- **顧客ID** は会社を指す字（§1）。事務所全体の問いは `事務所`。
- **答えの原本**: 返った物は事務所の根の〔答えの原本〕に 1 回 1 ファイルでそのまま置く（確認ページの貼り戻しの答え・オーナーがチャットで AI に直に返した文＝AI がその文をそのまま日付つきで原本に入れ、同じ道で振り分ける）。名は送信そのものから決まる（確認ページの答えは `答え_<受付番号>.txt`・受付番号の無い送信は回答日を含まない中身の印・チャットの文は日付と中身の印）＝もう 答え に入っている送信は別の日に貼り直しても何も書かない（答え・振り分けが二重にならない）。メールで来た物は月の 1_届いた物 に入り、そこから読む。「答え」の回答は原文のままで、パックは回答の文から印（取り下げ・補足・受付など）を読み分けない。
- **1 つの答え → 振り分けは何行でもよい**（人・会社・決まり・何人かに同時に効く）。問いに「人の問い／会社の問い」の種類を持たせない。効く先は振り分けの行が持つ。
- **振り分けは問いを作る時に決めておく**: 確認ページの選択肢ごとに「この答えなら誰の・何が・いくらに変わるか」を振り分けの形で持たせ、問いを足す時に 3_振り分け へ **候補の行**（列 `選択肢` に選択肢の見出しを書いた行）として書く（型 44・`質問と回答.問いを足す(…, 選択肢の振り分け=…)`。確認ページは振り分けを持たない＝正本は候補の行 1 つ。`読む` は候補の行を問いの `選択肢の振り分け` へ付け、反映する振り分けには入れない）。答えが返れば選ばれた選択肢の候補を、列 `選択肢` を空にした答えの行としてそのまま書く。1 問 1 つの事・2 通りに読めない問い。「その他」・自由記述の文だけ AI が読んで振り分け、`質問と回答.答えを振り分ける(問い, 振り分けたち)` で書いて問いを 答えた にする（1 つに決まらなければ振り分けずに次の問いにする＝問いは 聞いている のまま、答えが在るので `止まりを集める` が「振り分けがまだ」で止める）。「分からない」は振り分けを書かず、問いは聞いている のまま（次の確認で聞き直す）。
- **反映先** ＝実際に書き換える先: マスタのタブと列／給与のルール.md／作業のルール.md／台帳のタブ／`反映しない`（知らせだけ・今の設定のままで合うと確かめた答え）。§9。
- **反映済み** は必ず持つ。パックが書き換えを実物（マスタ・md・台帳の今の値）と照らして合った時だけ `済` と書き、反映した日を書く。人は書かない。照らす道は `初期設定/質問と回答.py` の 照らす 1 本で、マスタ「会社」（1 行に 1 項目）は顧客ID と項目の行の 今の値 で照らす（効く月が在ればその月を 適用開始 に持つ行、無ければいちばん新しい 適用開始 の行）。
- **効く月** は既定で空＝答えが来た時にまだ出していない月から後に効く。出し終えた月へ黙って当てない。答えの中身が過去の月を指す時だけ AI が書き（`YYYY-MM`）、その月が出し済みなら止めずに「出し直しの候補」として最後の出力に並べる。反映する支給月の欄は置かない。
- 見当・拠り所・資料・AIの読み などの前提の欄は表に持たない（確認ページ自体に載り、問いの 確認ページへのリンク で辿る）。
- AI の読みを人が確かめる所は 3 つだけ: 確認ページの答え・勤怠の書き写し・最後の出力。ほかに確かめの段を足さない。

#### 止まる所（これだけ）
- 振り分けの行が **この月の計算に効く先** で 反映済み≠済 → 対象が社員ならその人だけ仮で計算し出さない（⟦鍵:給与計算/足りない時は仮で計算し出さない⟧）／`会社`・決まり（md）ならその会社を止める。
- 答えの無い問い（状態＝聞いている）も同じ: その問いの選択肢の振り分けの候補が効く人だけ／会社だけ。候補の無い問いは問いの顧客ID の会社を止める。
- 止めない: 反映先 `反映しない`・効く月が後の月・過去の月（出し直しの候補）・状態＝取り下げ・書き方や番号の形。
- 理由は 1 回の実行で全部集め、それぞれに「誰の・何が・何をすれば通るか」を添える（最初の誤りで返さない）。止め方の口は `月次/` の `止まりを集める`。

### 書き方を 1 つに固定
- **NO**: 社員のタブの字のまま（0 埋めの有無も会社の原本のまま）。全タブで社員のタブと同じ字にする。
- **支給月**: シートの行は `YYYY.MM支給`、入口・芯の中は `YYYY-MM`、月の置き場の名は `YYYY.MM支給（M月分）`。
- **日付**: `YYYY-MM-DD`。
- **時刻**: `h:mm`（日またぎは 24 を足す）。
- **長さ**: 計算に使う列は整数の分のまま。人が読む要約の列（休憩の合計・労働の合計）だけ `h:mm`。
- **氏名**（台帳・マスタの氏名の列）: 道具（`月次/台帳の形.py`）がマスタ「社員」から NO で引いて書く。行に既に違う氏名があれば書く前に止める。年の台帳（読んだままの勤怠・確定した勤怠・その区間・その月だけの指示・人ごとの月の数字・起こした新しい台帳の引き継ぐ行）へは `月次/台帳へ書く.py` の口が社員を受けて埋めて照らす（空なら埋め・違う氏名・社員に居ない NO・社員の氏名が空 なら止める）。パックが書く手順をまだ返さない行（台帳「締めの記録」・マスタ「変更の記録」）は、給与エージェントが行を足す前に `台帳の形.氏名を埋める(鍵, 行たち, 氏名)` を通す（手で書かない）。
- 書き方の検査は、シートを表示形式の値ではなく書いた字（`9:00`・`2026-10-01`）で読む前提（Sheets の表示形式で `9:00:00` などに見える列は、ずれとして赤になる＝セルを字の書式にそろえる）。
- 置き場の検査（§2）が、支給月・日付・時刻の書き方のずれを赤で知らせる。

### 式を書いてよいか
- **マスタ・台帳には式を書かない**（値だけ）。値は給与エージェントが書き、パックは値だけを受ける。式があると、給与エージェントが読む値と人が見る値の出所が二重になる。
- 式を書いてよいのは **人が見るだけの物**（管理表の見る用のタブ）だけ。AI はそれらを読まない（読む時は式の元の表を読む）。

### MD の形
- 人は MD を読まない。MD の形は AI が決める（AI が読みやすい形）。中身は、AI が確認事項で人の言葉にして聞く時だけ確かめてもらう。
- 決まっているのは、給与のルール.md の決まりごとの見出し（`### <決まりの名>`）と例の表の列（上）だけ（パックが例の表を読むため）。
- 金額に効く数字は MD に書いてよいが、計算はマスタの値だけを読む。写す時に MD の見出しとマスタの値を照らす。
- **答えの行**（振り分けの反映先が md の時に書く 1 行）: `- ⟦答え:<問いの鍵>｜<何を>⟧ <値>`（行の頭から・反映先が `<md の名>#<見出し>` ならその節の中・何を が見出しならその節の中・どちらでもなければ決まりの文に触らず `# 答えの印` の節〔無ければ md の終わりに起こす〕の中）。組む口の正本は `初期設定/質問と回答.md_の答えの行`（書く側はこの口で組み、形を写さない）。反映済み=済 の照らし（`質問と回答.照らす`）はこの印の行だけを読み、同じ印の行の値が全部 振り分けの 値 と一字同じ時だけ合う＝本文に値の字が含まれるだけでは合わない（否定の文・別の数の中の字で 済 にならない）。鍵・何を・値が空か、改行・`⟧`・`｜`・HTML の注の印を含む振り分けは組まない（済 にならない）。

## 5. 状況の正本 1 つ（事務所の管理表の型）

### 決めた事
- **状況の正本は事務所の根の `管理表` の 1 本**。全社の月の状況・前の目次「月の状況」・給与計算 管理表「全社_予定と進み」・UTC の Notion のタスクの給与の状況の列を、ここ 1 つにする。UTC の Notion のタスクは次に動く人と窓の引き継ぎを持ち、計算の状況は管理表の行へのリンクで指す（同じ物を 2 か所に持たない）。
- 管理表の型も repo の `初期設定/` に置く（段階 2 の `管理表/` が読み書きの口を作る）。
- **今の例外（型の正本が 3 つ）**: 今は型の file が `初期設定/型.json`（マスタ・台帳・質問と回答・事務所の設定）・`管理表/型.json`（管理表）・`有給/型.json`（2_出す物 の有給休暇管理表）の 3 つに分かれ、版も別々に数える。§4 の「repo の 1 か所」と食い違う間の決まり: 同じシートのタブ・列を 2 つの file に書かない（各 file は自分のシートだけを持つ）。畳む段取り: `管理表/型.json`・`有給/型.json` の中身を `初期設定/型.json` のシートとして移し、版を 1 つに合わせる（窓の渡す形が変わる＝型の版を上げる PR で、`有給/` を触る窓が無い時に 1 本で）。

### 管理表のタブ
**「月の状況」**（会社 × 支給月で 1 行・月の給与の回だけ）

| 列 | 意味 |
|---|---|
| 会社 | 会社の呼び名 |
| 組 | その会社の束（会社が 1 つなら会社と同じ） |
| 支給月 | `YYYY.MM支給（M月分）` |
| 原本 | 空／済／止まり（全員の勤怠が締まったら済） |
| 集計 | 空／済／仮／止まり |
| 取り込み | 空／済／仮／止まり（事務所の給与ソフトへ渡すデータ） |
| 計算 | 空／済／仮／止まり（こちらで最後まで計算した結果） |
| 確認ページ | 空／お答え待ち／お答えいただいた |
| 納品 | 空／済 |
| 外した人 | 仮が残り出口から外した人の数（0 でないと取り込み・納品は済にしない） |
| 突き合わせ | 給与ソフトとの人×項目の差が続けて 0 の月の数（下の「突き合わせの記録」から `管理表/突き合わせの記録.py` が数えて書く＝読み返さない） |
| 止まりの理由 | 1 行 |
| タスクへのリンク | 次に動く人と引き継ぎを持つタスクの URL |
| 更新日 | YYYY-MM-DD |

**「賞与の状況」**（会社 × 支給月で 1 行・賞与の回だけ）

月の状況と同じ列から 集計・突き合わせ を除いた物（会社・組・支給月・原本〔賞与の支給一覧がそろったか〕・取り込み・計算・確認ページ・納品・外した人・止まりの理由・タスクへのリンク・更新日）。
同じ会社・同じ支給月に月の給与と賞与がある時も、月の給与は「月の状況」、賞与はこのタブの別の行に書く（賞与を書いて月の給与の行を上書きしない）。
どのタブに書くかは回（月・賞与）で決まり、管理表の型の「回」から `管理表.py` の `回のタブ` が引く。行を起こすのはパックの出す命令（出口/出す.py）＝賞与は払う会社・月だけに起きるので事務所の段が毎月起こさない。

**「突き合わせの記録」**（会社 × 支給月 × 回で 1 行・月の給与も賞与も）

給与ソフトとの突き合わせ（`確かめと仮.md` §2）の回ごとの記録。続けて差 0 の月数を数える元の正本（数だけでは賞与の回・抜けた月・場面が分からない＝月の状況の「突き合わせ」は読み返さない）。列: 会社・組・支給月（`YYYY.MM支給`）・回（月／賞与）・突き合わせた人・差の行・外した人・給与ソフトが違うで閉じた・場面・差0の月（はい／いいえ）・続けて差0の月数・まだ見ていない場面・更新日。行を起こすのは書く窓（〔口: 突き合わせ〕＝`管理表/突き合わせの記録.py` の `書く手順` が返す手順だけ）。前の回を突き合わせ直した時は、口がその回より後の回の数も記録から数え直して書く。管理表は事務所に 1 本＝年をまたいで数える（年の台帳には置かない）。

**「確認ページ」**（配った版 1 つで 1 行）

| 列 | 意味 |
|---|---|
| 載せた日 | YYYY-MM-DD |
| 会社 | 会社の呼び名（束の全社に向けた時は束の名） |
| 支給月 | その答えを初めて計算に使う支給月（月に紐づかない物は「全社の決まり」） |
| 何の確認か | 立ち上げ／毎月 |
| 何のための質問か | 事実だけを 1 行 |
| 問いの数 | 数 |
| 確認ページ | URL（配った版の正） |
| 答えていただいた日 | YYYY-MM-DD |
| 答えた方 | 役目の名 |
| 状況 | お答え待ち／お答えいただいた／差し替え |

### 他の表は式で引くか畳む
- 全社の月の状況・給与計算 管理表「全社_予定と進み」は管理表「月の状況」に寄せて畳む。
- UTC の Notion のタスクは給与の状況の列だけを畳む。タスクは次に動く人と窓の引き継ぎを持ち、計算の状況は管理表の行へのリンクで指す。
- 列「タスクへのリンク」はタスクを指すだけ（タスクの状態は管理表へ写さない）。

### 顧客の窓が全顧客の行に書かない仕切り
- 管理表へ書くのは給与エージェントの **管理表の書く口** だけ。口は窓が受け持つ会社を受け取り、その会社の行（鍵＝会社 × 支給月〔月の状況・賞与の状況はタブで回を分ける〕、確認ページは鍵＝会社 × 載せた日 × URL）だけを書く。他の会社の行・見出し・他のタブには書かない（口が拒む）。回（月・賞与）を渡した書き方は、その回のタブの外へ書かない（口が拒む）。
- 書く時は鍵で行を探して書く（行の位置で書かない）。行が無ければ足す。行を消さない。
- 月の状況の 会社 × 支給月の行を起こすのは事務所の段（管理表の道具）だけ。賞与の状況の行は書く窓が起こす（組は口が会社の組を書く）。

- 出す物は全部、パックの 1 命令（出口/出す.py）が置く。仮が残る人は人ごとに除いて置き、除いた人と理由を返す（取り込みも支給控除一覧も有給休暇管理表も同じ）。出す人が 1 人も残らない・誰を除くか決められない時は何も置かない。管理表の列が欠けていれば物を置く前に止める。書く物（出す物の中身・管理表の行・移す前の版の id）は全部組み終えてから書き始め、書く順は 新しい版を全部置く（スプレッドシートは物の名のタブ 1 つで作ってから書く）→ 前の版を 9_履歴/ へ移す → 管理表。書く途中で落ちた時は消さずに止まり、その回に作った物（所・名・id・中身が書けたか）と 9_履歴/ へ移した物（id と元の所）を返す（Drive の口に消す口は無く、消すのは人に聞く操作。前の版は新しい版を全部置き終えるまで動かさないので、置く途中で落ちても 2_出す物/ に残る）。戻すのは人が返りを見て決める。出した物を直す時は、直に直さずこの命令を回し直して出し直す。
- **仮が 1 つでも残る人は、取り込み・支給控除一覧・有給休暇管理表・納品の全部に出さない**（印つきでも出さない）⟦鍵:給与計算/足りない時は仮で計算し出さない⟧。

### 台帳と出力の境目

## 9. 確認事項の答えの行き先

答えは必ず反映先を書き換えてから使う（答えの字を計算に直に入れない）。道は 1 本: 返った物を〔答えの原本〕へそのまま置く → 質問と回答「答え」に 1 行 → 選ばれた選択肢の振り分け（問いを作る時に決めた物）を「振り分け」に書く → 書き戻しの口（`月次/答えの書き戻し.py`）が振り分けの行ごとに 反映先 を書き換える手順を返す → 窓は〔口: 書く手順を当てる〕で当てるだけ → パックが実物と照らして合った行だけ 反映済み に `済` と反映した日を書く。「分からない」の答えは振り分けを書かない（問いは聞いている のまま）。反映の前に同じ反映先の今の値と照らし、食い違えば問いにする（黙って上書きしない）。反映済み が `済` の行は書き直さない（人が設定を直した後でも古い答えで上書きしない）。

配った問いを下げる時は、パックが「問い」の 状態 を `取り下げ` にする（回答の文に印を書かない）。下げた問いへ後から届いた答えも原本と「答え」には残すが、振り分けは書かずに知らせる。

振り分けの 反映先 の書き方（問いの種類ごとの先）:

| 問いの種類 | 書き換える先 |
|---|---|
| 会社の決まり（割増・欠勤控除・手当・取り込みの形など） | 給与のルール.md。金額に効く物はマスタ（「会社」「支給控除の項目」「勤務の型」「つなぎ」）へも写す |
| 原本の読み方 | 作業のルール.md |
| その人だけの決まり | マスタ「社員」（数字・選べる式）。言葉で書く決まりは給与のルール.md で人を名指しして書く（型 39 に 人のルール.md は無い） |
| 人の事実（入退社・扶養・保険の加入・等級） | マスタ「社員」と「変更の記録」 |
| その月だけの事 | 台帳「その月だけの指示」 |
| 勤怠の日の事実 | 台帳「確定した勤怠」（直した訳に `問い:<問いの鍵>`） |
| 数え方の例の確かめ | 給与のルール.md の例の表（確かめた人・確かめた日に、答えた人と日）。振り分けの 何を はその例の見出しか 決まり の項目を指す（字の組み方と読み方の正本は `初期設定/型の口.py` の 反映先の節＝問いを作る `月次._例の問い`・出所の行を照らす `例の確かめ._行が例を指す`・`設問.反映の照らし` が同じ口を呼ぶ。ここに形を写さない） |

| 今の設定のままで合うと確かめた答え・知らせだけ | `反映しない`（止めない） |

- パックが計算できない事（式が無い・項目が無い）は問いにしない。パックの直しにする（`確かめと仮.md` §3「仮の 2 種類」）。

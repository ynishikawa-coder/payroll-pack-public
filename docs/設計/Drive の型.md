# Drive の型

- 書く中身: 会社の Drive の形（木と名の正本は `初期設定/型.json`・ここは役目だけ）・マスタと年の台帳と MD の例の表の型・確認事項の置き場・状況の正本 1 つ（管理表の型）・確認事項の答えの行き先

各事務所の Drive に置く「会社ごとの給与の DB」（決まりの MD・質問と回答・マスタ・年の台帳・月ごとの届いた物と出す物・確認事項・状況の表）の **1 つの型** を決める（2026-11-18 オーナーと確定した設計）。
新しい会社も、作り直す今の会社も同じ型に収まり、AI が読む物・人に配る物・履歴が混ざらないことが目的。

前提（変えない物）:
- 顧客の物は各事務所の Drive にだけ置く。repo には型（名・並び・意味）だけを置き、値は置かない ⟦鍵:給与計算/エンジンの共通化⟧。
- payroll-pack は **計算のパック** と **給与エージェントの部分**（毎月の手順・決まり・照らし）の 2 つを持つ。手順は給与エージェントの部分が持つ。Drive・Notion・確認事項を配る口は各社のエージェントが持ち、この紙の形（何をどこに書くか）を守って各々作る。計算のパックは Drive と Notion を開かず、受け取った値を計算して返すだけ。
- パックが計算に読むのは **マスタの値・マスタ・確定した勤怠** の 3 つだけ。
- 仮が残る人は出す物の全部に出さない ⟦鍵:給与計算/足りない時は仮で計算し出さない⟧。過去の結果と照らすのは初期設定の照らしだけで、計算（芯）には入れない（`確かめと仮.md` §1）。
- 今の Drive は、寄せる道具でこの形へ移す（前の置き場の名は寄せが今の名へ移す・移せない名だけ手で移す。§10）。

この紙が決めるのは **置き場の名と役目と列の型** だけ。毎月の手順は `docs/毎月の流れ.md`、仮と確かめは `確かめと仮.md`、会社ごとに選ぶ決まりの選択肢は `会社の決まり.md`、勤怠の列は `勤怠の形.md` が書く。

## 1. 会社の単位

### 決めた事
- **給与の DB の単位は会社**。根は組 1 つに `10_会社/<組>/` の 1 つ（2_マスタ 1 本・台帳 1 本〔支給年ごと〕・1_決まり 1 つ・月のフォルダ 1 列）。
- 組＝同じ決まり・同じ締めと支給日で同じ担当が回す会社の束（中の言葉）。会社が 1 つなら組は会社と同じ字。束ねた時も会社ごとの値は列「会社」で分ける。フォルダの名と確認事項の名に入るのは組の名（事務所の設定「会社の一覧」の「組」）で、会社の呼び名ではない（`初期設定/型.json` の 置き場 と同じ `<組>`）。
- **全部のシートの全部のタブに列「会社」を必須で置く**（表のタブは A 列）。値は会社の呼び名（事務所の設定「会社の一覧」の「会社」と同じ字）。会社が 1 つでも空にしない。
- 台帳のタブは A 列「会社」・B 列「支給月」の順（行の鍵は「会社 × 支給月 × NO」）。マスタのタブは A 列「会社」（行の鍵は「会社 × NO」か「会社 × 項目」）。
- 束の中で会社ごとに決まりが違う所は、MD の見出しの下で会社を名指しして書く。
- 会社を指す安定した字は **顧客ID**（事務所の設定「会社の一覧」と「置き場」の頭の列）。事務所が会社に付ける（例 `C0001`）。呼び名や組が変わっても顧客ID は変えない。AI は顧客ID を付けない（無い・決まらない時は事務所の担当者に聞く）。

## 2. フォルダの形

**木の名（フォルダ・シート・md の名）と並びの正本は `初期設定/型.json` の「木」「名の形」と各シートの「シート」・md の雛形の「名」の 1 か所**。この節は役目だけを書き、Drive の名を写さない（前は この文書・型.json・道具が別々に名を持ち、台帳の名が 2 つになった）。名つきの木は `python3 初期設定/型の口.py 木` で出す。道具は `初期設定/型の口.py` の 名()・道()・物たち()・台帳の名() で引く。下の〔 〕は 型.json の役。

### 事務所の根
```
<事務所の根>/
  〔事務所〕/                事務所の物（型.json の 木.事務所の物）
    〔事務所のルール〕       事務所の段の決まり（給与ソフトと取り込みの形を含む・§4「製品ごとの値の置き場」）
    〔事務所の設定〕         既定・会社の一覧・置き場（会社の物の ID の唯一の置き場＝§8）
    〔管理表〕               状況の正本（§5）
    〔質問と回答〕           事務所全体の決まりの問い（会社に紐づかない物）
    確認事項（名の形 確認事項・組は「事務所」）   事務所全体の問いの確認事項（§3）
    〔履歴〕/                事務所全体の問いの確認事項の前の版（§3）
  〔会社の根〕               （下の「会社の根」）
```
事務所の物（上の木の物と確認事項とその前の版）は〔事務所〕に置き、パックへはマスタの一部として渡す。事務所の根には〔事務所〕と〔会社たち〕のほかに物を置かず、〔事務所〕には上の木の物のほかに物を置かない。事務所の〔質問と回答〕は会社の〔質問と回答〕と同じ型（§4「質問と回答」・列「会社」は `事務所`）。

### 会社の根
```
〔会社の根〕＝〔会社たち〕/〔組〕/     会社の根の物（型.json の 木.会社の根の物）
  〔決まり〕/                 AI が読む物（木.決まりの物）
    〔給与のルール〕           会社の決まり（決まりごとに見出し・文・例の表＝§4）
    〔作業のルール〕           原本の読み方の決まり
    〔人のルール〕             その人だけの決まり
    〔質問と回答〕             問いと答えの台帳（§4）
  〔マスタ〕                  人・会社・項目の値（§4）
  〔台帳〕（名の形 台帳）     年の台帳（§4）
  〔月ごと〕/（名の形 月）/   木.月の物
    〔届いた物〕/             原本（触らない・名を変えない）
    〔出す物〕/               取り込み・支給控除一覧・有給休暇管理表（§6）・確定した勤怠（確定した勤怠のシート・§4）
  〔確認事項〕/               確認事項（名の形 確認事項）＝事務所の担当者に聞くページの写し（§3）
  〔履歴〕/                   前の版（AI の作業の物は Drive に置かない）
```

### 置き場の約束
- **1_決まり/ に置けるのは 4 つだけ**（MD 3 枚と質問と回答）。HTML・PDF・前の版・フォルダを置かない。
- **AI の作業の物（途中の .py・.json・引き継ぎのメモ・加工の途中の表）は Drive に置かない**。窓の作業場に置く。
- **口の記録**（殻の口が戻す・答えを当てるために残す .json）だけは置く: 会社の `9_履歴/寄せの記録_<YYYY-MM-DD>_<HHMMSS>.json`（〔口: 寄せる〕の前の値・書く手順・戻す手順・人の答え）と `00_事務所/9_履歴/消す問いの答え_<YYYY-MM-DD>_<HHMMSS>.json`（〔口: 消す〕のオーナーの答え）と `00_事務所/9_履歴/置き場の登録の写し_<YYYY-MM-DD>_<HHMMSS>.json`（管理表の 置き場の登録を移す を当てる前の表・手順・戻す）。名の形と置き場は `道具/寄せ/見回り.py` の `口の記録` の 1 か所。
- **「旧_」「コピー」「（1）」を名に持つ物を置かない**。前の版は 9_履歴/ へ移す。消してよい物は `9_履歴/消す_<消す日>_<元の名>`（持ち主は会社の担当＝事務所の設定「会社の一覧」の「担当」）。名に消す日の無い物は残す物。
- **初期設定の書類**（規程・契約書・過去の支給控除一覧・勤怠の原本・給与ソフトの初回出力）は、最初に計算する支給月の `3_月ごと/<月>/1_届いた物/` に頭 `書類_` を付けて置く。原本なので消さない。過去の支給控除一覧は初期設定の照らし（`確かめと仮.md` §1）にだけ使い、計算の入力にしない。
- 届いた物のファイル名は `<頭>_<受け取った日>_<元の名前>`（頭＝`勤怠_`・`変更_`・`メモ_`・`書類_`）。名を付けるのは `月次/届いた物.py`（`名を付ける`・`写す手順`）の 1 か所で、給与エージェントは受け取り口（事務所の設定「置き場」の 物＝受け取り口）の物を〔口: 届いた物を写す〕で写す（原本は動かさず名も変えない・同じ名が在れば写さない・写しの名〔旧_・コピー・（1）・Copy of〕と頭と日の付いた名は止める）。容器（zip など）は 出所 として同じ名の形で写し、中の file を 1 つずつ `<頭>_<受け取った日>_<容器名>__<中の名>`（名を組むのは `月次/台帳の形.容器の中の名` の 1 か所）で写す。原本は中の file で、台帳の 原本の名前 に容器を書かない。中身を写していない容器が在れば「容器の中身を写していない」で止める。`__` は容器と中の区切りだけに使う＝中の道の段（/ と \ で分けた物）が空・「.」「..」・前後の空白・`__` を持つ・`_` で始まるか終わる物と、中の file 名単体が写しの名の物は止める（名から出所の容器へ一意に戻す）。容器の中の容器は外の容器の名と生の中の道を `__` でつないで渡し、中の名と同じ直しを当てる（`月次/台帳の形.道の段` の 1 か所）。
- 勤怠の読み直し・確かめの結果は台帳（確定した勤怠）にだけ書く。月のフォルダに加工の途中の物を置かない。

### 殻が Drive に置く物（名と置き場の正本はこの表と `道具/寄せ/見回り.py` の 1 か所）
殻・窓は名を組まない。名は右の口が返し、殻はその名のまま置く。外れた名は置き場の検査（下の 1・5・7）が赤にする。

| 物 | 置き場 | 名 | 名を返す口 |
|---|---|---|---|
| 確認事項（配った版） | §3「確認事項の置き場の表」の置き場（会社＝`8_確認事項/`・事務所＝`00_事務所/`） | `確認事項_<組>_<YYYY.MM支給（M月分）>_v<版>.html`（1 社の会社は組＝会社。1 回に配る問いが 1 枚の上限を超えて分けた時は `_v<版>-<枚>.html`＝同じ版の何枚目） | `確認ページ/確認ページ.py` の `配る手順`（1 つの版の全部の枚＝`作る` の `枚たち` の全部の名と中身を 1 度に受け、置き場に今ある名と `9_履歴/` の名から版を決め、名の並びが 1 字でも違う・枚が欠ける／多い・中身の枚の印や版の字が名と違えば止める） |
| 確認事項（配る前） | 同じ置き場 | `下書き_` + 上の名（版は次に配る版） | 同じ `配る手順`（下書き・分けた枚も全部を 1 度に） |
| 確認事項の前の版・残った下書き | §3 の表の「前の版」（`9_履歴/`） | `消す_<移した日の翌月末>_<元の名>` | 同じ `配る手順` の `移す`（全部の枚を置いた後に 1 回当てる。配る時に前の版の全部の枚と同じ組・支給月の下書きを移す。前の版の file の中身を上書きしない・移した file はリンク共有を外す） |
| 月のフォルダ | `3_月ごと/` | `YYYY.MM支給（M月分）` | `道具/寄せ/見回り.py` の `置く物の名("月のフォルダ")`（中は `芯/支給月の字.py`＝確認事項の名の支給月と同じ口） |
| 届いた物 | `3_月ごと/<月>/1_届いた物/` | `<頭>_<受け取った日 YYYY-MM-DD>_<元の名前>` | `置く物の名("届いた物")`（中は `月次/届いた物.py` の `名を付ける`＝〔口: 届いた物を写す〕と同じ 1 か所） |
| 口の記録 | 「置き場の約束」の口の記録 | 「置き場の約束」の口の記録 | `口の記録の名` |
| 配りの見通し・寄せの見通し・消す問い | **窓の作業場だけ**（Drive に置かない＝会社の名が入る AI の作業の物。オーナーには窓で見せる） | `配り_見通し`・`寄せ_見通し`・`消す問い` の `.md`／`.json` | `置く物の名("作業場")` |

### 照らす検査の要件（置き場の検査）
各社のエージェントが、置き場の一覧（名と種類）を照らして赤にする物:
1. 会社の根・事務所の根（00_事務所 の中も）・3_月ごと・月のフォルダ・8_確認事項 に、上の木と「殻が Drive に置く物」の表に無い名がある（月のフォルダの名・確認事項の名と組の外れを含む）。
2. 1_決まり/ に 4 つ以外の物がある（HTML・フォルダ・前の版を含む）。
3. どこかに名が `旧_` で始まる物・`コピー`・`（1）` を含む物がある（字は `芯/字.py` でそろえて照らす＝半角の `(1)`・半角カナ・頭の `Copy of`〔大小を問わない〕の写しも同じ。並びは `道具/寄せ/見回り.py` の `写しの名か` の 1 か所）。
4. 9_履歴/ の `消す_<日>_` の日が過ぎている（赤でなく知らせ）。
5. AI の作業の物（.py・.json・引き継ぎ・配りの見通し・寄せの見通し・消す問い）が Drive にある（口の記録は、決まった名の形でその置き場の直下に在る物だけ外す。同じ名でも置き場が違えば赤）。
6. シートのタブ・見出しが型（§4）と 1 列でも違う・列「会社」が無いか空の行がある。
7. 殻が置く物の名・版が型と違う: 届いた物の名が形に合わない・確認事項の置き場に同じ組・支給月の前の版が残る・配った版と同じか古い版の下書きが残る。

殻は検査へ、会社の根の下（3_月ごと の月のフォルダの中の名まで・8_確認事項 と 9_履歴 の中の名）と 00_事務所 の中の名（`00_事務所/<名>`）を必ず渡す（名だけ・中身は読まない）。

## 3. 確認事項の置き場

### 決めた事
- **聞く相手はいつも事務所の担当者 1 人**。問いは確認事項（1 枚の HTML のページ）で聞く。会社の担当者に直に聞く道は持たない。
- **正本は 質問と回答**。確認事項は質問と回答から道具（`確認ページ/`）が起こす **表示と配る用の写し**。答えは質問と回答に書き戻し、反映先（§9）を書き換えてから使う（ページの上の答えを直に計算に使わない）。
- **配った版の正は URL**（配る口が返す URL）。URL は管理表「確認ページ」に 1 行で載せる（§5）。Drive の HTML は URL の中身の写し。
- 置き場と前の版の行き先は下の「確認事項の置き場の表」の 1 か所。名は `確認事項_<組>_<支給月>_v<版>.html`（初期設定の確認は最初に計算する支給月）。名・版・前の版の移しは §2「殻が Drive に置く物」の `配る手順` だけが決める。配り直したら、前の版は表の「前の版」へ `消す_<移した日の翌月末>_<元の名>` で移し（前の版の file の中身を新しい版で上書きしない）、管理表の前の行の状況を「差し替え」にする（行は消さない）。
- 事務所全体の問い（00_事務所/質問と回答）の確認事項は同じ名の形（会社の所は「事務所」）で、表の「事務所」の行の所に置く。

### 確認事項の置き場の表
置き場と前の版の正本は `初期設定/型.json` の 木.確認事項の置き場（行は `<組>` と `事務所`・道は木の役の並び）。道具（`確認ページ/確認ページ.py`）は `型の口.確認事項の置き場の表()` で読む（置き場を道具にも文書にも写さない）。形が違えば道具は読み込みで止まる。`<組>` は組の名（事務所の設定「会社の一覧」の「組」・会社が 1 つなら会社と同じ字）に置き換える。今の道は `python3 初期設定/型の口.py 木` の「確認事項の置き場」で見る。

- 確認事項の文には中の言葉（殻・段・組・つなぎ・表 A など）を使わない。

## 4. マスタ・台帳・MD の型

### 型の正本は repo の 1 か所
- タブ・列の名と並び・列の意味・選べる値・空の雛形は **repo だけ** に置く（`初期設定/型.json`）。Drive に雛形のフォルダを置かない。
- 新しい会社を始める時も、型を直した時も、Drive のシートは repo の型から起こす・直す。人が Drive の写しから写さない。
- **列の意味は 1 行**（何の値か・値の形・選べる値）。手順・経緯・日付・会社の事情を列の意味に書かない（手順は MD、変わった日は「変更の記録」）。
- シートに説明の行・メモの行を置かない。見出しは型の並びのとおり 1 列も違えない。値は 数・日付（YYYY-MM-DD）・選べる値 だけ。

### マスタ
タブ・列の名と並びの正本は `初期設定/型.json` の マスタ（`python3 初期設定/型の口.py 見出し` で出す）。下の表は役目だけを書き、列を写さない。

全タブの A 列は「会社」。マスタには金額に効く数字と、選べる式のどれを使うかを書く。金額に効く決まりは AI が MD からマスタへ写し、写す時に MD の該当の見出しとマスタの値を照らす。

| タブ | 役目 |
|---|---|
| 社員 | 人の固定の値。値の段は「人 ＞ 勤務の型 ＞ 会社 ＞ 事務所の既定」。**必ず埋める 6 欄**（人の区分・源泉の欄・保険の加入・労働時間の制度・扶養の数・保険料を引く月）が空なら計算しない（`確かめと仮.md` §3）。標準報酬は「保険料の月」で書く |
| 人ごとの支給控除 | 人ごとに決まった額の項目。氏名は人が見て確かめるための写し（計算は NO で引く） |
| 会社 | 会社の項目（会社の項目の辞書）。選べる式のどれを使うかもここ |
| 支給控除の項目 | 項目の性質（どの会社も同じ列）。使う会社の無い項目は持たない |
| 勤務の型 | 勤務の型 |
| つなぎ | 勤怠ツールと給与ソフトでの呼び名（NO が空の行は会社の行）。製品ごとの値の置き場（下） |
| 変更の記録 | 値の変わり目と確かめ（仮／確認済／記録だけ）。マスタの更新（毎月の 1-①）と答えの反映ごとに 1 行 |

前の「例」のタブは持たない。例は給与のルール.md の例の表（下）に置く。

### 台帳（名の形 台帳）
タブ・列の名と並びの正本は `初期設定/型.json` の 台帳（`python3 初期設定/型の口.py 見出し` で出す）。下の表は役目だけを書き、列を写さない。

全タブの A 列は「会社」・B 列は「支給月」。年に 1 本。年の最初の支給月に起こす。パックは前の年の台帳も受ける（月の頭の週・有給の時効・賞与の年度の累計・1 年の変形）。

| タブ | 役目 |
|---|---|
| 読んだままの勤怠 | 原本を読んだまま（1 次）。電子の表は道具の読み口の出力のまま、PDF・手書きは AI が読んだまま。1 人 1 日 1 行 |
| 読んだままの勤怠の区間 | 1 次の区間。1 区間 1 行 |
| 確定した勤怠 | 計算が読む勤怠（2 次）。1 次に原本の読み方の決まりと答えを当てた **事実** だけを直す（数え方の決まり＝丸め・休憩の引き方はパックが当てるので当てない）。1 次と違う行にだけ直した訳を書く: `決まり:<作業のルール.md か給与のルール.md の見出し>`・`問い:<問いの番号>`・`読み直し:<読み直した日 YYYY-MM-DD>`（原本を読み直して読み違いを直した時。1 次は読んだ時の字のまま直さず、2 次に直した値とこの訳を置く） |
| 確定した勤怠の区間 | 2 次の区間 |
| その月だけの指示 | 「この人は今月こう計算して」という指示（その月だけの手当・控除・時間・委託の人の月の値を含む）。1 件 1 行 |
| 人ごとの月の数字 | 人 × 月の数字の正。パックの計算の返りを書く。1 人 1 行 |
| 締めの記録 | 1 段目（材料をそろえる）の終わりの印。全員が `締まった` になるまで計算へ進まない。パックの版は締めた時の計算のパックの版で、その月はこの版で通す（今の版と違えば月を回さない＝`docs/毎月の流れ.md`「パックの版」） |
| 賞与の支給一覧 | 賞与の 1 回の元。パックの版は賞与の回の始めに控えた計算のパックの版で、その回はこの版で通す（今の版と違えば `賞与を回す` が止まる＝締めの記録の パックの版 と同じ照らし）。1 人 1 行。支給月は賞与を払う月（月の給与と同じ字・タブで分ける）。読むのは `月次.賞与の元を読む` だけ（`賞与を回す` へ渡す形に直す。欠け・形の違いは止める＝`月次/README.md`「賞与を回す」）。月の計算は読まない |

- 勤怠の機械の照らし（時刻の抜け・区間の重なり・1 日 24 時間超え・原本に印字された合計との違い・1 次と 2 次の差の行に直した訳があるか）は、確定した勤怠と読んだままの勤怠を並べて当てる。
- 確定した勤怠のシート（人ごとの月の合計と、どう確定させたか）を毎月、事務所の担当者へ渡す。置き場はその月の `2_出す物/` の `確定した勤怠_<会社>_<支給月>_v<n>`（タブ 人ごと・直した所）。名と版は `出口/名と版.渡す名を付ける`（出す物と同じ付け方・前の版は 9_履歴/ へ）、中身と書く手順は `月次/勤怠のシート.作る`（中身は `月次/勤怠の照らし.担当者へ渡す表`）。出荷の口を通らない＝出す前の照らしの物（取り込み・支給控除一覧・有給休暇管理表）には混ぜない。給与エージェントは〔口: 書く手順を当てる〕で当てる。
- **年をまたぐ値**（新しい年の台帳は `月次/年の台帳を起こす.起こす` が前の年の台帳から起こす。返った `書く手順`〔`月次/台帳へ書く.py`〕を給与エージェントが〔口: 書く手順を当てる〕で当てる＝表を手で写さない。1 月支給の出荷の口は新しい年の台帳が既に在るので 起こす を呼ばず、毎月と同じ `前の年の確定した勤怠`〔書く手順なし〕で前の確定した勤怠だけを読む）:

| 何 | 新しい年の台帳へ | 訳 |
|---|---|---|
| 全部のタブの見出し | 型から起こす | 型の正本は repo の 1 か所 |
| 前の年の台帳に在る新しい年の支給月の行（どのタブでも。12 月を回して返った 1 月の その月だけの指示「社保の立て替えの残り」など） | 引き継ぐ（移す） | 行の支給月の年の台帳に置く。写し漏れると 1 月にその人が仮になる |
| 前の年の支給月の 確定した勤怠・確定した勤怠の区間 | 写さない。前の年の台帳に残し、新しい年の 月を回す へ毎月（2〜12 月も）`前の確定した勤怠` として渡す（`年の台帳を起こす.前の年の確定した勤怠` で読む） | 月の頭の週・有給の取得と出勤率 8 割が前の年を読む（同じ物を 2 か所に持たない） |

| 前の年の支給月の 読んだままの勤怠・その区間・人ごとの月の数字・その月だけの指示・賞与の支給一覧 | 写さない | その月だけの物（前の年の台帳に残る） |
| 有給の残りの元（マスタ「社員」の 有給の始めの日・残り・繰越） | 台帳に置かない（マスタのまま）。新しい年の台帳を起こす時に、前の年の 12 月支給の `月を回す` が返す `有給の始めを進める`（12 月の基準の日の付与の残り・関所を通った人だけ）を `月次.有給の始めを進める` の書く手順でマスタへ書く | 新しい年は前の年の台帳までしか読まない＝マスタの値を前の年の台帳の中の日へ進める。12 月の月を回す は今年と前の年の台帳を両方持つ唯一の時。書くのは 1 月に起こす時（12 月の後に書くと 12 月の回し直しの元が動く）。進めない人（仮・付与が 3 つ以上生きている）は 起こす が知らせる |
| 前の年でも新しい年でもない支給月の行 | 止める | どの年の台帳の行か分からない |

- 前の「月の前提」「月の変動」「人ごと」「委託」「作業の記録」のタブは持たない（月の変動・委託→その月だけの指示、人ごと→人ごとの月の数字。月の前提・作業の記録は誰も読まないので消す）。前の形の月（`勤怠` に 種類・出勤・退勤・休憩（分）が在り区間のタブが無い）は今のタブへ移さない（移す口は 2026-11-27 に畳んだ・新しい会社のシートは `初期設定/始める.py` で作り直す）。

### 給与のルール.md の例の表
- 給与のルール.md は決まりごとに見出し（`### <決まりの名>`）・文・例の表を書く。例は決まりの文から作る（過去の結果からは作らない）。
- 例の表の列: 例の番号・決まり・種類（日・月・書けない）・支給月・勤務の型・人の値・日付・日の種類・区間・期待・確かめた日・確かめた人・備考。
- 例の 支給月 は、その例が当たる月（例を確かめた時の決まりの月）。例はその支給月の決まりで解いて照らす。決まりの値は、例の月も回す月も同じ `段の解決.解く`（事務所・会社・勤務の型・人の段と、変更の記録でその月へ戻した人の段）の 1 本で引く。例ごとに、例の人の決まりの値を例の支給月と回す月で、回す月の覆いが求める名と例が 決まり の欄に書いた名について比べる。比べる名・覆う名・止めの文の名は、どれもマスタの項目の名（`芯/設定の表.json` の項目の名）で数える（`段の解決.解く` が 1 つの項目を 2 つの鍵に分ける物＝時間.休憩の表 → 時間.休憩の表・時間.休憩の長さ は、`芯/設定の表.json` の `マスタの項目` で元の項目の名へ戻す＝対応の正本はその 1 か所。止めの文の値もマスタの字で出す）。`段の解決.解く` が 1 つの項目の値を別の名の鍵へ写して作る物＝時間.暦 → 時間.会社の暦 は、`芯/設定の表.json` のその鍵の行の `写す元` に元の項目の名を書く（`マスタの項目` と `写す元` は `項目の外` の行だけに付け、1 つの行に両方は付けない。値はどちらも表に在り `項目の外` でない名。`段の解決.分けて作る鍵`・`段の解決.写して作る鍵` はこの 2 つの欄から引く＝鍵の名を段の解決に字で書かない）。社員のいくつかの列を 1 つの項目にまとめて作る鍵（住民税.6月分・住民税.7月以降 → 住民税.額）は `段の解決.まとめて作る鍵` の 1 か所に置く。`解く` が出す鍵は、その人に置いた名・`マスタの項目` か `写す元` を持つ鍵・まとめて作る鍵・内の鍵（`芯/設定.py` の `内の鍵`＝勤務の型 など。`見当の値` もここ）・`見当の値` に名を出した鍵（見当で埋めたと知らせる）のどれかに限り（`見当の値` に出してよい名は芯が見当を読む名＝`芯/設定.py` の `見当を読む名`〔今は 時間.日の所定〕だけ。ほかの名を出すと `解く` は止める＝芯が読まない見当で人が仮にならず出口へ出る道を作らない）、置いた値を別の値で黙って替えない（`tests/作り物/test_作り物_例の名の空間.py` が、どの項目にも選べる値を全部・ほかの項目は形の見本を、置ける段〔会社・勤務の型・人〕ごとに置いて `解く` を回して照らす）。値の違う名は、その例ではその月の覆いと見分けに数えず、回す月にその名の値が在れば、回す月に当たる例でその名を書いた物を求め、無ければ覆いの外れとして止める。決まり の欄に書いた名がどれも違う値になる例は回す月に当たらない（まだ当たらない・もう当たらない）＝その月は数えずに外す（照らさない・返す物の `当たらない例`）。名を 1 つも書かない例は外さず、例の支給月で照らすが、覆いと見分けには数えない。支給月 が空の日の例は、どの月にも当たる例として回す月で照らす。支給月 が読めない例は止める。覆いが求める値（事務所・会社・勤務の型の段の値と、社員の列の変更の記録で戻した値）と見分けの今の値も、回す月の `段の解決.解く` から取る。回す月に当たる例が 1 つも無ければ止める（例の確かめは通らない）。決まり の欄（例の表の 決まり の升）には、マスタの項目の名（`芯/設定の表.json` の項目の名で `項目の外` でない名）だけを完全に同じ字で `・` で並べて書く（空＝名を書かない例）。見出し（`### <決まりの名>`）は例の行の 見出し に別に持ち、名としては読まない（見出しの括弧の説明を名と取り違えない）。項目の名でない字（綴りの揺れ・括弧の説明・`解く` が分けて作る鍵の名・`項目の外` の名＝時間.会社の暦・住民税.徴収 など）は「例が読めない」で止める（綴りの揺れた名を黙って拾わない・説明は見出しか文へ書く）。
- 例の確かめは、AI が例を人の言葉にして確認事項で聞き（「8:40 出勤・18:00 退勤・休憩 1 時間なら労働 8 時間でよいですか」）、答えた人（誰でもよい。オーナーの決定なら `オーナー`）と日を、確かめた人・確かめた日に書く。確かめた人 は `<答えた人の名>（<確かめの出所>）`（出所の種類・書き方・照らしに渡す証しは `月次/例の確かめ.py` の `出所の種類たち` の表が正本＝ここに写さない。照らしは既定で閉じる＝種類ごとに殻が渡す証し〔質問と回答・決定DB から引いた鍵の並び・照らしの差の表〕に在る物だけ通す。名では照らさない〔質問と回答 に答えた人の列は無い＝番号で照らす〕＝`月次/例の確かめ.py` の `確かめた人を読む` の 1 か所で読む）。事務所の設定に「確かめてよい人」の名簿は置かない（2026-11-19 オーナーの決定・型の版 32 で畳んだ）＝AI が自分で確かめたと書いて人が読んでいない数え方で給与が出るのを、名簿でなく例ごとの出所で防ぐ。
- 毎月の計算の前に、パックが全部の例をその月のマスタの値で計算に通す（給与エージェントが給与のルール.md の字を渡し、パックが `月次/例の確かめ.py` の `MD から例を読む` で例の表を読む）。1 つでも合わない・確かめた日が無い・確かめた人に確かめの出所が無い・`書けない` の例があれば、その会社の月は出さない。給与のルール.md の決め事とマスタの値が同じ事を言っているかを確かめる所はここ 1 か所。

### 書き方を 1 つに固定
- **NO**: 社員のタブの字のまま（0 埋めの有無も会社の原本のまま）。全タブで社員のタブと同じ字にする。
- **支給月**: シートの行は `YYYY.MM支給`、入口・芯の中は `YYYY-MM`、月の置き場の名は `YYYY.MM支給（M月分）`。
- **日付**: `YYYY-MM-DD`。
- **時刻**: `h:mm`（日またぎは 24 を足す）。
- **長さ**: 計算に使う列は整数の分のまま。人が読む要約の列（休憩の合計・労働の合計）だけ `h:mm`。
- **氏名**（台帳・マスタの氏名の列）: 道具（`月次/台帳の形.py`）がマスタ「社員」から NO で引いて書く。行に既に違う氏名があれば書く前に止める。年の台帳（読んだままの勤怠・確定した勤怠・その区間・その月だけの指示・人ごとの月の数字・起こした新しい台帳の引き継ぐ行）へは `月次/台帳へ書く.py` の口が社員を受けて埋めて照らす（空なら埋め・違う氏名・社員に居ない NO・社員の氏名が空 なら止める）。パックが書く手順をまだ返さない行（台帳「締めの記録」・マスタ「変更の記録」）は、給与エージェントが行を足す前に `台帳の形.氏名を埋める(鍵, 行たち, 氏名)` を通す（手で書かない）。
- 書き方の検査は、シートを表示形式の値ではなく書いた字（`9:00`・`2026-10-01`）で読む前提（Sheets の表示形式で `9:00:00` などに見える列は、ずれとして赤になる＝セルを字の書式にそろえる）。
- 置き場の検査（§2）が、支給月・日付・時刻の書き方のずれを赤で知らせる。

### 式を書いてよいか
- **マスタ・台帳には式を書かない**（値だけ）。値は給与エージェントが書き、パックは値だけを受ける。式があると、給与エージェントが読む値と人が見る値の出所が二重になる。
- 式を書いてよいのは **人が見るだけの物**（管理表の見る用のタブ）だけ。AI はそれらを読まない（読む時は式の元の表を読む）。

### 製品ごとの値の置き場（勤怠ツール・給与ソフト）
パックは特定の製品（勤怠ツール・給与ソフト）の名と形を持たない（⟦鍵:給与計算/パックに製品ごとの物を置かない⟧）。製品ごとの値は事務所の Drive の次の 2 か所（2_マスタ「つなぎ」「支給控除の項目」と 00_事務所/事務所のルール.md）だけに置き、給与エージェントが読んでデータとしてパックへ渡す。

| 値 | 置き場 | 書き方 | 殻が渡す先 |
|---|---|---|---|

### MD の形
- 人は MD を読まない。MD の形は AI が決める（AI が読みやすい形）。中身は、AI が確認事項で人の言葉にして聞く時だけ確かめてもらう。
- 決まっているのは、給与のルール.md の決まりごとの見出し（`### <決まりの名>`）と例の表の列（上）だけ（パックが例の表を読むため）。
- 金額に効く数字は MD に書いてよいが、計算はマスタの値だけを読む。写す時に MD の見出しとマスタの値を照らす。

## 5. 状況の正本 1 つ（事務所の管理表の型）

### 決めた事
- **状況の正本は `00_事務所/管理表` の 1 本**。全社の月の状況・前の目次「月の状況」・給与計算 管理表「全社_予定と進み」・UTC の Notion のタスクの給与の状況の列を、ここ 1 つにする。UTC の Notion のタスクは次に動く人と窓の引き継ぎを持ち、計算の状況は管理表の行へのリンクで指す（同じ物を 2 か所に持たない）。
- 管理表の型も repo の `初期設定/` に置く（段階 2 の `管理表/` が読み書きの口を作る）。
- **今の例外（型の正本が 3 つ）**: 今は型の file が `初期設定/型.json`（マスタ・台帳・質問と回答・事務所の設定）・`管理表/型.json`（管理表）・`有給/型.json`（2_出す物 の有給休暇管理表）の 3 つに分かれ、版も別々に数える。§4 の「repo の 1 か所」と食い違う間の決まり: 同じシートのタブ・列を 2 つの file に書かない（各 file は自分のシートだけを持つ）。畳む段取り: `管理表/型.json`・`有給/型.json` の中身を `初期設定/型.json` のシートとして移し、版を 1 つに合わせる（殻の渡す形が変わる＝型の版を上げる PR で、`有給/` を触る窓が無い時に 1 本で）。

### 管理表のタブ
**「月の状況」**（会社 × 支給月で 1 行・月の給与の回だけ）

| 列 | 意味 |
|---|---|
| 会社 | 会社の呼び名 |
| 組 | その会社の束（会社が 1 つなら会社と同じ） |
| 支給月 | `YYYY.MM支給（M月分）` |
| 原本 | 空／済／止まり（全員の勤怠が締まったら済） |
| 集計 | 空／済／仮／止まり |
| 取り込み | 空／済／仮／止まり（事務所の給与ソフトへ渡すデータ） |
| 計算 | 空／済／仮／止まり（こちらで最後まで計算した結果） |
| 確認ページ | 空／お答え待ち／お答えいただいた |
| 納品 | 空／済 |
| 外した人 | 仮が残り出口から外した人の数（0 でないと取り込み・納品は済にしない） |
| 突き合わせ | 給与ソフトとの人×項目の差が続けて 0 の月の数（下の「突き合わせの記録」から `管理表/突き合わせの記録.py` が数えて書く＝読み返さない） |
| 止まりの理由 | 1 行 |
| タスクへのリンク | 次に動く人と引き継ぎを持つタスクの URL |
| 更新日 | YYYY-MM-DD |

**「賞与の状況」**（会社 × 支給月で 1 行・賞与の回だけ）

月の状況と同じ列から 集計・突き合わせ を除いた物（会社・組・支給月・原本〔賞与の支給一覧がそろったか〕・取り込み・計算・確認ページ・納品・外した人・止まりの理由・タスクへのリンク・更新日）。
同じ会社・同じ支給月に月の給与と賞与がある時も、月の給与は「月の状況」、賞与はこのタブの別の行に書く（賞与を書いて月の給与の行を上書きしない）。
どのタブに書くかは回（月・賞与）で決まり、管理表の型の「回」から `管理表.py` の `回のタブ` が引く。行を起こすのは書く窓（出荷の口）＝賞与は払う会社・月だけに起きるので事務所の段が毎月起こさない。

**「突き合わせの記録」**（会社 × 支給月 × 回で 1 行・月の給与も賞与も）

給与ソフトとの突き合わせ（`確かめと仮.md` §2）の回ごとの記録。続けて差 0 の月数を数える元の正本（数だけでは賞与の回・抜けた月・場面が分からない＝月の状況の「突き合わせ」は読み返さない）。列: 会社・組・支給月（`YYYY.MM支給`）・回（月／賞与）・突き合わせた人・差の行・外した人・給与ソフトが違うで閉じた・場面・差0の月（はい／いいえ）・続けて差0の月数・まだ見ていない場面・更新日。行を起こすのは書く窓（〔口: 突き合わせ〕＝`管理表/突き合わせの記録.py` の `書く手順` が返す手順だけ）。前の回を突き合わせ直した時は、口がその回より後の回の数も記録から数え直して書く。管理表は事務所に 1 本＝年をまたいで数える（年の台帳には置かない）。

**「確認ページ」**（配った版 1 つで 1 行）

| 列 | 意味 |
|---|---|
| 載せた日 | YYYY-MM-DD |
| 会社 | 会社の呼び名（束の全社に向けた時は束の名） |
| 支給月 | その答えを初めて計算に使う支給月（月に紐づかない物は「全社の決まり」） |
| 何の確認か | 立ち上げ／毎月 |
| 何のための質問か | 事実だけを 1 行 |
| 問いの数 | 数 |
| 確認ページ | URL（配った版の正） |
| 答えていただいた日 | YYYY-MM-DD |
| 答えた方 | 役目の名 |
| 状況 | お答え待ち／お答えいただいた／差し替え |

### 他の表は式で引くか畳む
- 全社の月の状況・給与計算 管理表「全社_予定と進み」は管理表「月の状況」に寄せて畳む。
- UTC の Notion のタスクは給与の状況の列だけを畳む。タスクは次に動く人と窓の引き継ぎを持ち、計算の状況は管理表の行へのリンクで指す。
- 列「タスクへのリンク」はタスクを指すだけ（タスクの状態は管理表へ写さない）。

### 顧客の窓が全顧客の行に書かない仕切り
- 管理表へ書くのは給与エージェントの **管理表の書く口** だけ。口は窓が受け持つ会社を受け取り、その会社の行（鍵＝会社 × 支給月〔月の状況・賞与の状況はタブで回を分ける〕、確認ページは鍵＝会社 × 載せた日 × URL）だけを書く。他の会社の行・見出し・他のタブには書かない（口が拒む）。回（月・賞与）を渡した書き方は、その回のタブの外へ書かない（口が拒む）。
- 書く時は鍵で行を探して書く（行の位置で書かない）。行が無ければ足す。行を消さない。
- 月の状況の 会社 × 支給月の行を起こすのは事務所の段（管理表の道具）だけ。賞与の状況の行は書く窓が起こす（組は口が会社の組を書く）。

- 取り込みの列は事務所の物（給与ソフト）で決まるので、マスタの型に置かず出口の側（§4「製品ごとの値の置き場」）に置く。

## 8. 置き場の ID を持つ所を 1 か所に

### 決めた事
- 会社の物の ID は **`00_事務所/事務所の設定`「置き場」タブだけ** が持つ。列は 顧客ID・会社・組・物・ID。物の名の正本は `初期設定/型.json` の 木.置き場の物（会社の根 は字のまま・ほかは 木 の名。ここに並べ写さない）。台帳だけは年ごとの名（`台帳_<YYYY>`）で書き、型の字 `台帳_<支給年>` は書かない。

## 9. 確認事項の答えの行き先

答えは必ず反映先を書き換えてから使う。反映の前に、同じ反映先の前の答えと照らし、食い違えば問いにする（黙って上書きしない）。反映したら質問と回答の「反映済み」を書き、反映の照らし（`設問.反映の照らし`）でマスタ・MD・確定した勤怠に反映したかを照らす。

| 問いの種類 | 書き換える先 |
|---|---|
| 会社の決まり（割増・欠勤控除・手当・取り込みの形など） | 給与のルール.md。金額に効く物はマスタ（「会社」「支給控除の項目」「勤務の型」「つなぎ」）へも写す |
| 原本の読み方 | 作業のルール.md |
| その人だけの決まり | 人のルール.md。数字はマスタ「社員」 |

## 10. 前の形から畳む物

今の Drive は寄せる道具で新しい形へ移す（下の表の前の名→新しい名は直し 30 の「前の置き場を止める」が持ち、寄せが値と来歴を持ったまま移す。後が月で決まる名・移す先が既に在る名だけ寄せが止まり、手で移す）。まず Javis 側で回し、UTC 側も同じ形に直す。移した後に、前と新しい形の続きの値（有給の残り・住民税・答え済みの問い）を照らす（使い捨て）。

| 前の形 | 新しい形 |
|---|---|
| `01_ルール/` | `1_決まり/` |
| `02_初回の書類/` | 最初の支給月の `1_届いた物/` に `書類_` |
| `03_マスタ`（8 タブ・「例」を含む） | `2_マスタ`（7 タブ）。例は給与のルール.md の例の表 |
| `04_台帳_<支給年>`（勤怠・勤怠の区間・月の前提・月の変動・人ごと・委託・作業の記録） | `台帳_<支給年>`（§4 のタブ）。前の月の勤怠は移さない（前の台帳の月を移す口は 2026-11-27 に畳んだ・新しい会社のシートは `初期設定/始める.py` で作り直す。月の変動は寄せの毎回の読み〔`計算の形.py` の 11〕が その月だけの指示 へ写す） |

事務所の設定「置き場」の表は事務所の段で 1 回移す（§8 の口 `置き場の登録を移す`・顧客ID を足し・台帳を年ごとの行に分ける）。会社の段の寄せが置き場の物を移した時は、寄せが置き場の行を書く手順も返す（§8）。

### 確かめ方（本物の 1 社ずつ）
1. 置き場の検査（§2 の 6 つ）が赤 0。
2. 移す前の Drive の写しと移した後の Drive から、同じ支給月を同じパックで計算し、**人 × 項目** を突き合わせて差が 0（差が出たら、移しの漏れか、前の形の誤りかを問いにする）。
3. 続きの値（有給の残り・住民税・答え済みの問い）が前と同じ。
4. 管理表「確認ページ」の URL が、前に配った確認ページの URL を全部持つ。

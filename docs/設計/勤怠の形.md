# 勤怠の形

- 書く中身: 表 A「日」・表 B「区間」・月の数字の口・芯の境目（入口／芯／出口）

## 0. この紙が決めること

勤怠の入口（原本・勤怠ツール）がどれでも、同じ **1 人×1 日の記録**（表 A「日」と表 B「区間」）になる。芯はこの 2 表から月の数字を出し直す。
向きは 1 つだけ: **入口 → 表 A・B → 芯 → 出口**。表 A・B が入口と芯の唯一の境目で、月の合計しか無い顧客だけは 5 節の「月の数字の口」から入る。

決め打ちしない物: 夜勤・半休・休日出勤・休憩・中抜けの **数え方**（どちらに揃えるか）は会社の決まり（B2）。この紙は、どの数え方を選んでも表 A・B から出せるだけの事実（時刻・種類・単位・相手の日）を残す。

共通の値の形:

| 形 | 書き方 | 例 |
|---|---|---|
| 月 | `YYYY-MM` | `2026-11` |
| 日付 | `YYYY-MM-DD` | `2026-11-03` |
| 時刻 | `h:mm`。その行の日付の 0:00 から数える。日またぎは 24 を足す（0:00〜47:59） | `8:30`・`26:15` |
| 時間・分 | 整数の分 | `480` |
| 日数 | 0.5 刻みの数 | `1`・`0.5` |
| 印・複数の値 | 読点「、」で区切る | `遅刻、手で直した` |
| 空 | 何も書かない（`0` と別の意味を持つ列がある。列ごとに書く） | |

## 1. 表 A「日」（1 人×1 日＝1 行）

鍵: 支給月・会社・NO・日付。同じ鍵の行は 1 つだけ（組が複数ある日も 1 行。組は表 B に並べる）。
**期間の全部の日に 1 行**置く（休日も置く）。原本に書かれていない日も置き、日の種類は会社の暦（会社の決まり）で休日なら「休日」、そうでなければ「欠勤」として 読み取りの確かめ＝要確認・印＝原本に無い（仮の値。⟦鍵:給与計算/足りない時は仮で計算し出さない⟧）。

| 列 | 意味 | 必須 | 値の形・選べる値 |
|---|---|---|---|
| 支給月 | この日を数える給与の月 | 必須 | 月。締めの期間は会社の決まり |
| 会社 | 会社の鍵（Drive の会社の鍵と同じ） | 必須 | 字 |
| NO | 社員の番号（マスタの NO） | 必須 | 字。入口が原本の名からマスタで引く。引けない時は空にせず要確認 |
| 勤怠の表記 | 原本に書かれた人の名（照らす用） | 必須 | 原本の字のまま |
| 日付 | **勤務が始まった日**（日またぎの勤務も始まった日の 1 行） | 必須 | 日付 |
| 日の種類 | その日が何の日か（1 つだけ） | 必須 | `勤務`／`休日勤務`／`休暇`／`欠勤`／`休日`／`休職・休業` |
| 休日の区分 | 休日・休日勤務の日の区分 | 日の種類が休日・休日勤務の時 | `法定`／`所定`／空（空＝芯が会社の決まりで決める） |
| 休暇の種類 | 休んだ分の種類 | 休暇の単位がある時・日の種類が休職・休業の時 | `年休`／`特別休暇（有給）`／`特別休暇（無給）`／`子の看護等休暇`／`介護休暇`／`生理休暇`／`代休`／`出勤扱い`。日の種類が休職・休業の時は `会社都合の休業`／`産前産後休業`／`育児休業`／`介護休業`／`休職` |
| 休暇の単位 | どれだけ休んだか | 休暇の種類がある時 | `全日`／`午前半休`／`午後半休`／`時間` |
| 休暇の時間 | 時間単位で休んだ分 | 単位が `時間` の時 | 分 |
| 勤務の型 | その日の勤務の型（会社の決まりの勤務の型の一覧の鍵） | 任意 | 字。空＝会社の既定の型 |
| 所定の始業 | その日の所定の始め（シフト・変形の時） | 任意 | 時刻。空＝勤務の型の既定 |
| 所定の終業 | その日の所定の終わり | 任意 | 時刻（日またぎは 24 を足す） |
| 所定時間 | その日の所定労働時間（変形の日ごとの所定） | 任意 | 分。空＝勤務の型の既定 |
| 働いた場所 | どこで働いたか | 日の種類が勤務・休日勤務の時 | `事業所`／`在宅`／`直行直帰`／`出張`／`みなし`（事業場外のみなし。時刻を使わず所定かみなしの時間で数える） |
| 印 | 原本が示す事実・入口が見つけた事実 | 任意 | `遅刻`／`早退`／`定時扱い`／`打刻抜け`／`二重打刻`／`手で直した`／`原本に無い` を読点で |
| 遅延証明の分 | 遅刻のうち交通の遅れなどで証明がある分 | 任意 | 分 |
| 振替の相手の日 | 振り替えた先・元の日（両方の行に互いを書く） | 振替の時 | 日付 |
| 代休の相手の日 | 代休の行に、その元の休日勤務の日 | 休暇の種類が代休の時 | 日付 |
| 申請の残業 | 申請・承認された残業（照らす用・会社の決まりで境に使う） | 任意 | 分 |
| 時刻の無い休憩 | 時刻が分からない休憩の長さ | 任意 | 分。**空＝書いていない**（芯が会社の決まりの休憩の表で置く）／**0＝取っていない**。表 B に休憩の区間がある日は空 |
| 時刻の無い労働時間 | 時刻が無く長さだけ分かる労働 | 任意 | 分。表 B に労働の区間がある日は空 |
| 所属 | その日の所属（部門・事業所。按分や手当に使う） | 任意 | 字。空＝マスタの所属 |
| 原本の時間 | 原本・勤怠ツールが自分で出した日の時間（**照らす用・計算に使わない**） | 任意 | `語=分` を読点で。語は 5 節の項目の語（例 `総労働=480、法定外残業=60、深夜=0`） |
| 原本の名前 | どの原本から読んだか | 必須 | 字（file の名） |
| 原本の種別 | 原本の形 | 必須 | `PDFタイムカード`／`Excel出勤簿`／`勤怠システムの月報`／`集計済み勤怠表`／`メールとメモ` |
| 読み取りの確かめ | 読んだ値を確かめたか | 必須 | `確認済`／`要確認`（要確認が 1 つでも残る人は仮。出口へ出さない） |
| 備考 | 原本の字（読んだまま。道具はここを読まない） | 任意 | 字 |

決まり:
- **日の種類は 1 つだけ**。勤務した日に半休を取ったら 日の種類＝`勤務`・休暇の単位＝`午前半休` で 1 行（半休を種類にしない）。
- 日の種類が `勤務`・`休日勤務` なら、表 B に労働の区間があるか、時刻の無い労働時間があるか、働いた場所が `みなし` のどれか。
- 振替休日は休暇でなく休日: 振り替えて休んだ日＝日の種類 `休日`、振り替えて働いた日＝日の種類 `勤務`（休日勤務にしない）。両方の行に振替の相手の日を書く。代休は休暇（休日勤務はそのまま休日勤務）。
- 看護・介護・生理の休暇が有給か無給かは会社の決まり（行に書かない）。特別休暇だけは会社ごとに種類が多いので行に有給・無給を書く。

## 2. 表 B「区間」（1 人×1 日×区間 n 行）

鍵: 支給月・会社・NO・日付・区間の番号。日付は表 A の行の日付（勤務が始まった日）。

| 列 | 意味 | 必須 | 値の形・選べる値 |
|---|---|---|---|
| 支給月・会社・NO・日付 | 表 A の行を指す | 必須 | 表 A と同じ |
| 区間の番号 | その日の中の順 | 必須 | 1 から |
| 区間の種別 | 何の時間か | 必須 | `労働`／`休憩`／`外出`（私用で抜けた時間） |
| 始め | 区間の始め | 必須 | 時刻（日付の 0:00 から。0:00〜47:59） |
| 終わり | 区間の終わり | 必須（打刻抜けの時だけ空） | 時刻。日またぎは 24 を足す（例 `22:00`〜`30:00`） |
| 時刻の出所 | その時刻をどこから得たか | 必須 | `打刻`／`手書き`／`申請で直した`／`所定で埋めた` |

決まり（入口が出す時・芯が受ける時の両方で見る形の検査）:
- 始め＜終わり。労働の区間どうしは重ならない。休憩・外出の区間は労働の区間の中にある。
- 終わりが空なら表 A の印に `打刻抜け`・読み取りの確かめ＝要確認。`所定で埋めた` 時刻も要確認（仮の値）。
- 次の日の 0:00 を越えても行を分けない（日付は始まった日）。暦日・法定休日・深夜帯で切るのは芯（時刻が全部残っているので切れる）。
- 二重打刻は入口が 1 つに寄せ、表 A の印に `二重打刻` を書く（捨てた打刻は備考に原本の字で）。

## 3. 表 A・B に入れない物

- **勤怠ツールの名と列名**: 原本の種別と原本の名前だけを書く。ツールごとの列の読み替えは入口の中（`入口/`）に閉じる。
- **曜日**: 日付から出す。
- **芯が出す値**: 深夜・残業（法定内・法定外・60 時間超）・法定休日の時間・週 40 時間超・所定内・遅刻早退の分。これらは芯が表 A・B から出す。原本が出した値は「原本の時間」に照らす用として置くだけで、計算に使わない。
- **数え方の選択**: 夜勤を何日と数えるか・半休の日を出勤何日と数えるか・休日の深夜・残業の境・中抜けを休憩と見るか。これらは会社の決まり（B2）に置く。
- 顧客ごとの勤務の型の名・会社の暦は会社の決まり（各事務所の Drive）。表 A は鍵で指すだけ。

## 4. ずれていた 5 つを表 A・B でどう持つか

今の Javis 側の台帳「勤怠」は 1 行＝1 人×1 日×出勤退勤の 1 組・11 列で、「種類」の列に `勤務／夜勤／有給／半休／欠勤／休日出勤` を混ぜている。UTC 側の台帳も同じ元から分かれており、同じ所で意味がずれている。

### 4-1. 夜勤
- 今: 種類＝`夜勤`。退勤≦出勤なら +1440 分（`timecard_tally.py:108`）。「夜勤の数え方」が 夜勤 1 回＝2 日 なら出勤 2 日・残業の境は所定×2（`:384,416`）。
- 表 A・B: 日の種類＝`勤務`、日付＝始まった日、表 B の労働の区間の終わりに 24 を足す（例 `21:00`〜`33:00`）。夜勤かどうかは勤務の型と区間から芯が知る。
- どちらの数え方も出せるか: 1 回＝1 日・1 回＝2 日・暦日で 2 日に分ける のどれも、始めと終わりの時刻が全部あるので芯が出せる。夜勤の回数（手当の数）も区間から数えられる。深夜帯（22:00〜5:00）の重なりも 24 を足した時刻のまま切れる。

### 4-2. 半休で勤務ありの日
- 今: 種類＝`半休` に組があれば 有給 0.5＋出勤 0.5、実働・残業・深夜も数える（`:401`）。組が無ければ有給 1 日＋要確認。
- 表 A・B: 日の種類＝`勤務`、休暇の種類＝`年休`、休暇の単位＝`午前半休`／`午後半休`、表 B に働いた区間。組の無い半休だけの日は日の種類＝`休暇` で、残りの半日は芯が要確認にする。
- どちらの数え方も出せるか: 出勤 0.5＋年休 0.5 も、出勤 1＋年休 0.5 も、どちらも日の種類と単位から出せる。残業の境（半休の分を労働に足すか）も、休んだ分と働いた区間が別に残るので選べる。

### 4-3. 休日出勤
- 今: 種類＝`休日出勤` は休出日数＋1・休出時間＋＝実働で continue＝残業・深夜・週 40 時間に足さない（`:403-406`・休出日の深夜が落ちている疑い）。法定休日は「法定休日の曜日」で別に判定（`:324,388`）。
- 表 A・B: 日の種類＝`休日勤務`、休日の区分＝`法定`／`所定`／空、表 B に区間。
- どちらの数え方も出せるか: 法定休日の勤務は法定休日の時間、所定休日の勤務は週 40 時間に入れて法定外残業へ、の両方とも区分から出せる。区分が空なら芯が会社の決まり（曜日・4 週 N 休の起算日・週の最後の休日など）で決める。休日の深夜は区間の時刻から必ず出る（形の上で落とせない。深夜の割増は休日でも要る）。

### 4-4. 休憩
- 今: 台帳の休憩（分）はいつも引き、「休憩の表」の時刻と長さの休憩を足す（`:359-374`）。深夜帯の休憩は 11 列の外の「深夜の休憩（分）」を道具（`:11,377`）と `型.json:1821` が読む。
- 表 A・B: 時刻のある休憩は表 B の `休憩` の区間。時刻の無い休憩は表 A の時刻の無い休憩（空＝書いていない／0＝取っていない）。同じ日に両方は置かない（形の検査）。
- どちらの数え方も出せるか: 書いた休憩だけを引く・会社の休憩の表で補う、の両方を芯が選べる。空と 0 を分けたので「書いていないから表で補う」と「取っていない（法の最低の休憩の検査に出す）」を取り違えない。深夜帯の休憩は時刻があれば区間で、無ければ休憩の表の時刻で芯が置く（深夜の休憩の列は要らない）。

### 4-5. 1 日に打刻の組が複数ある日
- 今: 1 行＝1 組。同じ人×日をまとめ、組を足し休憩を合計（`:100,109`）。種類が 2 つなら前の行で数え要確認（`:101`）。
- 表 A・B: 表 A は 1 人×1 日＝1 行（日の種類は 1 つ）、組は表 B の労働の区間 n 行。
- どちらの数え方も出せるか: 組の間（中抜け）を休憩と見るか、ただの非労働と見るかを芯が選べる（間の時刻が全部ある）。種類のぶつかりは形の上で起きない。

## 5. 月の数字から入る口（月の合計しか無い顧客）

日の記録が無く、月の合計しか無い顧客の正式な口。今は「無い」。
1 行＝1 人×1 項目の縦の形。**項目の語は芯の 日→月 が出す語と同じ**（6 節）。決まった語の外は置かない。

| 列 | 必須 | 値の形 |
|---|---|---|
| 支給月・会社・NO・勤怠の表記 | 必須 | 表 A と同じ |
| 項目 | 必須 | 下の語だけ |
| 値 | 必須 | 項目の単位で |
| 原本の名前・原本の種別・読み取りの確かめ・備考 | 原本の名前・種別・確かめは必須 | 表 A と同じ |

| 項目 | 単位 | 意味 |
|---|---|---|
| 所定日数 | 日 | その月の所定労働日数 |
| 出勤日数 | 日 | 勤務した日（休日勤務を除く） |
| 休日勤務日数（法定） | 日 | |
| 休日勤務日数（所定） | 日 | |
| 年休（全日） | 日 | |
| 年休（半日） | 回 | |
| 年休（時間） | 分 | |
| 特別休暇（有給） | 日 | |
| 特別休暇（無給） | 日 | |
| 欠勤 | 日 | |
| 休業 | 日 | 休職・休業の日（理由ごとに行を分けない時は会社都合の休業） |
| 総労働 | 分 | 実際に働いた時間の全部（休暇の時間を入れない） |
| 所定内 | 分 | 総労働のうち所定の中 |
| 法定内残業 | 分 | 所定を越え法定（日 8 時間・週 40 時間）の中 |
| 法定外残業 | 分 | 法定を越えた分（法定休日の時間を除く） |
| 60 時間超 | 分 | 法定外残業のうち月 60 時間を越えた分（内数） |
| 深夜 | 分 | 22:00〜5:00 に働いた分（内数。どの時間とも重なる） |
| 法定休日 | 分 | 法定休日に働いた分 |
| 所定休日 | 分 | 所定休日に働いた分（内数。所定内・残業に入っている） |
| 遅刻早退 | 分 | |
| 夜勤の回数 | 回 | 日またぎの勤務の回数（手当の数） |
| 年休を取った日 | 日付 | 1 日 1 行（値に日付。年 5 日の取得の管理に使う） |

足し算の決まり: 総労働＝所定内＋法定内残業＋法定外残業＋法定休日。60 時間超・深夜・所定休日は内数。

この口ではできなくなる検査（芯は月の数字の口から来た人に、これらを「できない」と印して出す。黙って通さない）:
- 日 8 時間・週 40 時間の出し直し（法定内と法定外の分け目の確かめ）
- 深夜と休憩の重なり
- 変形労働時間制の三段（日・週・期間）の時間外
- 休日が週 1 日（4 週 4 日）あるか
- 打刻の抜け・二重打刻
- 日の和と月の値の突き合わせ（日の記録が無いので月の値をそのまま受ける）
- 法定休日の日の特定（休日勤務日数と法定休日の分を受けるだけ）

## 6. 芯の境目

| 層 | 受ける | 返す | 置き場 |
|---|---|---|---|
| 入口 | 原本・勤怠ツールの出力 | 表 A・B（月の合計しか無い時は 5 節の口） | `入口/`（B9） |
| 芯 | 表 A・B（または 5 節の口）・会社の決まり・マスタ・法の表 | 月の数字（5 節の語）→ 支給控除一覧 | `芯/集計/`（B8）・`芯/計算/` |
| 出口 | 支給控除一覧 | 給与ソフトの取り込み・確かめの形 | `出口/`（B10） |

- **境目は表 A・B の 1 つだけ**。今の「境目は台帳」と書きながらコードの境目が取り込み入力（`timecard_tally` の main `:252-536` が出し、`kyuyo_calc.py` が読む）になっている二重の境目をなくす。勤怠の解釈（夜勤・法定休日・休憩・残業の境）は手伝いの道具でなく芯の中に置く。
- **芯は日から出し直す**。原本や勤怠ツールが日ごとに出した総労働・残業・深夜は表 A の「原本の時間」に照らす用として置くだけで、月の数字は芯が表 A・B から出す。UTC 側は今、ある勤怠ツールが日ごとに出した総労働・残業・深夜をそのまま使い、そのツールの人とタイムカードの人で時間外の定義が 2 つあり、総労働に有休の時間が入っている（計画の正本の要約）。表 A・B ではどの入口の人も同じ区間から 1 つの定義（会社の決まり）で出し、有休の時間は休暇の時間として総労働の外に置く。
- **芯の 日→月 が出す語＝5 節の口の語**。月の数字の口から来た人は、日→月 を飛ばして同じ語の所から芯へ入る。語が 1 つなので出口・確かめも 1 つの形を見る。
- 芯は Drive を開かない。表 A・B と会社の決まりを受け取り、月の数字と支給控除一覧を返すだけ（Drive の読み書きは各エージェントの repo＝環境の口）。
- 要確認が残る人・所定で埋めた時刻がある人は仮で最後まで計算し、見当と確認の 1 問を出す。出口へは出さない（`docs/設計/確かめと仮.md`・B5）。

確かめ方: 段階 3 で本物の 1 社ずつ、入口 → 表 A・B → 芯 の月の数字を、その月の給与ソフトの実績と **人×項目** で突き合わせる（突き合わせの道具は開発の道具・B5。芯に入れない）。合わない所は (a) 入口の読み (b) 表 A・B が持てない事実 (c) 会社の決まりの選択 のどれかに分け、(b) だけをこの紙の直しにする。

## 7. 段階 2 で畳む物と渡し

畳む物（段階 2・3 で消す。切り替えや古い形の読み替えは残さない）:

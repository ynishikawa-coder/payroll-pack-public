# 法の表

- 書く中身: 1 つの形・効く月の範囲で引く・11 月に来年分を見る検査・毎年の入れ直し・表の一覧と 2027 年分の状態・段階 2・3 で畳む物

法の表は、国が決めて国が出す数字（源泉の税額表・保険の率・等級・最低賃金・控除の段など）の置き場である。
顧客の物ではない（どの事務所・どの会社でも同じ）ので、このパックの `法の表/` に置き、両方の窓が同じ物を引く。
健康保険組合の率・基金の掛金・住民税の特別徴収税額のように **会社や人ごとに違う物は法の表に置かない**（顧客の物＝各事務所の Drive）。

## 1. 1 つの形

### 1.1 表ごとに 1 ファイル

`法の表/<表の名>.json` に 1 つの表を置く。年でファイルを分けない（`rates/<年>/` のような dir を作らない）。
年が替わったら、同じファイルに **行を足す**。

```jsonc
{
  "表の名": "雇保の率",            // ファイルの名と同じ
  "基準": "締め日",                // 月分 | 支払日 | 締め日 | 年分 | 労働した日
  "単位": "‰（1,000 分の）",
  "引く鍵": ["事業の種類"],         // 都道府県・制度など。無ければ []
  "欠けた時": "仮で計算し問う",     // 止める | 仮で計算し問う（§2.2）
  "行": [
    {
      "鍵": {"事業の種類": "一般"},  // 引く鍵の値。空 {} はどの鍵にも当たる
      "効く始め": "2026-04-01",      // 基準の粒で書く（月分は YYYY-MM・年分は YYYY）。null は「この出典に無い」
      "効く終わり": "2027-03-31",    // null は「終わりが決まっていない」。同じ鍵で後に行がある行には使わない
      "状態": "出た",                // 出た | まだ | 未起こし
      "値": {"労働者‰": 5, "事業主‰": 8.5, "計‰": 13.5},
      "出典": {"URL": "…", "ファイル": "…", "sha256": "…", "照らした元": "…", "取った日": "2026-11-11"}
    },
    {"鍵": {}, "効く始め": "2027-04-01", "効く終わり": null, "状態": "まだ", "値": null,
     "例年の時期": "2〜3 月に告示", "出典": null}
  ]
}
```

- **行の 4 つ**: 効く始め・効く終わり（どちらも「基準」の粒）・値・出典。出典は URL・ファイル名・取った日を必ず持ち、ファイルを取った物は sha256 も持つ。
- **基準の 5 つ**: 同じ「2027 年 3 月」でも、表によって何の日で替わるかが違う。表が自分の基準を 1 つ持つ。
  - 月分（社保の率・等級。何月分の保険料か）
  - 支払日（源泉の税額表。支払う日がその年か）
  - 締め日（雇保。賃金の締め日がその年度か）
  - 年分（年末調整の控除の段）
  - 労働した日（最低賃金。発効日から）
- **状態の 3 つ**: `出た`（国が出し、値を入れた）・`まだ`（国が出していない。値は null、例年の時期を書く）・`未起こし`（国は出しているが、まだ起こしていない）。
- **値の中の数字**: 率は `率%` のように単位を名に付け、10 進の数で書く。読む側は 10 進で読む（Python なら `parse_float=Decimal`）。
  等級の上限・下限、税額表の区間の境、端数の決まりの文も **値に持つ**（コードに書かない）。
- **数字は国の原本からだけ**。民間の解説の値・推測の値は入れない。入れられない物は `まだ` か `未起こし` の行にして、値は null。

### 1.2 引く口

```
引く(表の名, 基準の日, 鍵…) → 値 | 欠け
```

- 鍵が合い（行の `鍵` の全部が引く側の鍵と同じ）、`効く始め ≦ 基準の日 ≦ 効く終わり` の行を 1 つ選ぶ。比べる時は基準の日を行の粒に切る（`2027-03-15` を月分の行と比べる時は `2027-03`）。
- 当たる行が無い、または当たった行が `まだ`・`未起こし` → **欠け**。
- 2 行に当たったら表の誤り（行の範囲が重なっている）。引く口は落ちる。
- 同じ鍵の行どうしの範囲は重ねない。後に行（`まだ` の行も）を足す時は、前の行の `効く終わり` をその前の日（月・年）で閉じる。`効く終わり: null` は同じ鍵で一番後の行だけに使う（引く口は null を「次の行の前で切る」とは読まない＝読み方を 1 つにする）。
- 引く口は芯の計算（`芯/計算/`）が持つ。今は `tests/法の表/test_国の例.py` に試験だけの小さな写しがある。

## 2. 効く月の範囲で引く

### 2.1 年で切らない

- 引く側は「何年の表」と言わない。「この基準の日に効く行」を引く。
- 年をまたぐ表（協会けんぽ 3 月分〜翌 2 月分・雇保 4/1〜翌 3/31・最低賃金 10 月ごろ〜翌 9 月ごろ）も 1 行で書ける。
- 改定が年の途中に来る物（厚年の等級の上限 2027-09 分から）は、そこで行を分ける。

### 2.2 欠けの時

欠けは「国がまだ出していない」か「起こしていない」である。**前の行の値で代えない**（代えてよいかは表ごとに違い、黙って代えると誤った額が出る）。
表ごとに次の 2 つのどちらかを `欠けた時` に書く。

| 欠けた時 | 何をするか | 使う表 |
|---|---|---|
| 止める | その人のその項目を計算しない。確認の 1 問を出す | 源泉の税額表 4 つ・標準報酬月額・厚年の率・標準賞与額の上限・年調の控除の段（前年で代えると毎年変わる額がずれる。税額表は R9 と R10 で必ず変わる） |
| 仮で計算し問う | 直前の `出た` 行の値で **仮** として計算し、見当と確認の 1 問を出す。仮が残る人は取り込み・納品に出さない ⟦鍵:給与計算/足りない時は仮で計算し出さない⟧ | 協会けんぽ・介護・支援金・拠出金・雇保・労災・最低賃金（国の公表を待つ間も計算は回したい。率の差は小さく、出す前に必ず本物へ替わる） |

- 仮の値を使った時は、その行の出典の代わりに「仮: 何年の何の値」と結果に残す（`docs/設計/確かめと仮.md` の仮の印に乗せる）。
- 「止める」表の欠けは §3 の検査で 11 月に見つけるので、1 月の支給の日に初めて気づくことは無い。

## 3. 11 月に来年分を見る検査

### 3.1 何を見るか

各表について、**来年 1 月 1 日の基準の日**（月分は `来年-01`・支払日・締め日・労働した日は `来年-01-01`・年分は `来年`）で引き、`出た` 行に当たるかを見る。
当たらない表のうち `欠けた時: 止める` の物が 1 つでもあれば **赤**、`仮で計算し問う` の物は **黄**（一覧に出すが落とさない）。
あわせて、**次に止まる日** を表ごとに出す（`出た` 行が切れる最初の基準の日）。

### 3.2 いつ・赤の時に誰へ

- **いつ**: 毎年 11 月 1 日に回し、赤が消えるまで 11 月の毎週回す。国税庁の税額表は前の年の 8〜9 月ごろに出る（R9 は 2026-08-31）ので、11 月の赤は「入れ忘れ」か「国の遅れ」で、どちらも 1 月の支給の前に分かる。
- **どこで**: この repo の CI の予定の走り（段階 2 で `.github/workflows/` に足す。CI は骨の窓の持ち物なので、この PR では書かない）と、手元の `bash scripts/check_all.sh` の中。
- **赤の時に誰へ**: Javis 側の親窓へ「表の名・次に止まる日・出典の頁」を 1 行で送る。親窓が §4 の入れ直しの窓を立てる。黄は月に 1 度、同じ窓へまとめて送る。
- 検査の道具（引く口で来年 1 月を引くだけの小さな物）は段階 2 で `芯/計算/` の引く口ができてから、その口を使って書く（引く口を 2 つ作らない）。

### 3.3 検査の行（2026-11-11 に国の原本で見た今）

| 表 | 来年 1 月 | 次に止まる日 | 欠けた時 | 次が出る例年の時期 |

| 子ども子育て支援金 | 出た（R8） | 2027-04 分（R9 の年度） | 仮で計算し問う | 年度の前 |

## 4. 毎年の入れ直しの段取り

1. **国の公開ファイルを取る**: 各表の `出典.頁` から新しい版のファイル（Excel・PDF・頁）を取り、URL・ファイル名・取った日・sha256 を控える。
2. **2 つの元で照らす**: 同じ数字を 2 つの元で照らす。照らせない数字は入れない。今回の組み:
   - 源泉の税額表: 国税庁の Excel と同じ表の PDF（全行の数字の並びを照らす）・電算機の特例は 18.pdf と 17-18.pdf。区間の式で次の点の税額がほぼ出ることも見る（段差は基礎控除の段のところだけ）
   - 協会けんぽ: 率の一覧の頁と 47 支部の保険料額表 PDF（健保・介護の差 1.62・支援金 0.23・厚年 18.300 を全支部で）
   - 標準報酬月額: 年金機構の厚年の額表 Excel と協会けんぽの額表（等級・報酬月額・額）
   - 雇保: 厚生労働省の案内 PDF と率の頁
   - 最低賃金: 全国一覧 PDF と、別の窓が同じ一覧から写した値
   - 年調の控除: 改正のあらましの表と、その注の足し算（62 万＋42 万＝104 万など）
3. **表を起こす**: 起こす道具で json を作る。道具は一時の物として窓の scratchpad で回し、repo には json と出典だけを入れる（段階 2 で 1 つの道具に寄せる時は §6 の 道具/ の物と合わせる）。前の行の `効く終わり` を閉じ、新しい行を足す。`まだ` の行は消して `出た` に替える。
4. **国の例で試す**: 国が答えを出している例（税額表の使い方の設例・保険料額表の額）を `tests/法の表/` に足し、`bash scripts/check_all.sh` を回す。
5. **PR**: 1 年分 1 PR。本文に表ごとの「出典・照らした元・入れた範囲・入れられなかった物」を書く。

## 6. 段階 2・3 で畳む物

| 畳む物 | 代わり | いつ |

## 7. 確かめ方

- **国の例**: `tests/法の表/test_国の例.py`。答えを国が決めている例だけ（国税庁の税額表の使い方の設例 3 つ・協会けんぽ東京支部の保険料額表の額・最低賃金の一覧・雇保の案内）。CI の入口 `bash scripts/check_all.sh` から走る。
- **正しさの判定**: 段階 3 の本物の 1 社ずつの人×項目の突き合わせ（源泉・健保・介護・厚年・雇保の各項目を、`法の表/` を引いて計算した結果と、その会社の過去の正しい結果で比べる）。答え合わせは開発の間だけで、芯に入れない。
- **置き場の見張り**: `tests/法の表/test_表の置き場.py`。法の表の形の json が `法の表/` の外に在れば赤、`法の表/` の全部が引く口の基準で引けるか。
- 制度ごとの作り物の会社の一揃いは作らない。

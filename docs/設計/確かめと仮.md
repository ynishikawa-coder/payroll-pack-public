# 確かめと仮

- 書く中身: 答え合わせを開発の道具へ外す・人×項目の突き合わせ・仮の人を出さない
- 決定: ⟦鍵:給与計算/足りない時は仮で計算し出さない⟧・⟦鍵:給与計算/エンジンの共通化⟧（共通の物はオーナーの持ち物。違いは事務所の物＝給与ソフト〔出口〕と顧客の物＝勤怠ツール〔入口〕だけ）

この紙の語:

| 語 | 意味 |
|---|---|
| 答え | 過去に事務所が出した給与の結果（給与ソフトの明細・一覧表など）。正しいとは限らない |
| 答え合わせ | こちらの計算を答えに合わせて確かめること。**開発の間だけ**の道具 |
| 突き合わせ | 同じ支給月について、こちらの計算と給与ソフトの計算を人×項目で照らすこと。**本番**の確かめ |
| 仮 | 原本や値が足りず、見当の値で計算した値。仮が 1 つでも残る人は出口へ出さない |
| 見当 | 仮の値として置く値と、その拠り所 |
| 質問と回答 | 顧客ごとの Drive にある問いと答えの台帳（`docs/設計/Drive の型.md` の型）。値を決める唯一の道 |

## 1. 答え合わせを開発の道具へ外す

### 決めたこと
- **芯・Drive の型・マスタ・台帳は「答え」の置き場も欄も持たない。** 芯は答えを受け取らず、読まず、比べない。
- 答え合わせは開発の道具として `道具/答え合わせ/` に置く（開発者の手元で回す。本番の毎月の流れに入らない）。
- 道具の口は 2 の突き合わせと **同じ芯**（人×項目を照らす 1 本）を使い、「相手」の読み口を 1 つ足すだけにする。答え用の照らし方を別に持たない。
  - 入れる物: 芯の出す人×項目の行（2 の形）と、開発者が手で渡す答えの file（置き場は開発者の手元。Drive の型に置かない）。
  - 出す物: 2 と同じ列の表。出す先は開発者の手元だけ（Drive の型・管理表へ書かない）。
- **会社の初期設定は答えから逆算しない。** 過去の答えから読めるのは「見当」まで。値は質問と回答で決める。
  - 例: 過去の明細で残業の単価が割り切れる値に見えても、その値をマスタへ書かない。見当として「単価の基の手当は X と Y に見える。合っていますか」の 1 問に載せ、答えが来た時に答えを出所としてマスタへ入れる。
  - 答えが来るまでは、その値を使う人は仮（3 の決まりで出口へ出ない）。

## 2. 本番の確かめ（人×項目の突き合わせ）

### 決めたこと
- **照らす芯は 1 本**（`出口/` の突き合わせ）。給与ソフトごとに違うのは **読み口へ渡す形だけ**（給与ソフトの形は殻が事務所の設定から渡す・パックに製品ごとの読み口を置かない）。読み口は給与ソフトの出力を下の「人×項目の行」へ直すだけで、比べない。
- 項目の名は芯の項目の名にそろえる。給与ソフトの欄と芯の項目の対応は、**出口が給与ソフトへ取り込みを渡す時の対応と同じ 1 つ** を逆に引く（読み用の対応を別に持たない）。会社ごとの自由な欄の対応は、その会社の Drive のマスタ「項目」の給与ソフトの欄に 1 つだけ持つ。
- 二軸で走る: こちらは最後まで計算し、同じ値を給与ソフトへも渡し、給与ソフトの計算結果を受け取って照らす。

### 入れる物と出す物
人×項目の行（芯の出す物・読み口の出す物の両方がこの形）:

| 列 | 中身 |
|---|---|
| 支給月 | `YYYY-MM`（賞与は `YYYY-MM-賞与`） |
| 会社 | 会社の番号（名は書かない） |
| NO | 社員の番号 |
| 項目 | 芯の項目の名（日数・時間・残業・総支給・差引・有給・欠勤・深夜・控除の各項目 …） |
| 値 | 数（円・日・時間。丸めは各々の決まりの後の値） |
| 出所 | 芯: 値の出どころ（原本の名か決まりの md の節か質問と回答の番号）／読み口: 給与ソフトの出力の file の名 |

突き合わせの出す表:

| 列 | 中身 |
|---|---|
| 支給月・会社・NO・項目 | 上と同じ |
| こちら | 芯の値（無ければ空） |
| 給与ソフト | 読み口の値（無ければ空） |
| 差 | こちら − 給与ソフト。片方が空なら「片方だけ」 |
| 差の見立て | 決まった語から 1 つ: `入力の違い`（給与ソフトへ渡した値と給与ソフトが使った値が違う）／`決まりの違い`（同じ入力で計算の決まりが違う）／`丸め`／`片方だけ`／`不明` |
| 差の出所 | こちらの値の出所（上の「出所」）。差の見立てを支える書類の名 |

- 差は **0 だけを一致** とする（許す幅を持たない。丸めの違いも差として出す）。
- 仮で外した人（3）は突き合わせない。表には出さず、月の数え方（下）で扱う。

### 差の流れ
- 差のある行は **質問と回答へ 1 問** にする（同じ見立て・同じ出所の差は 1 問にまとめる）。差を見てマスタや計算を直さない。
- 問いには「こちら・給与ソフト・差・見立て・出所」を載せ、答えで決まる物を書く:
  - こちらが違う → 答えを出所として決まりの md・マスタを直す（ふつうの直しの道。芯の不具合なら PR）。
  - 給与ソフトが違う → 事務所が給与ソフトの入力を直す（こちらは何も変えない）。
- 差のある人の納品は、その問いの答えが来るまで保留する（納品の元は今は給与ソフト。保留は事務所へ知らせるだけで、給与ソフトの操作はしない）。

### 毎月の流れのどこに入るか
1. 受け取り（勤怠など）→ 入口 → 芯で計算（仮の印つき）
2. 出口の手前の関所で仮の人を外す（3）
3. 出口が給与ソフトへの取り込みを作る → 事務所が給与ソフトで計算
4. 給与ソフトの出力を受け取る → 読み口 → **突き合わせ**
5. 差 0 の人は納品へ。差のある人は問い（上）を出して保留
6. 月の状況に「突き合わせ」（下の月数）と「外した人」の数を書く

### 「差が N か月 0」の数え方（給与ソフトを外す条件）
- 会社ごとに数える。支給月（賞与も 1 回を 1 か月と同じに数える）が次の全部を満たす時、その月を「差 0 の月」とする:
  1. 突き合わせた全員の全項目で差が 0（「片方だけ」も 0 でない）
  2. その月の全員を突き合わせた（仮で外した人が 0）
  3. その月の差の問いを「給与ソフトが違う」で閉じた物が 0（給与ソフトが違った月は、こちらが正しくても差 0 に数えない。事務所の入力の直しが要った月だから）
- **続けて** 差 0 の月の数を数え、どれか 1 つが外れた月で 0 に戻す。
- N は事務所の設定（推奨 3）。数は管理表の「突き合わせ」の列に会社ごとに出す。
- 数の横に、その N か月で出なかった場面（入社・退社・賞与・年の変わり目・料率の変わる月）を「まだ見ていない場面」として並べる。外すかどうかは事務所が数と並びを見て決める（芯は判断しない）。

### 確かめ方（段階 3 の正しさの判定）
段階 3 では本物の会社を **1 社ずつ** 二軸で走らせ、この突き合わせの表をそのまま正しさの判定にする。1 社の判定は「全員の全項目の差が 0 か、0 でない差の全部に質問と回答の答えがある」こと。作り物の会社の一揃いでは判定しない。試験に置くのは国の率や表の例と回帰の見張りだけ（`tests/作り物/`）。

## 3. 仮

### 決めたこと
- **値ごとの印**: 芯は人×項目の各値に `状態` を持たせる。`確定` か `仮` の 2 つだけ。
  - 仮になる時: 原本が無い・値が空・原本（⑥の書類など）に「仮」とある・マスタの値の出所が質問と回答に無い（答え待ち）。
  - 仮の値には `見当`（置いた値）・`見当の拠り所`（何から置いたか。過去の答えから読んだならそう書く）・`問いの番号` を持たせる。
  - 仮の値から計算した値も仮（総支給・差引など、仮を 1 つでも使った値は仮）。
- **人ごとの印**: 人の状態 ＝ その人の値に仮が 1 つでもあれば `仮`、無ければ `確定`。仮の数も持つ。
- **見当と確認の 1 問**: 足りない物 1 つにつき問いを 1 つ。同じ原因で何人も仮になる時は 1 問に人を並べる。問いの形:
  - 何が無いか（原本の名・項目）／見当とその拠り所／答えで変わる項目と人／答え方の例（「見当のとおり」「X 円」「原本を送る」）
  - 問いは芯が **返すだけ**。Drive の質問と回答へ書くのは各エージェントの repo（環境の口）。芯は Drive を開かない。
- **出口の手前の関所**: `出口/` の入り口に 1 つだけ関所を置く。給与ソフトごと・出す物ごとに持たない。毎月は `月次.月を回す` が仮の人を寄せて関所へ通す（`月次/README.md`）。
  - 関所は人の状態が `仮` の人を、給与ソフトへの取り込み・明細・支給控除一覧・納品の全部から **外す**（印つきで出すことはしない）。
  - 関所より後ろ（取り込みを作る所・突き合わせ）は仮の人を受け取らない。
- **外した人の知らせ方**: 関所は「外した人」の一覧を返す（支給月・会社・NO・仮の数・待っている問いの番号）。エージェントはそれを月の状況の「外した人」の列と、事務所への知らせの頭に出す。出口の出す file には外した人の行も印も書かない。
- **仮が消える条件**: 問いに答えが来て、その答えを出所として原本・決まりの md・マスタが埋まり、計算し直した時に仮が 0 になった時だけ。
  - 「見当のとおり」も答え（出所は質問と回答の番号）。期限で急ぐ時は事務所がこの答えを出せば出口へ出る。
  - 答え・給与ソフトの値・突き合わせの一致では仮は消えない。

### 確かめ方
段階 3 の本物の 1 社で、原本を 1 つ抜いた月を走らせ、その原本に関わる人が出口の全部の file に 0 行であり、外した人の一覧と問いが 1 つずつ出ることを見る。答えを入れて計算し直し、その人が出口に出て突き合わせに入ることを見る。回帰の見張り（`tests/作り物/`）には「仮の人は出口の file に 0 行」の 1 つだけを置く。

## 4. 確かめの状態の語

値の状態は 2 つ、突き合わせの状態は別の軸で 3 つ。2 つの軸を混ぜない。

| 軸 | 語 | 意味 |
|---|---|---|
| 値の状態 | `確定` | 出所が 原本・決まりの md・質問と回答 のどれか |
| 値の状態 | `仮` | 上のどれでもない（見当で置いた） |
| 人の状態 | `確認済` | その人の値が全部 `確定` |
| 人の状態 | `仮` | `仮` の値が 1 つ以上 |
| 突き合わせ | `一致` | その人の全項目の差が 0 |
| 突き合わせ | `差あり` | 差が 1 つ以上（問いを出した） |
| 突き合わせ | `未突き合わせ` | 仮で外した・給与ソフトの出力がまだ来ない |

「確認済」に数える物と数えない物:

| 物 | 確認済に数えるか |
|---|---|
| 原本から読んだ値 | 数える |
| 決まりの md から引いた値 | 数える |
| 質問と回答の答え（「見当のとおり」を含む）を出所にした値 | 数える |
| **「過去の支給と一致」** | **数えない＝仮の残りに数える**。印そのものを持たない。今の Drive に残る印は寄せの時に `仮` へ直し、問いを 1 つ起こす |
| 過去の答えから読んだ値 | 数えない（見当まで） |
| 給与ソフトの値と一致した値 | 数えない（突き合わせの軸の `一致` であって、値の状態は変えない） |

### 確かめ方
段階 3 の本物の 1 社で、人の状態の `確認済` の数と、値の出所が 原本・決まりの md・質問と回答 だけの人の数が同じであることを見る。

## 5. 段階 2・3 で畳む物と渡し

### 畳む物

| 畳む物 | 段階 | 誰が |

| 事務所の根の `80_答え`・事務所の設定「照合の置き場」 | 2（型から抜く）・3（各事務所の Drive から消す） | B3（型）・B12（寄せ） |
| `照合_<支給年>`（タブ「照合」） | 2・3 | B3・B12 |
| 全社の月の状況・00_目次 の「照合」の列 → 「突き合わせ」「外した人」の列 | 2 | B11（管理表） |
| マスタ「会社」の項目「答えの読み替え」 | 2・3 | B3・B12 |
| 型.json「答え」の別名と欄の寄せ | 2 | B3 |
| 受け取りで答えを写す手順・立ち上げの逆算の手順 | 2 | `初期設定/` |
| 「過去の支給と一致」の印と kensa.py qa の数え方（残る印は仮へ直し問いを起こす） | 2（型と数え方）・3（各 Drive の印） | B3・B11・B12 |
| 仮の印を出力の 1 行目に写すだけで納品へ流れる道 | 2 | B10（関所で畳む） |
| kotae.py shogo（答え相手の照合） | 2 | B10（突き合わせ）・答え相手は `道具/答え合わせ/` へ |

段階 3 で各事務所の Drive から消すのは、その会社が新しい型で 1 か月走り、突き合わせの表が出た後。

### 渡し: `出口/`（B10）
1. **関所**（3）: 入る物＝芯の人×項目の行（`状態` つき）と人の状態。仮の人を外し、「外した人」の一覧を返す。後ろへは確定の人だけを渡す。
2. **取り込みを作る**: 給与ソフトごとの書き口。給与ソフトの欄と芯の項目の対応は 1 つ（会社ごとの自由な欄は Drive のマスタ「項目」の給与ソフトの欄から受け取る）。
3. **読み口**: 給与ソフトごと。2 の対応を逆に引いて、給与ソフトの出力を人×項目の行へ直す。比べない。
4. **突き合わせ**: 1 本。2 の列の表を出す。差は 0 だけ一致。差の行を問いの形（3 の形と同じ）で返す。
5. **月数**: 会社ごとの続けて差 0 の月数と「まだ見ていない場面」を返す（2 の数え方）。
6. 出口は Drive を開かない。受け取って返すだけ。答え（過去の結果）を受け取る口を持たない。

### 渡し: `芯/計算/`（D8→B13）
1. 出す物は人×項目の行（支給月・会社・NO・項目・値・出所・状態・見当・見当の拠り所・問いの番号）と人の状態と問いの一覧。
2. 足りない値は見当で計算し、`仮` の印と問いを付けて返す（止まらない）。仮を使った値も仮。
3. 答え（過去の結果）を入れる口・読む所・比べる所を持たない。「過去の支給と一致」の印を読まない。
4. 給与ソフトの形を知らない（項目の名は芯の名）。

### 他の窓への渡し（この紙が前提にする物）
- B3（`docs/設計/Drive の型.md`）: 型に答えの置き場・欄を持たない。質問と回答の型に、問いの番号・見当・見当の拠り所・答えで変わる項目と人の欄。マスタ「項目」に給与ソフトの欄（会社ごとの自由な欄の対応）。
- B11（`管理表/`）: 月の状況の「照合」の列を「突き合わせ」（続けて差 0 の月数）と「外した人」（人数）へ。
- B12（`道具/寄せ/`）: 80_答え・照合_<年>・読み替え・「過去の支給と一致」の印を寄せの時に畳む（印は仮へ直し問いを起こす）。
- 骨の窓: `道具/答え合わせ/` の行を目次へ（この窓は目次に触らない）。

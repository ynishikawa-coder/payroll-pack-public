# 寄せる道具

- 書く中身: 既存の Drive を新しい型へ寄せる道具・型を直したら雛形と既存のシートへ配る道具・移行の間だけの物を消す段取り・旧_／99_／02_ の持ち主と期限
- 道具の実物: `道具/寄せ/`。この紙はその仕様。
- 型の中身（マスタ・台帳・md の雛形・フォルダの 4 分け・管理表の型）は `docs/設計/Drive の型.md`（B3）が決める。ここでは型の中身を書かず、**寄せ方・配り方・消し方の仕組み** だけを決める。

## 0. 前提と、この紙が止める散らかり

### 前提（変えない物）
- **芯は Drive を開かない**。寄せる道具も Drive を開かない。道具は「今のシートの値（get_values の JSON）・md の本文・置き場の一覧」と「型」を受け取り、「寄せた後の値・書く手順・寄せられない物・人が見る物」を返すだけ。Drive を読む・書く・写すのは各エージェントの repo の殻（環境の口）。
- **顧客の物は repo に置かない**。寄せの前の値・寄せの記録・配った記録・人が見る物は、各事務所の Drive に置く。repo に在るのは型・雛形・直し（下の 1.2）と道具だけ。
- **足りない値は仮で計算し出さない** ⟦鍵:給与計算/足りない時は仮で計算し出さない⟧。寄せる道具は値を作らない。型が既定値を決めている所だけ既定値を入れ、それ以外の足りない値は空のまま「足りない値」として `確かめと仮.md`（B5）の口へ渡す。
- 人の手が入った一点物・9_履歴/消す_ の中身・旧_ のタブを **消すのはオーナーの OK の後**。

### この紙で決めること（一言で）
**型の直しは、必ず「直し」1 つ（前の形 → 次の形への手順）と一緒に出す。寄せも配りも、その直しを会社のシートに当てる 1 つの道具で行う。読む側は今の型しか知らない。直しは全社に当たったら消す。** 古い形を読み続ける仕組み（別名・読み替え・要る日）は持たない。

## 1. 寄せる道具

### 1.1 入力と出力

入力（殻が Drive から読んで渡す。道具は Drive を開かない）:

| 入力 | 中身 | 出す所 |
|---|---|---|
| 今のシートの値 | タブごとの get_values の JSON（`{"タブの名": [[…], …]}`）と、タブの名の一覧・各セルが式か値か | 殻（Sheets を読む口） |
| md の本文 | 会社の md（会社の決まり・質問と回答 など、型が決める md）の本文 | 殻（Drive を読む口） |
| 置き場の一覧 | 会社のフォルダの中の file とフォルダの名（中身は読まない） | 殻 |
| 会社の型の版 | 管理表のその会社の行の「型の版」（版の無い会社は 0） | 殻（管理表を読む口） |
| 会社が選んだ部品 | 管理表のその会社の行の「選んだ部品」（入口＝勤怠ツールなど・出口＝給与ソフトなど） | 殻 |
| 型と直し | repo の型の正本と `道具/寄せ/直し/` | このパックの版 |
| 人の答え | 前の回の「寄せられない物」への人の答え（無ければ空）と、任意の「前の形の読み替え」（その事務所の前の道具の形を今の型へ読み替える操作の塊・版ごと。1.3） | 殻（事務所の Drive の寄せの記録） |

出力（道具が返す。書くのは殻）:

| 出力 | 中身 |
|---|---|
| 寄せた後の値 | 型の今の版の形にそろえた、タブごとの値と md の本文 |
| 書く手順 | 殻が Sheets・Drive に当てる操作の並び（タブを足す・名を変える・値を書く・file を移す）。殻はこの順に当てるだけで、判断をしない。値を書く は `書き方`＝`RAW`（字のまま書く＝数だけの字の頭の 0・支給月の字を数や日付に読ませない） |
| 戻す手順 | 書く手順の逆（寄せの前の値から作る）。殻はこれで書く前へ戻せる |
| 寄せられない物 | 型にも直しにも行き先の無い物の一覧（1.4）。1 つでもあれば書く手順は空 |
| 管理表へ書く | 照らす回（1.5 の 7＝書いた後に読み直して書く手順 0・寄せられない物 0）にだけ、管理表「会社」へ書く行（型の版・最後に配った日・写しの場所）。殻は管理表の書く口へそのまま渡す（型の版を記録する口。値は事務所の管理表）。写しの場所は、書く回に道具が返す「写した物」（その回の写しの名）を殻が照らす回の入力へ渡し返した物（殻は 9_履歴 の中身を読まず、名だけを照らす回の置き場に入れる＝道具が写しの場所を置き場で照らせる） |
| 足りない値 | 型が要るのに値の無い所（人×項目）。B5 の仮と 1 問の口へ渡す |
| 人が見る物 | 変わるタブ・列・件数、寄せられない物と選べる答え、足りない値の数を 1 枚にした物（窓の作業場にだけ置く＝`Drive の型.md` §2「殻が Drive に置く物」。Drive に置かない） |
| 値の保ちの照らし | 「前の空でない値の数 ＝ 後へ移った数 ＋ 寄せられない物に出た数 ＋ 人が捨てると答えた数」。合わなければ道具は止まる |

### 1.2 直し（寄せも配りも、これを当てる）

型を 1 回直すごとに、`道具/寄せ/直し/` に **直し** を 1 つ置く。直しは「版 N−1 の形を版 N の形へ持ち上げる操作の並び」。

```json
{
  "版": 7,
  "前の版": 6,
  "なぜ": "型を直した理由（1 行）",
  "部品": "共通",
  "操作": [
    {"する": "列の名を変える", "タブ": "社員", "前": "前の見出し", "後": "今の見出し"},
    {"する": "列を足す", "タブ": "社員", "見出し": "新しい項目", "値": "型の既定値 または 空"}
  ]
}
```

操作は閉じた一覧にする（これ以外は直しに書けない。足す時はこの紙を直す）:

| 操作 | 前の形の確かめ | 当たっている印 |
|---|---|---|
| タブを足す | そのタブが無い | 在る |
| タブの名を変える | 前の名が在り、後の名が無い | 後の名だけ在る |
| タブを畳む（型から消したタブ。前の直しのそのタブへの操作は当てない） | そのタブが会社のシートに在る（会社の型の版によらず照らす） | 消す問いに在る（値も列も変えない。9_履歴 へ写して消すのはオーナーの OK の後に殻） |
| 列を足す（型の既定値か空） | その見出しが無い | 在る |
| 列の名を変える | 前の見出しが在り、後が無い | 後だけ在る |
| 列の並びをそろえる | 型の列が全部在る | 型の並びと同じ |
| 値の語を読み替える（前の語→今の語） | その列に前の語が在る | 前の語が 0 |
| 列を md の見出しへ移す | 列が在る | 列が無く、見出しに文が在る |
| 列を畳む（移す先が決まっている時だけ） | 列が在り、移す先が在る | 列が無い |
| md の見出しの名を変える・見出しを足す | 前の見出しが在る／見出しが無い | 後の見出しだけ在る |
| file を置き場へ移す | 元の置き場に在る | 先の置き場に在る |
| 値をそろえる（形: 支給月・読み・都道府県・休憩の長さ・欄の名。先の列 で同じ行の別の列へ） | 列に今の形でない値が在る | 全部が今の形（読めない値は寄せられない物） |
| 人の列へ移す（会社の行の前の語 → 社員の列。人の値の在る人は人が勝つ） | 会社の行・社員の列に前の語が在る | 前の語が 0（移る人が 0 なら寄せられない物） |
| 前の道具の空を読む（前の道具〔型の版 0〕と今の型で空の意味が違う列の空を、前の意味の値へ書く＝値の意味を保つ。直し 20 の 割増の基礎） | 版 0 から寄せる会社で、入力に在った列の空の欄（行の整理の後） | 空でない（版 1 以上の会社は今の型の意味のまま知らせ 1 つ。除けない手当を除く向きになる行は寄せられない物） |

決まり:
- **どの操作も、前の形を確かめてから当て、当たっていれば飛ばす**。だから同じ直しを何度当てても同じ結果になり、途中で止まっても頭からやり直せる。前の形でも当たった形でもない時は「寄せられない物」に出す。
- 「部品」が付いた直しは、その部品を選んだ会社にだけ当てる（事務所の物＝出口・顧客の物＝入口を選ぶのは事務所と会社。部品は共通に並ぶ）。
- 直しは値を作らない。足すのは型の既定値か空だけ。値をそろえる・人の列へ移す は、前に在った値をその語のまま今の形・今の所へ置き直すだけ（例 前の「計算の仕方」の文の語から 単価の元 を読む）。文の語で 1 つに決まらない・読めない値は作らず、寄せられない物（人が答える）へ回す。前の「計算の仕方」の文は単価（×の前）と数量（×の後）の 2 つを持つ（例 日額×出勤日数＝単価の元 人の額・数量の元 勤怠の数:出勤日数）＝前の形の読み替えは 先の列 単価の元 と 先の列 数量の元 の 2 つの 値をそろえる で読む（1 つだけでは数量が空＝1 で残る）。毎回の読み（`計算の形.py` の 6）は、算出の単価（時間単価・日単価）と読んだ行に人ごとの額が在れば 人の額 へ直し、数量の元が空なら問いにする。変更の記録の前の名に人が そのまま と答えた記録は、確かめ の空の欄に 記録だけ を書いて残す（段の解決は読まない。確認済・仮 は人の確かめ＝書き替えず知らせだけ）。確かめが既に 確認済 の前の名の行（今の項目に無い名）も、段の解決は今の計算に効かない記録として読み飛ばす（確かめていない＝仮・空 の前の名だけ 仮＋問い）＝#91 で寄せが 確認済 を 記録だけ に上書きしなくなった後も、確認済 の前の名でその人が仮のまま残らない。変更の記録の 適用支給月 は支給月（YYYY.MM支給）へそろえるが、標準報酬（社保.標準報酬・社保.厚年の標準報酬）の行だけは型の決まりどおり保険料の月（YYYY.MM分）へ、社保.徴収の月（人 → 会社 → 事務所の設定の既定）と芯の 保険料の月 で直す（段の解決は支給月の字の標準報酬の行を古い書き方として止めるため）。徴収の月が引けなければ値を作らず問い（値:<YYYY.MM分>）。
- **型・雛形・直しは同じ PR で出す**。直しの無い型の直しは入れない（B12 の自己検査で止める。5.2）。
- 読む側（芯・入口・出口・型の読み口）は **今の版の型だけ** を知る。前の版の名や語は直しの中にしか無い。

### 1.3 寄せる＝会社の版から今の版まで直しを順に当てる

既存の会社を新しい型へ寄せることは、「その会社の型の版から今の版まで、直しを順に当てる」ことと同じにする。版の無い（今の型より前に作った）会社は版 0 から始める。
管理表の型の版を信じ切らない: 版 N の直しが足す今の型の列・タブが会社のシートに無ければ、そのシートは版 N−1 の形と見て、版 N から当てる（形から見た版。知らせに出す）。直しはどの操作も前の形を確かめて当てるので、低い版から当て直しても今の形の所は変わらない。型に無いシートに値が在れば黙って通さず寄せられない物（1.4 の 行き先の無いシート）に出す。

**直し 1（版 0 → 版 1）＝初めの寄せ**。パックの直し 1 は、どの事務所の版 0 の会社にも当たる **型の作り**（版 1 の全タブの列・足すタブ・md の見出し・型の並び）だけを持つ。
今ある移行の間だけの物（3 の表）の中身＝1 つの事務所の前の道具の形の読み替え（旧の列の行き先・別名・名の読み替え・旧の語・旧の形の Q-ID・畳んだ列・md へ移す文）は、パックに置かない（`入れてよい物.md` ⟦鍵:給与計算/移行だけの物はパックに入れない⟧）。その事務所の Drive の寄せの記録に **前の形の読み替え**（直しと同じ閉じた操作の塊・版ごと）として置き、殻が人の答えに入れて渡す。道具は版 N の塊を同じ版のパックの直しの前に当てる（便 2 で直し 1・3 から外した。形と塊に入れる物は `道具/寄せ/README.md` の入力。前の形の操作が頼る型の作りの操作も塊に入れる＝v0.1.6 の直し 1・3 の全部の操作をそのまま塊にすれば前と同じ寄せ）。渡さない事務所の前の形は、寄せられない物（1.4）に出て人が答える。
会社の型の版の鎖に乗らない質問と回答（事務所全体の問い `00_事務所/質問と回答`。型は会社の 質問と回答 と同じ列・並び・列「会社」＝事務所＝`初期設定/型.json` の 質問と回答「事務所」）は、1 枚に当てる口（`道具/寄せ/質問と回答.py`）で寄せる。事務所の前の形の読み替え（`列の名を変える`・`値の語を読み替える`・`列を足す`・`列の並びをそろえる` だけ・中身は事務所の寄せの記録）を当て、見出しを確かめてから、パックが型から型の作り（型の列を足す・会社＝事務所・支給月を型の列の意味 `YYYY.MM支給` の書き方へそろえる・並び）を当てる。問いの番号の読み替えは、型でこの表の問いを指す欄の字（回答の `出し直し→<番号>`・理由の `聞き直し: <番号>`）の中の番号にも同じに当てる。ほかの欄の字の中の前の形の番号はほかの表への参照なので直さず止めもしない。寄せた後は前の答えを照らす口と同じ読みで確かめ、見出しが欠けた表・型に無い列が残る表・会社が事務所でない行・今の形でない番号（問いを指す欄の字の中も）が残る表・支給月に読めない字が残る表・番号がぶつかる表は書かずに止める（何も消さない）。12 列の前の形（2026-11-19 に事務所の表で見た形）はパックのどの版の型（直し 1〜30）にも当たらない＝事務所の前の道具の形なので、読み替えの中身は事務所の寄せの記録に置く。

**型の上げ直し（会社の型の版が既に今の版）でも前の形を残さない**（2026-11-24）。版の鎖は版の上がる所にしか当たらないので、版に結びつかない前の形は版の鎖の外で毎回当てて照らす:
- 会社の `1_決まり/質問と回答` の問いの番号: 前の形の読み替え（人の答え）の、この表の問いの番号への `値の語を読み替える` を、会社の版によらず毎回当てる（`質問と回答.会社の表を当てる`。字の中の番号〔出し直し→・聞き直し:〕も同じ）。読み替えの後も今の形（`Q<支給年月 6 桁>-<順>`）でない番号が残る・番号がぶつかる表は書かずに止める（前は今の版の会社に当てる直しが無く、前の番号 `Q2026.12-xx` が黙って残った）。
- `8_確認事項/` の前の形（名が `確認ページ_…`・`下書き_確認ページ_…` のページ・月ごとに切ったフォルダ）: ページは `9_履歴/消す_<翌々月末>_<ページの名>` へ移す（`file を移す`・消さない。`当てる.確認事項の前の形を移す`）。月のフォルダは中のページを 1 つずつ同じ形で `9_履歴/` の直下へ移してから、残ったフォルダを `9_履歴/消す_<翌々月末>_<フォルダの名>/` へ。移した名は `確認ページ.履歴の名の形` が読む形＝`次の版` が前の版に数える（置き場の名を挟む・フォルダごと移すと、上げ直しの後の確認事項が v1 から付け直し、配った版と番号がぶつかる）。今の形の名（`確認事項_…`・`下書き_確認事項_…`）・人が見る物（`寄せ_人が見る物_…`）・ほかの物は動かさない（型の外の物は見回りが知らせる）。移す先が既に在ればぶつかりで止める。移した物は寄せの前の写しに数えない。

### 1.4 寄せられない物と、選べる答え

| 種類 | 例 | 選べる答え（人が見る物に並べる） |
|---|---|---|
| 行き先の無い列・タブ | 型にも直しにも無い見出し | 型へ足す（B3 へ直しを頼む）／会社の決まりの md へ移す／9_履歴 へ写して消す（オーナーの OK） |
| 一点物 | 型の列に式・手で足した注・型に無い色や並び | 型の値へ置く（式を値にする）／型へ足す／9_履歴 へ写して消す（オーナーの OK） |
| ぶつかり | 2 つの前の列が 1 つの今の列へ来て値が違う | どちらを取るか（人×項目で示す） |
| 形の合わない値 | 数の列に文 | 直した値を書く／空にして足りない値へ回す |
| 行き先の無いシート | 型に無いシート（前の置き場の 質問と回答 など）に値が在る | 型の置き場へ移す（名の終わりが同じ型のシート。移してから直しを当てる）／9_履歴 へ写して消す（オーナーの OK）／寄せの外に置く（型の外の file・知らせだけ） |
| 旧_ のタブ | 前の手作業の写しの元（4.1） | 中身が今のタブに在ると照らせた物は消す候補（オーナーの OK）／無い物は上のどれか |

- 寄せられない物が 1 つでも残る会社は書かない（1 社の寄せは全部か無しか）。人の答えを入力に足して、もう一度回す。
- 「消す」を含む答えは、その場で消さず 4.4 の **消す問い** にまとめる。

### 1.5 寄せる順番（1 社ずつ・戻せる形）

1 社ずつ、次の順で行う。前の会社が 7 まで済むまで次の会社へ行かない。

1. **止める**: 管理表のその会社を「寄せ中」にする（その間、毎月の仕事はその会社を回さない＝月を回す口・締める口は `管理表/管理表.py 寄せの印` で読み、寄せ中なら止める。印は `寄せの行` で組み `書く` で書く）。
2. **読む**（殻）: 1.1 の入力をそろえる。
3. **見通す**（道具・書かない）: 寄せた後の値・書く手順・寄せられない物・足りない値・人が見る物を出す。値の保ちが合わなければ止まる。
4. **人が見る**: 寄せられない物に答える。残りが 0 になるまで 2〜4 を回す。
5. **写す**（殻）: 書く前に、表計算の file を丸ごと写して 9_履歴/ に置く（名に消す日を付ける。4.2）。寄せの前の値の JSON・書く手順・戻す手順を、その会社の寄せの記録として事務所の Drive に置く。**旧_ のタブはもう作らない**（戻すのは写しと戻す手順で行う）。
6. **書く**（殻）: 書く手順を順に当てる。
7. **照らす**: 書いた後を読み直し、道具に「今の型と同じ形か・値の保ちが合うか」を照らさせる。合い、1.6 の人×項目の突き合わせも合えば管理表の型の版を今の版にし、「寄せ中」を外す。合わなければ戻す手順で戻し、「寄せ中」のまま理由を管理表に書く。書く途中で落ちた時も「寄せ中」のまま理由を書く（もう一度 寄せる で同じ所から当て直す＝直しは当たった所を飛ばす）。

### 1.6 確かめ方（正しさの判定）

寄せは給与の結果を 1 円も変えてはいけない。だから正しさは段階 3 の本物の 1 社ずつで、次の **人×項目の突き合わせ**（`確かめと仮.md` の形）で判定する。

- 寄せの前に、その会社の直近の月を計算した結果（人×項目）を取っておく。
- 寄せた後に同じ月を同じ版の芯で計算し、人×項目で突き合わせる。全部が一致して寄せは済む。
- 違う人×項目が 1 つでもあれば、その会社は戻す手順で戻し、違いの原因（直しの誤り・寄せられない物の答えの誤り）を直してから寄せ直す。
- 突き合わせは段 3 の本物だけの物でなく、殻の〔口: 寄せる〕が寄せる回ごとに 1.5 の 7 の中で行う（寄せ中を外す条件）。寄せの前の人×項目は、その会社が最後に出した月の `2_出す物/` に今ある出す物（実際に出した表）を読んだ物、寄せた後は同じ月を出荷の口の照らす（何も書かない）で計算した出す物。物ごとの表が 1 つの字も違わない時だけ寄せ中を外す。ただし見通し（段 3）で何も変わらない会社＝書く手順・寄せられない物・足りない値・管理表へ書く・写した物 が全部空で、管理表「会社」が寄せ中でない（前の回が途中で止まっていない）会社は、比べる入力を求めずに終える（寄せの前と後の値が同じで、型の版も今の版＝突き合わせる差が生まれない）。この判定も窓の申告でなく `突き合わせる月` に見通しと会社のタブを渡して決める。変わる物が 0 でも、計算に要る値が足りない（足りない値）・前の回が止まった（寄せ中）会社は済にせず、上の突き合わせを通す。違えば戻す手順で戻し、寄せ中のまま違いを理由に書く（寄せの前の月が無い会社＝まだ 1 度も出していない会社は突き合わせる物が無い訳を理由の代わりに寄せの記録へ残す）。どの月を突き合わせるか・まだ出していないかは窓の申告で決めず、管理表「月の状況」の出荷の印（取り込み・計算が 済／仮、納品が 済）から `管理表/管理表.py 突き合わせる月` が決める＝出した月が在る会社の無い訳と、最後に出した月でない月は拒む。突き合わせる物（出荷の口の入力）の会社・組・支給月は、寄せる会社・その会社の組（事務所の設定「会社の一覧」）・`突き合わせる月` が返した月と同じでなければ、殻は何も書かずに止める（どの会社のどの月かを 2 つの申告から組まない＝別の会社の出す物で寄せ中を外さない）。

repo に置く試験は道具の自分の試験だけ（5.2）。作り物の会社の一揃いは作らない。

## 2. 配る道具

### 2.1 正本は repo の 1 か所
- 雛形の正本は repo の 1 か所（`初期設定/型.json`・`Drive の型.md`「Drive に雛形のフォルダを置かない」）。事務所の Drive に雛形の写しは置かない（新しい会社は repo の型から起こす）。雛形を直したい時は repo の型の PR にする。
- 型の直しの PR には、型・雛形・直しの 3 つを入れる（1.2）。

### 2.2 配る流れ（型を直したら）

配るは、新しい直しを **事務所の全社** に当てること。中の仕組みは寄せと同じ（1.3 の道具を、管理表に載る全社について回す）。

1. 版を出す: 型の直しの PR が main に入り、版が出る（`docs/版の出し方.md`）。CHANGELOG のその版に「直し N を含む・配りが要る」と書く。
2. 版を上げる: 各エージェントの repo がこのパックの版を上げたら、殻の〔口: 配る〕を回す（呼び口 `配る`。`--管理表`＝管理表「会社」の今の値を必ず渡す）。
3. **見通し**（書かない）: 管理表の全社について 1.5 の 2〜3 を回し、事務所ごとに 1 枚の見通しを出す（殻の〔口: 配る〕が窓の作業場に置く。寄せ中の会社は当てずに頭へ並べる）:

   | 会社 | 今の版 | 当てる直し | 変わるタブ | 変わる列の数 | 寄せられない物 | 足りない値 |
   |---|---|---|---|---|---|---|

   （会社の名が入るので、この表は窓の作業場にだけ置き、オーナーには窓で見せる。repo にも Drive にも出さない＝`Drive の型.md` §2「殻が Drive に置く物」。）
4. **人の OK を 1 回**: 事務所ごと・直しごとに 1 回、見通しへ OK をもらう。寄せられない物のある会社は、この回は当てずに残し、答えを集める。
5. **当てる**: 見通しで「当てる」の会社だけ 1 社ずつ、殻の〔口: 寄せる〕で 1.5 の 1〜7（寄せ中を立てる・写す・書く・照らす・突き合わせ）を回す（配るの中身は寄せると同じ＝別の書く道を持たない）。
6. **配った記録**: 〔口: 寄せる〕が照らしと突き合わせの通った会社の管理表「会社」の行に「型の版・最後に配った日・写しの場所」を書き、寄せ中を外す（写しの期限の元＝4.2）。会社ごとの記録（前の値・書く手順・戻す手順・人の答え）は 〔口: 寄せる〕が `9_履歴/寄せの記録_<日>_<時刻>.json` に置く（口の記録＝`Drive の型.md` §2）。飛ばした会社は次の見通しの頭に並ぶ（2.3）。
7. **見回り**: 月に 1 回まで殻の〔口: 見回り〕で配り残し・寄せ中の会社・消してよい直し・消す問い（4.4）を出し、消す問いはオーナーへ 1 回で聞いて〔口: 消す〕で答えのとおり消す。

### 2.3 配り残しと、直しを消す時
- 寄せられない物があって当てられなかった会社は、管理表で前の版のまま残る。配る道具は毎回「前の版のままの会社」を見通しの頭に並べる（黙って残さない）。
- **直し N は、管理表の全社（両方の事務所）の型の版が N 以上になったら消す**。配る道具は見通しの終わりに「消してよい直し」を並べる。消す時は直しを消す PR を出す。新しい会社は雛形（今の版）から作るので、古い直しを要らない。
- 両方の事務所の版がそろうまでは直しを消さない。各事務所は自分の管理表の「消してよい直し」を、直しを消す PR の本文に書く（会社の名は書かず、版と社数だけ）。

## 4. 旧_・9_履歴/消す_・前の形の置き場 の持ち主と期限

どれも「誰が中を見るか・いつまでか・期限が来たら何が起きるか」を置いた時に決める。**期限が来ても道具は消さない**。期限の来た物は次の消す問い（4.4）に並び、オーナーの OK の後に殻が消す。

| 物 | これから作るか | 持ち主（中を見る窓） | 期限 | 期限が来たら |
|---|---|---|---|---|
| `旧_<名>` のタブ | **作らない**（寄せも配りも、写しと戻す手順で戻す。1.5） | 今あるもの: その会社を寄せる窓（段階 3 の C6・D 側） | その会社の寄せの日 | 寄せの時に旧_ を今のタブと照らし、消す問いへ並べる |
| `9_履歴/消す_<日>_<名>` | 寄せ・配りの写し・人が要らないと決めた物 | 置いた窓 | 名の日（4.2） | 消す問いへ並べる |
| 前の形の置き場（直し 30 の「前の置き場を止める」の名） | **作らない** | 会社の Drive を作り直す窓 | 無い（作り直すまで寄せは止まる） | 消さずに 作り直す と並べる（4.3） |

### 4.1 旧_ のタブ
- 今ある旧_ は、その会社の寄せ（1.5）の入力に含める。道具は旧_ の値が今のタブに在るかを照らし（値の保ちの照らしと同じ）、
  - 全部在る → 「中身は今のタブに在る」として消す候補にする。
  - 無い値が在る → 寄せられない物に出し、人が行き先を答える（1.4）。
- 寄せの写し（1.5 の 5）に旧_ も入るので、生きているシートから旧_ を外しても中身は期限まで 9_履歴/ に残る。外すのはオーナーの OK の後。
- これからの寄せ・配りは旧_ を作らないので、旧_ は寄せが全社を回り終えた時に 0 になる。

### 4.2 9_履歴/消す_
- 消してよい物は `9_履歴/消す_<消す日 YYYY-MM-DD>_<元の名>`（Drive の型 §2「置き場の約束」）。名に消す日の無い物は残す物（見回りは並べない）。
- 期限の決め方:
  - 寄せ・配りの写し: 寄せの回の中の人×項目の突き合わせ（1.6）が緑になった日（管理表「会社」の 最後に配った日）の翌月末。名の日は寄せた日の翌月末（`当てる.py` が付ける・いちばん早い日）で、見回りは名の日と 最後に配った日 の翌月末の遅い方まで並べない。寄せ中の会社・最後に配った日が空（まだ緑でない）の会社・管理表を読めない時は写しを並べない（`見回り.py` の `写しの期限` の 1 か所）。
  - 人が要らないと決めた物: 置いた日の翌月末。
  - 寄せが移した 8_確認事項 の前の形（確認ページ_… のページ・月ごとのフォルダ）: 寄せの写しと同じ翌々月末（1.3）。

### 4.3 前の形の置き場
- 前の形の Drive は新しい形で作り直す（移す道具は使わない・Drive の型 §10）。初期設定の書類は最初に計算する支給月の `3_月ごと/<月>/1_届いた物/` に頭 `書類_` を付けて置く（原本なので消さない）。
- 前の形の置き場の名は直し 30（`道具/寄せ/直し/直し_0030.json`）の「前の置き場を止める」の 1 か所にだけ在る。寄せはその名のシート・md・置き場が 1 つでも在る会社を、型の版によらず何も当てずに止め（寄せられない物 `前の形の置き場`・答えは作り直すだけ）、見回りは消さずに 作り直す と並べる。前の名を黙って読み続ける道は無い。

### 4.4 消す問い（オーナーへ 1 回で聞く形）
- 寄せの波ごと（段階 3 の間）と、その後は月に 1 回まで、事務所ごとに 1 枚にまとめて聞く。その間に期限の来た物と、寄せで出た「消す」答えを全部並べる。
- 1 枚の形（窓の作業場にだけ置き、オーナーには窓で見せる。会社の名が入るので repo にも Drive にも出さない＝`Drive の型.md` §2「殻が Drive に置く物」）:

  | 会社 | 物 | 置き場 | 中を見た窓 | 中身はどこに在るか（今のタブ／原本の置き場／どこにも無い） | 期限 | 推奨（消す／原本へ移す／残す＋新しい期限） |
  |---|---|---|---|---|---|---|

- オーナーは「推奨どおり全部」か、行ごとの答え（`消す`・`原本へ移す:<置き場>`・`残す:<YYYY-MM-DD>`）で返す。殻の〔口: 消す〕が呼び口 `消す` で今の消す問いに答えを当て、誤り（今の問いに無い鍵・消す手順の無い行への 消す・今日より後でない 残す・知らない答え）が 1 つでも在れば何も消さない。通れば先に答えを `00_事務所/9_履歴/消す問いの答え_<日>_<時刻>.json`（口の記録＝`Drive の型.md` §2）に置き、パックが返した手順だけを当てる（file は Drive のごみ箱へ）。「残す」の期限は次の見回りがこの記録から読む。
- 答えの無かった行は、次の消す問いにもう一度並ぶ（黙って消さず、黙って残さない）。「残す」と答えた行は新しい期限を必ず持つ。

### 5.2 B12（`道具/寄せ/`）へ渡す物
- 直しを当てる 1 つの中身（Drive を開かない・値だけを受けて返す）: 見通す（1.1 の出力を全部出す）・照らす（今の型と同じ形か・値の保ち）。
- 呼び口は 4 つ: 寄せる（1 社・版 → 今の版）・配る（全社・直し N）・見回り（期限の来た 9_履歴/消す_・前の版のままの会社・寄せ中の会社・消してよい直しを並べ、消す問いの 1 枚を作る）・消す（消す問いにオーナーの答えを当て、殻が当てる消す手順を返す）。殻の口は〔口: 配る〕〔口: 見回り〕〔口: 消す〕（`plugins/payroll-agent/口の一覧.md`）。
- `道具/寄せ/直し/` と直し 1（型の作り。3 の表の中身は各事務所の前の形の読み替えへ）。
- 道具の自分の試験（repo に置く。会社の値は使わない。雛形だけを使う）:
  1. 直しの一致: main の前の版の雛形に、足した直しを当てると、今の版の雛形と同じになる。直しの無い型の直しはここで赤になる。

  3. 値の保ち: 雛形に作り物の値を数個置いて当て、前の値が全部どこかへ移るか、寄せられない物に出る。
  4. 型に移行の物が無い: 型に別名・要る日・読み替え・移した印の欄が 0。
- 殻へ渡す「書く手順」と「戻す手順」の形（タブを足す・名を変える・値を書く・file を写す・file を移す）。Javis 側の殻（Sheets・Drive の口）と UTC 側の殻が同じ手順を当てられるよう、操作は Sheets と Drive の素の操作に限る。

### 5.3 段階 3（C6・D 側）へ渡す物
- 1 社ずつの寄せの段取り（1.5）と、確かめ方（1.6 の人×項目の突き合わせ）。
- 寄せる時に、今ある旧_・99_・02_ を 4 のとおり扱い、消す問いをオーナーへ 1 回で出す。
- 寄せ終えた会社は管理表の型の版を上げる。両方の事務所の全社が版 1 以上になったら、直し 1 を消す PR を出す。

## 6. 古い形の会社を今の形へ移す（`道具/寄せ/古い形を移す.py`・2026-11-24）

前の道具で始めた会社は、`1_決まり/質問と回答`（タブ 質問）の列の並びが前の形・仮の答え（今の型の `見当`）だけ書いてあり答え（`回答`）が空の問い・置き場のタブや管理表「会社」の行の欠け、のどれかが残り、確認ページと `設問.反映の照らし` が回らない。これを 1 社ずつ今の形へ移す。

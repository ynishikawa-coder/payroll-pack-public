# 寄せる道具

- 書く中身: 既存の Drive を新しい型へ寄せる道具・型を直したら雛形と既存のシートへ配る道具・移行の間だけの物を消す段取り・旧_／99_／02_ の持ち主と期限
- 道具の実物: `道具/寄せ/`。この紙はその仕様。
- 型の中身（マスタ・台帳・md の雛形・フォルダの 4 分け・管理表の型）は `docs/設計/Drive の型.md`（B3）が決める。ここでは型の中身を書かず、**寄せ方・配り方・消し方の仕組み** だけを決める。

## 0. 前提と、この紙が止める散らかり

### 前提（変えない物）
- **芯は Drive を開かない**。寄せる道具も Drive を開かない。道具は「今のシートの値（get_values の JSON）・md の本文・置き場の一覧」と「型」を受け取り、「寄せた後の値・書く手順・寄せられない物・人が見る物」を返すだけ。Drive を読む・書く・写すのは各エージェントの repo の殻（環境の口）。
- **顧客の物は repo に置かない**。寄せの前の値・寄せの記録・配った記録・人が見る物は、各事務所の Drive に置く。repo に在るのは型・雛形・直し（下の 1.2）と道具だけ。
- **足りない値は仮で計算し出さない** ⟦鍵:給与計算/足りない時は仮で計算し出さない⟧。寄せる道具は値を作らない。型が既定値を決めている所だけ既定値を入れ、それ以外の足りない値は空のまま「足りない値」として `確かめと仮.md`（B5）の口へ渡す。
- 人の手が入った一点物・99_ の中身・旧_ のタブを **消すのはオーナーの OK の後**。

### この紙で決めること（一言で）
**型の直しは、必ず「直し」1 つ（前の形 → 次の形への手順）と一緒に出す。寄せも配りも、その直しを会社のシートに当てる 1 つの道具で行う。読む側は今の型しか知らない。直しは全社に当たったら消す。** 古い形を読み続ける仕組み（別名・読み替え・要る日）は持たない。

## 1. 寄せる道具

### 1.1 入力と出力

入力（殻が Drive から読んで渡す。道具は Drive を開かない）:

| 入力 | 中身 | 出す所 |
|---|---|---|
| 今のシートの値 | タブごとの get_values の JSON（`{"タブの名": [[…], …]}`）と、タブの名の一覧・各セルが式か値か | 殻（Sheets を読む口） |
| md の本文 | 会社の md（会社の決まり・質問と回答 など、型が決める md）の本文 | 殻（Drive を読む口） |
| 置き場の一覧 | 会社のフォルダの中の file とフォルダの名（中身は読まない） | 殻 |
| 会社の型の版 | 管理表のその会社の行の「型の版」（版の無い会社は 0） | 殻（管理表を読む口） |
| 会社が選んだ部品 | 管理表のその会社の行の「選んだ部品」（入口＝勤怠ツールなど・出口＝給与ソフトなど） | 殻 |
| 型と直し | repo の型の正本と `道具/寄せ/直し/` | このパックの版 |
| 人の答え | 前の回の「寄せられない物」への人の答え（無ければ空）と、任意の「前の形の読み替え」（その事務所の前の道具の形を今の型へ読み替える操作の塊・版ごと。1.3） | 殻（事務所の Drive の寄せの記録） |

出力（道具が返す。書くのは殻）:

| 出力 | 中身 |
|---|---|
| 寄せた後の値 | 型の今の版の形にそろえた、タブごとの値と md の本文 |
| 書く手順 | 殻が Sheets・Drive に当てる操作の並び（タブを足す・名を変える・値を書く・file を移す）。殻はこの順に当てるだけで、判断をしない |
| 戻す手順 | 書く手順の逆（寄せの前の値から作る）。殻はこれで書く前へ戻せる |
| 寄せられない物 | 型にも直しにも行き先の無い物の一覧（1.4）。1 つでもあれば書く手順は空 |
| 足りない値 | 型が要るのに値の無い所（人×項目）。B5 の仮と 1 問の口へ渡す |
| 人が見る物 | 変わるタブ・列・件数、寄せられない物と選べる答え、足りない値の数を 1 枚にした物（置き場は `Drive の型.md` の確認の HTML の置き場） |
| 値の保ちの照らし | 「前の空でない値の数 ＝ 後へ移った数 ＋ 寄せられない物に出た数 ＋ 人が捨てると答えた数」。合わなければ道具は止まる |

### 1.2 直し（寄せも配りも、これを当てる）

型を 1 回直すごとに、`道具/寄せ/直し/` に **直し** を 1 つ置く。直しは「版 N−1 の形を版 N の形へ持ち上げる操作の並び」。

```json
{
  "版": 7,
  "前の版": 6,
  "なぜ": "型を直した理由（1 行）",
  "部品": "共通",
  "操作": [
    {"する": "列の名を変える", "タブ": "社員", "前": "前の見出し", "後": "今の見出し"},
    {"する": "列を足す", "タブ": "社員", "見出し": "新しい項目", "値": "型の既定値 または 空"}
  ]
}
```

操作は閉じた一覧にする（これ以外は直しに書けない。足す時はこの紙を直す）:

| 操作 | 前の形の確かめ | 当たっている印 |
|---|---|---|
| タブを足す | そのタブが無い | 在る |
| タブの名を変える | 前の名が在り、後の名が無い | 後の名だけ在る |
| 列を足す（型の既定値か空） | その見出しが無い | 在る |
| 列の名を変える | 前の見出しが在り、後が無い | 後だけ在る |
| 列の並びをそろえる | 型の列が全部在る | 型の並びと同じ |
| 値の語を読み替える（前の語→今の語） | その列に前の語が在る | 前の語が 0 |
| 列を md の見出しへ移す | 列が在る | 列が無く、見出しに文が在る |
| 列を畳む（移す先が決まっている時だけ） | 列が在り、移す先が在る | 列が無い |
| md の見出しの名を変える・見出しを足す | 前の見出しが在る／見出しが無い | 後の見出しだけ在る |
| file を置き場へ移す | 元の置き場に在る | 先の置き場に在る |
| 値をそろえる（形: 支給月・読み・都道府県・休憩の長さ・欄の名。先の列 で同じ行の別の列へ） | 列に今の形でない値が在る | 全部が今の形（読めない値は寄せられない物） |
| 人の列へ移す（会社の行の前の語 → 社員の列。人の値の在る人は人が勝つ） | 会社の行・社員の列に前の語が在る | 前の語が 0（移る人が 0 なら寄せられない物） |

決まり:
- **どの操作も、前の形を確かめてから当て、当たっていれば飛ばす**。だから同じ直しを何度当てても同じ結果になり、途中で止まっても頭からやり直せる。前の形でも当たった形でもない時は「寄せられない物」に出す。
- 「部品」が付いた直しは、その部品を選んだ会社にだけ当てる（事務所の物＝出口・顧客の物＝入口を選ぶのは事務所と会社。部品は共通に並ぶ）。
- 直しは値を作らない。足すのは型の既定値か空だけ。値をそろえる・人の列へ移す は、前に在った値をその語のまま今の形・今の所へ置き直すだけ（例 前の「計算の仕方」の文の語から 単価の元 を読む）。文の語で 1 つに決まらない・読めない値は作らず、寄せられない物（人が答える）へ回す。
- **型・雛形・直しは同じ PR で出す**。直しの無い型の直しは入れない（B12 の自己検査で止める。5.2）。
- 読む側（芯・入口・出口・型の読み口）は **今の版の型だけ** を知る。前の版の名や語は直しの中にしか無い。

### 1.3 寄せる＝会社の版から今の版まで直しを順に当てる

既存の会社を新しい型へ寄せることは、「その会社の型の版から今の版まで、直しを順に当てる」ことと同じにする。版の無い（今の型より前に作った）会社は版 0 から始める。

**直し 1（版 0 → 版 1）＝初めの寄せ**。パックの直し 1 は、どの事務所の版 0 の会社にも当たる **型の作り**（版 1 の全タブの列・足すタブ・md の見出し・型の並び）だけを持つ。
今ある移行の間だけの物（3 の表）の中身＝1 つの事務所の前の道具の形の読み替え（旧の列の行き先・別名・名の読み替え・旧の語・旧の形の Q-ID・畳んだ列・md へ移す文）は、パックに置かない（`入れてよい物.md` ⟦鍵:給与計算/移行だけの物はパックに入れない⟧）。その事務所の Drive の寄せの記録に **前の形の読み替え**（直しと同じ閉じた操作の塊・版ごと）として置き、殻が人の答えに入れて渡す。道具は版 N の塊を同じ版のパックの直しの前に当てる（便 2 で直し 1・3 から外した。形と塊に入れる物は `道具/寄せ/README.md` の入力。前の形の操作が頼る型の作りの操作も塊に入れる＝v0.1.6 の直し 1・3 の全部の操作をそのまま塊にすれば前と同じ寄せ）。渡さない事務所の前の形は、寄せられない物（1.4）に出て人が答える。

### 1.4 寄せられない物と、選べる答え

| 種類 | 例 | 選べる答え（人が見る物に並べる） |
|---|---|---|
| 行き先の無い列・タブ | 型にも直しにも無い見出し | 型へ足す（B3 へ直しを頼む）／会社の決まりの md へ移す／99_ へ写して消す（オーナーの OK） |
| 一点物 | 型の列に式・手で足した注・型に無い色や並び | 型の値へ置く（式を値にする）／型へ足す／99_ へ写して消す（オーナーの OK） |
| ぶつかり | 2 つの前の列が 1 つの今の列へ来て値が違う | どちらを取るか（人×項目で示す） |
| 形の合わない値 | 数の列に文 | 直した値を書く／空にして足りない値へ回す |
| 旧_ のタブ | 前の手作業の写しの元（4.1） | 中身が今のタブに在ると照らせた物は消す候補（オーナーの OK）／無い物は上のどれか |

- 寄せられない物が 1 つでも残る会社は書かない（1 社の寄せは全部か無しか）。人の答えを入力に足して、もう一度回す。
- 「消す」を含む答えは、その場で消さず 4.4 の **消す問い** にまとめる。

### 1.5 寄せる順番（1 社ずつ・戻せる形）

1 社ずつ、次の順で行う。前の会社が 7 まで済むまで次の会社へ行かない。

1. **止める**: 管理表のその会社を「寄せ中」にする（その間、毎月の仕事はその会社を回さない）。
2. **読む**（殻）: 1.1 の入力をそろえる。
3. **見通す**（道具・書かない）: 寄せた後の値・書く手順・寄せられない物・足りない値・人が見る物を出す。値の保ちが合わなければ止まる。
4. **人が見る**: 寄せられない物に答える。残りが 0 になるまで 2〜4 を回す。
5. **写す**（殻）: 書く前に、表計算の file を丸ごと写して 99_ に置く（名に期限を付ける。4.2）。寄せの前の値の JSON・書く手順・戻す手順を、その会社の寄せの記録として事務所の Drive に置く。**旧_ のタブはもう作らない**（戻すのは写しと戻す手順で行う）。
6. **書く**（殻）: 書く手順を順に当てる。
7. **照らす**: 書いた後を読み直し、道具に「今の型と同じ形か・値の保ちが合うか」を照らさせる。合えば管理表の型の版を今の版にし、「寄せ中」を外す。合わなければ戻す手順で戻し、「寄せ中」のまま理由を管理表に書く。

### 1.6 確かめ方（正しさの判定）

寄せは給与の結果を 1 円も変えてはいけない。だから正しさは段階 3 の本物の 1 社ずつで、次の **人×項目の突き合わせ**（`確かめと仮.md` の形）で判定する。

- 寄せの前に、その会社の直近の月を計算した結果（人×項目）を取っておく。
- 寄せた後に同じ月を同じ版の芯で計算し、人×項目で突き合わせる。全部が一致して寄せは済む。
- 違う人×項目が 1 つでもあれば、その会社は戻す手順で戻し、違いの原因（直しの誤り・寄せられない物の答えの誤り）を直してから寄せ直す。

repo に置く試験は道具の自分の試験だけ（5.2）。作り物の会社の一揃いは作らない。

## 2. 配る道具

### 2.1 正本は repo の 1 か所
- 雛形の正本は repo の 1 か所（置き場は `Drive の型.md` が決める）。事務所の Drive に置く雛形は **写し** で、配る道具が上書きする。Drive の雛形を手で直さない（直したい時は repo の型の PR にする）。
- 型の直しの PR には、型・雛形・直しの 3 つを入れる（1.2）。

### 2.2 配る流れ（型を直したら）

配るは、新しい直しを **事務所の全社** に当てること。中の仕組みは寄せと同じ（1.3 の道具を、管理表に載る全社について回す）。

1. 版を出す: 型の直しの PR が main に入り、版が出る（`docs/版の出し方.md`）。CHANGELOG のその版に「直し N を含む・配りが要る」と書く。
2. 版を上げる: 各エージェントの repo がこのパックの版を上げる時、殻が配るを始める。
3. 雛形の写しを上書きする（事務所の Drive の雛形）。
4. **見通し**（書かない）: 管理表の全社について 1.5 の 2〜3 を回し、事務所ごとに 1 枚の見通しを出す:

   | 会社 | 今の版 | 当てる直し | 変わるタブ | 変わる列の数 | 寄せられない物 | 足りない値 |
   |---|---|---|---|---|---|---|

   （会社の名が入るので、この表は事務所の Drive の確認の HTML の置き場に出す。repo には出さない。）
5. **人の OK を 1 回**: 事務所ごと・直しごとに 1 回、見通しへ OK をもらう。寄せられない物のある会社は、この回は当てずに残し、答えを集める。
6. **当てる**: 寄せられない物の無い会社から 1 社ずつ、1.5 の 5〜7（写す・書く・照らす）を回す。
7. **配った記録**: 管理表の各社の行に「型の版・最後に配った日・写しの場所」を書く。回ごとの記録（当てた会社・飛ばした会社と理由・戻した会社）は事務所の Drive の配りの記録に置く。

### 2.3 配り残しと、直しを消す時
- 寄せられない物があって当てられなかった会社は、管理表で前の版のまま残る。配る道具は毎回「前の版のままの会社」を見通しの頭に並べる（黙って残さない）。
- **直し N は、管理表の全社（両方の事務所）の型の版が N 以上になったら消す**。配る道具は見通しの終わりに「消してよい直し」を並べる。消す時は直しを消す PR を出す。新しい会社は雛形（今の版）から作るので、古い直しを要らない。
- 両方の事務所の版がそろうまでは直しを消さない。各事務所は自分の管理表の「消してよい直し」を、直しを消す PR の本文に書く（会社の名は書かず、版と社数だけ）。

## 3. 移行の間だけの物を消す段取り

**消す時期は全部同じ: 作り替えの便で一気に消す**（Javis 側の `agents/kyuyo` と UTC 側の給与の仕組みが、このパックへ移る便）。中身はその事務所の前の形の読み替え（1.3。事務所の Drive）へ写すので、このパックには 1 つも持ち込まない（便 1 までは直し 1 へ写していた＝便 2 で外した。下の表の「直し 1 の〜」は、今は「その事務所の前の形の読み替え（版 1）の〜」と読む）。パックの直し 1（型の作り）は、両方の全社が版 1 以上になった時に消す（2.3）。

| なくす物 | 今の在り処 | 中身の行き先 | 消す条件 | 消す時期 | 誰が |
|---|---|---|---|---|---|
| 旧の列の行き先 と読む口 | `道具/旧の列の行き先.json`・`kata.load`（`kata.py:6-65`） | 直し 1 の「列の名を変える・列を足す・列を畳む」 | 直し 1 に全部の行を写し、直し 1 の自己検査（5.2）が緑 | 作り替えの便 | 写す: B12／消す: 作り替えの便 |
| 名の読み替え（前の給与ソフトの名つきの欄→ソフトの欄） | `型.json:6043-`・`kata.py:323-337` | 直し 1 の「列の名を変える」。型は今の名（ソフトの欄）だけを持つ | 型に読み替えが 0 | 作り替えの便 | B3（型）・B12（直し 1） |
| 道具の引数の前の名 `--cells` | `kotae.py:913` | 無し（今の名の引数だけにする） | 呼ぶ側に `--cells` が 0 | 作り替えの便 | 作り替えの便 |
| 旧の語（出所の語） | `型.json:3462`・`kata.py:196-240` | 直し 1 の「値の語を読み替える」 | 型に旧の語が 0 | 作り替えの便 | B12 |
| 旧の形の Q-ID（要る日 2026-11-04） | 型の要る日と読み口 | 直し 1 の「値の語を読み替える」（質問と回答の Q-ID を今の形へ書き直す） | 型に要る日が 0 | 作り替えの便 | B12 |
| 別名（前の版の見出し） | `型.json:44-60,64,290,373,1241` | 直し 1 の「列の名を変える」「md の見出しの名を変える」 | 型に別名が 0 | 作り替えの便 | B3・B12 |
| 畳んだ列（質問と回答） | `型.json:385-388` | 直し 1 の「列を畳む」 | 型に畳んだ列が 0 | 作り替えの便 | B12 |
| 「要る日」より前を空で通す扱い（読めない理由・要る日 2026-11-10） | 型の要る日と読み口 | 直し 1 の「列を足す」で、要る日より前に閉じた行の空へ決まった値「欄より前」を入れる。読む側は日を見ずに一律で値を求める | 型に要る日が 0 | 作り替えの便 | B12 |
| md へ移す文と移した印 | `型.json:2722-2754` | 直し 1 の「列を md の見出しへ移す」。印は要らない（列が無いことが当たった印） | 型に移した印が 0 | 作り替えの便 | B12 |
| UTC 側の同じ役の物（ATO_RETSU など） | UTC 側の給与の仕組み | UTC 側の窓が同じ形（前の形の読み替え）へ写し、UTC の Drive に置く（パックの直しは型の作りの 1 つ） | UTC 側の読み口に旧の列の対応が 0 | 作り替えの便 | UTC 側の窓（D 側） |

「要る日より前」の決め方（推奨で決めた）: 空を日で許す例外を読む側に残すより、寄せの時に「欄より前」という決まった値で埋め、読む側は例外を持たない方を取った。値を作っているのではなく「この欄ができる前に閉じた行」という事実を書くだけなので、仮の決まりとぶつからない。

## 4. 旧_・99_・02_ の持ち主と期限

どれも「誰が中を見るか・いつまでか・期限が来たら何が起きるか」を置いた時に決める。**期限が来ても道具は消さない**。期限の来た物は次の消す問い（4.4）に並び、オーナーの OK の後に殻が消す。

| 物 | これから作るか | 持ち主（中を見る窓） | 期限 | 期限が来たら |
|---|---|---|---|---|
| `旧_<名>` のタブ | **作らない**（寄せも配りも、写しと戻す手順で戻す。1.5） | 今あるもの: その会社を寄せる窓（段階 3 の C6・D 側） | その会社の寄せの日 | 寄せの時に旧_ を今のタブと照らし、消す問いへ並べる |
| `99_` の物 | 寄せ・配りの写し・人が要らないと決めた物 | 置いた窓（名に書く） | 置いた時に名へ書く（4.2） | 消す問いへ並べる |
| `02_初回の書類` | 立ち上げの時だけ | 立ち上げの窓 | 先方の初回の確認の OK の日（管理表に書く） | 原本は原本の置き場へ、残りは 99_ へ移し、消す問いへ |

### 4.1 旧_ のタブ
- 今ある旧_ は、その会社の寄せ（1.5）の入力に含める。道具は旧_ の値が今のタブに在るかを照らし（値の保ちの照らしと同じ）、
  - 全部在る → 「中身は今のタブに在る」として消す候補にする。
  - 無い値が在る → 寄せられない物に出し、人が行き先を答える（1.4）。
- 寄せの写し（1.5 の 5）に旧_ も入るので、生きているシートから旧_ を外しても中身は期限まで 99_ に残る。外すのはオーナーの OK の後。
- これからの寄せ・配りは旧_ を作らないので、旧_ は寄せが全社を回り終えた時に 0 になる。

### 4.2 99_消してよい物
- 置く時に、file の名の頭へ **期限** を付ける: `<期限 YYYYMMDD>_<何>_<置いた窓の役>`。期限の無い名の物は置かない。
- 期限の決め方:
  - 寄せ・配りの写し: 寄せ・配りの後に、その会社の初めての月の人×項目の突き合わせ（1.6）が緑になった月の翌月末。
  - 人が要らないと決めた物: 置いた日の翌月末。
- 今ある期限の無い物（昔の木・人の名の入った原本など）は、その会社の寄せの時に寄せる窓が中を見て、原本は原本の置き場（`Drive の型.md` のフォルダの 4 分け）へ移す候補、残りは期限を付ける候補として、消す問いに並べる。

### 4.3 02_初回の書類
- 02_ は立ち上げの間だけの置き場。立ち上げの窓は、02_ の中の値で毎月の仕事に要る物を、立ち上げの間に台帳・マスタ・質問と回答・会社の決まりの md へ写す。**毎月の窓は 02_ を読まない**。
- 今の食い違い（手順.md:91「毎月の窓は読まない」と :136「仮を埋める時に読む」）は、:91 の方にそろえる。仮を埋めるのに要る値は、立ち上げの時に台帳・マスタへ写してあるはずで、無ければ `確かめと仮.md` の 1 問で聞く。:136 の道は畳む。
- 先方の初回の確認の OK の日を管理表に書き、その日に 02_ は期限が来る。原本は原本の置き場へ、残りは期限を付けて 99_ へ移し、消す問いに並べる。
- 今、立ち上げの後も残っている 02_ は、その会社の寄せの時に上と同じに扱う。

### 4.4 消す問い（オーナーへ 1 回で聞く形）
- 寄せの波ごと（段階 3 の間）と、その後は月に 1 回まで、事務所ごとに 1 枚にまとめて聞く。その間に期限の来た物と、寄せで出た「消す」答えを全部並べる。
- 1 枚の形（事務所の Drive の確認の HTML の置き場に出す。会社の名が入るので repo には出さない）:

  | 会社 | 物 | 置き場 | 中を見た窓 | 中身はどこに在るか（今のタブ／原本の置き場／どこにも無い） | 期限 | 推奨（消す／原本へ移す／残す＋新しい期限） |
  |---|---|---|---|---|---|---|

- オーナーは「推奨どおり全部」か、行ごとの答えで返す。答えは事務所の Drive の消す問いの記録に置き、殻が答えのとおり消す・移す。
- 答えの無かった行は、次の消す問いにもう一度並ぶ（黙って消さず、黙って残さない）。「残す」と答えた行は新しい期限を必ず持つ。

### 5.2 B12（`道具/寄せ/`）へ渡す物
- 直しを当てる 1 つの中身（Drive を開かない・値だけを受けて返す）: 見通す（1.1 の出力を全部出す）・照らす（今の型と同じ形か・値の保ち）。
- 呼び口は 3 つ: 寄せる（1 社・版 → 今の版）・配る（全社・直し N）・見回り（期限の来た 99_ と 02_・前の版のままの会社・消してよい直しを並べ、消す問いの 1 枚を作る）。
- `道具/寄せ/直し/` と直し 1（型の作り。3 の表の中身は各事務所の前の形の読み替えへ）。
- 道具の自分の試験（repo に置く。会社の値は使わない。雛形だけを使う）:
  1. 直しの一致: main の前の版の雛形に、足した直しを当てると、今の版の雛形と同じになる。直しの無い型の直しはここで赤になる。
  2. 二度当て: 当てた後へもう一度当てても変わらない。
  3. 値の保ち: 雛形に作り物の値を数個置いて当て、前の値が全部どこかへ移るか、寄せられない物に出る。
  4. 型に移行の物が無い: 型に別名・要る日・読み替え・移した印の欄が 0。
- 殻へ渡す「書く手順」と「戻す手順」の形（タブを足す・名を変える・値を書く・file を写す・file を移す）。Javis 側の殻（Sheets・Drive の口）と UTC 側の殻が同じ手順を当てられるよう、操作は Sheets と Drive の素の操作に限る。

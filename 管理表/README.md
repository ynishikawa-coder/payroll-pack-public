# 管理表 — 状況の正本（事務所の根/管理表）の型と書く口

月ごとの給与計算の状況の正本は、事務所に 1 本の `事務所の根/管理表`。全社の月の状況・会社ごとの目次の月の状況（今の形では持たない）・ほかの状況の表はここ 1 つに寄せる（`docs/設計/Drive の型.md` §5）。タスク（次に動く人・窓の引き継ぎ）は管理表の行を「タスクへのリンク」で指すだけで、タスクの状態を管理表へ写さない。

## 置く物

| file | 中身 |
|---|---|
| `型.json` | 7 タブ（月の状況・賞与の状況・突き合わせの記録・確認ページ・会社・出した物・段）の列・意味・選べる値（役で引く列は `値の役`）・鍵・行を起こす段・回（月・賞与） |
| `管理表.py` | 窓の書く口・事務所の段の口 |
| `段.py` | 出す の試しの返り・会社の状態・回のタブの行から、会社×支給月×回の段・足りない物・次にやること を組む口（`段を見る`・`管理表の行`＝「段」のタブへ書く行）。段の表は `docs/毎月の流れ.md` |
| `突き合わせの記録.py` | 給与ソフトとの突き合わせの結果から、記録のタブと月の状況「突き合わせ」を書く手順を組む口（`書く手順`） |

型の正本は `初期設定/` の 1 か所と決めているが（`Drive の型.md` §5）、管理表は組でなく事務所に 1 本で、書く口と同じ dir に置く方が読み書きの型が 1 つにそろうので `管理表/型.json` に置く。

## タブ

| タブ | 1 行 | 鍵 | 行を起こす |
|---|---|---|---|
| 月の状況 | 会社×支給月（月の給与の回） | 会社・支給月 | 事務所の段（`月の行`） |
| 賞与の状況 | 会社×支給月（賞与の回） | 会社・支給月 | 窓（`書く` が無ければ足す・組は会社の組） |
| 突き合わせの記録 | 会社×支給月×回（給与ソフトと突き合わせた 1 回） | 会社・支給月・回 | 窓（`突き合わせの記録.py 書く手順` が無ければ足す・組は会社の組） |
| 確認ページ | 配った版 1 つ | 会社・載せた日・確認ページ（URL） | 窓（`書く` が無ければ足す） |
| 会社 | 会社（型の版・選んだ部品・初回の確認の OK の日。`寄せ` などの前の道具の列は型に残るが書かない＝下の「選び方」） | 会社 | 事務所の段（`会社の行`） |
| 出した物 | 会社×支給月×回×物（今の版とリンク） | 会社・支給月・回・物 | 出口/出す.py |
| 段 | 会社×支給月×回（今の段・足りない物・次にやること） | 会社・支給月・回 | 窓（`出口/段を見る.py --書く`＝`書く` が無ければ足す・組は会社の組） |

## 呼び口

すべて `python3 管理表/管理表.py <口> < 入力.json`。出力は窓が順に当てる「書く手順」（`{"する": "値を書く", "タブ", "セル", "列", "前", "値", "書き方"}`・`{"する": "行を足す", "タブ", "値", "書き方"}`・`{"する": "タブを足す", "タブ", "見出し", "書き方"}`）。`書き方` は `RAW`＝値を字のまま書く（Sheets の valueInputOption=RAW。数だけの字・日付の字を数や日付に読ませない）。拒む時は `{"拒む": 理由}` で終わりの値 2。

| 口 | 入力 | 何をするか |
|---|---|---|
| `書く`（窓） | `タブ`・`今の値`（get_values・1 行目が見出し）・`会社の一覧`（`{会社: 組}`）・`受け持つ組`・`行たち`（鍵の列と書く列だけの辞書）・`今日`・`回`（任意: 月・賞与） | 受け持つ組の会社の行だけを鍵で探して書く。月の状況・賞与の状況は更新日を今日にする。`回` を渡したら、タブがその回のタブでなければ拒む |
| `回のタブ` | `回`（月・賞与） | その回の状況のタブの名（型の「回」から。知らない回は拒む）。出口/出す.py は `管理表の行` が返す `管理表のタブ` をそのまま使う（同じ表から引く） |
| `出した物のタブ` | なし | 物ごとの今の版とリンクを書くタブの名（タブ「出した物」1 つ）。出口/出す.py は `管理表の行` が返す `出した物のタブ` をそのまま使う |
| `月の行`（事務所） | `今の値`・`会社の一覧`（`[{会社, 組, 状態}]`）・`支給月`（管理表の字 `YYYY.MM支給（M月分）`＝ほかの字は拒む）・`今日` | 止めた以外の会社の、その支給月の行が無ければ足す |
| `月の段`（事務所） | `会社の一覧`（事務所の設定「会社の一覧」の get_values のまま）・`会社`（管理表「会社」の get_values・任意）・`今の値`（管理表「月の状況」の get_values）・`月たち`（`[{会社, 支給月}]`＝会社の 3_月ごと に在る月のフォルダの名のまま `YYYY.MM支給（M月分）`）・`今日` | 毎月の流れの頭（月のフォルダを作った時）に、無い物だけを起こす: 会社の一覧の 状態 が空の行へ 管理表「会社」の 初回の確認の OK の日 が在れば 毎月・無ければ 立ち上げ（`値を書く`・前は空）、月たちの (会社, 支給月) の月の状況の行が無ければ足す（中で `月の行`）。在る行・字の在るセルは触らない。会社の一覧に無い会社は拒む。前の形から移した事務所の空も同じ口で埋まる（`道具/移しの点検.py` が案に使う） |
| `会社の行`（事務所） | `今の値`・`会社の一覧`（`[{会社, 組, 型の版, 選んだ部品}]`・型の版は必ず数で渡す＝省く・空・数でない時は拒む） | 会社の行が無ければ足す |
| `立ち上げ`（事務所） | `今のタブ`（`{タブの名: 今の値}`・管理表の全部のタブ・値の無いタブは `[]`。必ず渡す＝省く・空の `{}`・値が行の並びでないタブは拒む） | 型のタブ（月の状況・賞与の状況・突き合わせの記録・確認ページ・会社・出した物・段）が無ければ見出しまで足す手順。在って見出しが型と違うタブは書き換えず拒む（違う列を並べる・前の値の移し方は事務所が決める）。型に無いタブ（前の管理表の `全社_会社` など）は触らない＝書く口・`型の版` は型のタブの名だけを読む。何度当てても同じ |
| `事務所の設定を寄せる`（事務所） | `会社の一覧`・`置き場`（事務所の設定の 2 タブの get_values のまま・置き場は空でもよい）・`型の版`（窓が読んだ型の版＝パックの版と違えば拒む）・`台帳`（`置き場の登録を移す` と同じ・前の形の台帳の 1 行が在る時だけ） | `{手順, 戻す, 問い, 振った, 後の表}`。2 タブを型の見出しの並びへそろえ（無い列は空で足す・型に無い列は拒む）、会社の一覧の空の 顧客ID へ次の番号（数だけの字の一番大きい物 + 1・3 桁・間は埋めない＝二度と使わない）を上の行から振り、置き場へ写す（中で `置き場の登録を移す` を呼ぶ）。変わるタブだけ `値を書く`（RAW）1 手ずつと戻す手順。問いが在れば手順は空。型の形で緑なら手順 0（Drive の型 §8「顧客ID を振る」） |
| `置き場の登録を移す`（事務所） | `置き場`（事務所の設定「置き場」の get_values のまま・前の 4 列の形も受ける）・`会社の一覧`（同じく「会社の一覧」・頭の列 `顧客ID` が要る）・`型の版`（窓が読んだ型の版＝パックの版と違えば拒む）・`台帳`（`{組: {支給年: [ID…]}}`＝型の字 `台帳_<支給年>` の 1 行を持つ組だけ・組の根の下を名で探した ID） | `{手順, 戻す, 問い, 後の表}`。置き場を 1 つの (顧客ID, 物) に 1 行（Drive の型 §8）へ移す「置き場」タブ全体の `値を書く` 1 手と、前の表へ書き戻す 1 手。顧客ID の列が無い・空のある一覧は拒む（先に `事務所の設定を寄せる` で振る）。決まらない所（一覧の顧客ID の重なり・呼び名で 1 つに決まらない会社・同じ (顧客ID, 物) の違う ID・台帳の年の ID が 0 か 2 つ以上）は手順を空にして `問い`（`{相手: 事務所の担当者, 所, 訳}`）を返す。移した表は置き場の検査の項目 8 と同じ口で照らす。今の形で緑の表は手順 0 |

突き合わせの記録は Python の口 `突き合わせの記録.書く手順(結果, 給与ソフトが違うで閉じた=…, 場面=…, 今の記録=…, 今の月の状況=…, 会社の一覧=…, 受け持つ組=…, 今日=…, 事務所の既定=…)` で書く（`事務所の既定` は事務所の設定「既定」のタブの get_values のまま＝N `突き合わせ.差0の月数の目安` を口が読む・無ければ `初期設定/項目.json` の既定）（`結果` は `月次.突き合わせる` が返した物だけを受ける＝窓が数を組まない。会社・支給月・回は結果の人から取る＝人の居ない結果・会社や回のまたがる結果は拒む。記録のタブの読めない支給月は行の番号つきで拒む）。返す `手順` は `書く` の手順と同じ形で、記録のタブの行と、月の回は月の状況「突き合わせ」（記録から数えた続けて差 0 の月数）を書く（賞与の回は記録のタブだけ）。窓は〔口: 突き合わせ〕で順に当てるだけ。

## 書く口の仕切り（拒む物）

- 見出しが型と 1 列でも違うタブ（違う列を拒む理由に並べる。事務所の管理表を型へそろえてから・タブが無ければ `立ち上げ`）。前の形の管理表（例 タブの名が `全社_会社` で 型の版・選んだ部品・寄せ の列が無い）は管理表の型でない＝事務所の段の立ち上げ（`立ち上げ` で型のタブを足し、前の値の要る列を事務所が移す）の後に書く。
- 受け持つ組の外の会社の行・行の組が受け持つ組でない行・型に無い列・鍵の列が空の行。
- 「組」を書き替えること（組を書くのは事務所の段だけ）。
- `=`・`+`・`@` で始まる字（管理表の書く所に式を置かない。窓は値をそのまま〔RAW〕で書く）。
- 月の状況と会社の行を窓が起こすこと（起こすのは事務所の段）。回を渡した書き方で、その回のタブの外へ書くこと（賞与の行を 月の状況 へ）。行を消す手順は出さない。
- 選べない値・数でない数・YYYY-MM-DD でない日付（足す行は全部の列を照らす。選べる値に空の無い列は空にできない）。
- 外した人が 0 でないのに 取り込み・納品 を 済 にすること。

## 回で行を分ける

- 同じ会社・同じ支給月に月の給与と賞与がある時、月の給与は「月の状況」、賞与は「賞与の状況」の別の行に書く（鍵は同じ 会社・支給月・タブで回を分ける）。前は 月の状況 の 1 行だけで、賞与の出荷が月の給与の 取り込み・止まりの理由（当時は今の版も書いていた）を上書きした。
- タブを分けた訳（回の列を足さない訳）: 月の状況 の列と鍵を変えると、事務所の今の管理表の見出しが型と違って 書く が拒み、月の給与まで止まる。新しいタブなら `立ち上げ` が見出しまで足すだけで、月の状況 は今のまま書ける。
- 賞与の状況の行を起こすのは出口/出す.py。賞与は払う会社・月にだけ起きるので、事務所の段が毎月起こす行にしない。組は口が会社の一覧の組を書く（窓は組の字を書かない）。

## 出した物（物ごとの今の版とリンク）

- 出荷した物の全部（取り込み・支給控除一覧・有給休暇管理表など、出す物の全部）の今の版とリンクは、タブ「出した物」に 1 物 1 行で書く（鍵は 会社・支給月・回・物）。行を起こすのも書くのも〔口: 出荷〕だけ（`書くのは: 出口/出す.py`）。同じ会社・支給月でも回が違えば別の行（月次の取り込みと賞与の取り込みが上書きし合わない）。管理表の回のタブと出した物の列が欠けていれば、出す.py は物を置く前に止める（置いてから止まって、2_出す物 だけ新しい版の半端を残さない）。
- 前は 取り込み の 1 物だけを回の状況のタブの 止まりの理由 に `今の版: 名 リンク` で書いていた。止まりの理由は止まった・仮の訳の欄で、今の版の置き場でない（取り違え）。そのため他の物のリンクが管理表のどこにも残らなかった。今は止まりの理由に今の版を書かず、前の形の `今の版: …` は次の出荷で外す。
- タブを足した訳（回の状況のタブに列を足さない訳）は「回で行を分ける」と同じ: 今のタブの見出しを変えると 書く が拒み、出荷まで止まる。新しいタブなら `立ち上げ` が足すだけで、今のタブは直さない。物の数は会社と月で違うので、列でなく行で持つ。
- 出した後の月を揃えるには、`立ち上げ` で 出した物 のタブを足し、その月を〔口: 出荷〕で出し直す（全部の物の次の版を置き、前の版を履歴へ移し、物ごとの行を書き、止まりの理由の前の形の今の版を外す）。

## 選び方

- 状況の語は列ごとの選べる値だけ（`型.json` の列の `選べる値`、または `値の役` の字）。道具は字を写さず `管理表.値の字(タブ, 列, 役)` で役から引く（確認ページ の 状況 は 待ち・答えた・差し替え の役）。止まり・仮の時は止まりの理由に 1 行。
- 確認ページを配り直したら、新しい行を足し、前の行の状況を 差し替え の役の字にする（行は消さない）。
- 型の版は事務所の段の `会社の行` で書く（列の字を窓が組まない）。`寄せ`・`寄せの理由`・`写しの場所`・`最後に配った日` の列は前の道具の列で、今は書かない（見出しを変えると在る管理表の見出しが型と違うので、型から抜くのは管理表の型の版を上げる時）。
- 管理表そのものの型（`型.json` の `版`）は直しの道が無く（事務所の管理表がどの版かの記録も無い）。在るタブの列・鍵を変える時は、`Drive の型.md` §5 の畳む段取り（`初期設定/型.json` のシートへ移して版を 1 つに）を先にする。タブを足すだけの変更（版 2 の 賞与の状況）は `立ち上げ` が足すので直しの道が要らない＝畳む段取りを待たない（在るタブは 1 字も変えない）。
- 鍵の 支給月 は字のまま比べず、支給月の字の正本（`芯/支給月の字.py` の `鍵の年月`）で年月に読んで比べる＝管理表の字 `YYYY.MM支給（M月分）`（docs/毎月の流れ.md「支給月の書き方」）の行を、出口/出す.py が渡す月次の字 `YYYY.MM支給` で探して当たる。探す鍵・同じ会社の行の支給月がどちらの字でもなければ拒む（黙って「行が無い」や別の月にしない）。前は字のまま比べ、決まりどおり（M月分）付きの行を出口/出す.pyが見つけられず止まった（2026-11-19）。

# 管理表 — 状況の正本（00_事務所/管理表）の型と書く口

月ごとの給与計算の状況の正本は、事務所に 1 本の `00_事務所/管理表`。全社の月の状況・会社ごとの目次の月の状況（今の形では持たない）・ほかの状況の表はここ 1 つに寄せる（`docs/設計/Drive の型.md` §5）。タスク（次に動く人・窓の引き継ぎ）は管理表の行を「タスクへのリンク」で指すだけで、タスクの状態を管理表へ写さない。

## 置く物

| file | 中身 |
|---|---|
| `型.json` | 4 タブ（月の状況・賞与の状況・確認ページ・会社）の列・意味・選べる値・鍵・行を起こす段・回（月・賞与） |
| `管理表.py` | 窓の書く口・事務所の段の口 |

型の正本は `初期設定/` の 1 か所と決めているが（`Drive の型.md` §5）、管理表は組でなく事務所に 1 本で、書く口と同じ dir に置く方が読み書きの型が 1 つにそろうので `管理表/型.json` に置く。

## タブ

| タブ | 1 行 | 鍵 | 行を起こす |
|---|---|---|---|
| 月の状況 | 会社×支給月（月の給与の回） | 会社・支給月 | 事務所の段（`月の行`） |
| 賞与の状況 | 会社×支給月（賞与の回） | 会社・支給月 | 窓（`書く` が無ければ足す・組は会社の組） |
| 確認ページ | 配った版 1 つ | 会社・載せた日・確認ページ（URL） | 窓（`書く` が無ければ足す） |
| 会社 | 会社（型の版・選んだ部品・寄せ・初回の確認の OK の日） | 会社 | 事務所の段（`会社の行`） |

## 呼び口

すべて `python3 管理表/管理表.py <口> < 入力.json`。出力は殻が順に当てる「書く手順」（`{"する": "値を書く", "タブ", "セル", "列", "前", "値", "書き方"}`・`{"する": "行を足す", "タブ", "値", "書き方"}`・`{"する": "タブを足す", "タブ", "見出し", "書き方"}`）。`書き方` は `RAW`＝値を字のまま書く（Sheets の valueInputOption=RAW。数だけの字・日付の字を数や日付に読ませない）。拒む時は `{"拒む": 理由}` で終わりの値 2。

| 口 | 入力 | 何をするか |
|---|---|---|
| `書く`（窓） | `タブ`・`今の値`（get_values・1 行目が見出し）・`会社の一覧`（`{会社: 組}`）・`受け持つ組`・`行たち`（鍵の列と書く列だけの辞書）・`今日`・`回`（任意: 月・賞与） | 受け持つ組の会社の行だけを鍵で探して書く。月の状況・賞与の状況は更新日を今日にする。`回` を渡したら、タブがその回のタブでなければ拒む |
| `回のタブ` | `回`（月・賞与） | その回の状況のタブの名（型の「回」から。知らない回は拒む）。出荷の口は `出す前の照らし.py 管理表の行` が返す `管理表のタブ` をそのまま使う（同じ表から引く） |
| `月の行`（事務所） | `今の値`・`会社の一覧`（`[{会社, 組, 状態}]`）・`支給月`（管理表の字 `YYYY.MM支給（M月分）`＝ほかの字は拒む）・`今日` | 止めた以外の会社の、その支給月の行が無ければ足す |
| `会社の行`（事務所） | `今の値`・`会社の一覧`（`[{会社, 組, 型の版, 選んだ部品}]`・型の版は必ず数で渡す＝省く・空・数でない時は拒む） | 会社の行が無ければ足す |
| `型の版` | `今の値`（会社のタブ）・`会社たち`（無ければ全社） | `{型の版: {会社: 数}, 版が空: [会社…]}`。寄せる道具の入力 `型の版` へ渡す。行の無い会社・数でない版は拒む（黙って 0 にしない）。空は 0（版の無い会社） |
| `立ち上げ`（事務所） | `今のタブ`（`{タブの名: 今の値}`・管理表の全部のタブ・値の無いタブは `[]`。必ず渡す＝省く・空の `{}`・値が行の並びでないタブは拒む） | 型のタブ（月の状況・賞与の状況・確認ページ・会社）が無ければ見出しまで足す手順。在って見出しが型と違うタブは書き換えず拒む（違う列を並べる・前の値の移し方は事務所が決める）。型に無いタブ（前の管理表の `全社_会社` など）は触らない＝書く口・`型の版` は型のタブの名だけを読む。何度当てても同じ |

## 書く口の仕切り（拒む物）

- 見出しが型と 1 列でも違うタブ（違う列を拒む理由に並べる。事務所の管理表を型へそろえてから・タブが無ければ `立ち上げ`）。前の形の管理表（例 タブの名が `全社_会社` で 型の版・選んだ部品・寄せ の列が無い）は管理表の型でない＝事務所の段の立ち上げ（`立ち上げ` で型のタブを足し、前の値の要る列を事務所が移す）の後に書く。
- 受け持つ組の外の会社の行・行の組が受け持つ組でない行・型に無い列・鍵の列が空の行。
- 「組」を書き替えること（組を書くのは事務所の段だけ）。
- `=`・`+`・`@` で始まる字（管理表の書く所に式を置かない。殻は値をそのまま〔RAW〕で書く）。
- 月の状況と会社の行を窓が起こすこと（起こすのは事務所の段）。回を渡した書き方で、その回のタブの外へ書くこと（賞与の行を 月の状況 へ）。行を消す手順は出さない。
- 選べない値・数でない数・YYYY-MM-DD でない日付（足す行は全部の列を照らす。選べる値に空の無い列は空にできない）。
- 外した人が 0 でないのに 取り込み・納品 を 済 にすること。

## 回で行を分ける

- 同じ会社・同じ支給月に月の給与と賞与がある時、月の給与は「月の状況」、賞与は「賞与の状況」の別の行に書く（鍵は同じ 会社・支給月・タブで回を分ける）。前は 月の状況 の 1 行だけで、賞与の出荷が月の給与の 取り込み・止まりの理由（今の版）を上書きした。
- タブを分けた訳（回の列を足さない訳）: 月の状況 の列と鍵を変えると、事務所の今の管理表の見出しが型と違って 書く が拒み、月の給与まで止まる。新しいタブなら `立ち上げ` が見出しまで足すだけで、月の状況 は今のまま書ける。
- 賞与の状況の行を起こすのは書く窓（出荷の口）。賞与は払う会社・月にだけ起きるので、事務所の段が毎月起こす行にしない。組は口が会社の一覧の組を書く（窓は組の字を書かない）。

## 選び方

- 状況の語は列ごとの選べる値だけ（済・仮・止まり・お答え待ち など）。止まり・仮の時は止まりの理由に 1 行。
- 確認ページを配り直したら、新しい行を足し、前の行の状況を 差し替え にする（行は消さない）。
- 型の版は、寄せる道具（`道具/寄せ/呼び口.py 寄せる`・`配る`）が照らす回に返す `管理表へ書く` の行を、殻が `書く`（タブ 会社）へそのまま渡して書く（`docs/設計/寄せる道具.md` §1.5 の 7）。読むのは `型の版`。
- 管理表そのものの型（`型.json` の `版`）は寄せる道具の外（直しの道が無く、事務所の管理表がどの版かの記録も無い）。在るタブの列・鍵を変える時は、`Drive の型.md` §5 の畳む段取り（`初期設定/型.json` のシートへ移して版を 1 つに）を先にする。タブを足すだけの変更（版 2 の 賞与の状況）は `立ち上げ` が足すので直しの道が要らない＝畳む段取りを待たない（在るタブは 1 字も変えない）。
- 鍵の 支給月 は字のまま比べず、支給月の字の正本（`芯/支給月の字.py` の `鍵の年月`）で年月に読んで比べる＝管理表の字 `YYYY.MM支給（M月分）`（docs/毎月の流れ.md「支給月の書き方」）の行を、出荷の口が渡す殻の字 `YYYY.MM支給` で探して当たる。探す鍵・同じ会社の行の支給月がどちらの字でもなければ拒む（黙って「行が無い」や別の月にしない）。前は字のまま比べ、決まりどおり（M月分）付きの行を出荷の口が見つけられず止まった（2026-11-19）。

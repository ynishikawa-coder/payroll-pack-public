# 管理表 — 状況の正本（00_事務所/管理表）の型と書く口

月ごとの給与計算の状況の正本は、事務所に 1 本の `00_事務所/管理表`。全社の月の状況・00_目次 の月の状況・ほかの状況の表はここ 1 つに寄せる（`docs/設計/Drive の型.md` §5）。タスク（次に動く人・窓の引き継ぎ）は管理表の行を「タスクへのリンク」で指すだけで、タスクの状態を管理表へ写さない。

## 置く物

| file | 中身 |
|---|---|
| `型.json` | 3 タブ（月の状況・確認ページ・会社）の列・意味・選べる値・鍵・行を起こす段 |
| `管理表.py` | 窓の書く口・事務所の段の口・00_目次 へ引く式 |

型の正本は `初期設定/` の 1 か所と決めているが（`Drive の型.md` §5）、管理表は組でなく事務所に 1 本で、書く口と同じ dir に置く方が読み書きの型が 1 つにそろうので `管理表/型.json` に置く。

## タブ

| タブ | 1 行 | 鍵 | 行を起こす |
|---|---|---|---|
| 月の状況 | 会社×支給月 | 会社・支給月 | 事務所の段（`月の行`） |
| 確認ページ | 配った版 1 つ | 会社・載せた日・確認ページ（URL） | 窓（`書く` が無ければ足す） |
| 会社 | 会社（型の版・選んだ部品・寄せ・初回の確認の OK の日） | 会社 | 事務所の段（`会社の行`） |

## 呼び口

すべて `python3 管理表/管理表.py <口> < 入力.json`。出力は殻が順に当てる「書く手順」（`{"する": "値を書く", "タブ", "セル", "列", "前", "値"}` か `{"する": "行を足す", "タブ", "値"}`）。拒む時は `{"拒む": 理由}` で終わりの値 2。

| 口 | 入力 | 何をするか |
|---|---|---|
| `書く`（窓） | `タブ`・`今の値`（get_values・1 行目が見出し）・`会社の一覧`（`{会社: 組}`）・`受け持つ組`・`行たち`（鍵の列と書く列だけの辞書）・`今日` | 受け持つ組の会社の行だけを鍵で探して書く。月の状況は更新日を今日にする |
| `月の行`（事務所） | `今の値`・`会社の一覧`（`[{会社, 組, 状態}]`）・`支給月`・`今日` | 止めた以外の会社の、その支給月の行が無ければ足す |
| `会社の行`（事務所） | `今の値`・`会社の一覧`（`[{会社, 組, 型の版, 選んだ部品}]`） | 会社の行が無ければ足す |
| `目次の式` | `組`・`管理表のID`（殻が 事務所の設定「置き場」から引く） | 00_目次 の月の状況の左上に置く式（組の行だけを引く・見るだけ） |

## 書く口の仕切り（拒む物）

- 見出しが型と 1 列でも違うタブ（寄せる道具で型へそろえてから）。
- 受け持つ組の外の会社の行・行の組が受け持つ組でない行・型に無い列・鍵の列が空の行。
- 「組」を書き替えること（組を書くのは事務所の段だけ）。
- `=`・`+`・`@` で始まる字（管理表の書く所に式を置かない。殻は値をそのまま〔RAW〕で書く）。
- 月の状況と会社の行を窓が起こすこと（起こすのは事務所の段）。行を消す手順は出さない。
- 選べない値・数でない数・YYYY-MM-DD でない日付（足す行は全部の列を照らす。選べる値に空の無い列は空にできない）。
- 外した人が 0 でないのに 取り込み・納品 を 済 にすること。

## 選び方

- 状況の語は列ごとの選べる値だけ（済・仮・止まり・お答え待ち など）。止まり・仮の時は止まりの理由に 1 行。
- 確認ページを配り直したら、新しい行を足し、前の行の状況を 差し替え にする（行は消さない）。
- 型の版は寄せる道具が寄せ・配りの後に書く（`docs/設計/寄せる道具.md`）。

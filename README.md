# payroll-pack
給与計算のパック（共通）

この repo は 2 つの部分を持ちます。①**計算のパック**（`入口/`・`芯/`・`出口/`・`月次/` ほか）: 渡された値だけで給与を計算し、置き場を開きません。②**給与エージェントの部分**（`plugins/payroll-agent/`）: 毎月の手順・守る決まり・照らしを、窓を開く前に入れる plugin として配ります（根の `.claude-plugin/marketplace.json`）。両側の窓が同じ版の印で両方を使い、各社の側には環境の設定と口（`plugins/payroll-agent/口の一覧.md`）だけを置きます。線の正本は `docs/設計/入れてよい物.md`、版は `docs/版の出し方.md`。

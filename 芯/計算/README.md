# 芯/計算 — 芯の計算を置く。

`芯/集計`（B8）が出す **月の数字**（人×項目の縦・状態 確定／仮・出所）と、その人のその月に効く **会社の決まりと人の値**（`分野.名`）と、
**法の表**（`法の表/`）から、支給・控除を **人×項目の縦**（支給月・会社・NO・項目・値・状態・出所・見当・見当の拠り所・問いの番号）で返す。
返す縦は `出口/`（B10）の仮の関所 `出口.関所.通す` と書き口が受ける形（`出口/README.md` の「入力の形」）。毎月の呼び順は `月次/README.md`。

- 芯は Drive を開かない（殻が渡す値を受けて返すだけ）。入口の元の形・出口の先の形（給与ソフトの欄）を知らない。
- 答え（過去の結果）を受ける口・読む所・比べる所を持たない（`docs/設計/確かめと仮.md` §1）。
- 法の値（率・等級・税額表・最低賃金・日 8 時間・割増の下限・祝日）はコードに書かない。全部 `引く口.引く` で `法の表/` から引く。
- 足りない値は見当で計算し、`仮` の印と確認の 1 問を返す（止めない）。仮が 1 つでも残る人は人の状態が `仮`＝出口の関所で外れる ⟦鍵:給与計算/足りない時は仮で計算し出さない⟧。
- Python 3・標準ライブラリだけ。数は `Decimal`、円は整数で返す。

前の道具（pixel-office の履歴の kyuyo_calc・timecard_tally など。下で行の数を挙げる所の出典）の勤怠の読み替え・型の読み替え・旧の列名は持ち込まない。

## 部品

| `要る値.py` | 要る値の確かめ（hitsuyo）。会社の決まり §2 の語の既定で埋め、既定の無い要る値は見当で埋めて仮の理由を返す。端数の語（`丸めの項目`）が選べる値の外なら既定の語に替えて仮。必ず埋める欄（`必ずの要る時`）が空の人は計算しない（`必ずの欠け`・返す物の `止めた`） |

| `検査.py` | 法の線の検査（kensa hou・hitsuyo の最低賃金）。最低賃金・割増の率・割増の基礎から除く手当・所定と法定・36 協定の線・固定残業 |

| `形.py` | 端数の語（会社の決まり §2 の選べる値）→ 丸め・仮の理由・人×項目の帳 |

## 呼び口

```python
from 芯.計算 import 計算する

結果 = 計算する(
    月の数字,                       # 芯.集計.集計する の返す物（{"行", "人", …}）か、その "行" の並び
    決まり={(会社, NO): {...}},      # その人のその月に効く会社の決まり（`分野.名`。段の解決は手前で済ませる・会社の決まり §1.1）
    人={(会社, NO): {...}},          # マスタの人の値（`分野.名`。決まりの上に重ねる）
    入力={(会社, NO): {名: 値}},      # 部品の行の数量の元が `入力の値` の物（月の変動）。任意
    置き場=None,                     # 法の表の置き場（既定は repo の 法の表/。試験だけ渡す）
)
# 出口へは 月次.月を回す が段の解決・入口の仮を寄せてから関所へ通す（呼び順は 月次/README.md。結果を手で関所へ渡さない）

from 芯.計算 import 賞与を計算する

賞与の結果 = 賞与を計算する(
    [{"会社": …, "NO": …, "額": 円, "原本の名前": …}],   # 支給一覧を人に結んだ後の行（結ぶのは入口・殻）
    支給日="2027-06-30",             # 標準賞与額の上限・雇保の率・源泉の表を引く日。行の 支給月 は "2027-06-賞与"
    決まり={...}, 人={...},          # 計算する と同じ（社保・雇保・源泉の値）
    前月の課税対象額={(会社, NO): 円},  # 前月の 計算する の 課税対象額（前月の給与なしの人は値 None）。None＝渡されていない・鍵の無い人＝その人の分が無い＝仮
    前の標準賞与額={(会社, NO): 円},    # 同じ年度の前の賞与の 標準賞与額（健保）の計（無い人は 0）。None＝渡されていない＝仮
    置き場=None,
    計算期間={(会社, NO): 月数 | {"始め": 日, "終わり": 日}},  # 賞与の計算期間（任意）。源泉を月額表で出す人だけが読む。無い＝仮
)   # 返す物は 計算する と同じ形
```

  法定休日の無い月は読まない。所定休日の時間は 割増.休日の率 のまま）・
  `委託.源泉率`・`委託.社保と源泉の元に入れる`・`委託.雇用分`・`委託.出張日額`・`源泉.報酬`。人の値（名は初期設定にまだ無い＝PR の他の窓へ回す）:
  `委託.月給`・`委託.時給`・`委託.日給`・`委託.通勤日額`（名が無い＝通勤費なし。名は在るのに空・数でない・負＝0 円で見当して 委託分の通勤費 を仮）。入力（月の数字の語に無い物）: `委託.日ごとの実働`（{日付: 分か h:mm}）・`委託.出張日数`（名が無い＝その月の指示の行が無い＝出張なし。名は在るのに空・数でない・負と、期間の暦日を超える日数＝0 日で見当して 委託分の出張 を仮。仮でも 委託.出張日額 は同じ回に読んで問う）・`委託.雇用分の出勤時間`（委託の併用・月の和）

### 引く法の表

`源泉_月額表`（支払日）・`標準報酬月額`・`健保_協会けんぽ`・`介護_協会けんぽ`・`子ども子育て支援金`・`厚年の率`（保険料の月）・`雇保の率`（締め日）・

`法の線` から読む線と欄（`支給控除._線の読み方`。率%は 割増＝1＋率/100・深夜＝率/100 に直す）:

  芯の名は芯の中の名で、会社が持ち替えない（例 `休日手当`＝法定休日の労働の割増）。今できる直しは会社の行を別の名（例「休日手当（会社）」）にすること。会社の行と芯の `休日手当` を給与ソフトの同じ欄（例「休日手当」）に出す時は、欄の対応でその欄に両方を当てる（出口が足す。芯が作る項目の欄は ⑥つなぎ の会社の行 側＝出口〔Drive の型.md §4〕）。ぶつかりの問いの答え方の例にこの直し方を書く。

  役員でない人は計算せず `差引支給額` 1 行を値なしの仮で返し、問い「月の数字が無い（…）」を出す。支給月は `支給月=` か月の数字の支給月（1 つの時）。決まらなければ知らせに出す。

## 役員と委託（⟦鍵:給与計算/役員と委託と残業の扱い⟧）

- **役員**（`人.区分`＝役員）: 勤怠が無くても計算する。部品の行（役員報酬など）から社保と源泉（と住民税）を引く。雇保は引かない（役員には `雇保.加入` を求めない＝必ず埋める欄の要る時 `要る値.必ずの要る時`。兼務役員は求める）。
  割増・欠勤控除・遅刻早退控除は 0（労基法の外）。月の所定と時間単価を出さない。検査は最低賃金（最低賃金法 2 条の労働者でない）・割増・所定・36 協定を当てない。
- **委託だけ**（`人.区分`＝委託）: 雇用分の項目を出さず、`委託分の…` の項目と `支払合計` だけを出す。社保・雇保・住民税は無い。
- **委託の併用**（`人.区分`＝委託の併用）: 雇用分（部品の行・社保・雇保・源泉・住民税・差引支給額）→ `委託分の…` → `支払合計`（雇用分の差引＋委託分の差引）を 1 人の縦に並べる。
  雇用分は決まった額: 雇用分へ渡す月の数字は 所定日数・出勤日数・年休・特別休暇（有給）だけ（時間外・深夜・休日・欠勤は委託分の式で払う＝前の道具と同じ）。
  最低賃金は 雇用分の額÷雇用として働いた時間（`入力` の `委託.雇用分の出勤時間`＝勤怠ソフトの出勤時間・分か h:mm）で見る（委託分は足さない・⟦鍵:給与計算/委託の併用の最低賃金の時間⟧）。
  出勤時間が無い人は月の所定時間で割って見て、仮＋問い。`委託.社保と源泉の元に入れる`＝入れる なら委託分の源泉は 0 で、委託分の課税計を雇保の元と源泉の課税対象額へ足す。
- **役員＋委託の併用**（`人.区分`＝`役員＋委託の併用`。読み方は `形.py` の `区分を読む`＝空白と後ろの括弧の説明を除き、`＋` で併せ持つ）:
  役員報酬の分は役員の扱い（割増・欠勤控除・遅刻早退控除は 0・雇保は引かない・月の所定と時間単価を出さない・検査は最低賃金などを当てない）で社保と源泉と住民税を引き、
  委託の分は 委託の併用 と同じ（`委託分の…` → `支払合計`。`委託.雇用分` は月額の式で引く。勤怠は委託の分に要る＝勤怠の来ない月は仮）。
  併せ持てる組はこれだけ。知らない語・ほかの組（例 `兼務役員＋委託`）は 社員 で見当して全部を仮＋問い（`要る値.py`）。
- `委託.式` は会社の値でも人の値でも選べる（`人=` の値が `決まり=` に勝つ＝前の道具の 社員 > 会社。段の解決 #24 の人の段の値をそのまま渡す）。
- `委託.みなし残業時間`（h:mm・無し）: `月額` の式の残業（会社の数え方の残業か 法定内＋法定外−所定休日）から引く（オーナーの答え: 会社の数え方は「1 日の所定超え − みなし」。
  前の道具 timecard_tally の itaku の `みなし残業` の式も 総勤務−委託の所定時間−委託のみなし残業時間 を追加残業にした＝みなしの分は払わない）。負にしない。
  残業のある月に値が無い・読めない時は引かずに見当で仮＋問い（黙って 0 にしない。`10` のような h:mm でない数は 10 時間で見当して仮）。
  引いた後が法の線の法定外残業（所定休日の分を除く）を下回れば知らせ（払うのは会社の決まりのまま）。月額でない式では引かない（値があれば知らせ）。
- `委託.式`＝みなし残業: 委託分の報酬＝`委託.報酬`・委託分の残業＝`委託.定額残業`＋追加残業×時給（追加残業＝max(0, 総労働−`委託.所定時間`〔1 か月の時間〕−`委託.みなし残業時間`)）・
  委託分の休日＝法定休日の時間×時給×(休日の率−1)（法定休日の時間は総労働の内＝上乗せの分だけ。所定休日は上乗せ無し＝月額の式の 法定＋所定休日の全部の時間×時給×休日の率 と違う）・通勤費＝`委託.通勤日額`×出勤日数。深夜と欠勤は無い（深夜があれば知らせ）。
  `委託.雇用分` は引かない。所定やみなしが無い・読めない・所定が 60:00 未満（月の時間として小さすぎる＝1 日か 1 週の時間に見える。境は `委託.py` の `_月の時間の下限`）なら見当して仮＋問い。時給は追加残業か法定休日のある月だけ引く。
- `委託.日当の境` の既定: 空・`無し` は **1 日の所定（`時間.日の所定`）以上**（前の道具 timecard_tally 596 行の `edge = mins(e) if e else cap` と同じ）。
- 委託分の項目: `委託分の報酬`・`委託分の残業`・`委託分の深夜`・`委託分の休日`・`委託分の出張`・`委託分の通勤費`・`委託分の欠勤控除`（引く額を正で）・`委託分の課税計`・
  `委託分の源泉所得税`・`委託分の差引支給額`。式は `委託.py` の頭の説明。率は `割増.*`（無ければ法の線）。
- 委託の源泉: `法の表/源泉_報酬`（基準 支払日・値 `{"率%", "境の額", "境を超えた分の率%"}`。所得税法 204・205 条）。`委託.源泉率` が法の率を下回れば法の率で仮。
  表はまだ `法の表/` に無い＝表が来るまで `委託.源泉率` のある会社はその率で仮、無ければ値なしの仮（率をコードに書かない）。
  `源泉.報酬` は字の 1 つ（対象・対象でない）。対象でない なら 0。空は 対象。ほかの形（並び・知らない字）は法の率で見当して仮＋問い（黙って確定しない）。

## 式（今の範囲）

- 割増の基礎から除く手当: 行の `割増の基礎から除く訳` が労基則 21 条の 7 つ（`検査.除ける訳`＝初期設定/法の線の点検.json の写し）と割増の賃金そのもの（`検査.割増そのものの訳`＝`固定残業手当`・型の版 21）のどれでもない・訳が無い行は、その人にその月払う時だけ（`支給控除.払う除けない行`＝人の額の無い人・人の額が 0・回の数がその月 0・皆勤を払わない月は払わない。日・分を数量にする行は 入る の行と同じく月の数に関わらず単価の読み）、赤＋その手当を割増の単価に入れて仮（37 条 5 項の法の線で計算）。`法の線.承知` に `割増.基礎に入る` の印があれば会社のまま除いて仮にせず、差額を知らせへ（§1.4）。
- 割増の単価: 労基則 19 条＝部品の行のうち `割増の基礎`＝入る の支給の行（数量の元が休暇の語〔休業も〕の行・7 つの訳と固定残業手当の訳で除いた行は除く。皆勤の条件の行は払った月だけ入れる）を、数量の元で 時間（分の語）・日（÷ `時間.日の所定`）・月（÷ 月の所定時間）に分けて足す。`端数.時間単価` で丸める。
- 割増の単価の式が無い人（既定で止める）: `支払.賃金の形`＝歩合・出来高（出来高払制＝その総額÷総労働時間×0.25・労基則 19 条 1 項 6 号）・年俸（確定した賞与を含むとその賞与も単価に入る・平成 12 年 3 月 8 日 基収 78 号・含むかを持つ値が無い）の人と、`割増の基礎`＝入る の支給の行のうち数量の元が `入力の値`・回の語（件数・回数で払う出来高・歩合の形）の行にその月の額がある人は、割増の付く時間（法定内残業・法定外・60 時間超・休日・深夜）がある月に割増の項目を仮にする（`支給控除.式の無い賃金の形`・`_式の無い割増を止める`）。時間が無い月は割増が 0＝止めない。式は要った会社が来た時に足す。
- 会社の数え方の残業（芯/集計 が `割増.残業の数え方`＝1日の所定超え・月の総労働が月の所定を超えた分 で出す `残業（会社の数え方）`・`60 時間超（会社の数え方）`）がある人は、
  払う時間はその語（所定超えの全部）。その内の法定内残業（所定を超え法定以内・所定休日の分を除く）は `割増.法定内残業の率`、残りを時間外の率で払い、60 時間超はその残りの内で払う（数え方は時間を決め、率は率の値が決める＝所定 8 時間未満の人の法定内の時間に黙って割増を乗せない。`所定休日の法定外` が無い月は所定休日の時間を全部法定内から引く＝割増の側）。会社の数え方は休日勤務の日を数えないので、所定休日の時間も休日の率で休日手当へ（前の道具の休出時間・timecard_tally 403〜406 行。仮にしない）。無い人は今の `法定外残業`・`60 時間超`。委託の月額の残業も同じ語を使う。
- みなし残業: `割増.固定残業` が無い時、`割増.みなし残業の時間`（月の時間）を **月給で役員でない人だけ** 時間外から引く（前の道具 kyuyo_calc 348〜349・423〜424 行）。
- 割増: 法定内残業×法定内残業の率・（法定外−60 時間超）×時間外の率（45 時間超の率が違えば `協定.月の限度時間` で分ける。境で数えるのは 60 時間までの分＝min(法定外, 60)−45。45 時間超の率が時間外の率より低ければ知らせ）・60 時間超×60 時間超の率・法定休日×休日の率・深夜×深夜の率。
  `休日.休日出勤の数え方` の `所定休日の率`＝★時間外の率で払う なら、所定休日の時間のうち法定外に入っていない分（`所定休日`−`所定休日の法定外`。法定内残業の内）を法定内残業から時間外の率へ移す（45 時間・60 時間の境には数えない・みなし残業と固定残業を当てた後に足す＝選ばない時より下げない・時間外の率が法定内残業の率より低ければ移さない。会社の数え方の人は所定休日の時間をもともと休日の率で払うので変えない〔下げない〕。`所定休日の法定外` が月の数字に無く所定休日に働いた人は全部を移して見当の仮）。
  率は会社の値が法の線を下回れば法の線の率で仮。ただし `法の線.承知` の印のある率は会社の率のまま（0＝払わない）で仮にしない（下の「承知した食い違い」）。固定残業は時間でなら超えた時間だけ・額でなら計算した額から引く。`端数.割増の総額` で丸める。
  時給の人の基本給の行は `勤怠の数:所定内` で払う形（割増の項目は 1.0 を含む率で払う。総労働で払うと二重＝法の線の知らせ）。
  率と `割増.法定内残業の行` は会社・勤務の型・人の段に置ける（型の版 6。芯は段を解いた 1 つの値を読む＝時給の人の型は時間外 1.00・月給の人は会社の 0 のように分ける）。
- 法定内残業を載せる行（`割増.法定内残業の行`・会社の決まり §3.6）: 支給の行の名（例 基本給）なら、法定内残業の額（率は `割増.法定内残業の率`）をその行の額へ足し、
  `法定内残業手当` は 0 で残す（計は変わらない・その行は割増の理由も受ける）。行が項目に無い・控除・非課税・社保の報酬か雇保の対象に入らない行は `法定内残業手当` のまま仮、
  その人に行が無い（額の無い人）時は `法定内残業手当` のまま知らせ。
- 時間外の 1.0 倍の分を載せる行（`割増.時間外の基礎の行`・型の版 7・会社の決まり §3.6）: 支給の行の名なら、`時間外手当`・`60時間超手当` の額（率は変えない）のうち
  割増の単価×時間（それぞれ `端数.割増の総額` で丸めて手当の額を上限）をその行の額へ足し、手当には残り（1.25 なら 0.25 の分）だけ残す（計は変わらない・その行は割増の理由も受ける）。
  載せられない行（ほかの割増の項目の名も＝法定内残業の行も同じ）・その人に行が無い時は法定内残業の行と同じ（手当に全額のまま仮・知らせ）。固定残業（額で）の人は載せない（知らせ）。
  手当に残るのは丸めた全額−丸めた 1.0 倍の分（率の残りを丸めた額と 1 円違うことがある）。
  承知した食い違いの差額で「同じ時間を数量に払う行」の分を数える時、芯が載せた額（法定内残業・時間外の 1.0 倍）はその行の額から除く（会社の別の払いでない）。
- 欠勤（月給・日給月給・年俸）: 基礎＝`欠勤.控除の基礎` の行（数量 1）。引く方式・出た日で払う方式・欠勤が多い月だけ出た日で払う（多い月＝`欠勤.多い月の線`: 既定は欠勤が所定日数の半分を超えた月・欠勤が N 日以上の月〔N＝`欠勤.多い月の日数`。空・読めない時は半分の線で見当して仮＋問い〕）。
  `特別休暇（無給）` も欠勤に数える。遅刻早退は基礎÷月の所定時間×時間（日給は日額÷日の所定）。
  `欠勤.控除の割り方` があれば割る数は: 所定日数で日割り＝月の数字の `所定日数`（遅刻早退は ×日の所定）／所定時間で日割り＝月の所定時間÷日の所定（遅刻早退は 月の所定時間）／
  時間割り＝`欠勤.控除の割る時間`÷日の所定（遅刻早退は 割る時間）。分数で数えて 1 回だけ丸める。
  欠勤を遅刻早退に入れる人（月給の形）は欠勤日数で引かず、欠勤の日×`時間.日の所定` を遅刻早退の時間へ足し、月の所定−（総労働＋`年休の時間`）（負は 0）と比べて少ない方で引く（型の版 18。年休の時間を足すのは型の版 25＝年休の日・時間は不足に数えない）。`欠勤.遅刻早退の数え方`＝日々の不足（月の所定時間−総労働で頭打ち）（型の版 24）なら欠勤の無い月も同じ少ない方を 1 回で取る（月の所定が出なければ遅刻早退控除を仮）。比べる月の所定は `欠勤.頭打ちの月の所定`（型の版 25）: 既定 `時間.月の所定時間`＝単価の割る数の月の所定時間／`割増.月の残業の所定時間`＝芯/集計 が時間外を数える月の所定と同じ数で出す月の語 `月の残業の所定`（語が無い・仮なら遅刻早退控除を仮）。割る数は月の所定時間のまま。欠勤を遅刻早退に入れない人は欠勤を日数で別に引くので、月の所定時間−総労働 から欠勤の日×`時間.日の所定` を除いた残りで頭打ちにする（欠勤控除と遅刻早退控除の和が働かなかった時間を超えない。日の所定が無ければ遅刻早退控除を仮）。`欠勤.遅刻早退の控除`＝引かない（所定の不足を知らせる）は引かずに遅刻早退の時間を知らせに出す。その人のまるごと欠勤の月
  （出勤 0・年休 0・欠勤あり・入退社の月でない）は日割する 固定の月額（支給）を 0 にし、欠勤控除を出さない。
- 月の所定の欠け: 割増・欠勤・遅刻早退の時間が無く、所定で割る行も使わない月（勤怠の無い役員など）は、月の所定が出なくても仮にしない（単価は出さず最低賃金も見ない）。
- 月の所定: 年平均＝その年（期間の終わりの年の 1〜12 月）の会社の暦の所定日数（と各日の所定の和）÷12。その月の所定日数・暦日・固定の値も選べる。
- 日割: 入社日・退職日が期間の中なら、`日割する` の月額の行を在籍÷割る数で日割（`日割.端数`）。`日割.形`＝欠けた日を引く なら 月額−欠けた日×月額÷割る数（欠けた日＝期間の日−在籍の日・引き過ぎは 0 円）。
  割る数の 年平均の所定日数＝その年（期間の終わりの年の 1〜12 月）の会社の暦の所定日数÷12（その月の所定日数で代えない）。
  `日割.入退社` が無い会社は黙って暦日割にせず、入退社の月の人を暦日割で見当して仮＋問い 1 つ（その人は出口へ出ない）。
- 社保: 保険料の月（翌月徴収なら支給月の前の月）の率と等級。介護は `年齢.介護の始め` 歳に達した日の月〜`年齢.介護の終わり` 歳に達した日の月の前、厚年は `年齢.厚年の終わり` 歳に達した日の月の前、健保は `年齢.健保の終わり` 歳の誕生日の月の前まで（歳は法の線から引く）。
  合わせて＝3 つの率の和で 1 回丸め、介護・支援金を丸めて健保は差。別に＝健保を単独で丸める。
- 雇保: 総支給から `雇保の対象`＝入らない の行を引いた額×労働者の率（期間の終わりの日の率）。
- 源泉: 課税対象額＝課税計−社会保険計。月額表（支給日の年）の甲（扶養 0〜7・7 人超は 1 人ごとに表の値を引く）・乙（`源泉.扶養の数`＝従たる給与の扶養の数ごとに表の
  `従たる給与の1人ごとに引く` を引く）・740,000 円以上の区間の率。1 円未満切り捨て。
- 住民税: 特別徴収の額（6 月は `6月分`）。退職の月の一括・切替は仮＋問い。

## 承知した食い違い（`法の線.承知`・会社の決まり §1.4）

- 印（`{線の名: 問いの番号}`・字 `線=問い、…`）のある線は会社の値のまま計算し、仮にしない。印の無い線・問いの番号の無い印は今のまま法の線で仮（読めない印は知らせ）。
- 率の線（`割増.時間外の率` ほか 4 つ）: 会社の率で払う。最低賃金: 会社の額のまま（仮にしない）。検査の行は `赤` でなく `承知: …`。
- 集計の線（`時間.日の所定`・`時間.週の法定`・`時間.打刻の丸めの向き`・`割増.深夜の時間帯`）は 芯/集計 が会社の値で数えた月の数字のまま払う。
- **知らせ** に 1 人 1 線 1 行: `承知した食い違い: <線>（<問いの番号>）＝…を会社の値で計算した。法の線なら総支給額 <円> 円（差額 <円> 円）`。
  率の線は、その線の印だけを外して計算し直した総支給額との差。その線の時間（法定外残業・60 時間超・法定休日・深夜）を数量の元 `勤怠の数:<語>` で払う別の支給の行が在れば、
  その行の額のうち線の時間の分（行の時間に占める割合・1 円未満切り捨て）は法の線の率に含めて引く（知らせの差額の後ろに `同じ時間を数量に払う行「…」の <円> 円は法の線の率に含めた`）。集計の線は、月の数字の人の状態の `法の線で数えた`（芯/集計 がその線の印だけを外して数え直した語）に替えて計算し直した総支給額との差。
  最低賃金は（最低賃金の時間額−時間あたりの賃金）×所定内の時間（無ければ月の所定時間）で 1 円未満は切り上げ。

## 賞与（`賞与を計算する`）

項目: `賞与`・`健康保険`・`介護保険`・`子ども・子育て支援金`・`厚生年金`・`標準賞与額（健保）`・`標準賞与額（厚年）`・`雇用保険`・`社会保険計`・`社保控除後`・
`前月の社保控除後の給与`（前月の給与がある人）・`源泉所得税`（出所に出し方）・`控除合計`・`差引支給額`。

- 標準賞与額＝額の 1,000 円未満切り捨て。健保は `標準賞与額の上限`（健保）から同じ年度の前の賞与の計を引いた残りまで・厚年は 1 か月の上限まで。
  保険料は支給月の分（`社保.徴収の月` に依らない）。社保の式・丸めの順・年齢・資格・免除は月の給与と同じ。社保が掛からない人の標準賞与額は 0。
- 雇保＝額×労働者の率（支給日で引く・`雇保.本人負担率` が先）。源泉＝社保控除後×算出率（前月の課税対象額・扶養・甲乙）。前月の給与が無い・0 以下・
  社保控除後がその 10 倍を超える時は月額表で ÷月数×月数（前月がある時は 前月＋÷月数 の税額 − 前月の税額 に ×月数。所得税法 第186条第1項第1号ロ・第2号ロ・第2項）。
  月数は `法の表/源泉_賞与の月額表の月数`（境の月数 6・境まで 6・境を超える 12）を支給日で引く（コードに書かない）。賞与の計算期間（`計算期間=` の月数か 始めと終わりの日）が
  境を超えれば 12（日で渡れば 終わり が 始め の 6 か月後の同じ日〔無ければ月末〕以後で超える）。甲欄・乙欄とも同じ。月額表の道で計算期間が無い・読めない人は
  境まで（6）で見当して `源泉所得税` を仮＋問い 1 つ（⟦鍵:給与計算/足りない時は仮で計算し出さない⟧）。算出率の表の道（前月が在り 10 倍以下）は計算期間を読まない＝仮にしない。退職日より後の支払いは仮。

## D8 が当てた時の境目

- **形は変えない所**: `計算する` の引数と返す物の形・人×項目の縦の列・問いの形・`引く口.引く` の形（出口と集計がこれに乗る）。
- **差分を当てる所**: `支給控除.py` の式（UTC の芯/計算 の式を、この部品の項目名と決まりの語のまま当てる）・`要る値.py` の要る値の表・`検査.py` の検査の行。
  会社名・グループの名・手当の名で分けない（会社の決まり §5）。新しい選び方は 会社の決まり の項目を足してから式にする。
- **まだ無い式**（`式が無い` で仮になる所）: 委託の `報酬の行のまま`・非居住者と丙欄・日額表・電算機の特例・年末調整（§3.2）・
  平均賃金の出し方と一部休業の日（§3.5。休業手当は 単価の元＝平均賃金 の行で書ける＝型の版 21）・有給の 1 日の賃金の平均賃金と標準報酬日額（§3.6）・皆勤の N 回・所定休日を休日の率で払う・退職の月の社保 2 か月分。

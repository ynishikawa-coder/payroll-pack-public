# 芯/計算 — 芯の計算を置く。

`芯/集計`（B8）が出す **月の数字**（人×項目の縦・状態 確定／仮・出所）と、その人のその月に効く **会社の決まりと人の値**（`分野.名`）と、
**法の表**（`法の表/`）から、支給・控除を **人×項目の縦**（支給月・会社・NO・項目・値・状態・出所・見当・見当の拠り所・問いの番号）で返す。
返す縦は `出口/`（B10）の仮の関所 `出口.関所.通す` と書き口が受ける形（`出口/README.md` の「入力の形」）。毎月の呼び順は `月次/README.md`。

- 芯は Drive を開かない（殻が渡す値を受けて返すだけ）。入口の元の形・出口の先の形（給与ソフトの欄）を知らない。
- 答え（過去の結果）を受ける口・読む所・比べる所を持たない（`docs/設計/確かめと仮.md` §1）。
- 法の値（率・等級・税額表・最低賃金・日 8 時間・割増の下限・祝日）はコードに書かない。全部 `引く口.引く` で `法の表/` から引く。
- 足りない値は見当で計算し、`仮` の印と確認の 1 問を返す（止めない）。仮が 1 つでも残る人は人の状態が `仮`＝出口の関所で外れる ⟦鍵:給与計算/足りない時は仮で計算し出さない⟧。
- Python 3・標準ライブラリだけ。数は `Decimal`、円は整数で返す。

前の道具（pixel-office の履歴の kyuyo_calc・timecard_tally など。下で行の数を挙げる所の出典）の勤怠の読み替え・型の読み替え・旧の列名は持ち込まない。

| `要る値.py` | 要る値の確かめ（hitsuyo）。会社の決まり §2 の語の既定で埋め、既定の無い要る値は見当で埋めて仮の理由を返す |
| `支給控除.py` | 1 人の支給控除（kyuyo_calc・zeigakuhyo・shaho_ritsu）。部品の行・割増・欠勤・日割・社保・雇保・源泉・住民税・計 |

## 呼び口

```python
from 芯.計算 import 計算する

結果 = 計算する(
    月の数字,                       # 芯.集計.集計する の返す物（{"行", "人", …}）か、その "行" の並び
    決まり={(会社, NO): {...}},      # その人のその月に効く会社の決まり（`分野.名`。段の解決は手前で済ませる・会社の決まり §1.1）
    人={(会社, NO): {...}},          # マスタの人の値（`分野.名`。決まりの上に重ねる）
    入力={(会社, NO): {名: 値}},      # 部品の行の数量の元が `入力の値` の物（月の変動）。任意
    置き場=None,                     # 法の表の置き場（既定は repo の 法の表/。試験だけ渡す）
)
# 出口へは 月次.月を回す が段の解決・入口の仮を寄せてから関所へ通す（呼び順は 月次/README.md。結果を手で関所へ渡さない）

from 芯.計算 import 賞与を計算する

賞与の結果 = 賞与を計算する(
    [{"会社": …, "NO": …, "額": 円, "原本の名前": …}],   # 支給一覧を人に結んだ後の行（結ぶのは入口・殻）
    支給日="2027-06-30",             # 標準賞与額の上限・雇保の率・源泉の表を引く日。行の 支給月 は "2027-06-賞与"
    決まり={...}, 人={...},          # 計算する と同じ（社保・雇保・源泉の値）
    前月の課税対象額={(会社, NO): 円},  # 前月の 計算する の 課税対象額（無い人＝前月の給与なし）。None＝渡されていない＝仮
    前の標準賞与額={(会社, NO): 円},    # 同じ年度の前の賞与の 標準賞与額（健保）の計（無い人は 0）。None＝渡されていない＝仮
    置き場=None,
    計算期間={(会社, NO): 月数 | {"始め": 日, "終わり": 日}},  # 賞与の計算期間（任意）。源泉を月額表で出す人だけが読む。無い＝仮
)   # 返す物は 計算する と同じ形
```

### 引く法の表

`源泉_月額表`（支払日）・`標準報酬月額`・`健保_協会けんぽ`・`介護_協会けんぽ`・`子ども子育て支援金`・`厚年の率`（保険料の月）・`雇保の率`（締め日）・
`最低賃金`（期間の終わりの日）・賞与は `標準賞与額の上限`・`源泉_賞与の算出率`・`源泉_月額表`・`源泉_賞与の月額表の月数`・`雇保の率`（支給日）・`祝日`（1 年 1 行・値 `{"日": {日付: 名}}`）・`法の線`（期間の終わりの日・鍵 `線`）。
`法の線` から読む線と欄（`支給控除._線の読み方`。率%は 割増＝1＋率/100・深夜＝率/100 に直す）:
`法定労働時間`（日の時間・週の時間）・`時間外の割増`・`月60時間超の時間外の割増`・`休日の割増`・`深夜の割増`（率%）・
`36協定の上限`（月の時間）・`36協定の特別条項の上限`（月の時間外と休日の未満）・`社保の年齢`（介護の始め・介護の終わり・厚年の終わり・健保の終わり）。
`祝日` と `法の線` は並走の窓 W2 が `法の表/` に置く（形は W2 の表に合わせた）。`社保の年齢` の行は W2 の表にまだ無い＝置かれるまで生年月日のある社保の人は仮。
表が無い・行が無い時は引くと欠け＝その項目は仮（試験は同じ形の試験の表で回す）。

## 返す物

```python
{
  "行":   [{支給月, 会社, NO, 項目, 値, 単位: "円", 状態: "確定"|"仮", 出所, 見当, 見当の拠り所, 問いの番号}, …],
  "人":   [{支給月, 会社, NO, 状態: "確認済"|"仮", 仮の数}, …],
  "人の状態": {(支給月, 会社, NO): "確認済"|"仮"},     # 出口.関所.通す の 2 つ目へそのまま
  "問い": [{番号: "計1", 何が無いか, 見当, 見当の拠り所, 答え方の例, 人: [(会社, NO)], 変わる項目: [...]}, …],
  "知らせ": [...],    # 仮にしない知らせ（総支給が 0 の月・通勤の上限を超えた分 など）
  "法の線": [...],    # 「<会社> <NO>: 赤: …［条文］」「…: 知らせ: …」
}
```

- 項目の並び: 支給の部品の行 → `法定内残業手当`・`時間外手当`・`60時間超手当`・`休日手当`・`深夜手当`・`欠勤控除`・`遅刻早退控除` → `課税計`・`非課税計`・`総支給額` →
  `健康保険`・`介護保険`・`子ども・子育て支援金`・`厚生年金`・`雇用保険`・`社会保険計`・`課税対象額`・`源泉所得税`・`住民税` → 控除の部品の行 → `控除計`・`控除合計`・`差引支給額`。
  部品の行の名はこの決まった名（と `委託分の…`・`支払合計`）とぶつけない。ぶつかる行・同じ名の 2 つ目からの行は **全員を止めず**、その行を使わずに知らせ＋その行のある人（会社の行ならその会社の全員）を仮にし問いを 1 つ出す（⟦鍵:給与計算/足りない時は仮で計算し出さない⟧）。
- 問いの番号は `計<n>`（芯/集計 の `問<n>` と分ける）。集計の仮の行を使った項目は、その集計の問いを理由に書いて仮になる。集計の人が仮なら計算の人も仮。
- 欠けた表（`欠けた時: 止める`）を引く項目は **値なしの仮**（その項目は計算しない）。それを足す計は 0 で見当して仮。`仮で計算し問う` の表は前の `出た` 行で仮。
- この芯に式がまだ無い選び方（委託の `報酬の行のまま`・非居住者・丙欄・皆勤の N 回・所定休日を休日の率で払う・休業手当）の人は、止めずに `差引支給額` 1 行を値なしの仮で返し問いを 1 つ出す。
- 月の数字の無い人（`決まり`・`人` に居て月の数字の来ない人と、芯/集計 が `勤怠が無い` とした人）は **黙って抜けない**: 役員は下の役員報酬の式で計算し、
  役員でない人は計算せず `差引支給額` 1 行を値なしの仮で返し、問い「月の数字が無い（…）」を出す。支給月は `支給月=` か月の数字の支給月（1 つの時）。決まらなければ知らせに出す。

## 役員と委託（⟦鍵:給与計算/役員と委託と残業の扱い⟧）

- **役員**（`人.区分`＝役員）: 勤怠が無くても計算する。部品の行（役員報酬など）から社保と源泉（と住民税）を引く。雇保は引かない（`雇保.加入` を既定で埋めない）。
  割増・欠勤控除・遅刻早退控除は 0（労基法の外）。月の所定と時間単価を出さない。検査は最低賃金（最低賃金法 2 条の労働者でない）・割増・所定・36 協定を当てない。
- **委託だけ**（`人.区分`＝委託）: 雇用分の項目を出さず、`委託分の…` の項目と `支払合計` だけを出す。社保・雇保・住民税は無い。
- **委託の併用**（`人.区分`＝委託の併用）: 雇用分（部品の行・社保・雇保・源泉・住民税・差引支給額）→ `委託分の…` → `支払合計`（雇用分の差引＋委託分の差引）を 1 人の縦に並べる。
  雇用分は決まった額: 雇用分へ渡す月の数字は 所定日数・出勤日数・年休・特別休暇（有給）だけ（時間外・深夜・休日・欠勤は委託分の式で払う＝前の道具と同じ）。
  最低賃金は 雇用分の額÷雇用として働いた時間（`入力` の `委託.雇用分の出勤時間`＝勤怠ソフトの出勤時間・分か h:mm）で見る（委託分は足さない・⟦鍵:給与計算/委託の併用の最低賃金の時間⟧）。
  出勤時間が無い人は月の所定時間で割って見て、仮＋問い。`委託.社保と源泉の元に入れる`＝入れる なら委託分の源泉は 0 で、委託分の課税計を雇保の元と源泉の課税対象額へ足す。
- `委託.式` は会社の値でも人の値でも選べる（`人=` の値が `決まり=` に勝つ＝前の道具の 社員 > 会社。段の解決 #24 の人の段の値をそのまま渡す）。
- `委託.みなし残業時間`（h:mm・無し）: `月額` の式の残業（会社の数え方の残業か 法定内＋法定外−所定休日）から引く（オーナーの答え: 会社の数え方は「1 日の所定超え − みなし」。
  前の道具 timecard_tally の itaku の `みなし残業` の式も 総勤務−委託の所定時間−委託のみなし残業時間 を追加残業にした＝みなしの分は払わない）。負にしない。
  残業のある月に値が無い・読めない時は引かずに見当で仮＋問い（黙って 0 にしない。`10` のような h:mm でない数は 10 時間で見当して仮）。
  引いた後が法の線の法定外残業（所定休日の分を除く）を下回れば知らせ（払うのは会社の決まりのまま）。月額でない式では引かない（値があれば知らせ）。
- `委託.日当の境` の既定: 空・`無し` は **1 日の所定（`時間.日の所定`）以上**（前の道具 timecard_tally 596 行の `edge = mins(e) if e else cap` と同じ）。
- 委託分の項目: `委託分の報酬`・`委託分の残業`・`委託分の深夜`・`委託分の休日`・`委託分の出張`・`委託分の通勤費`・`委託分の欠勤控除`（引く額を正で）・`委託分の課税計`・
  `委託分の源泉所得税`・`委託分の差引支給額`。式は `委託.py` の頭の説明。率は `割増.*`（無ければ法の線）。
- 委託の源泉: `法の表/源泉_報酬`（基準 支払日・値 `{"率%", "境の額", "境を超えた分の率%"}`。所得税法 204・205 条）。`委託.源泉率` が法の率を下回れば法の率で仮。
  表はまだ `法の表/` に無い＝表が来るまで `委託.源泉率` のある会社はその率で仮、無ければ値なしの仮（率をコードに書かない）。
  `源泉.報酬` は字の 1 つ（対象・対象でない）。対象でない なら 0。空は 対象。ほかの形（並び・知らない字）は法の率で見当して仮＋問い（黙って確定しない）。

## 式（今の範囲）

- 割増の基礎から除く手当: 行に `割増の基礎から除く訳` が無ければ赤＋割増を仮（7 つの一覧は法の表にまだ無い＝訳の中身は照らさない）。
- 割増の単価: 労基則 19 条＝部品の行のうち `割増の基礎`＝入る の支給の行を、数量の元で 時間（分の語）・日（÷ `時間.日の所定`）・月（÷ 月の所定時間）に分けて足す。`端数.時間単価` で丸める。
- 会社の数え方の残業（芯/集計 が `割増.残業の数え方`＝1日の所定超え で出す `残業（会社の数え方）`・`60 時間超（会社の数え方）`）がある人は、
  時間外と 60 時間超をその語で払い、法定内残業手当は 0（所定超えの全部を含む）。会社の数え方は休日勤務の日を数えないので、所定休日の時間も休日の率で休日手当へ（前の道具の休出時間・timecard_tally 403〜406 行。仮にしない）。無い人は今の `法定外残業`・`60 時間超`。委託の月額の残業も同じ語を使う。
- みなし残業: `割増.固定残業` が無い時、`割増.みなし残業の時間`（月の時間）を **月給で役員でない人だけ** 時間外から引く（前の道具 kyuyo_calc 348〜349・423〜424 行）。
- 割増: 法定内残業×法定内残業の率・（法定外−60 時間超）×時間外の率（45 時間超の率が違えば `協定.月の限度時間` で分ける。境で数えるのは 60 時間までの分＝min(法定外, 60)−45。45 時間超の率が時間外の率より低ければ知らせ）・60 時間超×60 時間超の率・法定休日×休日の率・深夜×深夜の率。
  率は会社の値が法の線を下回れば法の線の率で仮。固定残業は時間でなら超えた時間だけ・額でなら計算した額から引く。`端数.割増の総額` で丸める。
  時給の人の基本給の行は `勤怠の数:所定内` で払う形（割増の項目は 1.0 を含む率で払う。総労働で払うと二重＝法の線の知らせ）。
- 欠勤（月給・日給月給・年俸）: 基礎＝`欠勤.控除の基礎` の行（数量 1）。引く方式・出た日で払う方式・欠勤が多い月だけ出た日で払う（欠勤が所定日数の半分を超えた月）。
  `特別休暇（無給）` も欠勤に数える。遅刻早退は基礎÷月の所定時間×時間（日給は日額÷日の所定）。
  `欠勤.控除の割り方` があれば割る数は: 所定日数で日割り＝月の数字の `所定日数`（遅刻早退は ×日の所定）／所定時間で日割り＝月の所定時間÷日の所定（遅刻早退は 月の所定時間）／
  時間割り＝`欠勤.控除の割る時間`÷日の所定（遅刻早退は 割る時間）。分数で数えて 1 回だけ丸める。
  欠勤を遅刻早退に入れる人（月給の形）は欠勤日数で引かない（芯/集計 が欠勤の日を遅刻早退の時間に入れている）。その人のまるごと欠勤の月
  （出勤 0・年休 0・欠勤あり・入退社の月でない）は日割する 固定の月額（支給）を 0 にし、欠勤控除を出さない。
- 月の所定の欠け: 割増・欠勤・遅刻早退の時間が無く、所定で割る行も使わない月（勤怠の無い役員など）は、月の所定が出なくても仮にしない（単価は出さず最低賃金も見ない）。
- 月の所定: 年平均＝その年（期間の終わりの年の 1〜12 月）の会社の暦の所定日数（と各日の所定の和）÷12。その月の所定日数・暦日・固定の値も選べる。
- 日割: 入社日・退職日が期間の中なら、`日割する` の月額の行を在籍÷割る数で日割（`日割.端数`）。
- 社保: 保険料の月（翌月徴収なら支給月の前の月）の率と等級。介護は `年齢.介護の始め` 歳に達した日の月〜`年齢.介護の終わり` 歳に達した日の月の前、厚年は `年齢.厚年の終わり` 歳に達した日の月の前、健保は `年齢.健保の終わり` 歳の誕生日の月の前まで（歳は法の線から引く）。
  合わせて＝3 つの率の和で 1 回丸め、介護・支援金を丸めて健保は差。別に＝健保を単独で丸める。
- 雇保: 総支給から `雇保の対象`＝入らない の行を引いた額×労働者の率（期間の終わりの日の率）。
- 源泉: 課税対象額＝課税計−社会保険計。月額表（支給日の年）の甲（扶養 0〜7・7 人超は 1 人ごとに表の値を引く）・乙（`源泉.扶養の数`＝従たる給与の扶養の数ごとに表の
  `従たる給与の1人ごとに引く` を引く）・740,000 円以上の区間の率。1 円未満切り捨て。
- 住民税: 特別徴収の額（6 月は `6月分`）。退職の月の一括・切替は仮＋問い。

## 賞与（`賞与を計算する`）

項目: `賞与`・`健康保険`・`介護保険`・`子ども・子育て支援金`・`厚生年金`・`標準賞与額（健保）`・`標準賞与額（厚年）`・`雇用保険`・`社会保険計`・`社保控除後`・
`前月の社保控除後の給与`（前月の給与がある人）・`源泉所得税`（出所に出し方）・`控除合計`・`差引支給額`。

- 標準賞与額＝額の 1,000 円未満切り捨て。健保は `標準賞与額の上限`（健保）から同じ年度の前の賞与の計を引いた残りまで・厚年は 1 か月の上限まで。
  保険料は支給月の分（`社保.徴収の月` に依らない）。社保の式・丸めの順・年齢・資格・免除は月の給与と同じ。社保が掛からない人の標準賞与額は 0。
- 雇保＝額×労働者の率（支給日で引く・`雇保.本人負担率` が先）。源泉＝社保控除後×算出率（前月の課税対象額・扶養・甲乙）。前月の給与が無い・0 以下・
  社保控除後がその 10 倍を超える時は月額表で ÷月数×月数（前月がある時は 前月＋÷月数 の税額 − 前月の税額 に ×月数。所得税法 第186条第1項第1号ロ・第2号ロ・第2項）。
  月数は `法の表/源泉_賞与の月額表の月数`（境の月数 6・境まで 6・境を超える 12）を支給日で引く（コードに書かない）。賞与の計算期間（`計算期間=` の月数か 始めと終わりの日）が
  境を超えれば 12（日で渡れば 終わり が 始め の 6 か月後の同じ日〔無ければ月末〕以後で超える）。甲欄・乙欄とも同じ。月額表の道で計算期間が無い・読めない人は
  境まで（6）で見当して `源泉所得税` を仮＋問い 1 つ（⟦鍵:給与計算/足りない時は仮で計算し出さない⟧）。算出率の表の道（前月が在り 10 倍以下）は計算期間を読まない＝仮にしない。退職日より後の支払いは仮。

## D8 が当てた時の境目

- **形は変えない所**: `計算する` の引数と返す物の形・人×項目の縦の列・問いの形・`引く口.引く` の形（出口と集計がこれに乗る）。
- **差分を当てる所**: `支給控除.py` の式（UTC の芯/計算 の式を、この部品の項目名と決まりの語のまま当てる）・`要る値.py` の要る値の表・`検査.py` の検査の行。
  会社名・グループの名・手当の名で分けない（会社の決まり §5）。新しい選び方は 会社の決まり の項目を足してから式にする。
- **まだ無い式**（`式が無い` で仮になる所）: 委託の `報酬の行のまま`・`みなし残業`・非居住者と丙欄・日額表・電算機の特例・年末調整（§3.2）・
  休業手当と平均賃金（§3.5）・有給の 1 日の賃金の平均賃金と標準報酬日額（§3.6）・皆勤の N 回・所定休日を休日の率で払う・差押・支払額の端数・退職の月の社保 2 か月分。

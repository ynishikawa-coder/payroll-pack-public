# 芯/集計 — 芯の集計を置く。

表 A「日」・表 B「区間」（`docs/設計/勤怠の形.md` 1・2 節）と、その人の決まり（`docs/設計/会社の決まり.md` の `分野.名`）・法の線から、
**月の数字**（勤怠の形.md 5 節の語の縦の形＝1 人×1 項目）を日から出し直す。月の合計しか無い会社は「月の数字の口」から同じ縦の形に通す。
入口がどれでも同じ語・同じ形で出るので、`芯/計算/` はこの出力だけを読んで支給控除を計算できる。毎月の呼び順は `月次/README.md`。前の道具（timecard_tally など）は pixel-office の履歴にある（下で挙げる所の出典）。

芯は Drive を開かない（受け取って返すだけ）。答え合わせ（過去の結果）を受ける口を持たない。法の値はコードに書かない（法の線で受ける）。
Python 3・標準ライブラリだけ。時間は整数の分、日数は `Decimal`（0.5 刻み）。

## 呼び口

```python
from 芯.集計 import 集計する

結果 = 集計する(
    表A, 表B,                       # 勤怠の形.md 1・2 節の行（列名の dict。値は表の書き方のまま: 時刻 "26:15"・分 "480"）
    決まり={(会社, NO): {...}},       # その人のその月に効く値（段の解決は手前で済ませる。会社の決まり.md §1.1）
    法の線={...},                     # 法の値（下）。法の表/ か芯の手前が渡す
    月の口=[...],                     # 月の合計しか無い会社の行（勤怠の形.md 5 節）。任意
    前の表A=[...], 前の表B=[...],     # 期間の頭の週が前の期間にかかる時の前の期間の行（週の判定にだけ使う）。任意
    支給月="YYYY-MM",                 # 決まりに居て勤怠の来ない人の支給月。任意（省けば行の支給月が 1 つの時それ）
)
```

決まりに居て表 A も月の口も来ない人は **黙って抜けない**（行は出さない・人の状態に `勤怠が無い: True`）:
- `人.区分`＝役員: 勤怠が要らない＝`確認済`（仮の数 0）。芯/計算 が勤怠なしの式で計算する。
- ほかの人: `仮`（仮の数 1）と知らせ。問いは芯/計算 が 1 つ出す（集計と計算で同じ人に 2 問を出さない）。
- 支給月が決まらない時（`支給月=` も行の支給月も無い・2 つ以上）は人の状態を出せない＝知らせと、役員でない人の問い「…支給月が決まらない」を集計が出す。

1 人ずつ呼ぶ時は `一人を集計する(日たち, 区間たち, 決まりの値, 法の線)`・`一人を通す(月の口の行たち)`。

### 決まり（その人の値）

`{"分野.名": 値}`。勤務の型ごとに違う値は `"勤務の型": {型の鍵: {"分野.名": 値}}` に置き、表 A の「勤務の型」の列で引く（型の値が先）。
曜日ごとに置ける値（`時間.日の所定`・`時間.所定の始業`・`時間.所定の終業`）は `{"月": "8", …}` でも渡せる。

読む項目: `時間.制度`・`時間.週の法定`・`時間.週の起算`・`時間.日の所定`・`時間.週の所定`・`時間.所定の始業`・`時間.所定の終業`・
`時間.休憩の出し方`・`時間.休憩の表`（`["12:00〜13:00", …]`）・`時間.休憩の長さ`（`[["6:00", 45], …]`＝何時間を超えたら何分）・`人.区分`（委託なら所定日数に数えない）・`時間.打刻の丸めの単位`・`時間.始業前の打刻`・`時間.終業後の打刻`・
`時間.夜勤の出勤日数`・`時間.半休の日の数え方`・`時間.みなし時間`・`時間.変形の期間`（`{"起算日", "終わりの日"}`）・
`時間.フレックスの清算期間`（`{"起算日", "終わりの日", "総労働時間"}`）・`休日.法定休日の決め方`・`休日.法定休日の曜日`・`休日.4週の起算日`・
`休日.休日出勤の数え方`（`{"出勤日数に入れる": "入れる"|"入れない"}`）・`割増.深夜の時間帯`（会社が広げた時だけ）・`割増.深夜に入る休憩`・
`有給.出勤時間に足す`・`有給.半日`・`休暇.子の看護など`・`割増.残業の数え方`・`割増.みなし残業の時間`（下の 6）。無い項目は会社の決まり.md §2 の既定（法の線に近い方）で数える。既定が「無し」の項目は見当で数えて仮にする。

### 法の線（引数）

| 鍵 | 形 | 要る |
|---|---|---|
| `時間.日の法定` | 時間 | 要る |
| `時間.週の法定` | 時間 | 要る |
| `割増.深夜の時間帯` | `22:00〜5:00` の形 | 要る |
| `時間.週の法定の特例` | 時間（労基則 25 条の 2） | 任意（無ければ会社の 44 は仮） |
| `割増.60時間超の境` | 月の時間 | 任意（無ければ 60 時間超が仮） |
| `時間.休憩の長さ` | `[[超える時間, 休憩の分], …]`（34 条） | 任意（無ければ休憩の見当と 34 条の知らせができない） |
| `休日.4週の休日数` | 日（35 条 2 項） | 任意（4 週 4 休の会社だけ要る） |

法の表から作る: `法の線を引く(始め, 終わり, 置き場=None)`（`法の線の橋.py`）が `法の表/法の線.json` の行をこの dict にする（引く口は 芯/計算/引く口.py の 1 つ）。
線の対応: `法定労働時間`（日の時間・週の時間）・`深夜帯`（始め〜終わり）・`特例の週の時間`（週の時間）・`月60時間超の時間外の割増`（境の時間）・
`休憩`（段）・`法定休日`（4週の日数）。要る線が欠ければ `欠け` で止まる。60 時間超の線は効く始め（2023-04-01）より前は無しで渡す。
期間の始めと終わりで値が違えば止まる（期間を分けて渡す）。返す dict の `出所` は引いた行の字（集計は読まない）。

```python
集計する(表A, 表B, 決まり=…, 法の線=法の線を引く("2026-11-01", "2026-11-30"))
```

## 返す物

```python
{
  "行":   [{支給月, 会社, NO, 勤怠の表記, 項目, 値, 単位, 状態, 出所, 印, 見当, 見当の拠り所, 問い}, …],
  "人":   [{支給月, 会社, NO, 勤怠の表記, 状態: "確認済"|"仮", 仮の数, 勤怠が無い?}, …],   # 勤怠が無い は来ない人だけ True
  "問い": [{番号, 何が無いか, 人: [(会社, NO)], 日付: [...], 変わる項目: [...]}, …],
  "知らせ": [...],   # 仮にしない知らせ（休憩が 34 条の長さに足りない日・代休の日など）
  "日ごとの実働": [{支給月, 会社, NO, 日ごと: {日付: 分}}, …],   # 委託・委託の併用の人だけ（下）
}
```

- `日ごとの実働`: 決まりの `人.区分` が 委託・委託の併用 で表 A から数えた人の、勤務の日ごとの実働（休憩・外出を引いた労働＝法定休日の外＋法定休日。定時扱い・みなしの日はその時間）。休日勤務の日・全日の休暇・欠勤・休日は入れない（休日勤務は休日出勤×時給×休日の率で別に払う＝前の道具 timecard_tally の日ごとと同じ）。芯/計算 の `入力` の `委託.日ごとの実働` へ渡す（`初期設定/入口の文脈.計算の入力`）。月の数字の口から来た人は日が無いので出さない（芯/計算 が仮）。

- `項目` は勤怠の形.md 5 節の語だけ（`形.月の語` の順）。`年休を取った日` は 1 日 1 行（値は日付）、ほかは 1 人 1 行。
- `状態` は `確定`／`仮`（`docs/設計/確かめと仮.md` §3）。仮の値は `見当`（置いた値）・`見当の拠り所`・`問い` を持つ。仮が 1 つでもある人は `人` の状態が `仮`＝出口の関所で外す。
- `出所` は値を足した日（読点区切り）。月の数字の口から来た行は原本の名前。
- `割増.残業の数え方` が `1日の所定超え` の人だけ、5 節の語の後ろに `残業（会社の数え方）`・`60 時間超（会社の数え方）`（分）の 2 行を足す（数え方は下の 6）。
- `印` は値の読み方の注（みなしの日・1 年変形の清算の月・月の数字の口から来た等）。
- 足し算: 総労働＝所定内＋法定内残業＋法定外残業＋法定休日。60 時間超・深夜・所定休日は内数。
- 仮の広さ: 仮は理由の効く語だけに付く。例えば期間の頭の週を前の期間の日なしで数えた時は、総労働・日数は確定のまま、内訳（所定内・法定内残業・法定外残業・60 時間超）だけが仮。時刻・休憩・所定の見当は時間の語だけが仮、要確認の日・形の誤りはその人の全部の語が仮。

## 数え方（日 → 週・制度 → 月）

1. **日→区間**（`日.py`）: 表 B の労働の区間から休憩・外出の区間を引く。時刻は日付の 0:00 から（日またぎは 24 を足したまま）。
   打刻・手書きの時刻だけ `時間.打刻の丸めの単位` で長くする向きに丸める。`時間.始業前の打刻`・`時間.終業後の打刻` で所定の始業・終業に寄せる。
   休憩を書いていない日（表 B に休憩が無く、時刻の無い休憩も空）は `時間.休憩の出し方`: 実績（組の間の空き）→ 休憩の表 → 会社の `時間.休憩の長さ`（勤務の型の値が先・仮にしない。34 条より短ければ 34 条の知らせ）→ 無ければ 34 条の長さで見当（仮）。ただし実績で出す型で、労働が法の線の休憩の一番下の段以下（34 条で休憩の要らない長さ）の日は空を 0 分と読み仮にしない。会社の長さの形が違えば 34 条の長さで仮。
   時刻の無い休憩は 0＝取っていない、空＝書いていない。打刻抜け・所定で埋めた時刻・要確認の日は仮。2 節の形の検査もここで回し、誤りは仮にして止めない。
2. **日の時間**: 法定休日は暦日で数える（法定休日の 0:00〜24:00 の労働が法定休日。日またぎの勤務も暦日で切る）。
   日またぎが表 A に無い日（期間の外）へかかる時は決まりで区分を出す: `曜日を決める` ならその曜日で確定（法定休日の曜日でない日は所定休日に数えない）、ほかの決め方は決まらないので法定休日でないとして数え、法定休日・総労働・内訳を仮＋問い。
   法定休日の外の労働を、所定内（その日の所定−休んだ分）→ 法定内残業（日の線まで）→ 法定外 の順に分ける。日の線は通常なら日の法定、変形なら max(所定, 日の法定)。
   `有給.出勤時間に足す`＝足す なら日の線から有給の分を引く。深夜は深夜帯との重なり（休日の日も数える）。遅刻早退＝所定の残り−実に働いた分（法定休日へかかった分も含む）−遅延証明の分。
3. **週・制度**（`月.py`）: 法定休日の外の「法定外でない分」を週（`時間.週の起算`）ごとに足し、週の線を超えた分を後ろの日から法定外へ移す（法定内残業から先に）。
   - 通常・事業場外みなし・裁量: 週の線＝週の法定。みなしの日（働いた場所＝みなし・裁量の勤務の日）は `時間.みなし時間`。
   - 1 か月変形: 週の線＝max(週の所定, 週の法定)。期間の総枠＝週の法定×期間の暦日÷7（分未満は切捨て＝労働者に有利な向き）を超えた分も法定外。
   - 1 週間変形: 日と週の 2 段。1 年変形: 日と週。期間の総枠は期間の終わりの月に清算する（その月は仮＋問い）。
   - フレックス: 清算期間が給与の期間と同じ時だけ書ける（総枠を超えた分が法定外・所定の総労働時間を超え総枠までが法定内・足りない分は遅刻早退）。1 か月を超える清算期間は見当で数え仮＋問い。
   - 管理監督者・高度プロフェッショナル: 全部を所定内に置く（深夜は数える。割増の要否は `芯/計算/` が制度で決める）。
   - みなした日（表 A の印 `定時扱い`。出勤簿が無い人を入口が所定どおりとみなした日など）の時間も働いた日と同じに週の線で数える。変形の定めが無い（`時間.制度` が通常系）なら週の法定を超えた分は法定外残業＝37 条の割増（仮にしない・問いも出さない）。変形なら上の変形の週の線に従う。みなした日の印（総労働の印 `… は定時扱い`）は残す。
   - 定時扱いの日の時間は その日の所定−休暇の分。その所定が決まりの `見当の値` に `時間.日の所定` がある見当（段の解決が委託だけの人へ置いた 8 など。表 A の所定時間・その日の勤務の型の所定が在れば見当でない）なら、その日を時間の語で仮にする（黙って見当の時間で確定しない）。
   - 期間の頭の週が前の期間にかかる時は `前の表A`・`前の表B` を足して判定する。受けていなければ、その週に労働がある時だけ仮＋問い。
   - 60 時間超＝月の法定外残業−法の線の 60 時間の境。
   - 委託だけの人（`人.区分`＝委託）は労基法の労働者でない＝前の期間の日を求めない（期間の頭の週の仮を出さない）。週の移しは委託の式（`芯/計算/委託.py` の月額の残業＝法定内残業＋法定外残業−所定休日）が受ける数なので、期間の中の日だけで今までどおり数える（委託の式が受ける数は変わらない）。`委託の併用` の人の雇用分は今までどおり前の期間の日を求める。
4. **日数**: 所定日数＝休日・休日勤務の外の日（`人.区分`＝委託 の人は所定が無い＝0。働いた日は出勤日数だけ）。出勤日数＝勤務の日（夜勤・半休・休日勤務・出勤扱いは会社の選択肢どおり。既定は法の線に近い方: 1 勤務＝1 日・半休の日は 0.5・休日勤務は入れない）。
   `休日.休日出勤の数え方` の `所定休日の率`（週の法定で判定・休日の率で払う）は集計の数を変えない（所定休日の分は内数で出し、週 40 の判定はいつも入れる）。率を選ぶのは `芯/計算/`。
   休日の区分が空の日は `休日.法定休日の決め方`（曜日・週の最後の休日・4 週 4 休）で決める。看護・介護・生理の休暇は `休暇.子の看護など` で特別休暇（有給／無給）に数える。
5. **月の数字の口**（`口.py`）: 5 節の語だけを通す（語の外は通さず仮）。値の形・足し算・内数を見て、合わなければ仮。
   全部の行に「日の記録が無い（できない検査: …）」を印す。所定日数・出勤日数・総労働が無ければ 0 で置いて仮。

6. **会社の残業の数え方**（`会社の残業.py`）: `割増.残業の数え方` が空か `法定どおり` なら何もしない（月の数字は上のまま）。
   `1日の所定超え` なら、勤務の日ごとに「その日の所定（休暇の分を引く前）を超えた労働」を足して `残業（会社の数え方）`（分）に出す。
   `60 時間超（会社の数え方）`＝それ−法の線の 60 時間の境。法定休日・休日勤務の日は数えない（休日の語で払う）。
   `割増.みなし残業の時間` は集計では引かない（前の道具は月給で役員でない人だけに当てる。給与の形は集計に来ないので `芯/計算/` が固定残業として引く）。値は印に残す。
   法の線で数えた `法定外残業`・`60 時間超` はそのまま並べて出す。会社の数え方がそれを下回る月（週の法定・休日勤務の日の法定外など）は
   **知らせ**（問い・仮にしない）に月の差と「法定外がその日の所定超えより多い日」を出す。払うのは会社の数え方の方（率を選ぶのは `芯/計算/`）。
   選べる値の外・数えられない制度（フレックス・管理監督者・高度プロフェッショナル）は会社の 2 語を法定外で置いて仮（ほかの語は確定のまま）。
   みなしの当て方（月給で役員でない人だけ・残業−みなし）は `芯/計算/` が持つ。夜勤の「所定×2」は持たない（その日の所定時間で受ける）。

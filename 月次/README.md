# 月次 — 1 か月（と賞与の 1 回）を回す口

殻（各エージェントの repo の環境の口）が手で組んでいた部品の呼び順を、パックの 1 つの口にまとめた **組み立て役**。3 層（入口／芯／出口）の外に置き、3 層と `初期設定/`・`有給/` の部品を今のまま呼ぶだけ（部品の中身・呼び口・額は変えない）。
**段ごとの部品の呼び順の正本はここ 1 か所**。ほかの README と `docs/毎月の流れ.md` はここを指す。

- 殻は Drive・シートから読んだ値を渡し、返った物を Drive・台帳・管理表へ書くだけ。部品を手で組まない（Javis と UTC の殻が別々に組んで結果が食い違う所を無くす）。
- **仮の人は出口へ出ない** ⟦鍵:給与計算/足りない時は仮で計算し出さない⟧: 段の解決・入口の文脈・入口（要確認・NO が引けない）・芯/集計・芯/計算・有給/ のどこかで仮が 1 つでも残る人は、返す `関所を通った`・`取り込み`・`支給控除一覧`・`有給の出す行` のどこにも出ない。殻が仮を `人の状態` へ写す手は要らない。
- Drive を開かない。答え（過去の結果）を受けない。Python 3・標準ライブラリだけ。

## 月を回す

**型の版 27 から（形の約束 1）**: `月を回す` は原本を読まない。勤怠は年の台帳 `台帳_<支給年>` の `確定した勤怠`・`確定した勤怠の区間` だけを読む（読む口は `月次/台帳の形.py` の `確定した勤怠を読む` の 1 か所）。

```python
o = 月次.月を回す("2027.02支給", "C1", タブ,              # マスタのタブ＋年の台帳の その月だけの指示・人ごとの月の数字
    確定した勤怠=<年の台帳「確定した勤怠」>, 確定した勤怠の区間=<「確定した勤怠の区間」>,   # get_values の形だけ（dict の並びは止める）
    読んだままの勤怠=<「読んだままの勤怠」>, 読んだままの勤怠の区間=<「読んだままの勤怠の区間」>,   # 必須。計算の前に勤怠の照らしへ
    締めの記録=<「締めの記録」>,                          # 必須。渡さなければ止める（黙って全員締まったとみなさない）。行の パックの版 が今の版と違えば止める
    前の確定した勤怠=…, 前の確定した勤怠の区間=…,          # 毎月 年の台帳を起こす.前の年の確定した勤怠 の返りを渡す（期間の頭の週・有給が前の年を読む）
    月の数字=…, 給与のルール=<給与のルール.md の字>, 有給の値={}, 出口=…, 置き場=…,   # 有給の値: None＝有給を回さない・{}＝回す（中に鍵を入れると止める）
    作業のルール=<作業のルール.md の字>, 問いの表=<質問と回答「質問」のタブ>)   # 必須。勤怠の照らしが直した訳の行き先を照らす
```

- 台帳のタブ（確定した勤怠・その区間・読んだままの勤怠・その区間・締めの記録・前の確定した勤怠）は年の台帳の get_values の形（1 行目が見出し）だけ受ける。dict の並びは止める（殻が列名を手で組んだ行を読まない）。
- 計算の前に `月次/勤怠の照らし.照らす`（読んだままと確定した勤怠のその会社・その支給月の行・`決まりの見出したち`＝作業のルール.md と給与のルール.md の見出し・`問いの番号たち`＝その会社の答えのある問い）を通す。直した訳の `決まり:<見出し>`・`問い:<番号>` がその中に無ければ挙がる（`作業のルール`・`問いの表`〔質問と回答「質問」のタブ・答えは当てない〕を渡さなければ止める）。挙がった人は締まった にできない＝返す `勤怠の照らし`（挙がり）と `締めの記録へ`（状態 まだ の行＝殻が台帳「締めの記録」へ書く）。
- 確定した勤怠が 1 行も無い人・締めの記録で `締まった` でない人・勤怠の照らしで挙がった人は芯へ渡さない（計算しない）＝`締まっていない人` と `問い.締め` に返す。
- **1 人でも締まらない人が居れば、その会社のその月は誰も出口へ出さない**（決定 6・23。必ず埋める 6 欄が空の人＝芯/計算 の `止めた` が居る時も同じ）。締まった人も関所で外し、`取り込み`・`支給控除一覧`・`有給休暇管理表` と `証明` を返さない（`証明`＝{}）。訳は `待つ訳`。締まった人の見当の額は数える（問いに添える）。
- 例は 給与のルール.md の字（`給与のルール=`）から `例の確かめ.MDから例を読む` で読む。前のマスタ「例」のタブ（タブ の `例`）は型から消えた＝渡すと止まる。
- タブ の年の台帳は型の名（`その月だけの指示`・`人ごとの月の数字`）で渡す。前の台帳の名（月の変動・人ごと・勤怠 など）で渡すと止まる。
- 返す `台帳` は `人ごとの月の数字` と `その月だけの指示`（次の支給月の 社保の立て替えの残り）だけ。`日の要約` は確定した勤怠の 休憩の合計・労働の合計 の写しの元。
- 原本を読んで `読んだままの勤怠`（1 次）を作るのは AI の道具 `月次.読んだままの勤怠を作る(支給月, 会社名, タブ, 原本, …)`（入口の読み口を順に呼び重ね・原本の来ない 出勤簿が無い 人に所定どおりの日を足す。質問と回答の答えは当てない＝1 次は原本を読んだまま）。質問と回答の日の問いの答えは `月次.答えを確定した勤怠へ(支給月, 会社名, タブ, 原本, 質問と回答, …)` が、答えで変わった日だけの確定した勤怠・区間の行（直した訳 `問い:<番号>`）にする（殻は同じ日の行を置き換える・決定 7。答えの照らしは `設問.反映の照らし(…, 台帳=)`）。どちらも `月を回す` の中から呼ばない。確定した勤怠の表は `台帳の形.勤怠の表たち(確定=True, …)` で作る（要確認の日は書けない・1 次と違う行は 直した訳）。年の台帳へは `台帳へ書く.勤怠` が返す書く手順で書く（下の「年の台帳へ書く」）。

### 呼び順（口の中・型の版 27 から＝`月次/__init__.py` の `月を回す` の順）

1. 例を分ける: `給与のルール=`（MD の字）を受け、`例の確かめ.MDから例を読む` でその会社の例を読む（タブ の `例` は止める）
2. 台帳の勤怠のタブ（確定した勤怠・その区間・読んだままの勤怠・その区間・締めの記録）を引数か タブ から分け、確定した勤怠・読んだままの勤怠が無ければ止める。前の確定した勤怠も含めて get_values の形かを照らす（dict の並びは止める）
3. `締めの記録` をその会社・その支給月で読む（無ければ止める）。その月の行の `パックの版`（締めた時の版）が今のパックの版（`出口/証明.py` の `パックの版()`）と違う・空・行で割れる時は止める（月の途中で版を変えない。その月をどちらの版で出すかはオーナーが毎回決める＝締めた時の版で出すなら殻がその版のパックを置いて回し、今の版で出すなら締め直して `パックの版` を今の版に書き替える）
4. `月次/勤怠の照らし.照らす`（読んだままと確定した勤怠のその会社・その支給月の行と、`作業のルール`・`給与のルール` の見出し・`問いの表` のその会社の答えのある問いの番号）
5. 年の台帳のタブを段の解決の名へ（`その月だけの指示`→月の変動。`人ごとの月の数字` は段の解決へ渡さない＝自分の前の回の結果を計算の元に読まない・証明の計算の元にも結ばない＝回す順で証明が変わらない。前の台帳の名は止める）・⑥つなぎ を分ける
6. `台帳の形.確定した勤怠を読む` で 確定した勤怠 → 表 A・B、前の確定した勤怠 → 前の表 A・B（見出しが型と違う・読めない行は止める）
7. `r = 段の解決.解く(支給月, **タブ)` → `x = 入口の文脈.入口の文脈(支給月, 会社, r, **タブ)` → 表 A・B をその会社・その支給月に絞る
8. 在籍が期間にかからない人（`入口の文脈.期間の外の人`）を外す（その月の物が来た人は外さない）
9. 確定した勤怠が無い・締まった でない・勤怠の照らしで挙がった人（`_締まっていない人`）を芯へ渡さない＝`締めの仮`
10. 法の線（渡さなければ 法の表/ から期間で引く）→ 例の確かめ（`_例の関所`＝通らなければ会社の全員に仮）
11. `集 = 芯.集計.集計する(表A, 表B, 決まり, 法の線, 月の口=月の数字, 前の表A, 前の表B, 支給月)` → `計 = 芯.計算.計算する(集, 決まり, 人, 入力=入口の文脈.計算の入力(r["入力"], 集))`
12. 待つ訳（締まらない人・芯/計算 の `止めた`）→ 1 人でも居れば全員に `待つの仮`
13. 立て替えの残りの仮（`_立て替えの残りの仮`）・`出口.関所.勤怠の行を分ける` → `入口の文脈.給与の関所へ` → `出口.関所.通す`
14. 待つ訳が無ければ出口（`_出口へ`＝`書き口.取り込み`・`支給控除一覧`。`道具` から欄の対応と渡さない人を組む）
15. **台帳へ書く形**: `台帳の形.台帳へ書く形`（人ごとの月の数字）＋ `_立て替えの残りを次の月へ`（その月だけの指示＝次の支給月の 社保の立て替えの残り の行）
16. **見当の額**: `見当の額(計["行"])`（仮の人も含む見込みの額＝問いに添える。出口へは出さない）
17. `有給の値`（`{}`）があれば有給（中に鍵を入れると止める。`入口の文脈.有給の入力` → 確定した勤怠＝前の確定した勤怠と確定した勤怠のその会社の行 → `有給.管理表` → `入口の文脈.有給の関所へ` → `出口.関所.通す` → `有給の出す行`。待つ訳が無く `出口` を渡した時だけ出す物 `有給休暇管理表`＝計算だけ〔`出口=None`〕では作らない）
18. **証明を付ける**: `計算の元`（公開の口＝殻の出荷の口も同じ口で組む・マスタ・確定した勤怠・その区間・その月だけの指示・給与のルール.md の字）→ `_証明たち`（出す物ごと。待つ訳がある月は {}）

前の原本を読む・原本を読む・出勤簿が無い人に所定どおりの日を足す 手順は `読んだままの勤怠を作る` の中、答えを当てる所は `答えを確定した勤怠へ` の中（どちらも月を回す の中ではない）。下の「前の版の呼び順」の 0・3・4 がその中身。

3. 入口の読み口を `原本` の順に `読む()` し `口.重ねる`。入口は読みながら `日の答え` をその日に当てる（答えた日は返す `台帳` の勤怠に 確認済・備考〔問いの番号と答え〕・区分が載る＝殻が出力をそのまま書けば答えの記録は消えない。答えの無い日・答えと合わない日は要確認のまま。読めた答えでどの日にも当たらなかった物〔問いの何が無いかがその人の日の理由と違う・時刻を置く区間が決まらない など〕は `入口.口.当てなかった日の答え` で `知らせ.入口の文脈` に出す＝黙って捨てない）。`人の状態()` が仮の人（要確認・NO が引けない）は口の仮の値に足す。入口が月の変動の行を読んだ時（`手当控除の一覧`・`メールとメモ`）は、タブの月の変動に足して（同じ原本の同じ人×項目は読んだ行が勝つ・要確認の行は入口の問いのまま渡さない）`段の解決.解く` を解き直す（殻が台帳へ書く前の同じ回でも `入力` へ渡る）
4. 在籍が期間にかからない人（`人.退職日` が期間の始めより前・`人.入社日` が期間の終わりより後）で勤怠の来ない人は、`入口の文脈.期間の外の人` で外し、芯へ渡さず仮にもしない（`期間の外の人` と `知らせ.月次` に出す。その月の物〔勤怠・月の変動〔台帳のその支給月の行は読めたかに関わらず・入口〕・入口の人ごとの支給控除〕が来た人は日付の誤りかもしれないので外さない。外した人の段の解決・入口の文脈の仮は `期間の外の人` の `読まなかった仮` と知らせに名を出す）
   - 勤怠を管理しない月給の固定給の人（`時間.出勤簿が無い`＝無い で原本が 1 枚も来ない。役員でない家族の従業員など）は、`入口.口.所定どおりの日(文脈, その NO たち)` で所定どおり働いたとみなした表 A を作って `口.重ねる` で足す（入口の日の部品の「出勤簿が無い＝所定どおりとみなす」と同じ道＝勤務日は 定時扱い・時刻の無い労働時間＝所定時間、休日は休日）。原本に出た人（来た）は入口がその道で定時扱いにするので足さない。期間の外の人も足さない。日の所定が渡されない人はその日の部品が要確認にする（黙って確定にしない）＝足した要確認を `入口の仮` に寄せ直す。最低賃金は今までどおり芯/計算 が点検する（印が無ければ下回る時は赤＋仮・`法の線.承知` の印があれば承知＝§1.4）
   例の確かめ: `月次/例の確かめ.確かめる(支給月, 会社, タブ, 例, 法の線)` がその会社の例を全部、今のマスタの値で芯に通す（下の「例の確かめ」）。通らなければその会社の全員に仮の値 `例の確かめ` を 1 つ置き、7 の関所と有給の関所で外す（計算は回す＝見当の額と問いは返す・出口へ出さない）
   `集 = 芯.集計.集計する(表A, 表B, 決まり=r["決まり"]〔その会社〕, 法の線, 月の口=入口の月の数字, 前の表A/B, 支給月)`
5. `計 = 芯.計算.計算する(集, 決まり, 人=r["人"], 入力=入口の文脈.計算の入力(r["入力"], 集))`（委託の `委託.日ごとの実働` は必ずここで渡る）
6. `渡す, 出さない = 出口.関所.勤怠の行を分ける(集["行"], 決まり, 集["所定で頭打ちの実働"], r["入力"]〔その会社〕)`（勤怠の欄を出口へ。決まり・頭打ちの実働＝`出口.実働の上限`＝所定 の人の 総労働 を日ごとに所定で頭打ちにした実働で書く〔型の版 18〕・入力＝委託の併用の人の 出勤日数 を段の解決が引いた `委託.雇用分の出勤日数` で書く〔型の版 19〕。どちらも出口の欄だけで計算は変えない）
7. `z = 入口の文脈.給与の関所へ({"行": 計["行"] + 渡す, "人の状態": 計["人の状態"]}, r の仮の値, x の仮の値 + 入口の仮)` → `通 = 出口.関所.通す(z["行"], z["人の状態"])`
8. `出口` があれば `出口.書き口.取り込み(通, …)`・`支給控除一覧(通, …)` の両方を作る（`出口` に `取り込み`・`支給控除一覧` のどちらかが無ければ止まる）。取り込み の `道具` は必ず要る（無ければ止まる）: 給与ソフトへ入れない人を `出口.形.渡さない人を組む(会社, 道具, つなぎ)`（⑥つなぎ の人の行 その道具での番号＝`渡さない`）で必ず組んで外す（`欄の対応` を渡しても同じ・殻が `渡さない人` を渡すと止まる）。`欄の対応` は任意で、渡さなければ `出口.形.欄の対応を組む(会社, 道具, タブの支給控除の項目, つなぎ, 支給月)` で組む
9. `有給の値` があれば `y = 入口の文脈.有給の入力(支給月, 会社, r, 表A, 社員=…, **有給の値)` → 入力の `勤怠` を外し `確定した勤怠`（前の確定した勤怠と確定した勤怠のその会社の全部の行＝有給の年の台帳）を渡して `表 = 有給.管理表(入力, 置き場)`（取得と出勤率 8 割は台帳から数える・要る日の行が無い人は `有給の止めた人`。`有給の値` に `勤怠の始め`・`出勤率が足りない付与日` を渡すと止まる。付与日数は `法の表/`） → `入口の文脈.有給の関所へ(y, 表, r・x・入口の仮・締めの仮)` → `出口.関所.通す` → `入口の文脈.有給の出す行(表, 通った)` → 出す物 `有給休暇管理表`（名は `出口/名と版`・前の版の名は `出口` の頭の `今ある名`・`履歴にある名`＝`出口.有給休暇管理表` の中に置けばそちらが先）
10. 証明（`_証明たち`）: 出す物ごと（取り込み・支給控除一覧・有給休暇管理表）に、計算の元（マスタ・確定した勤怠・その月だけの指示・給与のルール.md）の指紋を結ぶ

- 段の解決は全部の会社を解くが、芯へ渡すのは `会社` の人だけ（別の会社の人を勤怠の無い人として数えない）。
- 有給の関所には段の解決の仮だけでなく、入口の文脈・入口の仮も寄せる（年休の読みと人の値がその仮に乗る）。給与は確定でも有給/ が仮の人は `有給の出す行` に出ない（逆も同じ）。

### 立て替えの残り（社保.引けない月の本人負担＝立て替えて復帰後に引く）

給与から引けない月に会社が立て替えた社保の本人負担の残り（芯/計算 の `社保の立て替えの残り`）は、人が写さず月次が前の月の確定した結果から次の月へ渡す。

- 回した月: 関所を通った人の残りを、返す `台帳` の `その月だけの指示`（次の支給月の行・項目＝社保の立て替えの残り・値＝残り・中身＝どの月の結果か）にする。立て替える式の人は残りが 0 でも書く（次の月の「行が無い」と分ける）。式の外の人は残りが在る時だけ。仮で外した人の行は書かない。
- 次の月: 段の解決がその行を 入力 `社保の立て替えの残り` へ渡し（`初期設定/段の解決.入力の名たち`）、芯が給与から引ける所まで `社保の立て替えの返し` で引く。
- 立て替える式の人に、その月の行が無い（前の月を回していない・前の月に仮で外れた・初めて使う月）なら、残りを黙って 0 にせず仮＋問い 1 つ（`問い` の `立て替えの残り`。答えは その月だけの指示 に前の月までの残り〔無ければ 0〕の行を書く）。毎月請求の人に残りの行が在れば芯が仮にする（返し方が決まっていない）。
- 残りは残高＝出す物（取り込み・支給控除一覧・突き合わせ）に載らない（`出口/README.md`「欄の対応」）。`社保の引けない額`・`社保の立て替えの返し` は ⑥つなぎ の `欄.<名>` で給与ソフトの欄へ載る。

年の最初の支給月に、②（その月だけの指示）の前に 1 回呼ぶ（`docs/毎月の流れ.md` 1-①）。Drive に書くのは給与エージェント。

```python
# 前の年の台帳が無い会社: 起こす(2027, None, 今ある名=[…], 社員=…)＝止めない（前の確定した勤怠は見出しだけ・0 で埋めない）。
# 前の年の日が要る人（月の頭の週・有給の取得と出勤率）は 月を回す が人ごとに止め、その人の結果を出口へ出さない
```

```python
y = 年の台帳を起こす.前の年の確定した勤怠(2027, 前の年の台帳={<8 タブの名>: <get_values の値>}, 社員=<マスタ「社員」>)
```

1 月支給の出荷の口は 起こす を呼ばない（1 月の出荷の時には `台帳_<支給年>` が既に在る＝起こす は必ず「既に在る」で止まる）。毎月と同じ `前の年の確定した勤怠(支給年, 前の年の台帳, 社員=…)` で読む（書く手順なし・会社の根の名を受けない・同じ照らし）。

有給の始めを進める（同じ時に 1 回）: 前の年の 12 月支給を `月を回す` で回し直し（出荷の口の 照らす＝書かない）、返った `有給の始めを進める` を `有給の始めを進める(進める, 新しい支給年=2027, 今の社員=<マスタ「社員」の get_values>)` へ渡す。返る物は `{書く手順: [値を書く（ファイル 2_マスタ・タブ 社員・有給の始めの日〜繰越 の 3 列）], 書いた後: {社員: 値}, 進めた, 済み}`。12 月支給の値でない・新しい支給年の前の年の日でない・社員に居ない NO／2 行在る NO・氏名が違う・マスタの今の始めの日が進める日より後（戻さない）・見出しが型と違う・手で組んだ dict の並びは止める。同じ値が既に書いてあれば `済み`（書かない）。12 月の後でなく 1 月に書く訳: 12 月の回し直しの元（マスタ）を動かさない（有給/ は始めの日より前の取得も 年 5 日・付与日からの取得・今月の取得 に数える）。

止める: `今ある名` か `社員` を渡さない・同じ名の台帳が在る・引き継ぐ行の 氏名 が社員と違う・社員に居ない NO／社員の氏名が空の NO・日と区間のタブに新しい年の支給月の行が在る（勤怠 の口は支給月の年の台帳へだけ書く＝手で書いた行）・渡した前の年の台帳のタブが欠ける／型に無いタブ／前の台帳のタブ・get_values の形でない・見出しが型と違う・支給月が読めない・前の年でも新しい年でもない支給月の行・前の年の確定した勤怠が 1 行も無い・確定した勤怠が読めない。何を引き継ぐかの表の正本は `docs/設計/Drive の型.md` §4。

## 年の台帳へ書く

年の台帳（`台帳_<支給年>`）へは、口が返した表を窓が〔口: シートに書く〕で写さない。`月次/台帳へ書く.py` の口が **書く手順**（殻が順に当てるだけの操作の並び・`docs/設計/寄せる道具.md` 1.1 と同じ考え・値は字のまま RAW）と **書いた後**（タブごとの書いた後の値）を返し、殻は手順を当てて読み直し、`初期設定/型の口.書いた値を照らす(書いた後, 読み直した値)` が空でなければ止める。

```python
from 月次 import 台帳へ書く

台帳へ書く.月の台帳(o["台帳"], 今の台帳={<タブ>: <get_values>}, 台帳の名="台帳_2027", 社員=<マスタ「社員」>)
台帳へ書く.勤怠(確定=False, 勤怠=<日の行>, 勤怠の区間=<その日の区間の全部>, 今の台帳=…, 台帳の名=…, 社員=…, 原本のリンク={<原本の名前>: <在り処>})
台帳へ書く.日の要約を書く(o["日の要約"], 今の台帳=…, 台帳の名=…, 社員=…, 原本のリンク=…)
```

| 口 | 書くタブ | 置き換える単位 |
|---|---|---|
| `新しい台帳`（`起こす` が呼ぶ） | 新しい台帳の 8 タブ（スプレッドシートを作る・タブを足す・値を書く） | 新しい台帳だけ（同じ名が在れば止める） |
| `月の台帳` | 人ごとの月の数字・その月だけの指示（月を回す の `台帳`） | 人ごとの月の数字＝会社×支給月（回し直しはその月の行を全部置き換える）・その月だけの指示＝会社×支給月×NO×項目 |
| `勤怠` | 読んだままの勤怠・確定した勤怠 とその区間 | 会社×支給月×NO×日付（その日の区間は渡した区間で全部置き換える） |
| `日の要約を書く` | 確定した勤怠 の 休憩の合計・労働の合計（月を回す の `日の要約`＝芯の数え） | 日の要約の会社×支給月の行（口が今のタブから選ぶ） |

- 写しの列（氏名＝マスタ「社員」・曜日・出勤と退勤の時刻＝区間・休憩と労働の合計＝芯の 日の要約・原本のリンク＝置き場の在り処）は口が埋める。窓は空で渡すか、道具が返した値のまま渡す（違えば止める）。休憩と労働の合計は 日の要約 が無ければ空。埋めて照らすのは `台帳の形.py` の 1 か所（`勤怠の表たち`・`氏名を埋める` の `厳しく=True`）。4 つの口（`新しい台帳` も）はどれも `社員` を必ず受け、関所（`台帳へ書く._通す`・`_勤怠を通す`）が返す「通した表」からしか手順を組めない（通らない口は作れない）。社員に居ない NO の行と、社員の行の 氏名 が空の行は止める（空の氏名で書かない）。
- 止める（書く手順を出さない）: 書く先の今のタブの見出しが型と違う（1 つ違う・無い・型に無い列・並びが違う・字の前後に空白・タブが無い）・書く表の見出しが型と違う・書き方が型と違う・支給月が台帳の年でない（その月だけの指示の翌年 1 月は書く）・同じ鍵の行が 2 つ・原本の在り処が引けない・区間の日の行が無い・1 回に会社×支給月が 2 つ。
- 手順の形: `値を書く`（範囲・値・書き方）・`行を足す`（値＝行の並び・書き方）・`行を消す`（行＝シートの行の番号・下から順）・`スプレッドシートを作る`・`タブを足す`。どの手順にも `ファイル`（台帳の名）と `タブ`。

確定した勤怠のシート（`月次/勤怠のシート.作る(会社, 支給月, 今の台帳=<読んだままの勤怠とその区間・確定した勤怠とその区間・人ごとの月の数字>, 今ある名=<その月の 2_出す物/ の名>, 履歴にある名=<9_履歴/ の名>)`）も同じ形の `{名, 書く手順, 書いた後, 履歴へ移す}` を返す（`2_出す物/` に `確定した勤怠_<会社>_<支給月>_v<n>` を作り タブ 人ごと・直した所 を書く。中身は `勤怠の照らし.担当者へ渡す表`・名と版は `出口/名と版.渡す名を付ける`＝出荷の物と混ぜない）。届いた物（`月次/届いた物.写す手順(届いた物, 今ある名=…)`）は `ファイルを写す`（元＝受け取り口の在り処・先＝1_届いた物・名）を返す。

試験: `tests/月次/test_年の台帳の束C.py`（新しい年の台帳が在っても前の年を読める・確定した勤怠のシート・届いた物・写しの名・有給の全取得と始めを進める、どれもわざと入れた誤りで止まる）・`tests/月次/test_台帳へ書く.py`（手順を当てた値が `書いた後` と同じ・4 つの口それぞれで 空の氏名を埋める／違う氏名・社員に居ない NO・社員の氏名が空・社員を渡さない で止まる・関所を通らない表から手順を組めない・書く先の見出しが 1 つ違う／並びが違う／タブが無い・道具が埋める列を窓が違う値で渡す・同じ年の台帳が在る、で止まる・手順の文書に〔口: シートに書く〕で年の台帳を写す段が戻れば赤）。

## 例の確かめ

給与のルール.md（人と AI が読む）に書いた決まりと、計算が読む 2_マスタ の値が同じ事を言っているかを、毎月の計算の前に機械で確かめる所（`月次/例の確かめ.py`）。
マスタの欄が埋まったか・字が選べる値かの照らしは、**選べる値の中で取り違えた値**（始業前の打刻の 所定の始業から ↔ 打刻のまま）を止めない。止めるのはここだけ。

- 例は 給与のルール.md の決まりごとの `### <決まりの名>` の下の例の表に書く（列は `docs/設計/Drive の型.md` §4。殻は MD の字を `給与のルール=` で渡し、口が `MDから例を読む` で読む）。決まりの文から作り、給与ソフトの過去の答えからは作らない（答え合わせではない）。
- 種類: `日`＝1 日の打刻（区間）を今のマスタの勤務の型・人の値で芯/集計 に通し、期待（台帳「人ごとの月の数字」の月の語と その日の 休憩・労働）と照らす。例の日の前の 7 日は休みの日として渡す（週の法定の例は 1 日の例では書かない）。休暇を取った日は 日の種類 の括弧に 休暇の種類・休暇の単位〔・休暇の時間〕を書く（例 `休暇（年休・全日）`）。`月`＝その支給月の締めの始め・終わりを入口の文脈と同じ式で出して照らす。`書けない`＝マスタに書けない決まりの印（型の側へ項目を頼むまで止める）。
- 止める時（1 つでもあればその会社の月は出口へ出ない）: 例が 1 つも無い・例を渡さない・期待と芯の数えが合わない・芯が仮で数えた・事務所の **確かめた日** が無い・**確かめた人** が空か確かめの出所が無い（名だけ・AI の名だけ・形の違う出所・`決定DB <日付>` だけ）・`書けない`・読めない例。AI が決まりを取り違えると例にも同じ取り違えが入るので、人が読むのは例（打刻と分）の 1 か所にする。
- **覆い**（2026-11-18 オーナーの決定＝勤怠の数え方の決まりは全部）: 2_マスタの会社の行と勤務の型に値がある勤怠の数え方の決まり（`芯/設定の表.json` の 読む所 に 集計 が在る名・`人.` の名と `支払.賃金の形` を除く・`支払.締め日` を足す）は全部、どれかの例の **決まり** の欄にその名（例 `時間.始業前の打刻`）が書かれていないと止める。2_マスタ「社員」の列に置いた数え方の決まり（`人で覆う名`＝人の段に置けて形が選べる値・休憩の表の物: 時間.終業後の打刻・時間.制度・有給.出勤時間に足す・時間.休憩の表・時間.出勤簿が無い）は、社員に在る値ごとに、例の **人の値** にその値を置き 決まり にその名を書いた例が無いと止める。社員の列の時間・時刻・数の形の値（日の所定・みなし残業の時間 など人ごとの契約の量）は事実で決まりの文の写しでない＝覆いに数えない。
- **見分け**: 例が名を書いた決まりのうち、芯/集計 が勤務の型ごとに引く選べる値の決まり（`日で見分ける名`）は、選べる値のほかの値に替えて例を数え直し、名を書いた日の例が全部それでも合えば止める（例がその取り違えを見分けない）。社員の列の決まりは、人の値にその値を置いた例の人の値をほかの値に替えて同じに照らす。替えた値で思わぬ誤りが出て数えられない時も止める（見分けたか分からない）。数えの外れがある時は出さない。週・月で効く決まり（週の起算・暦・制度〔1 日で効くのは所定が日の法定を超える日だけ〕など）と字・時刻の形の決まりは覆いだけ（人が例を読む）。
- **確かめた人** は `<答えた人の名>（<確かめの出所>）`（出所＝確認ページの答えの受付番号 `R<YYMMDD>-<英数 4 字>`・決定DB の行 `決定DB <YYYY-MM-DD> <行の URL か ⟦鍵:…⟧>`・回答のある問いの番号 `Q<支給年月>-<順>`・過去の結果の照らし `過去の結果 <支給月> <資料の名> <NO>:<項目>[・…] 一致` のどれか。過去の結果の照らしの一致は月次では見ない＝初期設定の照らしの終わりに `道具/答え合わせ` の `出所を見る` が照らしの差の表で見る・形の欠けた字は月次でも止める）。読むのは `例の確かめ.確かめた人を読む` の 1 か所（過去の結果の形の正本は `例の確かめ.過去の結果を読む`）（全角半角は NFKC でそろえる・形の正本は 確認ページ/確認ページ.py の 受付番号の形 と 初期設定/型の口.py の 問いの番号を読む）。誰が答えてもよい＝名簿は照らさない（2026-11-19 オーナーの決定。前の事務所の設定「確かめてよい人」は型の版 32 で畳んだ＝`確かめてよい人=` かタブで渡すと止める）。出所が付いている事だけを照らす＝AI が自分で確かめたと書いただけの例は通さない。
- **確かめた日** は `YYYY-MM-DD` の在る日で今日より後でない物だけ。無い日付・人の段に置けない人の値・段の解決が読めない例の人の値は「例が読めない」で止める（月は落ちない）。
- 例で照らさない物（次の便）: 給与額の決まり（割増率・端数・保険）＝次に「額の例」を足す（月と賞与で同じ例の口に足す）。
- `賞与を回す` も同じ口（`_例の関所`）で例を照らす（支給月のマスタの値・支給月の締めの期間の法の線）。通らなければ賞与も会社の全員を外す。
- 例は毎月その月のマスタの値で数える（マスタを直したら次の月から例が照らす）。例を作るのは会社を始める時と決まりが変わった時（答えの反映と同じ回）。

試験: `tests/月次/test_例の確かめ.py`（取り違えたマスタ・締め日の取り違え・確かめた日の無い例・確かめた人が空か確かめの出所の無い例〔名だけ・AI の名だけ・形の違う受付番号・日付だけの決定DB〕・書けない例・例が無い・読めない例をわざと入れて、会社の全員が出口へ出ないことを見る）。

## 賞与を回す

```python
o = 月次.賞与を回す("2027.06支給", "C1", タブ, 支給一覧=[{"会社", "NO", "額", "原本の名前", "パックの版"}], 支給日="2027-06-30",
                   前月の課税対象額={...}, 前の標準賞与額={...}, 計算期間={...},   # 賞与を計算する の残りの引数はそのまま渡す
                   出口={"取り込み": {...}, "支給控除一覧": {...}})
```

賞与だけの元（支給一覧・支給日・前月の課税対象額・前の標準賞与額・計算期間）は、年の台帳「賞与の支給一覧」（型 `初期設定/型.json`・1 人 1 行・`docs/設計/Drive の型.md` §4）に置き、殻は手で組まずに読む口で直して渡す:

```python
元 = 月次.賞与の元を読む(台帳の「賞与の支給一覧」の get_values, "C1", "2027.06支給")   # 行の パックの版（回の始めに控えた版）も支給一覧へ写す
o = 月次.賞与を回す("2027.06支給", "C1", タブ, 元["支給一覧"], 支給日=元["支給日"], **元["賞与の引数"], 出口=…, 給与のルール=…)
計算の元 = 月次.計算の元(タブ, つなぎ, 給与のルール, 支給一覧=元["支給一覧"], 法の線=…, 賞与の引数={"支給日": 元["支給日"], **元["賞与の引数"]})
```

- 読む口（`月次/賞与の元.py`）は、見出しが型と違う・その会社と支給月の行が無い・NO が空か重なる・額が円の数でない・支給日が無い／行で違う／支給月の月の日でない・前月の課税対象額が空（円の数か `前月の給与なし` を書く）・前の標準賞与額が空（無ければ 0）・計算期間が片方だけ・原本の名前が空 の時に `賞与の元の誤り` で止める（誤りを全部並べる）。止まったら賞与を回さない＝何も出ない。
- `前月の給与なし` の人は `前月の課税対象額` に値 None で置く（芯/計算 の「前月の給与が無い」。鍵の無い人は芯がその人の分が渡されていないとして仮にする）。計算期間は 2 つとも空なら渡さない（月額表で出す人だけ芯が仮＋問いにする）。
- 回の版: 賞与の回の始めに、支給一覧の行の `パックの版` へ今のパックの版（`出口/証明.py` の `パックの版()`）を控える。`賞与を回す` はその会社の行の版が今の版と違う・空・行で割れる時は止める（`月を回す` の締めた時の版と同じ `_控えた版を照らす`。どちらの版で出すかはオーナーが毎回決める＝控えた版で出すなら殻がその版のパックを置いて回し、今の版で出すなら回を組み直して `パックの版` を今の版に書き替える）。`賞与の元を読む` は列の値を支給一覧の行へそのまま写す（照らすのは `賞与を回す` だけ）。
- 管理表は回で行を分ける: 賞与の出荷の行は管理表「賞与の状況」へ書く（同じ支給月の「月の状況」の行を上書きしない・`管理表/README.md`）。

呼び順: 控えた版の照らし（`_控えた版を照らす`・支給一覧の `パックの版`） → `段の解決.解く` → 例の確かめ（`月を回す` と同じ `_例の関所`。例は `給与のルール=`（MD の字）・法の線は `法の線=` か支給月の締めの期間で引く） → `芯.計算.賞与を計算する(支給一覧, 支給日, 決まり, 人, **残り)` → `入口の文脈.給与の関所へ(計, r の仮の値＋例の仮)` → `出口.関所.通す` → 書き口 → 証明（`_証明たち`・回＝賞与）。
月の給与と同じ穴（段の解決の仮＝変更の記録の 確かめ＝仮 など を芯は知らず確認済で返す・決まりの例が通らない会社）を同じ関所で塞ぐ。返す物は `関所を通った`・`外した人`・`取り込み`・`支給控除一覧`・`例の確かめ`・`証明`（月を回す と同じ形・`回`＝賞与）・`問い`（`例`・`段の解決`・`計算`）・`法の線`・`見当の額`・`知らせ`。
殻の出荷の口は賞与の出す物も月と同じ `出口.証明.照らす(出す物, 証明, 入力={"マスタ": …, "給与のルール": MD の字})` で照らす（自前の賞与の計算で作った表は証明が無い＝出せない）。

試験: `tests/月次/test_賞与_始めに控えた版.py`（支給一覧の `パックの版` が今の版と違う・空・行で割れる・鍵が無い回をわざと入れて止まる・台帳から読んだ元も止まる・月と同じ部品で照らす）。`tests/月次/test_賞与の元.py`（型どおりに置いた元を読めば手で渡した元と同じに直り、賞与を回すが回って証明が通る・元の欠けと形の違いをわざと入れて止まる）。`tests/月次/test_賞与の関所.py`（例が無い・合わない・確かめた日が無い・確かめた人に確かめの出所が無い・仮が残る人・月と賞与の取り違え・表の差し替えをわざと入れて出口へ出ない／照らすが通さない・通る人は証明付きで出る）。

## 給与ソフトと突き合わせる

事務所が取り込みで給与ソフトを計算した後（`docs/毎月の流れ.md`「給与ソフトとの突き合わせ」・設計の正本は `docs/設計/確かめと仮.md` §2）:

```python
r = 月次.突き合わせる(o, 給与ソフトの出力, "書類_<受け取った日>_<元の名前>")   # o＝その月の 月を回す（賞与は 賞与を回す）の戻り値のまま
手 = 管理表の口.書く手順(r["結果"], 会社=…, 支給月="2027.02支給", 回="月", 給与ソフトが違うで閉じた=…, 場面=…,
                    今の記録=…, 今の月の状況=…, 会社の一覧=…, 受け持つ組=…, 今日=…,
                    事務所の既定=…)      # 管理表/突き合わせの記録.py（事務所の既定＝事務所の設定「既定」のタブ・N を読む）
```

- `突き合わせる` は `月を回す`・`賞与を回す` が取り込みを組んだ時の `突き合わせの元`（関所を通った・欄の対応・給与ソフトの形・渡さなかった人）だけで読む＝殻は欄の対応・形を組み直さない。元の無い物（出口.取り込み を渡さずに回した・殻が組んだ dict）は止める。
- 返す `要確認`（読み口の読めない欄・対応に受ける欄の無い項目）は黙って捨てずに見る。差の問い（`結果.問い`）は溜めて次の締めの後にまとめて聞く。
- 管理表へ書くのは `管理表/突き合わせの記録.py` の `書く手順` が返す手順だけ（記録のタブ「突き合わせの記録」と、月の回は月の状況「突き合わせ」）。

## 部品をじかに呼ぶ時

部品の呼び口（`段の解決.解く`・`入口の文脈.*`・`芯.集計.集計する`・`芯.計算.計算する`・`出口.関所.通す` など）は残してある（試験と道具が使う）。毎月の流れでは殻はこの口だけを呼び、部品を手で組まない。

# 月次 — 1 か月（と賞与の 1 回）を回す口

殻（各エージェントの repo の環境の口）が手で組んでいた部品の呼び順を、パックの 1 つの口にまとめた **組み立て役**。3 層（入口／芯／出口）の外に置き、3 層と `初期設定/`・`有給/` の部品を今のまま呼ぶだけ（部品の中身・呼び口・額は変えない）。
**段ごとの部品の呼び順の正本はここ 1 か所**。ほかの README と `docs/毎月の流れ.md` はここを指す。

- 殻は Drive・シートから読んだ値を渡し、返った物を Drive・台帳・管理表へ書くだけ。部品を手で組まない（Javis と UTC の殻が別々に組んで結果が食い違う所を無くす）。
- **仮の人は出口へ出ない** ⟦鍵:給与計算/足りない時は仮で計算し出さない⟧: 段の解決・入口の文脈・入口（要確認・NO が引けない）・芯/集計・芯/計算・有給/ のどこかで仮が 1 つでも残る人は、返す `関所を通った`・`取り込み`・`支給控除一覧`・`有給の出す行` のどこにも出ない。殻が仮を `人の状態` へ写す手は要らない。
- Drive を開かない。答え（過去の結果）を受けない。Python 3・標準ライブラリだけ。

## 月を回す

```python
import 月次

o = 月次.月を回す(
    "2027.02支給", "C1",
    タブ={"会社": [...], "勤務の型": [...], "社員": [...], "人ごとの支給控除": [...], "支給控除の項目": [...],
          "事務所": [...], "変更の記録": [...], "月の変動": [...], "人ごと": [...]},   # 段の解決.解く に渡すタブ（列名の dict か get_values の形）
    原本=[{"部品": "Excel出勤簿", "値": {"原本の名前": …, "見出し": […], "行": […]}},
          {"部品": "メールとメモ", "値": [...], "引数": {"項目の辞書": {...}}}],      # 読む順に並べる（2 つ目から 口.重ねる で上に）
    区分の読み替え={...}, つなぎ=[...],          # 入口の文脈 に足す殻の値（作業のルール・マスタ⑥つなぎ）。任意
    前の表A=[...], 前の表B=[...],                 # 期間の頭の週が前の期間にかかる時の台帳の行。任意
    法の線=None,                                  # 無ければ 法の表/ から期間で引く（芯/集計/法の線の橋）
    有給の値={"勤怠の始め": "…", "出勤率が足りない付与日": {NO: [日付]}},   # None なら有給を回さない
    出口={"取り込み": {"欄の対応": …, "形": {"名": …, "鍵の欄": …, "文字コード": …}, "時間の書き方": …, "氏名": …, "委託の人": …, "今ある名": …},
          "支給控除一覧": {"項目の並び": …, "項目の形": …, "委託の人": …, "今ある名": …}},     # 書き口の残りの引数。無い物は作らない
    置き場=None,                                  # 法の表の置き場（試験だけ渡す）
)
```

`原本` の `部品` は入口の読み口の名（`入口/README.md` §2）: `Excel出勤簿`・`PDFタイムカード`・`勤怠システムの月報`・`集計済み勤怠表`・`メールとメモ`・`手当控除の一覧`・`日次の勤怠CSV`（`引数` に `{"道具": <マスタ⑥つなぎ の勤怠ツールの呼び名>}`）。`値` は部品の第 1 引数、`引数` は残り（`文脈` は口が渡す）。部品は原本の一般の形で選び、製品の名で選ばない。給与ソフトの形（`出口.取り込み.形`）も殻が事務所の設定から読んだ値を渡す（パックに既定の形は無い・無ければ止まる）。

### 呼び順（口の中）

1. `r = 初期設定/段の解決.解く(支給月, **タブ)`（台帳「月の変動」→ `r["入力"]`: 値は額＝支給控除の項目で 固定の額 × `入力の値` の名と `委託.出張日数`。読めない行・渡せない名の人は `r["仮の値"]`＝関所で外す。読み方は `初期設定/README.md`「段の解決」）
2. `x = 初期設定/入口の文脈.入口の文脈(支給月, 会社, r, **タブ)` → `入口.口.文脈(**x["文脈"], 区分の読み替え, つなぎ)`
3. 入口の読み口を `原本` の順に `読む()` し `口.重ねる`。`人の状態()` が仮の人（要確認・NO が引けない）は口の仮の値に足す。入口が月の変動の行を読んだ時（`手当控除の一覧`・`メールとメモ`）は、タブの月の変動に足して（同じ原本の同じ人×項目は読んだ行が勝つ・要確認の行は入口の問いのまま渡さない）`段の解決.解く` を解き直す（殻が台帳へ書く前の同じ回でも `入力` へ渡る）
4. `集 = 芯.集計.集計する(表A, 表B, 決まり=r["決まり"]〔その会社〕, 法の線, 月の口=入口の月の数字, 前の表A/B, 支給月)`
5. `計 = 芯.計算.計算する(集, 決まり, 人=r["人"], 入力=入口の文脈.計算の入力(r["入力"], 集))`（委託の `委託.日ごとの実働` は必ずここで渡る）
6. `渡す, 出さない = 出口.関所.勤怠の行を分ける(集["行"])`（勤怠の欄を出口へ）
7. `z = 入口の文脈.給与の関所へ({"行": 計["行"] + 渡す, "人の状態": 計["人の状態"]}, r の仮の値, x の仮の値 + 入口の仮)` → `通 = 出口.関所.通す(z["行"], z["人の状態"])`
8. `出口` があれば `出口.書き口.取り込み(通, …)`・`支給控除一覧(通, …)`
9. `有給の値` があれば `y = 入口の文脈.有給の入力(支給月, 会社, r, 表A, 社員=…, **有給の値)` → `表 = 有給.管理表(y["入力"], 置き場)`（付与日数は `法の表/`） → `入口の文脈.有給の関所へ(y, 表, r・x・入口の仮)` → `出口.関所.通す` → `入口の文脈.有給の出す行(表, 通った)`

- 段の解決は全部の会社を解くが、芯へ渡すのは `会社` の人だけ（別の会社の人を勤怠の無い人として数えない）。
- 有給の関所には段の解決の仮だけでなく、入口の文脈・入口の仮も寄せる（年休の読みと人の値がその仮に乗る）。給与は確定でも有給/ が仮の人は `有給の出す行` に出ない（逆も同じ）。

### 返す物

| 鍵 | 中身 | 殻が書く先 |
|---|---|---|
| `関所を通った` | `出口.関所.通す` の返す物（確定の人の計算の行と勤怠の欄の行） | 突き合わせ（`出口/突き合わせ.突き合わせる`）へ |
| `取り込み`・`支給控除一覧` | 書き口の `出す物`（`出口` を渡した時だけ） | `03_出力/01_取り込み/`・`02_支給控除一覧/`（名は出す物の名） |
| `外した人` | `[{支給月, 会社, NO, 仮の数, 問いの番号}]` | 管理表「外した人」・事務所への知らせの頭 |
| `有給の出す行`・`有給の見出し`・`有給の外した人` | 関所を通った人の有給休暇管理表の行（`有給の値` を渡した時だけ） | `03_出力/03_有給休暇管理表/` |
| `台帳` | `勤怠`（表 A）・`勤怠の区間`（表 B）・`月の数字の口`・`月の変動`・`人ごとの支給控除`（入口）・`人ごと`（集計の月の数字）・`人ごとの状態` | 台帳・マスタ（値で書く。出口へは出さない） |
| `出口へ出さない勤怠の行` | `勤怠の行を分ける` の出さない方（`年休を取った日` の日付など） | どこにも出さない（黙って捨てないため返す） |
| `問い` | 出所ごと: `段の解決`・`入口の文脈`・`入口`（要確認）・`集計`・`計算`・`有給` | 質問と回答（`docs/毎月の流れ.md` 5） |
| `知らせ` | 出所ごと（仮にしない知らせ） | 事務所への知らせ |

## 賞与を回す

```python
o = 月次.賞与を回す("2027.06支給", "C1", タブ, 支給一覧=[{"会社", "NO", "額", "原本の名前"}], 支給日="2027-06-30",
                   前月の課税対象額={...}, 前の標準賞与額={...}, 計算期間={...},   # 賞与を計算する の残りの引数はそのまま渡す
                   出口={"取り込み": {...}, "支給控除一覧": {...}})
```

呼び順: `段の解決.解く` → `芯.計算.賞与を計算する(支給一覧, 支給日, 決まり, 人, **残り)` → `入口の文脈.給与の関所へ(計, r の仮の値)` → `出口.関所.通す` → 書き口。
月の給与と同じ穴（段の解決の仮＝変更の記録の 確かめ＝仮 など を芯は知らず確認済で返す）を同じ関所で塞ぐ。返す物は `関所を通った`・`外した人`・`取り込み`・`支給控除一覧`・`問い`・`知らせ`。

## 部品をじかに呼ぶ時

部品の呼び口（`段の解決.解く`・`入口の文脈.*`・`芯.集計.集計する`・`芯.計算.計算する`・`出口.関所.通す` など）は残してある（試験と道具が使う）。毎月の流れでは殻はこの口だけを呼び、部品を手で組まない。

## 試験

`tests/月次/test_月の変動.py`: 月の変動に手当・控除のある人が確認済で額が出る（台帳の行・入口が読んだ行）・読めない月の変動の行の人が仮で出ない・月の変動の無い会社の結果が前と同じ（回帰）。
`tests/月次/test_月次.py`: 全員確認済の作り物の会社で手で組んだ今の正しい順と口の結果が同じ（回帰の見張り）・段の解決で仮・入口の文脈で仮・入口の要確認・委託の日ごとの実働が無い・有給で仮 の人が `関所を通った`・`取り込み`・`支給控除一覧`・`有給の出す行` に出ない・賞与も段の解決の仮の人を外す。

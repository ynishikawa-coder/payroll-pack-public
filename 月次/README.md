# 月次 — 1 か月（と賞与の 1 回）を回す口

殻（各エージェントの repo の環境の口）が手で組んでいた部品の呼び順を、パックの 1 つの口にまとめた **組み立て役**。3 層（入口／芯／出口）の外に置き、3 層と `初期設定/`・`有給/` の部品を今のまま呼ぶだけ（部品の中身・呼び口・額は変えない）。
**段ごとの部品の呼び順の正本はここ 1 か所**。ほかの README と `docs/毎月の流れ.md` はここを指す。

- 殻は Drive・シートから読んだ値を渡し、返った物を Drive・台帳・管理表へ書くだけ。部品を手で組まない（Javis と UTC の殻が別々に組んで結果が食い違う所を無くす）。
- **仮の人は出口へ出ない** ⟦鍵:給与計算/足りない時は仮で計算し出さない⟧: 段の解決・入口の文脈・入口（要確認・NO が引けない）・芯/集計・芯/計算・有給/ のどこかで仮が 1 つでも残る人は、返す `関所を通った`・`取り込み`・`支給控除一覧`・`有給の出す行` のどこにも出ない。殻が仮を `人の状態` へ写す手は要らない。
- Drive を開かない。答え（過去の結果）を受けない。Python 3・標準ライブラリだけ。

## 月を回す

```python
import 月次

o = 月次.月を回す(
    "2027.02支給", "C1",
    タブ={"会社": [...], "勤務の型": [...], "社員": [...], "人ごとの支給控除": [...], "支給控除の項目": [...],
          "事務所": [...], "変更の記録": [...], "月の変動": [...], "人ごと": [...]},   # 段の解決.解く に渡すタブ（列名の dict か get_values の形）
    原本=[{"部品": "Excel出勤簿", "値": {"原本の名前": …, "見出し": […], "行": […]}},
          {"部品": "メールとメモ", "値": [...], "引数": {"項目の辞書": {...}}}],      # 読む順に並べる（2 つ目から 口.重ねる で上に）
    区分の読み替え={...}, つなぎ=[...],          # 入口の文脈 に足す殻の値（作業のルール・マスタ⑥つなぎ）。任意
    人の区分の読み替え={NO: {語: 読み}},          # 任意。その人だけ 区分の読み替え の上に重ねる（同じ語の夜勤を人ごとの勤務の型へ）
    前の原本=[{"部品": "Excel出勤簿", "値": …}],   # 任意。前の支給月の勤怠（原本 と同じ形）＝口が前の表 A・B を作る（下の 0.）
    前の表A=[...], 前の表B=[...],                 # 期間の頭の週が前の期間にかかる時の台帳の行。任意（前の原本 と一緒には渡せない）
    法の線=None,                                  # 無ければ 法の表/ から期間で引く（芯/集計/法の線の橋）
    有給の値={"勤怠の始め": "…", "出勤率が足りない付与日": {NO: [日付]}},   # None なら有給を回さない
    質問と回答=[...],                             # 任意。01_ルール/質問と回答 の行＝日の問いの答えを読む元の 1 本（台帳は渡さない＝口の出力のまま）
    出口={"取り込み": {"欄の対応": …（か "道具": ⑥つなぎ の給与ソフトの呼び名＝口が支給控除の項目・つなぎ から組む）, "形": {"名": …, "鍵の欄": …, "文字コード": …（渡し方＝CSV の時）, "渡し方": "CSV"|"表"}, "時間の書き方": …, "氏名": …, "委託の人": …, "今ある名": …},
          "支給控除一覧": {"項目の並び": …, "項目の形": …, "委託の人": …, "今ある名": …}},     # 書き口の残りの引数。無い物は作らない
    置き場=None,                                  # 法の表の置き場（試験だけ渡す）
)
```

`原本` の `部品` は入口の読み口の名（`入口/README.md` §2）: `Excel出勤簿`・`PDFタイムカード`・`勤怠システムの月報`・`集計済み勤怠表`・`メールとメモ`・`手当控除の一覧`・`日次の勤怠CSV`（`引数` に `{"道具": <マスタ⑥つなぎ の勤怠ツールの呼び名>}`）。`値` は部品の第 1 引数、`引数` は残り（`文脈` は口が渡す）。部品は原本の一般の形で選び、製品の名で選ばない。給与ソフトの形（`出口.取り込み.形`）も殻が事務所の設定から読んだ値を渡す（パックに既定の形は無い・無ければ止まる）。

### 呼び順（口の中）

0. `前の原本` があれば、前の支給月（`月次.前の支給月`）で 1〜3 と同じ部品の並び（`段の解決.解く` → `入口の文脈` → `入口を読む`。区分の読み替え・つなぎ・人の区分の読み替えは今の月と同じ値）を通し、読んだ表 A・B を `前の表A`・`前の表B` にする（期間の頭の週が前の期間にかかる時の週の判定にだけ使う）。殻は前の表 A・B を部品で手で組まず、前の期間の勤怠を Drive から読んで `前の原本` に渡すだけ（2 つの殻が同じ物を作る）。前の期間も、原本の来ない `時間.出勤簿が無い`＝無い の人は所定どおりの日を重ねる（4 と同じ道・在籍の外の日は置かない）。前の期間の読みに要確認が残る人（入口の `人の状態` が確定でない）は、その人の前の期間の行を前の表に入れない（確かめていない日で週を判定しない）＝頭の週に労働があれば前の期間の日を受けていない時と同じに仮＋問いで出口へ出ない。外した訳は `知らせ.月次` に出す。`前の原本` も `前の表A/B` も渡さない殻は今までどおり（前の期間にかかる週に労働があればその人は仮＋問い）
1. `r = 初期設定/段の解決.解く(支給月, **タブ)`（台帳「月の変動」→ `r["入力"]`: 値は額＝支給控除の項目で 固定の額 × `入力の値` の名と `委託.出張日数`。条件＝皆勤 の行は 0＝その月は付けない だけ。読めない行・渡せない名の人は `r["仮の値"]`＝関所で外す。読み方は `初期設定/README.md`「段の解決」）
2. `x = 初期設定/入口の文脈.入口の文脈(支給月, 会社, r, 質問と回答=…, **タブ)` → `入口.口.文脈(**x["文脈"], 区分の読み替え, つなぎ)`（文脈の `日の答え`＝その支給月の日の問いに会社が質問と回答で答え、口が読める答え〔時刻・長さ・区分・日〕・`在籍`＝入社日と退職日。日の問いの答えを読む元は質問と回答の 1 本＝台帳へ写さない・台帳から読まない）
3. 入口の読み口を `原本` の順に `読む()` し `口.重ねる`。入口は読みながら `日の答え` をその日に当てる（答えた日は返す `台帳` の勤怠に 確認済・備考〔問いの番号と答え〕・区分が載る＝殻が出力をそのまま書けば答えの記録は消えない。答えの無い日・答えと合わない日は要確認のまま）。`人の状態()` が仮の人（要確認・NO が引けない）は口の仮の値に足す。入口が月の変動の行を読んだ時（`手当控除の一覧`・`メールとメモ`）は、タブの月の変動に足して（同じ原本の同じ人×項目は読んだ行が勝つ・要確認の行は入口の問いのまま渡さない）`段の解決.解く` を解き直す（殻が台帳へ書く前の同じ回でも `入力` へ渡る）
4. 在籍が期間にかからない人（`人.退職日` が期間の始めより前・`人.入社日` が期間の終わりより後）で勤怠の来ない人は、`入口の文脈.期間の外の人` で外し、芯へ渡さず仮にもしない（`期間の外の人` と `知らせ.月次` に出す。その月の物〔勤怠・月の変動〔台帳のその支給月の行は読めたかに関わらず・入口〕・入口の人ごとの支給控除〕が来た人は日付の誤りかもしれないので外さない。外した人の段の解決・入口の文脈の仮は `期間の外の人` の `読まなかった仮` と知らせに名を出す）
   - 勤怠を管理しない月給の固定給の人（`時間.出勤簿が無い`＝無い で原本が 1 枚も来ない。役員でない家族の従業員など）は、`入口.口.所定どおりの日(文脈, その NO たち)` で所定どおり働いたとみなした表 A を作って `口.重ねる` で足す（入口の日の部品の「出勤簿が無い＝所定どおりとみなす」と同じ道＝勤務日は 定時扱い・時刻の無い労働時間＝所定時間、休日は休日）。原本に出た人（来た）は入口がその道で定時扱いにするので足さない。期間の外の人も足さない。日の所定が渡されない人はその日の部品が要確認にする（黙って確定にしない）＝足した要確認を `入口の仮` に寄せ直す。最低賃金は今までどおり芯/計算 が点検する（印が無ければ下回る時は赤＋仮・`法の線.承知` の印があれば承知＝§1.4）
   `集 = 芯.集計.集計する(表A, 表B, 決まり=r["決まり"]〔その会社〕, 法の線, 月の口=入口の月の数字, 前の表A/B, 支給月)`
5. `計 = 芯.計算.計算する(集, 決まり, 人=r["人"], 入力=入口の文脈.計算の入力(r["入力"], 集))`（委託の `委託.日ごとの実働` は必ずここで渡る）
6. `渡す, 出さない = 出口.関所.勤怠の行を分ける(集["行"])`（勤怠の欄を出口へ）
7. `z = 入口の文脈.給与の関所へ({"行": 計["行"] + 渡す, "人の状態": 計["人の状態"]}, r の仮の値, x の仮の値 + 入口の仮)` → `通 = 出口.関所.通す(z["行"], z["人の状態"])`
8. `出口` があれば `出口.書き口.取り込み(通, …)`・`支給控除一覧(通, …)`（取り込み に `欄の対応` が無く `道具` があれば `出口.形.欄の対応を組む(会社, 道具, タブの支給控除の項目, つなぎ, 支給月)` で組む。どちらも無ければ止まる）
9. `有給の値` があれば `y = 入口の文脈.有給の入力(支給月, 会社, r, 表A, 社員=…, **有給の値)` → `表 = 有給.管理表(y["入力"], 置き場)`（付与日数は `法の表/`） → `入口の文脈.有給の関所へ(y, 表, r・x・入口の仮)` → `出口.関所.通す` → `入口の文脈.有給の出す行(表, 通った)`

- 段の解決は全部の会社を解くが、芯へ渡すのは `会社` の人だけ（別の会社の人を勤怠の無い人として数えない）。
- 有給の関所には段の解決の仮だけでなく、入口の文脈・入口の仮も寄せる（年休の読みと人の値がその仮に乗る）。給与は確定でも有給/ が仮の人は `有給の出す行` に出ない（逆も同じ）。

| `取り込み`・`支給控除一覧` | 書き口の `出す物`（`出口` を渡した時だけ。渡し方＝表 の物は `書く手順()` を当て、CSV の物は `csvの中身()` を置く） | `03_出力/01_取り込み/`・`02_支給控除一覧/`（名は出す物の名） |
| `外した人` | `[{支給月, 会社, NO, 仮の数, 問いの番号}]` | 管理表「外した人」・事務所への知らせの頭 |
| `有給の出す行`・`有給の見出し`・`有給の外した人` | 関所を通った人の有給休暇管理表の行（`有給の値` を渡した時だけ） | `03_出力/03_有給休暇管理表/` |
| `台帳` | 型のタブの形の表（1 行目が型の見出し・支給月は YYYY.MM支給）: `勤怠`（表 A）・`勤怠の区間`（表 B）・`月の変動`（台帳）・`人ごとの支給控除`（マスタ）・`人ごと`（集計の月の数字＝1 人 1 行・氏名・状態〔確認済・仮〕・芯/集計 の `出す語`＝月の語と会社の数え方の語）。形を作るのは `月次/台帳の形.py` の 1 か所（列は型の口から引く・型に無い列の値は止める） | 台帳・マスタ（値で書く＝字のまま〔Sheets の valueInputOption=RAW〕。殻の書く口が RAW を選べず入力扱いだけなら `初期設定/型の口.入力扱いでも字のまま(表)`〔字の頭に '〕で渡し、書く手順は `型の口.入力扱いの手順(手順)`〔出口の出す物は `書く手順("USER_ENTERED")`〕。書いた後は読み直して `型の口.書いた値を照らす(書いた, 読んだ)` が空でなければ止める。NO の頭の 0・支給月の字を数や日付に読ませない。見出しの行が型と同じかを照らして 2 行目より下を書く。出口へは出さない） |
| `期間の外の人` | `[{会社, NO, 訳, 読まなかった仮}]`（在籍が期間にかからず芯へ渡さなかった人） | 事務所への知らせ（仮でも外した人でもない） |
| `出口へ出さない勤怠の行` | `勤怠の行を分ける` の出さない方（`年休を取った日` の日付など） | どこにも出さない（黙って捨てないため返す） |
| `問い` | 出所ごと: `段の解決`・`入口の文脈`・`入口`（要確認）・`集計`・`計算`・`有給` | 質問と回答（`docs/毎月の流れ.md` 5） |
| `知らせ` | 出所ごと（仮にしない知らせ） | 事務所への知らせ |
| `法の線` | 芯/計算 の法の線の検査の行（`<会社> <NO>: 赤:／知らせ:／承知: …`） | 問いの種（`初期設定/設問.py` の `種を集める`＝赤と知らせを法の線の箱へ。`知らせ` の `集計` の法の線の物〔休憩の長さ・会社の残業の数え方〕も） |
| `見当の額` | `{NO: {総支給額, 差引支給額, 仮}}`（仮の人も含む見込みの額） | 問いに添える額（`設問.種を集める`・`候補ごとの額`）。出口へは出さない |

## 賞与を回す

```python
o = 月次.賞与を回す("2027.06支給", "C1", タブ, 支給一覧=[{"会社", "NO", "額", "原本の名前"}], 支給日="2027-06-30",
                   前月の課税対象額={...}, 前の標準賞与額={...}, 計算期間={...},   # 賞与を計算する の残りの引数はそのまま渡す
                   出口={"取り込み": {...}, "支給控除一覧": {...}})
```

呼び順: `段の解決.解く` → `芯.計算.賞与を計算する(支給一覧, 支給日, 決まり, 人, **残り)` → `入口の文脈.給与の関所へ(計, r の仮の値)` → `出口.関所.通す` → 書き口。
月の給与と同じ穴（段の解決の仮＝変更の記録の 確かめ＝仮 など を芯は知らず確認済で返す）を同じ関所で塞ぐ。返す物は `関所を通った`・`外した人`・`取り込み`・`支給控除一覧`・`問い`・`法の線`・`見当の額`・`知らせ`。

## 部品をじかに呼ぶ時

部品の呼び口（`段の解決.解く`・`入口の文脈.*`・`芯.集計.集計する`・`芯.計算.計算する`・`出口.関所.通す` など）は残してある（試験と道具が使う）。毎月の流れでは殻はこの口だけを呼び、部品を手で組まない。

## 試験

`tests/月次/test_月の変動.py`: 月の変動に手当・控除のある人が確認済で額が出る（台帳の行・入口が読んだ行）・読めない月の変動の行の人が仮で出ない・月の変動の無い会社の結果が前と同じ（回帰）。
`tests/月次/test_月次.py`: 全員確認済の作り物の会社で手で組んだ今の正しい順と口の結果が同じ（回帰の見張り）・段の解決で仮・入口の文脈で仮・入口の要確認・委託の日ごとの実働が無い・有給で仮 の人が `関所を通った`・`取り込み`・`支給控除一覧`・`有給の出す行` に出ない・賞与も段の解決の仮の人を外す・`前の原本` を渡すと手で前の表 A・B を組んで渡した時と同じ判定（渡さなければ前の期間にかかる週は今までどおり仮）・前の期間の読みに要確認が残る人（重なる週の日の要確認・原本に無い日）は出口へ出ない・手書きの退勤の問いに「手書きの時刻で数える」と答えれば次の回で出る（違う答え・前の月の答えでは外れない）・入社日が期間の中の人は入社日の前の日で前の期間の日を求めず原本に無い日にもしない（前の期間に在籍した人は今までどおり）・欄の対応を渡さず道具を渡せば口がマスタとつなぎから組む（時給の人も基本給の欄・勤怠の欄）。

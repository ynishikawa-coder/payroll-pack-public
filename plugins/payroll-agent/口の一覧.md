# 口の一覧（各社の側が満たす口）

給与エージェントの手順（`skills/payroll-steps/SKILL.md`）と決まり（`決まり.md`）は、外とつなぐ所を **口の名** だけで呼ぶ。各社の側（環境の設定とつなぐ道具）は、下の口を全部満たす。口の中身（どの道具・どの置き場・どの記録の場所か）は各社の側に置き、この plugin には書かない（線の正本 `docs/設計/入れてよい物.md`「口だけパック・中身は事務所」）。

- 手順と決まりの中で亀甲の括弧で囲んだ口の名は、この表の 1 列目の名だけを使う（表に無い名は試験 `tests/test_給与エージェントの器.py` が赤）。表の口が手順と決まりのどこからも呼ばれなければそれも赤（使わない口を残さない）。
- 照らし（出す前の照らし・止める見張り・問いの照らし）の芯はパック（この plugin の照らしと、計算のパックの部品）が持つ。各社の口は、照らしの結果を受けて置く・書く・配る手だけ。
- 口が無い・口が失敗した時は、その段で止めて、止めた訳を〔口: 記録を置く〕で残す（代わりの道で手で書かない）。

| 口 | 渡す物 | 返す物 | 守る事 |
|---|---|---|---|
| 〔口: シートを読む〕 | シートの在り処・タブ・範囲 | 行（見出しの名の dict か、値の並び） | 書式の値でなく書いた値を返す |
| 〔口: シートに書く〕 | シートの在り処・タブ・範囲・値 | 書いた範囲 | 書いた後に読み直して照らす。管理表の今の版と取り込みの本は書かない（〔口: 出荷〕だけ） |
| 〔口: ファイルを取る〕 | 事務所の置き場の file の在り処 | 手元の file | 原本は触らない（写して読む） |
| 〔口: ファイルを置く〕 | 手元の file・置き場のフォルダ・名 | 置いた file の在り処 | 1 件ずつ置き、置いた後に親のフォルダを読み直す |
| 〔口: 置き場を引く〕 | 事務所の根（各社の側が知る在り処はこの 1 つ） | 会社ごとのフォルダとシートの在り処（事務所の設定「置き場」から） | 在り処を repo にも手順にも書かない |
| 〔口: 決まりの経緯を引く〕 | ⟦鍵⟧ | 決定の文 | 引けなくても手順と決まりだけで動ける（経緯は読むだけ） |
| 〔口: 記録を置く〕 | 作業の記録・引き継ぎ・止めた訳 | 置いた所 | repo に置かない（各社の記録の置き場へ） |
| 〔口: 確認ページを配る〕 | 計算のパックで作った確認ページの HTML・パックの値の表（`config/skill-values.json`）・質問と回答の在り処 | 配った在り処（宛先が開ける URL） | 配る前に確認ページの検査と〔口: 問いの関所〕を通す。配った在り処は管理表へ |
| 〔口: 問いの関所〕 | 出す問い（確認ページか文面）・質問と回答の行 | 通す／止める と、当たった答え済みの行 | 照らしの芯は計算のパックの `確認ページ/前の答え.py`。口は行を読んで渡すだけ |
| 〔口: 答えを受け取る〕 | 質問と回答の在り処か、いつからの答えか | 届いた答え（問いの番号・選んだ選択肢の文・答えた人と日） | 届いた答えは先に書き戻す（書き戻すまで計算に使わない） |
| 〔口: 出荷〕 | 計算のパックの出口が返した出す物と証明・計算に渡した計算の元（`月次.計算の元` で組む＝手で組まない。名は `出口/証明.py` の `計算の元に要る名`＝計算が読む材料の全部。前の確定した勤怠・月の数字・法の線・賞与の支給一覧なども）・支給月（月を回す・賞与を回す に渡した `YYYY.MM支給` のまま＝この字だけ受ける。名と証明の字 `YYYY-MM`／`YYYY-MM-賞与` へは照らしが `出口/名と版.py` の `出す支給月` で直す）・管理表の在り処 | 置いた file と管理表へ書いた行。外れたら止めた訳 | 出す前の照らしを通った物だけを置く。取り込みの本と管理表の今の版を書くのはこの口だけ。支給月の字を口で組み直さない。`月次.月を回す`・`賞与を回す` の `出口` に、その月の置き場の `2_出す物/` の名の並びを `今ある名`・会社の根の `9_履歴/` の名の並びを `履歴にある名` として必ず渡す（前の版が無ければ `[]`。渡さないとパックが止まる＝前の版を見ずに v1 を付けない）。賞与の元は年の台帳「賞与の支給一覧」を `月次.賞与の元を読む` で読む（手で組まない・止まったら出さない）。管理表は `出す前の照らし.py 管理表の行` が返す `管理表のタブ`・`回` のまま `管理表/管理表.py 書く` へ渡す（賞与は「賞与の状況」＝同じ支給月の月の行を上書きしない） |
| 〔口: 選べる値を付ける〕 | マスタの在り処・計算のパックの選べる値の一覧（`芯/設定.py` の `選べる値の一覧`） | 入力規則を付けた範囲 | 選べる値の外の字を手で足さない |
| 〔口: 穴を起票する〕 | パックで表せない決まり・式の無い所（穴）の行 | 起票した課題の在り処 | 穴は事務所への問いにしない（パックの直しにする） |

# 口の一覧（各社の側が満たす口）

給与エージェントの手順（`skills/payroll-steps/SKILL.md`）と決まり（`決まり.md`）は、外とつなぐ所を **口の名** だけで呼ぶ。各社の側（環境の設定とつなぐ道具）は、下の口を全部満たす。口の中身（どの道具・どの置き場・どの記録の場所か）は各社の側に置き、この plugin には書かない（線の正本 `docs/設計/入れてよい物.md`「口だけパック・中身は事務所」）。

- 手順と決まりの中で亀甲の括弧で囲んだ口の名は、この表の 1 列目の名だけを使う（表に無い名は試験 `tests/test_給与エージェントの器.py` が赤）。表の口が手順と決まりのどこからも呼ばれなければそれも赤（使わない口を残さない）。
- パックは Drive の口を持つ（パックの drive口/ が Drive を開き、置き場を引く）。鍵と置き場の根の id は給与の窓が環境から渡す（〔口: 鍵と根の id を渡す〕・パックの repo に置かない）。
- 出荷・締めは殻の口でなく、パックの命令（出す物と管理表は 出口/出す.py の 1 命令・締めは `月次/締めの関所.py`）。殻の口は「鍵と根の id を渡す・答えを受け取る・記録を置く」に畳む（下の表のほかの口は、パックの命令へ移すまでの今の形）。
- 出す時の照らし（仮・名の形）はパックの 1 命令（出口/出す.py）の中に在る。
- 口が無い・口が失敗した時は、その段で止めて、止めた訳を〔口: 記録を置く〕で残す（代わりの道で手で書かない）。

| 口 | 渡す物 | 返す物 | 守る事 |
|---|---|---|---|
| 〔口: 鍵と根の id を渡す〕 | 環境の変数の名（鍵は `GOOGLE_DRIVE_SA_JSON`・事務所の置き場の根の id は `PAYROLL_OFFICE_ROOT_ID`。値は環境だけに置く） | パックの命令が開いた Drive の口 | 鍵の値と根の id を repo にも手順にも記録にも書かない。パックの命令へは変数の名か引数 `--根` で渡す |
| 〔口: シートを読む〕 | シートの在り処・タブ・範囲 | 行（見出しの名の dict か、値の並び） | 書式の値でなく書いた値を返す |
| 〔口: シートに書く〕 | シートの在り処・タブ・範囲・値 | 書いた範囲 | 出す物と管理表の今の版はパックの 1 命令（出口/出す.py）で書く。出した物を直す時は、直に直さず出口/出す.py を回し直して出し直す。年の台帳は書かない（〔口: 書く手順を当てる〕だけ） |
| 〔口: 書く手順を当てる〕 | パックの口が返した `書く手順`（年の台帳は `月次/台帳へ書く.py` の口・`月次/年の台帳を起こす.py` の 起こす、マスタ「社員」の有給の始めは `月次.有給の始めを進める`、確定した勤怠のシートは `月次/勤怠のシート.作る` が返す）と、手順の `ファイル` の在り処（置き場は〔口: 置き場を引く〕で引いて照らす＝窓が渡す在り処を照らさずに使わない） | 当てた手順 | 戻す手順は当てる前に先頭の `形を照らす` が名指すタブ・md・置き場を読み、`月次/台帳へ書く.戻す手順を照らす` が空でなければ当てずに止める（頭の無い戻す手順も止まる。書く手順が途中で切れた時は同じ入力で回し直して書き終えてから 1 回目の戻す手順を当てる）。手順を順に当てるだけ（値を組まない・足さない・写しの列を埋めない）。口に渡す今のタブは〔口: シートを読む〕で読んだまま。口が止めたら書かない |
| 〔口: 届いた物を写す〕 | 受け取り口の新着（在り処・元の名・受け取った日。容器〔zip など〕の中の file は開いて 1 つずつ在り処と中の名〔容器から読んだままの生の道＝フォルダの区切り / を含んだまま〕に `容器`＝容器の元の名を添える。容器の中の容器は `容器` に外の容器の名と生の中の道を `__` でつないで渡す〔例 `c.zip__dir/n.zip`〕＝パックが 中の名 と同じ直し〔/ と \ を _〕を当て、中の容器自身の写しの名と同じ形になる）と、中身で選んだ頭（`勤怠_`・`変更_`・`メモ_`・`書類_`）・その月の `1_届いた物/` の名の並び（`今ある名`） | 写した物の名と在り処・既に在って写さなかった名 | 名はパックの `月次/届いた物.写す手順` が返す `書く手順`（`ファイルを写す`）のまま（手で名を組まない）。原本は動かさず名も変えない。受け取り口と `1_届いた物/` の在り処は〔口: 置き場を引く〕で引く。容器は 出所 として写し、中の file の名はパックの `月次/台帳の形.容器の中の名` が組む（殻は名を組まない・原本は中の file） |
| 〔口: ファイルを取る〕 | 事務所の置き場の file の在り処 | 手元の file | 原本は触らない（写して読む） |
| 〔口: 置き場を引く〕 | 事務所の根（各社の側が知る在り処はこの 1 つ） | 会社ごとのフォルダとシートの在り処（事務所の設定「置き場」から） | 在り処を repo にも手順にも書かない。「置き場」は 1 つの (顧客ID, 物) に 1 行（Drive の型 §8）で、顧客ID と物で引く。前の形の表（顧客ID が無い・物の前の字・会社が空の組の行・台帳の 1 行）は〔口: 事務所の段〕で `管理表/管理表.py 事務所の設定を寄せる` が返す手順で 1 回寄せる（顧客ID は口が振る＝事務所に聞かない・手で書かない。問いが返れば書かずに事務所の担当者へ聞く） |
| 〔口: 決まりの経緯を引く〕 | ⟦鍵⟧ | 決定の文 | 引けなくても手順と決まりだけで動ける（経緯は読むだけ） |
| 〔口: 記録を置く〕 | 作業の記録・引き継ぎ・止めた訳 | 置いた所 | repo に置かない（各社の記録の置き場へ）。月のタスク（次に動く人と引き継ぎを持つ物）を置いたら、その在り処を管理表の回のタブ（`管理表/管理表.py 回のタブ`）のその会社×支給月の行の `タスクへのリンク` へ `管理表/管理表.py 書く` で書く（タスクの状態は管理表へ写さない。行が無ければ〔口: 事務所の段〕の 月の行 で起こしてから） |
| 〔口: 確認ページを配る〕 | 計算のパックで作った確認ページの HTML・パックの値の表（`config/skill-values.json`）・質問と回答の在り処 | 配った在り処（宛先が開ける URL） | 配る前に確認ページの検査を通す。配った在り処は管理表へ。`確認ページ.作る` には、その組の置き場の名の並びを `今ある名`・その組の `9_履歴/` の名の並びを `履歴にある名` として必ず渡す（前の版が無ければ `[]`。渡さないとパックが止まる＝前の版を見ずに v1 を付けない）。問いを `設問.まとめる` でまとめる時は質問と回答の今の行を `既にある` に必ず渡す。置く前に `確認ページ.配る手順` へ 1 つの版の全部の枚（`作る` の `枚たち` の全部の `(名, html)`・分けない時は 1 つ）・今の置き場の名・`9_履歴/` の名・今日（下書きなら 下書き）を 1 度に渡し、返った `名たち` の新しい file を全部置いてから `移す` を 1 回当てる（移した file はリンク共有を外す・前の版の file の中身を上書きしない・止まったら 1 枚も置かない） |
| 〔口: 答えを受け取る〕 | 質問と回答の在り処か、いつからの答えか | 届いた答え（問いの番号・選んだ選択肢の文・答えた人と日） | 届いた答えは先に書き戻す（書き戻すまで計算に使わない） |
| 〔口: 事務所の段〕 | する事（`立ち上げ`＝管理表に型のタブ／`月の行`＝支給月／`会社の行`＝会社ごとのその会社の Drive の型の版）。管理表の在り処は〔口: 置き場を引く〕の事務所の根から、会社・組・状態は事務所の設定「会社の一覧」から読む | 当てた手順。外れたら止めた訳 | 管理表のタブ・行を起こすのは `管理表/管理表.py 立ち上げ・月の行・会社の行` が返す手順だけ（タブ・見出し・行を手で足さない・値を組まない）。見出しが型と違うタブ・型の版の無い会社は口が拒む＝前の値の移し方と型の版は事務所に聞く |
| 〔口: 突き合わせ〕 | 出す命令（出口/出す.py）と同じ入力（その月の `月次.月を回す`・`賞与を回す` の戻り値のまま・支給月・管理表の在り処）と、事務所が取り込みで給与ソフトを計算した出力（file とその名）・その回の差の問いのうち「給与ソフトが違う」で閉じた数（0 も必ず）・その回にあった場面の並び（無ければ空の並び）・事務所の設定「既定」のタブの今の値（N＝`突き合わせ.差0の月数の目安` は口がここから読む） | 管理表の記録のタブ「突き合わせの記録」の行と、月の回は月の状況「突き合わせ」（続けて差 0 の月数）へ書いた行・読み口の `要確認`。外れたら止めた訳 | パックの `月次.突き合わせる` に回した戻り値と給与ソフトの出力を渡し、返った `結果` を〔口: シートを読む〕で読んだ記録のタブ・月の状況の今の値と一緒に `管理表/突き合わせの記録.py` の `書く手順` へそのまま渡して、返った手順だけを順に当てる（欄の対応・形を組み直さない）。`要確認` は黙って捨てず、差の問い（`結果.問い`）は溜めて次の締めの後にまとめて聞く。突き合わせるか外すかは事務所が決める |
| 〔口: 選べる値を付ける〕 | マスタの在り処・計算のパックの選べる値の一覧（`芯/設定.py` の `選べる値の一覧`） | 入力規則を付けた範囲 | 選べる値の外の字を手で足さない |
| 〔口: 穴を起票する〕 | パックで表せない決まり・式の無い所（穴）の行・今の job（`親job`） | 起票した課題の在り処 | 穴は事務所への問いにしない（パックの直しにする）。課題は今の job を `親job` に持たせて立てる（親job が無ければ立てない） |

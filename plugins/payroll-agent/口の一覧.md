# 口の一覧（各社の側が満たす口）

給与エージェントの手順（`skills/payroll-steps/SKILL.md`）と決まり（`決まり.md`）は、外とつなぐ所を **口の名** だけで呼ぶ。各社の側（環境の設定とつなぐ道具）は、下の口を全部満たす。口の中身（どの道具・どの置き場・どの記録の場所か）は各社の側に置き、この plugin には書かない（線の正本 `docs/設計/入れてよい物.md`「口だけパック・中身は事務所」）。

- 手順と決まりの中で亀甲の括弧で囲んだ口の名は、この表の 1 列目の名だけを使う（表に無い名は試験 `tests/test_給与エージェントの器.py` が赤）。表の口が手順と決まりのどこからも呼ばれなければそれも赤（使わない口を残さない）。
- 照らし（出す前の照らし・止める見張り・問いの照らし）の芯はパック（この plugin の照らしと、計算のパックの部品）が持つ。各社の口は、照らしの結果を受けて置く・書く・配る手だけ。
- 各社の側は、口ごとの約束の条（渡す物・返す物・守る事の 1 文ずつ。分け方と指紋の正本は `bin/口の約束.py`）を、条を確かめた試験の本文で確かめの文（assert・pytest.raises）の真上のコメントか同じ行に置く印 `口の約束 <指紋>`（skip・xfail で飛ばされる試験の印は数えない）か、試験の無い訳（穴）を表に持つかのどちらかで持ち、`bin/口の約束.py 照らす` で今の条と照らす（この表の文を変えると指紋が変わり、見直していない殻の試験と表は赤。表に試験の名を並べる形は使わない＝名の在る試験が違う物を試していても通るため）。
- 口が無い・口が失敗した時は、その段で止めて、止めた訳を〔口: 記録を置く〕で残す（代わりの道で手で書かない）。

| 口 | 渡す物 | 返す物 | 守る事 |
|---|---|---|---|
| 〔口: シートを読む〕 | シートの在り処・タブ・範囲 | 行（見出しの名の dict か、値の並び） | 書式の値でなく書いた値を返す |
| 〔口: シートに書く〕 | シートの在り処・タブ・範囲・値 | 書いた範囲 | 書いた後に読み直して照らす。管理表の今の版と取り込みの本は書かない（〔口: 出荷〕だけ）。年の台帳は書かない（〔口: 書く手順を当てる〕だけ） |
| 〔口: 書く手順を当てる〕 | パックの口が返した `書く手順`（年の台帳は `月次/台帳へ書く.py` の口・`月次/年の台帳を起こす.py` の 起こす が返す）と、手順の `ファイル` の在り処 | 当てた手順と、書いた後に読み直した値 | 手順を順に当てるだけ（値を組まない・足さない・写しの列を埋めない）。口に渡す今のタブは〔口: シートを読む〕で読んだまま。書いた後に読み直し、`初期設定/型の口.py` の `書いた値を照らす` に返った `書いた後` と読んだ値を渡して空でなければ止める。口が止めたら書かない |
| 〔口: ファイルを取る〕 | 事務所の置き場の file の在り処 | 手元の file | 原本は触らない（写して読む） |
| 〔口: ファイルを置く〕 | 手元の file・置き場のフォルダ・名 | 置いた file の在り処 | 1 件ずつ置き、置いた後に親のフォルダを読み直す |
| 〔口: 置き場を引く〕 | 事務所の根（各社の側が知る在り処はこの 1 つ） | 会社ごとのフォルダとシートの在り処（事務所の設定「置き場」から） | 在り処を repo にも手順にも書かない |
| 〔口: 決まりの経緯を引く〕 | ⟦鍵⟧ | 決定の文 | 引けなくても手順と決まりだけで動ける（経緯は読むだけ） |
| 〔口: 記録を置く〕 | 作業の記録・引き継ぎ・止めた訳 | 置いた所 | repo に置かない（各社の記録の置き場へ）。月のタスク（次に動く人と引き継ぎを持つ物）を置いたら、その在り処を管理表の回のタブ（`管理表/管理表.py 回のタブ`）のその会社×支給月の行の `タスクへのリンク` へ `管理表/管理表.py 書く` で書く（タスクの状態は管理表へ写さない。行が無ければ〔口: 事務所の段〕の 月の行 で起こしてから） |
| 〔口: 確認ページを配る〕 | 計算のパックで作った確認ページの HTML・パックの値の表（`config/skill-values.json`）・質問と回答の在り処 | 配った在り処（宛先が開ける URL） | 配る前に確認ページの検査と〔口: 問いの関所〕を通す。配った在り処は管理表へ。`確認ページ.作る` には、その組の置き場の名の並びを `今ある名`・その組の `9_履歴/` の名の並びを `履歴にある名` として必ず渡す（前の版が無ければ `[]`。渡さないとパックが止まる＝前の版を見ずに v1 を付けない）。問いを `設問.まとめる` でまとめる時は質問と回答の今の行を `既にある` に必ず渡す |
| 〔口: 問いの関所〕 | 出す問い（確認ページか文面）・質問と回答の行 | 通す／止める と、当たった答え済みの行 | 照らしの芯は計算のパックの `確認ページ/前の答え.py`。口は行を読んで渡すだけ |
| 〔口: 答えを受け取る〕 | 質問と回答の在り処か、いつからの答えか | 届いた答え（問いの番号・選んだ選択肢の文・答えた人と日） | 届いた答えは先に書き戻す（書き戻すまで計算に使わない） |
| 〔口: 出荷〕 | 計算のパックの出口が返した出す物と証明・計算に渡した計算の元（`月次.計算の元` で組む＝手で組まない。名は `出口/証明.py` の `計算の元に要る名`（回ごと）を読む＝計算が読む材料の全部。ここに名を写さない）・支給月（月を回す・賞与を回す に渡した `YYYY.MM支給` のまま＝この字だけ受ける。名と証明の字 `YYYY-MM`／`YYYY-MM-賞与` へは照らしが `出口/名と版.py` の `出す支給月` で直す）・管理表の在り処 | 置いた file と管理表へ書いた行。外れたら止めた訳 | 出す前の照らしを通った物だけを置く。管理表「会社」のその会社が寄せ中なら（`管理表/管理表.py 寄せの印`）何も読まず回さずに止める（〔口: 寄せる〕が突き合わせに使う照らすだけは回す）。取り込みの本と管理表の今の版を書くのはこの口だけ。支給月の字を口で組み直さない。`月次.月を回す`・`賞与を回す` の `出口` に、その月の置き場の `2_出す物/` の名の並びを `今ある名`・会社の根の `9_履歴/` の名の並びを `履歴にある名` として必ず渡す（前の版が無ければ `[]`。渡さないとパックが止まる＝前の版を見ずに v1 を付けない）。賞与の元は年の台帳「賞与の支給一覧」を `月次.賞与の元を読む` で読む（手で組まない・止まったら出さない）。出す前の照らしの `材料` にも、置く前の `2_出す物/` の名の並びを `今ある名`・`9_履歴/` の名の並びを `履歴にある名` として必ず渡す（前の版が無ければ `[]`。名の版が前の版の最大の次でなければ止まる）。`管理表の行` には管理表の今の行の 止まりの理由 の欄の字を `--今の止まりの理由` で必ず渡す（空の欄・行が無い時は `""`。省くと止まる）。管理表は `出す前の照らし.py 管理表の行` が返す `管理表のタブ`・`回` のまま `管理表/管理表.py 書く` へ渡す（賞与は「賞与の状況」＝同じ支給月の月の行を上書きしない）。試算か正式か（出口が null＝試算は何も出さない・正式の出口は 取り込み・支給控除一覧・取り込み.道具 が全部要る）は `月次/出口の指定.py 照らす` の返りのまま止める（殻で出口の形を照らし直さない）。締めた時の版で回すかと、その版は `月次/締めの関所.py` の `締めた時の版で回すか`・`締めた時の版` が返す（殻は締めの記録を読んで渡し、返った版のパックを置くだけ） |
| 〔口: 締める〕 | 会社・支給月・人ごとの締めの状態（`締まった`／`まだ` と残る問いの番号）・締めの記録の在り処。締め直す時だけ、オーナーが選んだ答えの在り処 | 締めの記録へ書いた行。外れたら止めた訳 | 締めた時のパックの版（締めの記録の `パックの版`）は窓が書かず、口が今置いたパックの版を押す。同じ月に別の版で締めた行が在れば止める。締め直す（今の版で出す）と、締めた時の版で回すのは、オーナーが選んだ答えの在り処を渡した時だけ（AI が決めて版を書き替えない＝`決まり.md`）。管理表「会社」でその会社が寄せ中なら（`管理表/管理表.py 寄せの印`）書かずに止める。何を書くか・止めるか（`パックの版` の列が無い型が古い台帳では締めない・別の版で締めた行・締め直す答えの決定DB の行に同じ会社・同じ支給月・範囲「今の版で出す」が無い）は `月次/締めの関所.py` の `締める`・`答えの行`・`締め直す` が返す赤と書く行のまま（殻は締めの記録と決定DB の行を読んで渡し、返った行を書くだけ） |
| 〔口: 事務所の段〕 | する事（`立ち上げ`＝管理表に型のタブ／`月の行`＝支給月／`会社の行`＝会社ごとのその会社の Drive の型の版）。管理表の在り処は〔口: 置き場を引く〕の事務所の根から、会社・組・状態は事務所の設定「会社の一覧」から読む | 当てた手順。外れたら止めた訳 | 管理表のタブ・行を起こすのは `管理表/管理表.py 立ち上げ・月の行・会社の行` が返す手順だけ（タブ・見出し・行を手で足さない・値を組まない）。見出しが型と違うタブ・型の版の無い会社は口が拒む＝前の値の移し方と型の版は事務所に聞く |
| 〔口: 寄せる〕 | 会社の呼び名（会社の根は〔口: 置き場を引く〕で引く）・寄せられない物への人の答え（無ければ空）・突き合わせる月（その会社が最後に出した月の〔口: 出荷〕の入力。まだ 1 度も出していない会社は無い訳。どちらも `管理表/管理表.py 突き合わせる月` が管理表「月の状況」の出荷の印と照らす） | 見通し（書く手順・寄せられない物・足りない値）か、書いた手順・突き合わせの結果・管理表「会社」の型の版と寄せの印。外れたら止めた訳 | 会社の根の直下と 1 段下の置き場・全部のタブ（値と式のセル）・md と、管理表「会社」の 型の版・選んだ部品 を読んだまま `道具/寄せ/呼び口.py 寄せる` へ渡すだけ（値を組まない）。寄せられない物が 1 つでも在れば何も書かない（全部か無し）。見通す回の返す物と管理表「会社」の今の値を `管理表/管理表.py 突き合わせる月` の `見通し`・`会社のタブ` へ渡し、`変わらない` が真なら（書く手順・寄せられない物・足りない値・管理表へ書く・写した物 が全部空で寄せ中でない・見通しの会社が寄せる会社と同じ）突き合わせる月も無い訳も求めずに終える（偽なら `残り` を見せて下の道を通す＝済にしない）。何かを書く前に、管理表「月の状況」を `管理表/管理表.py 突き合わせる月` へ渡し、出した月が在る会社の無い訳・最後に出した月でない月を拒まれたら何も書かずに止める（申告で突き合わせを飛ばさない）。突き合わせる月の入力の 会社・組・支給月 が、寄せる会社・その会社の組・`突き合わせる月` が返した月と 1 つでも違えば、何も書かずに止める（別の会社・別の月の出す物で寄せ中を外さない＝寄せる会社と突き合わせる物を別々の申告のまま受けない）。書く前に、突き合わせる月の `2_出す物/` に今ある出す物（寄せの前の人×項目）を読み、管理表「会社」を寄せ中にする（`管理表/管理表.py 寄せの行` の `立てる` を `書く`〔タブ 会社〕へ）。次に寄せの記録（前の値・書く手順・戻す手順）を会社の根の `9_履歴/` に置き、返った書く手順を順に当てる（`値を書く` は `RAW`）。書く回が返した `写した物`（寄せの前の写しの名）は、読み直してもう一度 寄せる を呼ぶ回（照らす）の会社の入力 `写しの場所` へそのまま渡し返す（9_履歴 の中を辿って名を組まない。道具は照らす回に読んだ置き場に在り同じ元の一番新しい写しかを照らし、照らす回の `管理表へ書く` に載せる）。`道具/寄せ/呼び口.py` の終わりの値 2（落ちた＝標準出力は空）は寄せられない物の 1 と分け、何も読まずに寄せ中のまま止まった理由を書く。読み直してもう一度 寄せる が書く手順 0・寄せられない物 0 を返し、同じ月を〔口: 出荷〕の照らす（書かない）で計算した出す物が寄せの前と物ごとに 1 字も違わない時だけ（`docs/設計/寄せる道具.md` §1.6）、返った `管理表へ書く` と `寄せの行` の `外す` を `管理表/管理表.py 書く` で書く。書く途中で落ちた・照らしか突き合わせが合わない時は、寄せ中のまま `寄せの行` の `止まった` で理由を書いて止める（照らしか突き合わせが合わない時は戻す手順で戻す）。型・直しの中身を手で写さない（タブ・列を手で足さない）。続けるか・終わるか・止めるか（両方渡した・別の会社の入力・前の回の寄せの記録・寄せられない物・変わらない会社・足りない値だけの終わり・前の回の写しからの続き）は `道具/寄せ/続き.py` が、比べる字・人×項目の違い・版の違い・比較の写しの締めの行は `道具/寄せ/突き合わせ.py` が返すまま（殻は置き場を読んで渡し、返った赤・止める訳のまま止める）。前の回の寄せの記録に無い写しが履歴に在れば重ねて書かない |

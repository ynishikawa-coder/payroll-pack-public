# 給与の毎月の手順（3 段）

始める前に、この plugin の根の `決まり.md` を読む（起動時に差し込まれていれば読み直さない）。外とつなぐ所は `口の一覧.md` の口の名で呼ぶ。計算のパックは同じ版の印を手元に置き、下の `…` の path はそのパックの repo の中を指す。

段の設計の理由と置き場の名の正本は、計算のパックの `docs/毎月の流れ.md`（段ごとに読む物・書く物）と `docs/設計/Drive の型.md`（置き場の形）。ここには写さない。

## 0. 初期設定（会社の始めと、会社の決まりが変わった時）

1. 〔口: 置き場を引く〕で会社の置き場を引き、規程・過去の支給控除一覧・勤怠の原本を〔口: ファイルを取る〕で受ける。
2. 型で会社を始める（`初期設定/README.md` の「始める」）。
3. 法律どおりに計算し、過去の一覧と人×項目で照らす（`道具/答え合わせ/` の 照らす）。差 0 の所は聞かずに決まり（MD・マスタ）へ書き、出所に 過去の結果の照らし（形は `月次/例の確かめ.py` の 過去の結果を読む）を書く。違う所・過去の資料に表れない所だけを問いにする（照らしの線は `docs/設計/確かめと仮.md` §1）。
4. 決まりを聞き切る。問いの種の集め方は `初期設定/設問.py`（`docs/設計/設問の作り方.md`）。数え方の決まりごとに例を作り、人の言葉で聞く。給与ソフトへの取り込みの形（どの時間をどの欄に出すか）も聞く。
5. 問いは確認ページで聞く（`確認ページ/README.md`）。〔口: 問いの関所〕を通してから〔口: 確認ページを配る〕。
6. 答えは〔口: 答えを受け取る〕で受け、反映先を書き換える: 文の決まりは会社の決まりの MD、金額に効く値はマスタ（〔口: シートに書く〕）。選べる値は〔口: 選べる値を付ける〕で付けた選択肢から選ぶ。
7. 止める所: 毎月の計算へ進む前に `道具/答え合わせ/` の 出所を見る（照らすの出した差と MD を渡す）が 0 で終わる事（変更の記録・MD の出所・例の 確かめた人 に書いた過去の結果の照らしが、照らしで差 0 か。1 なら毎月へ進まない）。必ず埋める欄（区分・源泉の欄・保険の加入・労働時間の制度・扶養の数・保険料を引く月）が空なら計算しない。パックに無い式は〔口: 穴を起票する〕し、パックへ足すまで受けない。

## 1. 材料をそろえる（毎月）

順は ①→②→③（①が先＝育休や退職が分からないと休みを欠勤と読む）。

1. **① マスタの更新**: 入退社・休職・育休・昇給・扶養を、マスタと変更の記録へ〔口: シートに書く〕。
   - 年の最初の支給月は、②の前に新しい年の台帳を起こす: 前の年の台帳の型（`初期設定/型.json` の `台帳_<支給年>`）の全部のタブとマスタ「社員」を〔口: シートを読む〕で読み、パックの `月次/年の台帳を起こす.起こす` に渡し、返った `台帳の名` のシートへ返った表を全部〔口: シートに書く〕（何を引き継ぐかの正本は `docs/設計/Drive の型.md` §4・手順は `docs/毎月の流れ.md` 1-①）。止まったら起こさず、訳を問いにする。返った `前の確定した勤怠` はその年の 月を回す へ渡す。
2. **② その月だけの指示**: 「この人は今月こう計算して」を、年の台帳の「その月だけの指示」へ書く。
3. **③ 勤怠の締め**:
   - 原本を〔口: ファイルを取る〕で受ける。電子の表はパックの入口の読み口で読む（`入口/README.md` §2。製品の名でなく原本の一般の形で選ぶ）。PDF・手書きは AI が読む。
   - 読んだまま（1 次）と、会社の決まりの MD と答えを当てた確定した勤怠（2 次）を、年の台帳へ並べて書く。
   - 勤怠の機械の照らしを通す（時刻の抜け・重なり・1 日 24 時間超え・原本に印字された合計・1 次と 2 次の差の行に当てた決まりか問いの番号があるか）。照らしの芯はパックが持つ。
   - 読めない所・不安な所は必ず問いにする。その場で送らず溜め、全員の原本を読み照らし終えた時（締めが終わった時）に、月の途中に溜めた問いと合わせてまとめて 1 回で聞く（聞く時の正本は `docs/毎月の流れ.md` 前提「聞く相手と聞き方」・道は 0 の 5・6 と同じ）。
   - 事務所の担当者へ、確定した勤怠のシート（人ごとの月の合計と、どう確定させたか）を毎月〔口: ファイルを置く〕で渡す。
   - 締めた事を締めの記録へ書く: 問いの要らない人は `締まった`、答えの要る人は残る問いの番号つきで `まだ`。答えが来たら確定した勤怠を直して `締まった` にする。
4. 止める所: 全員が締まるまで 2 へ進まない。

## 2. 給与計算（全員が締まった後に 1 回）

1. 計算のパックの `月次.月を回す` を呼ぶ（渡す物と呼び順と返す物の正本は `月次/README.md`。賞与は `月次.賞与を回す`）。〔口: シートを読む〕で読んだ値を渡すだけで、部品を手で組まない。
2. 計算の前に、会社の決まりの MD の例をその月のマスタの値で計算に通す（`月次/例の確かめ.py`。口の中で回る）。合わなければその会社は出さない。
3. 1 人でも締まっていなければ全員を待たせる。仮が残る人は口が外す（出さない）。
4. 返った物を書く先へ書く: 人ごとの月の数字は年の台帳へ〔口: シートに書く〕。取り込み・支給控除一覧・有給休暇管理表は、返った出す物と証明（形は `出口/証明.py`）を、月を回すに渡したのと同じ計算の元（名は `出口/証明.py` の `計算の元に要る名`＝マスタ・確定した勤怠とその区間・前の確定した勤怠とその区間・その月だけの指示・人ごとの月の数字・月の数字・有給の値・法の線・給与のルール.md の字）と一緒に出す前の照らし（この plugin の `bin/出す前の照らし.py`）へ通して〔口: 出荷〕。元を作り直さない・前のマスタ「例」の行は渡さない。
5. 給与ソフトとの突き合わせ（`出口/突き合わせ.py`）は、差が続けて 0 になるまで続ける。外すかは事務所が決める。差の問いはその場で送らず溜め、次の原本の締めが終わった時にまとめて聞く（`docs/毎月の流れ.md` 前提「聞く相手と聞き方」・道は 0 の 5・6 と同じ）。
6. 管理表の行は `管理表/README.md` の書く口が返す手順で書く（今の版と取り込みは〔口: 出荷〕だけ）。
7. 止めた時・終えた時は〔口: 記録を置く〕で残す。

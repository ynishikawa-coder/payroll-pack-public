# 給与の毎月の手順（3 段）

始める前に、この plugin の根の `決まり.md` を読む（起動時に差し込まれていれば読み直さない）。外とつなぐ所は `口の一覧.md` の口の名で呼ぶ。計算のパックは同じ版の印を手元に置き、下の `…` の path はそのパックの repo の中を指す。

段の設計の理由と置き場の名の正本は、計算のパックの `docs/毎月の流れ.md`（段ごとに読む物・書く物）と `docs/設計/Drive の型.md`（置き場の形）。ここには写さない。

## 0. 初期設定（会社の始めと、会社の決まりが変わった時）

1. 〔口: 置き場を引く〕で会社の置き場を引き、規程・過去の支給控除一覧・勤怠の原本を〔口: ファイルを取る〕で受ける。
2. 型で会社を始める（`初期設定/README.md` の「始める」）。管理表に型のタブが無ければ〔口: 事務所の段〕の 立ち上げ、管理表「会社」にその会社の行が無ければ 会社の行（その会社の Drive の型の版を渡す）で起こす（タブ・行を手で足さない）。
3. 法律どおりに計算し、過去の一覧と人×項目で照らす（`道具/答え合わせ/` の 照らす）。差 0 の所は聞かずに決まり（MD・マスタ）へ書き、出所に 過去の結果の照らし（形は `月次/例の確かめ.py` の 過去の結果を読む）を書く。違う所・過去の資料に表れない所だけを問いにする（照らしの線は `docs/設計/確かめと仮.md` §1）。
4. 決まりを聞き切る。問いの種の集め方は `初期設定/設問.py`（`docs/設計/設問の作り方.md`）。数え方の決まりごとに例を作り、人の言葉で聞く。給与ソフトへの取り込みの形（どの時間をどの欄に出すか）も聞く。
5. 問いは確認ページで聞く（`確認ページ/README.md`）。〔口: 問いの関所〕を通してから〔口: 確認ページを配る〕。
6. 答えは〔口: 答えを受け取る〕で受け、反映先を書き換える: 文の決まりは会社の決まりの MD、金額に効く値はマスタ（〔口: シートに書く〕）。選べる値は〔口: 選べる値を付ける〕で付けた選択肢から選ぶ。
7. 止める所: 毎月の計算へ進む前に `道具/答え合わせ/` の 出所を見る（照らすの出した差と MD を渡す）が 0 で終わる事（変更の記録・MD の出所・例の 確かめた人 に書いた過去の結果の照らしが、照らしで差 0 か。1 なら毎月へ進まない。2 は道具の故障＝結果ではない・標準エラーの訳で直して回し直す）。必ず埋める欄（区分・源泉の欄・保険の加入・労働時間の制度・扶養の数・保険料を引く月）が空なら計算しない。パックに無い式は〔口: 穴を起票する〕し、パックへ足すまで受けない。

## 0.5 型を寄せる（版を上げた後・月を回す前）

設計の正本は計算のパックの `docs/設計/寄せる道具.md` §1.5（順番）・§1.6（人×項目の突き合わせ）。

1. 置いたパックの型の版（`初期設定/型.json` の `版`）が管理表「会社」のその会社の `型の版` より新しい時は、その会社の月に入る前に〔口: 寄せる〕で見通す（書かない）。型の版が同じでも、月を回す口が「型の列に無い」「締めた時の版が無い」で止まったら同じく見通す。
2. 寄せられない物が在れば、出力の `選べる答え` と `手がかり` を読み、会社の決まりの MD・マスタ・過去の結果で決まる物は答えを決めて出所を残し、決まらない物だけを 0 の 5・6 と同じ道で事務所の担当者へ聞く。
3. 見通しで何も変わらない会社（書く手順・寄せられない物・足りない値・管理表へ書く・写した物 が全部空で寄せ中でない＝`管理表/管理表.py 突き合わせる月` に見通しと管理表「会社」を渡して `変わらない` が真）は、突き合わせる月も無い訳も渡さずに終える。足りない値が残る・前の回が止まった会社は済にしない。寄せられない物が 0 になったら〔口: 寄せる〕で書く。突き合わせる月（その会社が最後に出した月の〔口: 出荷〕の入力。まだ 1 度も出していない会社は無い訳）を渡す。口は管理表「月の状況」の出荷の印から最後に出した月を決め（`管理表/管理表.py 突き合わせる月`）、出した月が在る会社の無い訳と最後でない月は何も書かずに止まる。書く回が返した寄せの前の写しの名（`写した物`）は、書いた後に読み直す回（照らす）へ `写しの場所` として渡し返す（管理表「会社」の 写しの場所 はこの回にだけ書かれる）。口は書く前に管理表「会社」を寄せ中にし（寄せ中の会社は〔口: 出荷〕と〔口: 締める〕が止まる＝毎月の仕事を回さない）、書いた後に照らしと人×項目の突き合わせ（寄せの前に出した出す物と、寄せた後に同じ月を計算した出す物が 1 字も違わない）が通った時だけ、型の版を今の版にして寄せ中を外す。
4. 止まったら（寄せ中のまま理由が管理表「会社」の `寄せの理由` に在る）、その会社の月へ進まない。理由を読み、直しの誤り・答えの誤りなら直してから 1 からやり直す（直しは当たった所を飛ばす）。タブ・列や寄せ中の印を手で書かない。

## 1. 材料をそろえる（毎月）

月の始めに〔口: 事務所の段〕の 月の行 で、管理表「月の状況」に会社×支給月の行を起こす（止めた 以外の会社）。月のタスクを〔口: 記録を置く〕で置いたら、その在り処を同じ行の `タスクへのリンク` へ書く。どの口でも「行が無い（行を起こすのは事務所の段）」で止まったら、〔口: 事務所の段〕で行を起こしてから同じ口をやり直す（行を手で足さない）。

順は ①→②→③（①が先＝育休や退職が分からないと休みを欠勤と読む）。

1. **① マスタの更新**: 受け取り口の新着を中身で読んで頭（`勤怠_`・`変更_`・`メモ_`・`書類_`）を選び、〔口: 届いた物を写す〕でその月の `1_届いた物/` へ写す（名はパックの `月次/届いた物.写す手順` が付ける＝手で名を組まない・原本は動かさない）。入退社・休職・育休・昇給・扶養を、マスタと変更の記録へ〔口: シートに書く〕。
   - 年の最初の支給月は、②の前に新しい年の台帳を起こす: 前の年の台帳の型（`初期設定/型.json` の `台帳_<支給年>`）の全部のタブとマスタ「社員」を〔口: シートを読む〕で読み、パックの `月次/年の台帳を起こす.起こす` に会社の根の名の並び（`今ある名`）とマスタ「社員」（`社員`）と一緒に渡し、返った `書く手順` を〔口: 書く手順を当てる〕（表を手で写さない。何を引き継ぐかの正本は `docs/設計/Drive の型.md` §4・手順は `docs/毎月の流れ.md` 1-①）。止まったら起こさず、訳を問いにする。同じ時に、前の年の 12 月支給を〔口: 出荷〕の照らす（書かない）で回し直し、返った `有給の始めを進める` をパックの `月次.有給の始めを進める` にマスタ「社員」と一緒に渡し、返った `書く手順` を〔口: 書く手順を当てる〕（マスタの 有給の始めの日・残り・繰越 を 12 月の基準の日へ進める）。1 月支給の〔口: 出荷〕は起こさず、毎月と同じ `月次/年の台帳を起こす.前の年の確定した勤怠` で前の年の確定した勤怠を読む。
2. **② その月だけの指示**: 「この人は今月こう計算して」を、年の台帳の「その月だけの指示」へ書く。
3. **③ 勤怠の締め**:
   - 原本を〔口: ファイルを取る〕で受ける。電子の表はパックの入口の読み口で読む（`入口/README.md` §2。製品の名でなく原本の一般の形で選ぶ）。PDF・手書きは AI が読む。
   - 読んだまま（1 次）と、会社の決まりの MD と答えを当てた確定した勤怠（2 次）を、年の台帳へ並べて書く: その日の行と区間の全部・今のタブ・マスタ「社員」・原本の置き場の名と在り処をパックの `月次/台帳へ書く.勤怠` に渡し、返った `書く手順` を〔口: 書く手順を当てる〕（氏名・曜日・出勤と退勤の時刻・休憩と労働の合計・原本のリンクは口が埋める＝窓は空で渡す）。
   - 勤怠の機械の照らしを通す（時刻の抜け・重なり・1 日 24 時間超え・原本に印字された合計・1 次と 2 次の差の行に当てた決まりか問いの番号があるか）。照らしの芯はパックが持つ。
   - 読めない所・不安な所は必ず問いにする。その場で送らず溜め、全員の原本を読み照らし終えた時（締めが終わった時）に、月の途中に溜めた問いと合わせてまとめて 1 回で聞く（聞く時の正本は `docs/毎月の流れ.md` 前提「聞く相手と聞き方」・道は 0 の 5・6 と同じ）。
   - 事務所の担当者へ、確定した勤怠のシート（人ごとの月の合計と、どう確定させたか）を毎月渡す: 年の台帳の 5 タブ（読んだままの勤怠とその区間・確定した勤怠とその区間・人ごとの月の数字）とその月の `2_出す物/`・`9_履歴/` の名の並びをパックの `月次/勤怠のシート.作る` に渡し、返った `書く手順` を〔口: 書く手順を当てる〕（`確定した勤怠_<会社>_<支給月>_v<n>`・前の版は `9_履歴/` へ）。
   - 締めた事を〔口: 締める〕で締めの記録へ書く: 問いの要らない人は `締まった`、答えの要る人は残る問いの番号つきで `まだ`。どの行の `パックの版` にも、口が今置いたパックの版（締めた時の版）を押す（窓は版を書かない）。答えが来たら確定した勤怠を直して〔口: 締める〕で `締まった` にする（`パックの版` は締めた時のまま替えない）。
4. 止める所: 全員が締まるまで 2 へ進まない。

## 2. 給与計算（全員が締まった後に 1 回）

1. 計算のパックの `月次.月を回す` を呼ぶ（渡す物と呼び順と返す物の正本は `月次/README.md`。賞与は `月次.賞与を回す`）。〔口: シートを読む〕で読んだ値を渡すだけで、部品を手で組まない。
2. 計算の前に、会社の決まりの MD の例をその月のマスタの値で計算に通す（`月次/例の確かめ.py`。口の中で回る）。合わなければその会社は出さない。
3. 1 人でも締まっていなければ全員を待たせる。仮が残る人は口が外す（出さない）。
   - 締めた時の版（締めの記録の `パックの版`）が今の版と違うと口が止まる。その月をどちらの版で出すかをオーナーに選択肢の画面で聞き、答えの道（締めた時の版を置いて回す／〔口: 締める〕で締め直して版を書き替える）だけを取る（AI が決めない）。賞与は回の始めに賞与の支給一覧の `パックの版` へ今の版を書き、違うと `月次.賞与を回す` が同じに止まる（聞き方も同じ）。
4. 返った物を書く先へ書く: 返った `台帳`（人ごとの月の数字・その月だけの指示）は `月次/台帳へ書く.月の台帳` に、返った `日の要約` は `月次/台帳へ書く.日の要約を書く` に、今のタブと一緒に渡し、返った `書く手順` を〔口: 書く手順を当てる〕。取り込み・支給控除一覧・有給休暇管理表は、返った出す物と証明（形は `出口/証明.py`）を、月を回すに渡したのと同じ計算の元（名は `出口/証明.py` の `計算の元に要る名`（回ごと）を読む＝計算が読む材料の全部。ここに名を写さない。年の台帳「人ごとの月の数字」は計算の元に結ばない）と一緒に出す前の照らし（この plugin の `bin/出す前の照らし.py`）へ通して〔口: 出荷〕。元を作り直さない・前のマスタ「例」の行は渡さない。
5. 給与ソフトとの突き合わせ（`出口/突き合わせ.py`）は、差が続けて 0 になるまで続ける。外すかは事務所が決める。事務所が取り込みで給与ソフトを計算した後に〔口: 突き合わせ〕で回し、記録と月の状況「突き合わせ」は口が返す手順だけで書く（数を窓が書かない）。差の問いはその場で送らず溜め、次の原本の締めが終わった時にまとめて聞く（`docs/毎月の流れ.md` 前提「聞く相手と聞き方」・道は 0 の 5・6 と同じ）。
6. 管理表の行は `管理表/README.md` の書く口が返す手順で書く（今の版と取り込みは〔口: 出荷〕だけ）。
7. 止めた時・終えた時は〔口: 記録を置く〕で残す。親の窓・オーナーへ答え待ちを返す時は、問いの番号でなく、`決まり.md`「聞く」の形（どの会社の担当者に何を聞き、どこで答えが見られるか）で書く。

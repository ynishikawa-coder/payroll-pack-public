# 給与の毎月の手順（3 段）

始める前に、この plugin の根の `決まり.md` を読む（起動時に差し込まれていれば読み直さない）。外とつなぐ所は `口の一覧.md` の口の名で呼ぶ。計算のパックは同じ版の印を手元に置き、下の `…` の path はそのパックの repo の中を指す。

段の設計の理由と置き場の名の正本は、計算のパックの `docs/毎月の流れ.md`（段ごとに読む物・書く物）と `docs/設計/Drive の型.md`（置き場の形）。ここには写さない。

## 0. 初期設定（会社の始めと、会社の決まりが変わった時）

1. 〔口: 置き場を引く〕で会社の置き場を引き、規程・過去の支給控除一覧・勤怠の原本を〔口: ファイルを取る〕で受ける。
2. 型で会社を始める（`初期設定/README.md` の「始める」）。管理表に型のタブが無ければ〔口: 事務所の段〕の 立ち上げ、管理表「会社」にその会社の行が無ければ 会社の行（その会社の Drive の型の版を渡す）で起こす（タブ・行を手で足さない）。
3. 法律どおりに計算し、過去の一覧と人×項目で照らす（`道具/答え合わせ/` の 照らす）。差 0 の所は聞かずに決まり（MD・マスタ）へ書き、出所に 過去の結果の照らし（形は `月次/例の確かめ.py` の 過去の結果を読む）を書く。違う所・過去の資料に表れない所だけを問いにする（照らしの線は `docs/設計/確かめと仮.md` §1）。
4. 決まりを聞き切る。問いの種の集め方は `初期設定/設問.py`（`docs/設計/設問の作り方.md`）。数え方の決まりごとに例を作り、人の言葉で聞く。給与ソフトへの取り込みの形（どの時間をどの欄に出すか）も聞く。
5. 問いは確認ページで聞く（`確認ページ/README.md`）。〔口: 確認ページを配る〕で配る。
6. 答えは〔口: 答えを受け取る〕で受け、反映先を書き換える: 文の決まりは会社の決まりの MD、金額に効く値はマスタ（〔口: シートに書く〕）。選べる値は〔口: 選べる値を付ける〕で付けた選択肢から選ぶ。
7. 止める所: 必ず埋める欄（区分・源泉の欄・保険の加入・労働時間の制度・扶養の数・保険料を引く月）が空なら計算しない。パックに無い式は〔口: 穴を起票する〕し、パックへ足すまで受けない。

## 1. 材料をそろえる（毎月）

月の始めに〔口: 事務所の段〕の 月の行 で、管理表「月の状況」に会社×支給月の行を起こす（止めた 以外の会社）。月のタスクを〔口: 記録を置く〕で置いたら、その在り処を同じ行の `タスクへのリンク` へ書く。どの口でも「行が無い（行を起こすのは事務所の段）」で止まったら、〔口: 事務所の段〕で行を起こしてから同じ口をやり直す（行を手で足さない）。

順は ①→②→③（①が先＝育休や退職が分からないと休みを欠勤と読む）。

1. **① マスタの更新**: 受け取り口の新着を中身で読んで頭（`勤怠_`・`変更_`・`メモ_`・`書類_`）を選び、〔口: 届いた物を写す〕でその月の `1_届いた物/` へ写す（名はパックの `月次/届いた物.写す手順` が付ける＝手で名を組まない・原本は動かさない。容器〔zip など〕は開いて中の file を 1 つずつ同じ回に写す＝原本は中の file・容器は 出所。名は `月次/台帳の形.容器の中の名`）。入退社・休職・育休・昇給・扶養を、マスタと変更の記録へ〔口: シートに書く〕。
   - 年の最初の支給月は、②の前に新しい年の台帳を起こす: 前の年の台帳の型（`初期設定/型.json` の `台帳_<支給年>`）の全部のタブとマスタ「社員」を〔口: シートを読む〕で読み、パックの `月次/年の台帳を起こす.起こす` に会社の根の名の並び（`今ある名`）とマスタ「社員」（`社員`）と一緒に渡し、返った `書く手順` を〔口: 書く手順を当てる〕（表を手で写さない。何を引き継ぐかの正本は `docs/設計/Drive の型.md` §4・手順は `docs/毎月の流れ.md` 1-①）。止まったら起こさず、訳を問いにする。同じ時に、前の年の 12 月支給を出す命令（出口/出す.py）の照らす（書かない）で回し直し、返った `有給の始めを進める` をパックの `月次.有給の始めを進める` にマスタ「社員」と一緒に渡し、返った `書く手順` を〔口: 書く手順を当てる〕（マスタの 有給の始めの日・残り・繰越 を 12 月の基準の日へ進める）。1 月支給のパックの 1 命令（出口/出す.py）で出すは起こさず、毎月と同じ `月次/年の台帳を起こす.前の年の確定した勤怠` で前の年の確定した勤怠を読む。
2. **② その月だけの指示**: 「この人は今月こう計算して」を、年の台帳の「その月だけの指示」へ書く。
3. **③ 勤怠の締め**:
   - 原本を〔口: ファイルを取る〕で受ける。電子の表はパックの入口の読み口で読む（`入口/README.md` §2。製品の名でなく原本の一般の形で選ぶ）。PDF・手書きは AI が読む。
   - 読んだまま（1 次）と、会社の決まりの MD と答えを当てた確定した勤怠（2 次）を、年の台帳へ並べて書く: その日の行と区間の全部・今のタブ・マスタ「社員」・原本の置き場の名と在り処をパックの `月次/台帳へ書く.勤怠` に渡し、返った `書く手順` を〔口: 書く手順を当てる〕（氏名・曜日・出勤と退勤の時刻・休憩と労働の合計・原本のリンクは口が埋める＝窓は空で渡す）。
   - 勤怠の機械の照らしを通す（時刻の抜け・重なり・1 日 24 時間超え・原本に印字された合計・1 次と 2 次の差の行に当てた決まりか問いの番号があるか）。照らしの芯はパックが持つ。
   - 読めない所・不安な所は必ず問いにする。その場で送らず溜め、全員の原本を読み照らし終えた時（締めが終わった時）に、月の途中に溜めた問いと合わせてまとめて 1 回で聞く（聞く時の正本は `docs/毎月の流れ.md` 前提「聞く相手と聞き方」・道は 0 の 5・6 と同じ）。
   - 事務所の担当者へ、確定した勤怠のシート（人ごとの月の合計と、どう確定させたか）を毎月渡す: 年の台帳の 5 タブ（読んだままの勤怠とその区間・確定した勤怠とその区間・人ごとの月の数字）とその月の `2_出す物/`・`9_履歴/` の名の並びをパックの `月次/勤怠のシート.作る` に渡し、返った `書く手順` を〔口: 書く手順を当てる〕（`確定した勤怠_<会社>_<支給月>_v<n>`・前の版は `9_履歴/` へ）。
   - 締めた事を締める命令（`月次/締めの関所.py`）で締めの記録へ書く: 問いの要らない人は `締まった`、答えの要る人は残る問いの番号つきで `まだ`。どの行の `パックの版` にも、口が今置いたパックの版（締めた時の版）を押す（窓は版を書かない）。答えが来たら確定した勤怠を直して締める命令（`月次/締めの関所.py`）で `締まった` にする（締め直した行の `パックの版` は、その時に置いたパックの版に替わる＝最後に締めた版。計算した版と違っても月を回す は止まらず、知らせに出る）。

## 2. 給与計算（締めた後に回す）

1. 計算のパックの `月次.月を回す` を呼ぶ（渡す物と呼び順と返す物の正本は `月次/README.md`。賞与は `月次.賞与を回す`）。〔口: シートを読む〕で読んだ値を渡すだけで、部品を手で組まない。
2. 計算の前に、会社の決まりの MD の例をその月のマスタの値で計算に通す（`月次/例の確かめ.py`。口の中で回る）。合わなければその会社は出さない。例の 確かめた日・確かめた人 は控えとして書くが、口は照らさない（2026-11-27 に畳んだ）。
3. 締まっていない人・必ず埋める欄が空の人も計算し、値は仮になる。仮が 1 つでも残る人は口が外す（出さない）。ほかの人は待たせず出す。
   - 締めた時の版（締めの記録の `パックの版`）が今の版と違っても止まらない（今の版で計算し、知らせ「締めた時の版」に出る）。
4. 返った物を書く先へ書く: 返った `台帳`（人ごとの月の数字・その月だけの指示）は `月次/台帳へ書く.月の台帳` に、返った `日の要約` は `月次/台帳へ書く.日の要約を書く` に、今のタブと一緒に渡し、返った `書く手順` を〔口: 書く手順を当てる〕。取り込み・支給控除一覧・有給休暇管理表は、パックの 1 命令（出口/出す.py）で出す。元を作り直さない・前のマスタ「例」の行は渡さない。
   - 出す命令: `python3 出口/出す.py --会社 <会社> --支給月 <YYYY-MM> --回 <給与|賞与> [--根 <id>] [--鍵の変数名 <変数の名>] [--試しに書かない]`。根の id は `--根` か環境の変数 PAYROLL_OFFICE_ROOT_ID、鍵は環境の変数 GOOGLE_DRIVE_SA_JSON（〔口: 鍵と根の id を渡す〕・値はどこにも書かない）。命令の中で Drive を開き、会社の置き場を引き、月を回し、仮と名の形を照らし、緑の時だけ新しい版を書き前の版を履歴へ写し管理表へ書く。
   - 先に `--試しに書かない` で回す。終わりの値 0＝緑（書いていない）なら同じ命令を外して叩く。2＝止めた（何も書いていない）なら stdout の JSON の `赤`（誰の・どの照らしか）をオーナーへ返し、手で直して出さない。
   - Drive を開けない（鍵が無い・形が違う・道具が無い）・置き場を引けない（事務所の設定「置き場」の表が型に合わない）で止まったら、直さずに訳をオーナーへ知らせる（訳に変数の名は出るが値は出ない）。
5. 給与ソフトとの突き合わせ（`出口/突き合わせ.py`）は、差が続けて 0 になるまで続ける。外すかは事務所が決める。事務所が取り込みで給与ソフトを計算した後に〔口: 突き合わせ〕で回し、記録と月の状況「突き合わせ」は口が返す手順だけで書く（数を窓が書かない）。差の問いはその場で送らず溜め、次の原本の締めが終わった時にまとめて聞く（`docs/毎月の流れ.md` 前提「聞く相手と聞き方」・道は 0 の 5・6 と同じ）。
6. 管理表の行は `管理表/README.md` の書く口が返す手順で書く（出す物と管理表はパックの 1 命令 出口/出す.py で書く。Drive の鍵と置き場の根の id は〔口: 鍵と根の id を渡す〕で渡す。出した物を直す時は、直に直さず出口/出す.py を回し直して出し直す）。
7. 止めた時・終えた時は〔口: 記録を置く〕で残す。親の窓・オーナーへ答え待ちを返す時は、問いの番号でなく、`決まり.md`「聞く」の形（どの会社の担当者に何を聞き、どこで答えが見られるか）で書く。

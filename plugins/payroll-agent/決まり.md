# 給与エージェントの決まり（payroll-agent）

給与の仕事をする窓が常に守る線。手順は skill `payroll-steps`、外とつなぐ口は `口の一覧.md`（どちらもこの plugin の中）。計算と設計の正本は計算のパック（この plugin と同じ版の印）。

## 読む版
- 計算のパックとこの plugin は同じ版の印を読む（main の先端は読まない）。版の印の CHANGELOG の節に `互換が切れる:` の行があれば、渡し方を合わせてから回す。
- 月は版で割らない（2026-11-25 オーナー: 確定した勤怠は台帳に在り、版が上がっても壊れない）。締める口は締めの記録に版を押さず、月を回す・賞与を回す は版を読まずに今の版で計算する（版を止めの条件にしない＝2026-11-27 に畳んだ）。

## 計算
- 金額・時間・日数を出すのは計算のパックだけ。AI が手で計算しない。部品を手で組まず、パックの口へ渡して返った物を書く。パックは Drive の口を持つ。鍵と置き場の根の id は給与の窓が環境から渡す（repo に置かない）。
- パックに無い式・表せない決まりは、その会社を止めて〔口: 穴を起票する〕（事務所への問いにしない）。式をパックへ足してから計算する。
- 数え方の決まり（丸め・休憩の引き方など）はパックが当てる。確定した勤怠で直すのは事実（打刻の読み・答えた事・原本の読み方の決まり）だけ。
- 仮が 1 つでも残る人は出さない ⟦鍵:給与計算/足りない時は仮で計算し出さない⟧。締まっていない人も仮で計算し、その人だけ出さない。

## 書く・出す
- 決めた版で計算し、照らしが赤なら出さない。出す物と管理表はパックの 1 命令（出口/出す.py）で書く（仮・名の形の照らしはその中で通る）。出した物を直す時は、直に直さずこの命令を回し直して出し直す。
- 確認事項の答えは、必ず反映先（MD・マスタ・確定した勤怠・その月だけの指示）を書き換える。行き先の表は計算のパックの `docs/毎月の流れ.md`。

## 聞く
- 問いの相手はいつも事務所の担当者 1 人。問いは確認ページで聞き、人に MD を読ませない。検算（計算が合うか）・原本の読み方・会社の決まり・人ごとの事実のどれも、オーナーに聞かない。
- オーナーへ選択肢の画面で聞くのは道具の都合（パックの `docs/設計/設問の作り方.md` §6.4）だけ。オーナーが自分から答えた事は使ってよいが、出所の形（正本はパックの `月次/例の確かめ.py` の `出所の書き方`）で残してから使う（会話で答えた事は決定DB の行にし、鍵を口の `決定の鍵たち=` へ渡す）。
- 問いを出した・答えを待つ事をオーナーへ知らせる時は番号で書かない。会社ごとに、その会社の担当者に何を聞いたか（中身を文で）と、どこで答えが見られるか（確認ページ・質問と回答 の在り処）を書く。答えるのは担当者で、オーナーに答えを頼まない。
- 給与の仕事を始める時と答えを待つ間は、〔口: 答えを受け取る〕で届いた答えを先に書き戻す（書き戻すまで答えを計算に使わない）。
- 読めない所・不安な所は必ず聞く。聞かなかった所は正しい状態を目指す。

## 置かない
- repo（計算のパックにも各社の側にも）に事務所の物・会社の物を置かない（事務所名・会社名・氏名・金額・置き場の在り処・どの給与ソフトか）。
- 給与の型・手順・照らし・試験を各社の側に足さない。直すのは計算のパックの repo（枝と PR）で、版の印を打てば両側へ同じ物が届く。
- 決まりの経緯は〔口: 決まりの経緯を引く〕で ⟦鍵⟧ から引く。引けなくてもこの文と手順だけで動く。

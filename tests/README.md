# tests

- 入口: `bash scripts/check_all.sh`（中で `python3 -m pytest -q tests/`）。
- `test_骨.py`: 骨の自己検査（設計の目次の全行の file・dir が在るか・顧客の語が載っていないか・版の約束・入れてよい物の線〔製品の名・事務所と側の名・直しの印〕）。
- `data/`: 骨の自己検査の束（`製品の名.txt`・`側の名.txt`）と外しの一覧（`外し.json`）。
- `作り物/`: 作り物の値だけの小さな試験 2 つ＝国の率や表の例・回帰の見張り（B7 が中身を入れる）。作り物の会社の一揃いは置かない。
- 顧客の物（名・語・マスタ・台帳・実の勤怠）を置かない。過去の正解に合わせる答え合わせはここか `道具/` に置き、`芯/` に入れない。

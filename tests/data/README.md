# tests/data

骨の自己検査（`tests/test_骨.py` の「4. 入れてよい物の線」）が読む束と外しの一覧。線の正本は `docs/設計/入れてよい物.md`。

| file | 中身 |
|---|---|
| `製品の名.txt` | 製品（勤怠ツール・給与ソフト）の名の束。1 行 1 語・`#` から後は注 |
| `側の名.txt` | 側の名（自分たちのアカウントと事務所の呼び名）の束。顧客の名は入れない。1 行 1 語・`#` から後は注 |
| `外し.json` | 外しの一覧（path ごと・`なぜ` と `畳む`）。増やすのは PR の本文に理由を書いた時だけ |

- 顧客の語の束はここに置かない（`CONTRIBUTING.md` §3。環境から渡す）。

# 有給 — 有給の付与と残りを数え、有給休暇管理表の行を返す

Drive を開かない。殻が渡す値を受けて返す。法の付与日数の表（労基法 39 条 2・3 項・労基則 24 条の 3）・時効の年・年 5 日は `法の表/有給_付与日数.json` に置き、ほかの法の表と同じ引く口（`芯/計算/引く口.py`）で **付与日に効く行** を引く（基準＝労働した日・欠けた時＝止める）。有給休暇管理表は 1 つの形（`型.json`）で、`2_出す物/` に支給月ごとに出す（名は出口が付ける）。

## 置く物

| file | 中身 |
|---|---|
| `型.json` | 有給休暇管理表の列（1 行＝会社×支給月×人） |
| `有給.py` | 付与と残りを数える道具 |

## 呼び口

| 呼び口 | 入力 | 出力 |
|---|---|---|
| `有給.法の日数(勤続の月, 週の所定日数, 週の所定時間)` | 週の所定時間は時間の数（`40`・`29.5`。下の単位の表） | `(日数, "通常"/"比例・週 N 日")`。決められない時 `(None, 理由)` |
| `有給.付与の日たち(入社日, 終わりの日, 揃えた日, 表, 初回は法の日)` | 揃えた日は `MM-DD` か None・初回は法の日は真偽（既定 偽） | `[(付与日, 段, 法の付与日)]` |
| `有給.管理表(入力, 置き場=None)` | 下の入力（置き場は法の表の置き場・試験だけ渡す） | `{"見出し", "行", "問い", "止めた人", "知らせ"}`（止めた人＝`[{"会社", "支給月", "NO", "氏名", "理由"}]`。行に入らない。知らせ＝承知した食い違いの字の並び・仮にしない） |
| `python3 有給/有給.py < 入力.json` | 同上 | 同上（JSON） |

毎月の流れでは殻はこの呼び口を組まず、`月次.月を回す(…, 給与のルール=<給与のルール.md の字>, 有給の値={…})` の返す出す物 `有給休暇管理表`を〔口: 出荷〕で出す（取得と出勤率は年の台帳の確定した勤怠から数え、入力を組み、関所で仮の人を外すのは口・`月次/README.md`）。

入力:
```json
{"会社": "…", "支給月": "YYYY.MM支給", "基準の日": "締めの終わりの日", "勤怠の始め": "台帳の勤怠が揃っている最初の日",
 "会社の値": {"有給.付与の基準日": "…", "有給.付与の表": "…", "有給.会社の表": "…", "有給.揃えた日": "MM-DD"},
 "人": [{"NO": "…", "氏名": "…", "入社日": "…", "退職日": "…", "人.区分": "…",
         "時間.週の所定日数": 5, "時間.週の所定": 40, "有給.1日の時間": 480, "法の線.承知": "有給.付与=問の番号",
         "有給の始めの日": "…", "有給の始めの残り": 0, "有給の始めの繰越": 0, "出勤率が足りない付与日": []}],
 "勤怠": [{"支給月": "…", "NO": "…", "日付": "…", "休暇の種類": "年休", "休暇の単位": "全日", "休暇の時間": 0}]}
```
- 人の値は段を解いた後の値（人 → 勤務の型 → 会社 → 事務所 → 既定）を殻が渡す。単位は下の表（段の解決が渡す形のまま。殻は掛けたり割ったりしない）。
- 勤怠は台帳「勤怠」（表 A）の行。有給の始めの日（無ければ入社日）から基準の日までを渡す。

### 年の台帳の確定した勤怠から数える（`確定した勤怠` を渡す時）

```json
{"会社": "…", "支給月": "YYYY.MM支給", "基準の日": "締めの終わりの日", "会社の値": {…},
 "人": [{"NO": "…", "入社日": "…", "有給の始めの日": "…", "有給の始めの残り": 0, "有給の始めの繰越": 0, …}],
 "確定した勤怠": [{"会社": "…", "支給月": "YYYY-MM", "NO": "…", "日付": "YYYY-MM-DD", "日の種類": "勤務", "休暇の種類": "", "休暇の単位": "", "休暇の時間": ""}]}
```
- `確定した勤怠` は年の台帳 `台帳_<支給年>` のタブ「確定した勤怠」の行（列名→値の dict）を、今年と前の年（基準日によってはもう 1 本前）の台帳から合わせて渡す。列と値は `docs/設計/勤怠の形.md` §1 の表 A のとおり（読むのは 会社・支給月・NO・日付・日の種類・休暇の種類・休暇の単位・休暇の時間）。今月の行もこの中に入れる（パックは別の今月の勤怠を読まない＝決定 2）。
- この時は `勤怠`・`勤怠の始め`・人の `出勤率が足りない付与日` を渡さない（渡せば ValueError。出勤率はパックが数える）。1 社の行だけ渡す（会社が混ざれば ValueError）。要る列（会社・支給月・NO・日付・日の種類）の無い行・読めない日付も ValueError。
- マスタ「社員」の 有給の始めの日・始めの残り・始めの繰越 は台帳より前の分の始めの値。始めの日の翌日（無ければ入社日）から基準の日までの取得を台帳から引く（前の月までの分も）。
- **要る期間の行が無ければ止める**（黙って 0 にしない）: 取得を数える期間と、始めの日の後の各付与の出勤率の期間の **全部の日** に、その人の行が要る（表 A は期間の全部の日に 1 行）。1 日でも無い・同じ日が 2 行・数えられない日の種類の人は `行` に入れず `止めた人` に理由を返す。ほかの人は数える。
- **出勤率 8 割**（39 条 1・2 項）: 期間は初回が入社日から、2 回目からは前の付与日から、付与日の前の日まで。出勤 ÷ 全労働日 が 8 割に満たなければその付与は 0 日（勤続の段は進む）。
- **出勤率の期間が有給の始めの日より前にかかって止まる時**は、訳に「有給の始めの日 と 有給.揃えた日 を事務所の有給管理表の付与日で照らす」を添える。始めの日が付与日なのに揃えた日がずれていると、始めの日のすぐ後に付与日ができ、始めの日より前の 1 年の勤怠を求めて止まる（真の原因は勤怠の欠けでなく日のずれ）。

| 日 | 数え方 | 拠り所 |
|---|---|---|
| 勤務（半休・遅刻早退の日も） | 出勤 | |
| 休暇の 年休・出勤扱い、休職・休業の 産前産後休業・育児休業・介護休業 | 出勤とみなす | 39 条 10 項・平 25.7.10 基発 0710 第 3 号 |
| 欠勤 | 全労働日に入れ、出勤に入れない | |
| 休日・休日勤務・会社都合の休業 | 全労働日から除く | 昭 33.2.13 基発 90 号・平 25.7.10 基発 0710 第 3 号 |
| 特別休暇（有給・無給）・子の看護等休暇・介護休暇・生理休暇・代休・休職 | 会社の決まりで分かれる。欠勤とみなす時と出勤とみなす時の両方で数え、8 割の答えが割れる時だけ止める | |
| ほかの値 | 止める | |

  会社で揃えた日へ前倒しして期間が短くなった付与は、短くなった分を出勤とみなす（平 6.1.4 基発 1 号）。その数え方は表せないので、短い期間で 8 割を割る時は止める（割らなければ付与する）。
- 毎月の流れ（`月次.月を回す`）はまだ上の古い入力（`勤怠`・`勤怠の始め`・`出勤率が足りない付与日`）で呼ぶ。月次が `確定した勤怠` を渡す形に替わったら、古い入力の道（`勤怠の始め` で始めの残りを聞く問い・`出勤率が足りない付与日`）を畳む。

### 読む時間の値の単位

| 値 | 読む所 | 単位 | 例 | 無い・読めない時 |
|---|---|---|---|---|
| `時間.週の所定` | `法の日数`（比例付与の境） | **時間の数**（芯/集計・芯/計算 と同じ） | `40`・`29.5`・`"30"` | 無い時は週 4 日以下なら仮にして 1 問（見当は週 5 日の通常）。読めない値と週 168 時間を超える値（`1770`・`2400` など分で渡したらしい値）は週の日数によらず仮＋問い |
| `有給.1日の時間` | `_取得の日数`（時間単位の取得を日に直す） | **分の数**（芯は読まない） | `480`・`450` | 無い時は全日とみなし仮にして 1 問（段の解決が分の数に直して渡す） |
| 勤怠の `休暇の時間` | `_取得の日数` | 分の数 | `120` | — |
| `法の表/有給_付与日数.json` の `比例の週の所定時間の上限（分）` | `法の日数` | 分（`1800`＝30 時間） | — | — |

- `時間.週の所定` を分に直すのは 有給.py の中だけ（`_時間を分に`）。上限との比べは分で、30 時間ちょうど（1800 分）は通常、29.5 時間（1770 分）は週 4 日以下なら比例（労基法 39 条 3 項・労基則 24 条の 3）。

## 選び方（数え方の決まり）

- **付与の日**: `有給.付与の基準日` が入社日からなら、入社日から 6・18・30… か月の日。会社で揃えた日なら、法の付与の日ごとに (前の付与の日〔初回は入社日〕, 法の付与の日] の中で一番後の揃えた日へ前倒しする（無ければ法の日）。`初回は入社日から（2 回目から揃えた日）` なら初回だけ法の付与の日（入社 6 か月）・2 回目から同じに前倒しする。`有給.揃えた日` は月と日（`MM-DD`）。無い・月だけ（`10` など）の時は付与の日（時効・基準日の起点）が決まらない＝日を作らず問い 1 つ・法の付与の日で見当（仮）。
- **付与日数**: 法の表（通常・比例）を付与日ごとにその日に効く行で引く（次の付与日の行がまだ無ければ `次の付与日数` は空＝前の行で代えない）。比例は週の所定時間（時間の数）が 30 時間未満かつ週の所定日数が 4 日以下の人。`有給.付与の表` が会社の表なら `有給.会社の表`（7 段）を使い、法を下回る段は法の数で仮にして 1 問。
- **出勤率**: `確定した勤怠` を渡す時はパックが数える（上の表）。古い入力では 8 割に満たない付与を殻が `出勤率が足りない付与日` で渡す（その付与は 0 日）。
- **取得**: 休暇の種類が年休の行。全日 1・午前半休／午後半休 0.5・時間は 休暇の時間 ÷ `有給.1日の時間`。古い付与から使う。
- **時効**: 付与日から 2 年（39 条・115 条）。年 5 日: 付与日数 10 日以上の人の付与日から 1 年。
- **数え始め**: 有給の始めの日の残り（今の付与と繰越）から数える。始めの日が無く、入社日から勤怠が揃っていない人は仮にして 1 問。
- **仮**: 足りない値は見当で数え、行の状態を仮にし、`問い`（質問と回答の列の形）を返す。`行` には仮の人も入る。2_出す物 へ出す前に、出口の手前の関所（`出口/`・`docs/設計/確かめと仮.md` §3）が状態＝仮の人を外す。
- **法の付与をしない承知**（`法の線.承知` の線 `有給.付与`・39 条・人の段）: 会社が法の付与をしない人（今のまま）を事務所が承知した印（`有給.付与=<問いの番号>`。読み方は `芯/計算/承知.py`）。印の人は各付与を 0 日・出勤率を数えない・次の付与日数 0 で、仮にせず確定の行に出し、`知らせ` に 線・人・問いの番号・法の線なら何日（出勤率 8 割を満たす時の法の日数）を返す（毎月の流れでは `知らせ.有給`）。始めの残りと繰越も 0 なら取得を数える勤怠の行が揃うのを待たない（年休の行があれば 残りを超えた で問う＝仮）。問いの番号の無い印・ほかの線だけの印は承知に数えない（今までどおり数え、勤怠が無ければ止まる）。
- 役員・委託の人と、基準の日より前に辞めた人は出さない。

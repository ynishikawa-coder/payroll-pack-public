# 出口 — 明細・連携の形へ出す（仮が残る人は出さない）。

芯の結果を **仮の人を混ぜずに** 給与ソフトへ渡し、給与ソフトの計算結果と **人×項目** で突き合わせる部品を並べる。
パックは給与ソフトの製品の名と形を持たない。事務所の給与ソフトの形は殻が事務所の Drive から読んで渡す（⟦鍵:給与計算/UTCの迷い4つ⟧・⟦鍵:給与計算/パックに製品ごとの物を置かない⟧）。正本の設計は
`docs/設計/確かめと仮.md`（§2 突き合わせ・§3 仮の関所）と `docs/設計/Drive の型.md`（§6 出力・§7 委託）。

- 出口は **Drive を開かない**。殻（各エージェントの repo の環境の口）が渡す値を受けて返すだけ。
- 給与ソフトの欄の名・並び・文字コードは **出口の中だけ**。芯は知らない。顧客ごとに違う欄の対応は Drive のマスタ「項目」の給与ソフトの欄から殻が引数で渡す。
- 答え（過去の結果）を受ける口は持たない。差を見てマスタや計算を直さない（差は問いにして返す）。
- Python 3 の標準ライブラリだけ。数は `Decimal`（円は整数）。

行の状態は書かなければ仮に数える。人の状態は `確認済` 以外（`仮`・知らない語）を全部外す。

## 入力の形: 人×項目の縦（芯の出す物）

`芯/計算/` の `計算する`・`賞与を計算する` が返す縦（`芯/計算/README.md`「返す物」）。形は `確かめと仮.md` §2・§3（1 行＝dict）:

| 列 | 必須 | 値 |
|---|---|---|
| 支給月 | 必須 | `YYYY-MM`（賞与は `YYYY-MM-賞与`） |
| 会社 | 必須 | 会社の呼び名（型の列「会社」と同じ字・`Drive の型.md` §1。出力の名 `<物>_<会社>_<支給月>_v<n>` にもこの字のまま） |
| NO | 必須 | 社員の番号（字のまま。`0001` の頭の 0 を残す） |
| 項目 | 必須 | 芯の項目の名（勤怠の形.md §5 の語・支給控除の項目） |
| 値 | 必須 | `Decimal`・`int`・数の字（float は受けない）。円は整数・時間は **分**・日は数。空は仮 |
| 状態 | 必須 | `確定` か `仮`。`確定` でない物と値の空は全部仮に数える |
| 出所 | 任意 | 原本の名・決まりの md の節・質問と回答の番号（突き合わせの「差の出所」に出す） |
| 見当・見当の拠り所・問いの番号 | 仮の時 | 問いの番号は外した人の一覧に出す（字なら `・` 区切り） |

同じ 支給月×会社×NO×項目 が 2 行あれば止まる。

### 勤怠の欄（出勤日数・残業時間など）を渡す

芯/計算 は勤怠の語を返さない。勤怠の欄は芯/集計 の行から `関所.勤怠の行を分ける(集計の行)` で `(渡す, 出さない)` に分け、渡すを計算の行と一緒に関所へ入れる。
毎月は `月次.月を回す` がこれと段の解決・入口の仮の寄せ（`初期設定/入口の文脈.給与の関所へ`）を同じ順で回す（呼び順は `月次/README.md`。殻が手で組まない）。

- 渡す: 単位が `日`・`分`・`回` で値が数（か空＝仮）の行。集計の `問い` は `問いの番号` に写す（外した人の一覧に出る）。
- 出さない: 単位が数の外（`年休を取った日` の日付など）・単位が無い・値が数でない行。関所で止めずに分けて返す（出口の file には出さない）。
- 集計の行をそのまま `通す` へ混ぜると日付の値で止まる（混ぜずに分ける）。欄の対応の形は `日`・`分`・`回` で書く。
- 委託の併用の雇用分の出勤日数（`委託.雇用分の出勤日数`・会社の段・型の版 19）: `勤怠の行を分ける(…, 入力=段の解決の入力)` が、`入力` に `委託.雇用分の出勤日数` の在る人（委託の併用）の `出勤日数` の行の値をその日数で書く（実の出勤日数は委託分の日も含む＝給与ソフトには雇用分の日数を渡す）。計算と台帳は実の出勤日数のまま（出口の欄だけ）。`月次.月を回す` が渡す。
- 実働の頭打ち（`出口.実働の上限`・人の段・型の版 18）: `勤怠の行を分ける(集計の行, 決まり, 集計の所定で頭打ちの実働)` に段を解いた決まりと 芯/集計 の返す `所定で頭打ちの実働` を渡すと、`所定` の人の `総労働` の行の値を、勤務の日ごとに働いた時間をその日の所定で頭打ちにした和で書く（`所定内` は週・総枠の移しや制度で動くので使わない）。計算は変えない（出口の欄だけ）。値の無い人・知らない値は総労働のまま仮。`月次.月を回す` が決まりを渡す。

### 欄の対応（書き口と読み口が同じ 1 つを使う）

1 行＝`{項目, 欄, 形, 渡す, 受ける}`。形は `円`・`日`・`分`・`回`。渡す＝取り込みに書く欄・受ける＝給与ソフトの出力から読み突き合わせる欄（既定はどちらも はい）。
1 項目に 1 欄（同じ項目が 2 つの欄に出ると止まる）。**1 つの欄に幾つかの項目を当ててよい**（足す。例 時給・日給・基本給 → 基本給の欄）: 取り込みはその人に在る項目を足して書き（どれも無ければ空）、読み口は項目を `＋` で並べた名（例 `基本給＋時給＋日給`）の 1 行で読み、突き合わせは足した値と照らす。同じ欄の項目は 形・渡す・受ける がそろう（そろわなければ止まる）。欄ごとの組は `形.欄の組たち` の 1 か所（書き口・読み口・突き合わせが同じ物を使う）。

対応は殻が手で組まず `形.欄の対応を組む(会社, 道具, 支給控除の項目, つなぎ, 支給月)` で Drive の値から組む（`月次.月を回す` の `出口.取り込み` に `欄の対応` を渡さず `道具` を渡せば口が組む）。置き場は `docs/設計/Drive の型.md` §4「製品ごとの値の置き場」:
- ④支給控除の項目 の「給与ソフトの欄」（会社の部品の行・形は円）
- ⑥つなぎ の会社の行（NO 空・側＝出口・道具＝事務所が付けた給与ソフトの呼び名・その道具での名＝欄の字）。その道具での番号＝`欄.<項目>`（渡す・受ける）・`渡す.<項目>`（書くだけ）・`受ける.<項目>`（読んで照らすだけ）。芯が作る項目（時間外手当・総支給額 など）と勤怠の欄（出勤日数・法定外残業 など。形は芯/集計 の単位）はここに置く。給与ソフトの出勤時間の欄（出勤〜退勤の長さ＝休憩を含む）は `欄.出勤から退勤まで`、有給日数の欄（半日を 0.5 日）は `欄.年休の日数` で当てる（休憩を引いた働いた時間は `総労働`）。給与から引けない社保の本人負担は `欄.社保の引けない額`（差引支給額へ戻す額）・`欄.社保の立て替えの返し`（立て替えの返しの控除）で当てる

**残高は出さない**: 芯の行のうち `社保の立て替えの残り`（会社が立て替えた額の残高＝支給でも控除でもない。正本は `芯/計算/支給控除.py` の `出さない項目`）は、取り込み・支給控除一覧に載せず、`載せなかった項目`・突き合わせの `照らさなかった項目` にも出さない（月次が台帳「その月だけの指示」の次の月の行へ回す）。欄の対応でこの項目に欄を当てたら取り込み・突き合わせは止まる。

### 時間の書き方

芯の時間は分。給与ソフトへは会社のマスタ「時間の書き方」で書く: `60進`（`127.30`）・`時:分`（`127:30`）・`10進`（`127.50`。0.01 時間に四捨五入）。読む時は分へ戻す。

## 出力の形

- 取り込み: 1 人 1 行。欄は `[鍵の欄, 氏名の欄?, 対応の渡す欄…, 後ろの欄…]`。渡し方（給与ソフトの形の `渡し方`）は `CSV`（書かなければこれ＝前からの形。`csvの中身()`・文字コードが要る）か `表`（2_出す物 のスプレッドシートに書き、人が給与ソフトへ写す。文字コードは要らず CSV を作らない）。表の物は `書く手順()` が殻の当てる手順を返す: `file を移す`（前の版を会社の根の `9_履歴/` へ）→ `スプレッドシートを作る`（`フォルダ`＝番号フォルダ・`名`・`タブ`＝物）→ `値を書く`（`書き方`＝`RAW`＝NO の頭の 0・時間の字を数や日付に読ませない。管理表・寄せの書く手順と同じ形）。パス はその月の置き場（`3_月ごと/<月>/`）からの相対（前の版を移す先は会社の根の `9_履歴/`）。芯に値の無い所は空で書き `空の欄` に返す（推して埋めない）。対応に渡す欄の無い項目は `載せなかった項目` に返す。
- 給与ソフトへ入れない人（給与ソフトに載せない代表など）: 置き場は ⑥つなぎ の人の行（NO＝その人・側＝出口・道具＝給与ソフトの呼び名・その道具での番号＝`渡さない`）の 1 か所。`形.渡さない人を組む(会社, 道具, つなぎ)` が組み、`月次.月を回す` は `出口.取り込み.道具` を渡せば口が読む（殻が `渡さない人` を渡すと止まる・殻は返った表から行を消さない）。取り込みの行にも `空の欄` にも出さず、委託の人（`委託も取り込む=False`）と一緒に `渡さなかった人` に返す＝突き合わせの `渡さなかった人` へそのまま渡す。支給控除一覧には載る。
- 支給控除一覧: A 列が項目・列が人（NO）・最後が合計。氏名を渡せば 2 行目に氏名。業務委託（縦）は **ここの 1 本だけ**。取り込みに委託の人を載せるのは `委託も取り込む=True` の時だけ（同じ行から出す）。
- 突き合わせの表の列: `支給月・会社・NO・項目・こちら・給与ソフト・差・差の見立て・差の出所`。
  - 差＝こちら − 給与ソフト。片方が空なら `片方だけ`。**差は 0 だけを一致**（許す幅なし）。
  - 差の見立て: `片方だけ`／`入力の違い`（渡した欄の値が違う）／`丸め`（渡さない欄で、形が円か分で差が 1 以下。日・回は丸めと見ない）／`決まりの違い`（渡さない欄で、その人に入力の違いが無い）／`不明`（その人に入力の違いもある）。
  - 問い: 同じ 支給月・会社・見立て・出所 の差を 1 問にまとめる（人・項目・行・文・答え方の例）。殻が質問と回答へ書く。
- 給与ソフトの行に対応で受けない項目があれば照らさず `要確認` に返す。
- 外した人・照らさなかった項目・照らさなかった人・要確認は、黙って捨てずに返す。出口の出す file には外した人の行も仮の印も書かない。

### 差 0 の月の数え方

1 会社 1 支給月（賞与も 1 回を 1 か月）が次の全部の時「差 0 の月」: 突き合わせた人が 1 人以上・差の行が 0（片方だけも差）・仮で外した人が 0・「給与ソフトが違う」で閉じた問いが 0。
最新の月から遡って続けて数え、外れた月か記録の無い給与の月で切る。N は事務所の設定（推奨 3）。月数の横に、数えた月で出なかった場面（入社・退社・賞与・年の変わり目・料率の変わる月）を並べる。外すかどうかは事務所が決める（出口は判断しない）。

### 名と版

`3_月ごと/<月>/2_出す物/<物>_<会社>_<支給月>_v<n>`（物で分けたフォルダは切らない・最新の版 1 つだけ）。物は 取り込み・賞与の取り込み・支給控除一覧_雇用・支給控除一覧_業務委託・有給休暇管理表・明細（`名と版.出す物の置き場`）。
殻が `2_出す物/` の直下と会社の根の `9_履歴/` の名を渡し、出口は次の版の名と `9_履歴/` へ移す名を返す（人が名を付けない・雛形を写さない）。書く手順の `file を移す` は 前＝月の置き場から・後＝会社の根から（`後の根`）。

## 選び方（事務所ごと）

1. 給与ソフトの形を渡す: 殻が事務所のルール.md「## 1 給与ソフトと取り込みの形」の値（名・鍵の欄・氏名の欄・後ろの欄・文字コード・区切り・向き・確かめた・渡し方）を dict で読み、`形.形を組む(…)` か dict のまま `形=` へ渡す（置き場は `docs/設計/Drive の型.md` §4「製品ごとの値の置き場」）。書き口・読み口は中で `形を組む` を通し、名・鍵の欄・文字コード（渡し方＝CSV の時）が無ければ止まる（パックに既定の形は無い＝黙って既定で書かない）。
2. 欄の対応を会社のマスタから渡す（取り込みと読みで同じ物）。
3. 毎月: `月次.月を回す`（中で `関所.通す` → `書き口.取り込み`〔と `支給控除一覧`〕）→ 事務所が給与ソフトで計算 → `読み口.読む` → `突き合わせ.突き合わせる` → `月の記録` → `続けて差0の月数`。
   外した人と月数は殻が管理表の「外した人」「突き合わせ」の列へ書く。

有給休暇管理表の行は `有給/` が数え、`月次.月を回す` が関所を通して出す物 `有給休暇管理表`（名は `名を付ける()`・証明つき＝取り込み・支給控除一覧と同じ照らし）で返す。まだ無い部品: 明細（給与ソフトなしの道の 明細）。名と版の口だけはある。

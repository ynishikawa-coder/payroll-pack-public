# 出口 — 明細・連携の形へ出す（仮が残る人は出さない）。

芯の結果を **仮の人を混ぜずに** 給与ソフトへ渡し、給与ソフトの計算結果と **人×項目** で突き合わせる部品を並べる。
パックは給与ソフトの製品の名と形を持たない。事務所の給与ソフトの形は殻が事務所の Drive から読んで渡す（⟦鍵:給与計算/UTCの迷い4つ⟧・⟦鍵:給与計算/パックに製品ごとの物を置かない⟧）。正本の設計は
`docs/設計/確かめと仮.md`（§2 突き合わせ・§3 仮の関所）と `docs/設計/Drive の型.md`（§6 出力・§7 委託）。

- 出口は **Drive を開かない**。殻（各エージェントの repo の環境の口）が渡す値を受けて返すだけ。
- 給与ソフトの欄の名・並び・文字コードは **出口の中だけ**。芯は知らない。顧客ごとに違う欄の対応は Drive のマスタ「項目」の給与ソフトの欄から殻が引数で渡す。
- 答え（過去の結果）を受ける口は持たない。差を見てマスタや計算を直さない（差は問いにして返す）。
- Python 3 の標準ライブラリだけ。数は `Decimal`（円は整数）。

## 部品の一覧

| 部品 | file | 入れる物 | 返す物 |
|---|---|---|---|
| ① 仮の関所 | `関所.py` `通す()` | 芯の人×項目の行（状態つき）・人の状態（任意） | `関所を通った`（確定の人の行だけ）と外した人の一覧（支給月・会社・NO・仮の数・問いの番号） |
| ② 書き口 | `書き口.py` `取り込み()` | `関所を通った`・会社・支給月・欄の対応・給与ソフトの形・時間の書き方・NO→氏名（任意）・委託の人 | 取り込みの表（CSV の bytes にもできる）と名。支給月が `-賞与` なら賞与の取り込み |
| ② 支給控除一覧 | `書き口.py` `支給控除一覧()` | `関所を通った`・項目の並び・項目の形・委託の人 | 雇用（縦）と業務委託（縦）を 1 本ずつ |
| ③ 読み口 | `読み口.py` `読む()` | 給与ソフトの出力（bytes か字）・file の名・会社・支給月・欄の対応・給与ソフトの形 | 人×項目の行（出所＝file の名）と要確認 |
| ④ 突き合わせ | `突き合わせ.py` `突き合わせる()` | `関所を通った`・読み口の行・欄の対応・渡さなかった人 | 表（下の列）・人の状態・問い・照らさなかった項目と人 |
| ④ 月数 | `突き合わせ.py` `月の記録()` `続けて差0の月数()` | 突き合わせの結果・給与ソフトが違うで閉じた問いの数・場面／前の月までの記録 | 1 会社 1 月の記録／会社ごとの続けて差 0 の月数・数えた月・まだ見ていない場面 |
| ⑤ 名と版 | `名と版.py` `名を付ける()` | 物・会社・支給月・番号フォルダに今ある名・`旧版/` にある名 | 番号フォルダ・`<物>_<会社>_<支給月>_v<n>`・旧版へ移す名 |
| 形 | `形.py` `形を組む()` | 殻が事務所の設定から読んだ給与ソフトの形の値（dict） | 給与ソフトの形（型だけ・製品ごとの値は持たない）・欄の対応・時間の字 ↔ 分 |

後ろの部品（書き口・突き合わせ）は `関所を通った` しか受けない（関所を飛ばすと `TypeError`）。`関所を通った` は `通す()` の外では作れず、仮の値の行・外した人の行を持てない（中身でも止める）。
行の状態は書かなければ仮に数える。人の状態は `確認済` 以外（`仮`・知らない語）を全部外す。

## 入力の形: 人×項目の縦（芯の出す物）

`芯/計算/` の `計算する`・`賞与を計算する` が返す縦（`芯/計算/README.md`「返す物」）。形は `確かめと仮.md` §2・§3（1 行＝dict）:

| 列 | 必須 | 値 |
|---|---|---|
| 支給月 | 必須 | `YYYY-MM`（賞与は `YYYY-MM-賞与`） |
| 会社 | 必須 | 会社の番号（名は書かない） |
| NO | 必須 | 社員の番号（字のまま。`0001` の頭の 0 を残す） |
| 項目 | 必須 | 芯の項目の名（勤怠の形.md §5 の語・支給控除の項目） |
| 値 | 必須 | `Decimal`・`int`・数の字（float は受けない）。円は整数・時間は **分**・日は数。空は仮 |
| 状態 | 必須 | `確定` か `仮`。`確定` でない物と値の空は全部仮に数える |
| 出所 | 任意 | 原本の名・決まりの md の節・質問と回答の番号（突き合わせの「差の出所」に出す） |
| 見当・見当の拠り所・問いの番号 | 仮の時 | 問いの番号は外した人の一覧に出す（字なら `・` 区切り） |

同じ 支給月×会社×NO×項目 が 2 行あれば止まる。

### 勤怠の欄（出勤日数・残業時間など）を渡す

芯/計算 は勤怠の語を返さない。勤怠の欄は芯/集計 の行から `関所.勤怠の行を分ける(集計の行)` で `(渡す, 出さない)` に分け、渡すを計算の行と一緒に関所へ入れる。
毎月は `月次.月を回す` がこれと段の解決・入口の仮の寄せ（`初期設定/入口の文脈.給与の関所へ`）を同じ順で回す（呼び順は `月次/README.md`。殻が手で組まない）。

- 渡す: 単位が `日`・`分`・`回` で値が数（か空＝仮）の行。集計の `問い` は `問いの番号` に写す（外した人の一覧に出る）。
- 出さない: 単位が数の外（`年休を取った日` の日付など）・単位が無い・値が数でない行。関所で止めずに分けて返す（出口の file には出さない）。
- 集計の行をそのまま `通す` へ混ぜると日付の値で止まる（混ぜずに分ける）。欄の対応の形は `日`・`分`・`回` で書く。

### 欄の対応（書き口と読み口が同じ 1 つを使う）

1 行＝`{項目, 欄, 形, 渡す, 受ける}`。形は `円`・`日`・`分`・`回`。渡す＝取り込みに書く欄・受ける＝給与ソフトの出力から読み突き合わせる欄（既定はどちらも はい）。
1 項目に 1 欄・1 欄に 1 項目。殻が Drive のマスタ「項目」の給与ソフトの欄から渡す。

### 時間の書き方

芯の時間は分。給与ソフトへは会社のマスタ「時間の書き方」で書く: `60進`（`127.30`）・`時:分`（`127:30`）・`10進`（`127.50`。0.01 時間に四捨五入）。読む時は分へ戻す。

## 出力の形

- 取り込み: 1 人 1 行。欄は `[鍵の欄, 氏名の欄?, 対応の渡す欄…, 後ろの欄…]`。芯に値の無い所は空で書き `空の欄` に返す（推して埋めない）。対応に渡す欄の無い項目は `載せなかった項目` に返す。
- 支給控除一覧: A 列が項目・列が人（NO）・最後が合計。氏名を渡せば 2 行目に氏名。業務委託（縦）は **ここの 1 本だけ**。取り込みに委託の人を載せるのは `委託も取り込む=True` の時だけ（同じ行から出す）。
- 突き合わせの表の列: `支給月・会社・NO・項目・こちら・給与ソフト・差・差の見立て・差の出所`。
  - 差＝こちら − 給与ソフト。片方が空なら `片方だけ`。**差は 0 だけを一致**（許す幅なし）。
  - 差の見立て: `片方だけ`／`入力の違い`（渡した欄の値が違う）／`丸め`（渡さない欄で、形が円か分で差が 1 以下。日・回は丸めと見ない）／`決まりの違い`（渡さない欄で、その人に入力の違いが無い）／`不明`（その人に入力の違いもある）。
  - 問い: 同じ 支給月・会社・見立て・出所 の差を 1 問にまとめる（人・項目・行・文・答え方の例）。殻が質問と回答へ書く。
- 給与ソフトの行に対応で受けない項目があれば照らさず `要確認` に返す。
- 外した人・照らさなかった項目・照らさなかった人・要確認は、黙って捨てずに返す。出口の出す file には外した人の行も仮の印も書かない。

### 差 0 の月の数え方

1 会社 1 支給月（賞与も 1 回を 1 か月）が次の全部の時「差 0 の月」: 突き合わせた人が 1 人以上・差の行が 0（片方だけも差）・仮で外した人が 0・「給与ソフトが違う」で閉じた問いが 0。
最新の月から遡って続けて数え、外れた月か記録の無い給与の月で切る。N は事務所の設定（推奨 3）。月数の横に、数えた月で出なかった場面（入社・退社・賞与・年の変わり目・料率の変わる月）を並べる。外すかどうかは事務所が決める（出口は判断しない）。

### 名と版

`03_出力/<番号フォルダ>/<物>_<会社>_<支給月>_v<n>`。番号フォルダは 01_取り込み（取り込み・賞与の取り込み）・02_支給控除一覧（雇用・業務委託）・03_有給休暇管理表・04_明細。
殻がフォルダの直下と `旧版/` の名を渡し、出口は次の版の名と `旧版/` へ移す名を返す（人が名を付けない・雛形を写さない）。

## 選び方（事務所ごと）

1. 給与ソフトの形を渡す: 殻が事務所のルール.md「## 1 給与ソフトと取り込みの形」の値（名・鍵の欄・氏名の欄・後ろの欄・文字コード・区切り・向き・確かめた）を dict で読み、`形.形を組む(…)` か dict のまま `形=` へ渡す（置き場は `docs/設計/Drive の型.md` §4「製品ごとの値の置き場」）。書き口・読み口は中で `形を組む` を通し、名・鍵の欄・文字コードが無ければ止まる（パックに既定の形は無い＝黙って既定で書かない）。
2. 欄の対応を会社のマスタから渡す（取り込みと読みで同じ物）。
3. 毎月: `月次.月を回す`（中で `関所.通す` → `書き口.取り込み`〔と `支給控除一覧`〕）→ 事務所が給与ソフトで計算 → `読み口.読む` → `突き合わせ.突き合わせる` → `月の記録` → `続けて差0の月数`。
   外した人と月数は殻が管理表の「外した人」「突き合わせ」の列へ書く。

有給休暇管理表の行は `有給/` が数え、`月次.月を回す` が関所を通して `有給の出す行` で返す（名は `名を付ける()`）。まだ無い部品: 明細（給与ソフトなしの道の 04_明細）。名と版の口だけはある。

# 初期設定 — Drive の型の正本と、会社を始める手順

Drive の給与の DB（マスタ・台帳・質問と回答・事務所の設定・md の雛形）の型の正本はここ 1 か所（`docs/設計/Drive の型.md` §4）。Drive に雛形のフォルダを置かない。Drive のシートと md は、ここから道具が起こす・直す（直すのは `道具/寄せ/`）。

## 置く物

| file | 中身 |
|---|---|
| `型.json` | 型の版・シート×タブの列の名と並びと意味（1 行）・md の雛形の置き場 |
| `項目.json` | 会社の決まりの項目の辞書（`分野.名`・意味・選べる値・既定・法の線・段）。`docs/設計/会社の決まり.md` §2 の機械が読む形 |
| `雛形/` | md の雛形 4 枚（給与のルール・作業のルール・人のルール・事務所のルール） |
| `型の口.py` | 型を読む口（見出し・列の意味・md の見出し・見出しの照らし） |
| `始める.py` | 新しい会社を型で始める時に当てる物を起こす道具 |
| `段の解決.py` | マスタの段（事務所 → 会社 → 勤務の型 → 人）から、その人のその支給月に効く値（芯の `決まり`・`人`）を出す |
| `設問.py` | 問いの種の集め方とまとめ方（法の線の点検・型ごとの網・その月だけの物・種を集める・候補ごとの額・集まりへ直す・まとめる・問いの種類・反映の照らし）。正本は `docs/設計/設問の作り方.md` |

## 型の決まり

- タブの列は `型.json` の「列」の順のまま。「項目の列」を持つタブ（社員＝人・勤務の型＝勤務の型）は、`項目.json` の項目のうち、その段に置ける 1 つの値の項目を辞書の順に後ろへ並べる。
- 行の束の項目（`置く所` を持つ物）と優先 B の項目は列にしない。仕組みの段だけの項目（選べない物）も列にしない。
- 会社の段の項目は 2_マスタ「会社」の行（項目・今の値・適用開始）に置く。既定と同じなら行を置かない。事務所の段の項目は 事務所の設定「既定」。
- 列の意味は 1 行（何の値か・値の形・選べる値）。手順・経緯・日付・会社の事情を書かない。
- 型を直したら `型.json` の「版」を 1 上げ、同じ PR で `道具/寄せ/直し/` に直しを 1 つ置く（`docs/設計/寄せる道具.md` §1.2）。見出しの並びの見張り（`tests/初期設定/`）の写しも同じ PR で直す。

## 段の解決（毎月・芯の手前）

芯（`芯/集計`・`芯/計算`）は「この人のこの月に効く値」を受けるだけ（`docs/設計/会社の決まり.md` §1.1）。段の解決は殻ごとに書かず、`段の解決.py` を呼ぶ。Drive を開かない。

- **段**: 事務所の設定「既定」→ 2_マスタ「会社」→「勤務の型」→「社員」の順に重ね、**狭い方が勝つ**（人 > 勤務の型 > 会社 > 事務所）。仕組みの既定は埋めない（芯の 要る値 が埋める）。
- **適用開始**: 事務所・会社・支給控除の項目・人ごとの支給控除は、その支給月以前で最も新しい適用開始の行（空＝前から効く）。社員の行は今の値で、変更の記録に **その支給月より後** に効いた変更があれば、最も早い記録の `前の値` へ戻す（変更の記録は NO で引くので、勤務の型の行は戻さず今の値のまま）。その月に効く値が `確かめ＝仮` の記録から来ていれば `仮の値` に出す（`入口の文脈.給与の関所へ` がその人を関所で仮にし出さない＝下の「入口の文脈」）。
- **1 行の誤りで全体を止めない**（⟦鍵:給与計算/足りない時は仮で計算し出さない⟧）:
  - 支給月の字（`適用開始`・変更の記録の `適用支給月`）は `YYYY.MM支給`・`YYYY.MM`・`YYYY-MM`・`YYYY/MM`・`YYYY年M月`（`支給` つき・全角も）をそろえて読む。そろわない行（`来月`・`2027-13`・空の適用支給月 など）は効かせず、その行の人を `仮の値`＋問い 1 つにする: 人の行（人ごとの支給控除・変更の記録）→その人、会社の行（会社・支給控除の項目）→その会社の全員、事務所の行→全員（項目は `<タブ>.適用開始`・`変更の記録.適用支給月`）。段の誤りで止まるのは呼ぶ側が渡す `支給月` がそろわない時だけ。
  - 変更の記録の `項目` が今の項目に無い名（前の名など＝項目.json・社員の列・社員のタブの見出し・支給控除の項目と人ごとの支給控除の行の名のどれでもない）の行は、`確かめ＝仮` が効くかも分からない＝黙って確定にせず、その行を使わず、その人を `仮の値`＋問い 1 つ（項目 `変更の記録.項目`・知らない名を並べる）。`給与の関所へ`・`有給の関所へ` がその人を出さない。
  - そのほか 1 つのセルの形の誤り（崩れた JSON・数だけの `時間.休憩の表` など）は渡さず知らせ＋その値を使う人を `仮の値`＋問い 1 つ（会社・事務所・勤務の型の段の値なら会社の全員。芯の既定・見当で黙って数えない。扱いは読めない時間・そろわない字と同じ 1 つ＝`読めない字` の印を `_読めないを仮に` が仮にする）。
  - 項目の名が今の項目の辞書（`初期設定/項目.json`）に無い行・列（殻の写しの型の版が古い前の名・打ち間違い。会社・事務所の既定のタブの `項目`、勤務の型・社員のタブの `分野.名` の列）と、辞書に在ってもその段に置けない列（例 勤務の型の段だけの `時間.週の所定` を社員の列に書いた）は、芯が読まない＝今の名の値が黙って既定になる＝渡さず知らせ＋その値を使う人を `仮の値`＋問い 1 つ（印 `知らない名`）。`分野.名` でない列（氏名・勤怠の表記 など）は項目でない＝見ない。
- **出す形**:
  - `決まり[(会社, NO)]` = 重ねた値 ＋ `勤務の型`（`{型の名: 型の値に人の値を重ねた物}`＝表 A の「勤務の型」の列で引く）＋ `項目.行`（支給控除の項目のタブの行。`項目`→`名`。`給与ソフトの欄`・`足す行` は渡さない＝出口だけが読む）。芯/集計 と 芯/計算 の `決まり` へそのまま。
  - `人[(会社, NO)]` = 社員の行の値（`生年月日`→`人.生年月日`・`入社日`→`人.入社日`・`退職日`→`人.退職日`・`社保の取得日`→`社保.取得日`・`社保の喪失日`→`社保.喪失日`。項目の列はそのまま）＋ `項目.人の額`（人ごとの支給控除）＋ 行の束（`住民税.額` など）。芯/計算 の `人` へそのまま。人ごとの支給控除の `項目` が行の束でも、その会社の支給控除の項目の名でも、その会社の行の `単価の元` `額:<名>` が読む名（例 `額:資格単価÷所定日数` の 資格単価）でもない名（消した `控除.差押`・`現物.行`・打ち間違い）の行は `項目.人の額` に入れず、知らせ＋その人を `仮の値`＋問い 1 つ（印 `知らない名`。黙って入れると芯がどの行にも当てず額が消える）。
  - 住民税: 社員の列 `住民税.6月分`・`住民税.7月以降`（型の版 4）は `住民税.額` の `{"6月分", "7月以降"}` にまとめて渡す（段の解決は月を見ない）。人ごとの支給控除の行 `住民税.額`（優先 B）が在ればそれが勝ち、2 つの列は渡さない。支給月で 1 つを選ぶのは 芯/計算 の 1 か所だけ（特別徴収は 6 月支給分から新しい年度＝支給月が 6 月なら 6月分、7 月〜翌 5 月は 7月以降。前の道具 kyuyo_calc と同じ）。無い方の月は芯が仮にする。7 月以降の額が途中で変われば 変更の記録（項目 `住民税.7月以降`・適用支給月）。
  - `入力[(会社, NO)]` = 台帳「その月だけの指示」（段の解決の中の名は 月の変動）の値と `委託.雇用分の出勤時間`（委託の併用の人だけ）。その月だけの指示の読み方は `段の解決.その月の変動` の 1 か所（その支給月の行・同じ原本の同じ行は 1 つ）で、下の 2 つが同じ行を読む。

- **支給の月・暦の字**: 段の解決が `支払.支給の月` を 当月・翌月・翌々月 に（空白・全角はそろえる）、`時間.暦` を `{"休みの曜日": [曜日の 1 字], "祝日": "休み"|"出勤", "会社の休み": [...]}` の形にそろえる。そろわない字・崩れた JSON は渡さず知らせ＋その値を使う人（会社・事務所・勤務の型の段なら会社の全員）を `仮の値`＋問い 1 つ（芯/計算 は外れた字で落ち、無ければ既定〔翌月・土日祝〕で黙って数える＝締め日と違い 要る値 が問わないので段の解決が問う）。
- **締め日・支給日が無い**: 2_マスタ「会社」に `支払.締め日` の行が無い・そろわない字なら、期間を末締めで見当して `知らせ` に出す。値は埋めない。仮と問いは 芯/計算 の 要る値 が出す 1 つだけ（締め日・支給日とも。繋ぎで二重に出さない）。`支払.支給日` は入口の文脈に要らないので見ない。
- **休日**: 会社の `時間.暦`（会社の段 → 事務所の段。どちらにも無ければ土日祝で見当し、勤務の型の段に暦のある型の人・勤怠を取らない人の外を `仮の値`＋問い `「時間.暦」が無い`＝芯/計算 の 要る値 と同じ字で問い 1 つ）で期間の休みの日の set。祝日は 法の表/祝日（芯/計算/暦 の口）。引けない年は知らせ＋全員を仮。書いてあるのに読めない暦（会社・事務所・勤務の型の段）は土日祝で見当して知らせ（仮と問いは段の解決が会社の全員に 1 つずつ出す＝下の「字をそろえる」）。
- **型の休日**: 勤務の型のタブに `時間.暦` がある型だけ、期間の全部の日を `{日付: True=休日／False=勤務日}`（会社の休日より狭い段として全部の日を決める）。
- **人の型**: 社員の `勤務の型`（空で会社に型が 1 つならその型・段の解決と同じ）。**人の休日**: 段の解決の `人の休日`（鍵は NO）。**社員**: `勤怠の表記` → NO。
- **人の区分**: 段を解いた `人.区分`（入口は 委託 を所定の無い人に数える）。**所定の無い人**: 空（`人.区分` のほかに決める項目がまだ無い）。
- **勤怠を取らない人**: 段を解いた `人.区分`＝役員 の人（前に決めた事＝役員は勤怠を取らない。兼務役員は使用人の分の勤怠を取るので入れない）。入口は、その人の空のタブ（どの日も時刻・区分・備考が無い）を表 A に出さず（芯/集計 が勤怠の無い役員を確認済にし、芯/計算 が役員報酬の式で計算する）、書いた日のある時は空の日を 休日（要確認にしない）にする。役員でない人の空のタブは今までどおり要確認。
- **出勤簿が無い**: 段を解いた `時間.出勤簿が無い`（型・人の段）が `無い` の人 → その人の `時間.日の所定` の分。所定が曜日ごと・空なら `None`（入口が空の勤務日を要確認にする）。`ある`・`無い` の外の値は知らせ＋仮（出勤簿がある人として読む）。
- **委託.日ごとの実働**: 芯/集計 の `日ごとの実働`（表 A・B から数えた委託・委託の併用の人の、勤務の日ごとの実働の分）を `計算の入力` が 芯/計算 の `入力` の `委託.日ごとの実働` へ足す。段の解決の `入力`（`委託.雇用分の出勤時間`）は残す。

## 有給の入力（毎月・入口の後）

殻が手で書いていた 有給/ の管理表の入力（人の値・会社の値・表 A の年休の行・基準の日）をパックの口にした。有給/ と入口は今の形のまま受けるだけ。

- 呼び順: `月次/README.md`（`月次.月を回す(…, 給与のルール=<給与のルール.md の字>, 有給の値={…})` が回し、有給は年の台帳の確定した勤怠から数えて出す物 `有給休暇管理表`〔証明つき〕で返す）。
- **仮は関所へ**（⟦鍵:給与計算/足りない時は仮で計算し出さない⟧）: `有給の関所へ` が、管理表の 状態＝仮 の人（有給/ の仮）と、`y["仮の値"]`（口の仮）・`r["仮の値"]`（段の解決の仮）の人を（(会社, NO) で引く＝`給与の関所へ` と同じ。複数の会社を 1 度に回しても別の会社の同じ NO を取り違えない。会社の無い口の仮の値は口の会社の人）、その人の行を全部 状態＝仮・`人の状態`＝仮 にして関所の形（人×項目の縦・支給月 `YYYY-MM`・項目は `有給休暇管理表.<列>`・数の列だけ）で渡す。殻が仮を `人の状態` へ写さない。関所の中身は今のまま。問いは足さない（各々の仮の値・問い のまま）。
- **基準の日**: 締めの期間の終わり（入口の文脈 と同じ式）。
- **会社の値**: 段を解いた `有給.付与の基準日`・`有給.付与の表`・`有給.会社の表`・`有給.揃えた日`（書いた物だけ）。
- **人**: 段を解いた `人.区分`・`時間.週の所定日数`・`時間.週の所定`（時間の数のまま）・`有給.1日の時間`（分の数のまま）・`人.入社日`→`入社日`・`人.退職日`→`退職日`。掛け直さない。無い値は渡さない（既定を埋めない）＝有給/ が見当して仮と問いを出す（繋ぎで二重に問わない）。`氏名` と `有給の始めの日`・`有給の始めの残り`・`有給の始めの繰越` は社員のタブの列から。
- **字の揺れ**: 日付（入社日・退職日・有給の始めの日）は `2025/8/1`・`2025-8-1` を `YYYY-MM-DD` に、日数（有給の始めの残り・繰越）は `8日`→`8`、`時間.週の所定日数` は `3日`・`3.0`→`3` にそろえる（#48 の締め日と同じ考え）。そろわない字は渡さず `知らせ`。入社日・週の所定日数 は 有給/ が無い時に仮と問いを出すので繋ぎは問わない。退職日・有給の始めの* は 有給/ が問わないので `仮の値`＋問い 1 つ。
- **勤怠**: 表 A の `休暇の種類`＝`年休` の行の 支給月・NO・日付・休暇の種類・休暇の単位・休暇の時間（入口が出したまま）。`支給月` は呼ぶ側の支給月と同じ書き方（`YYYY.MM支給` など）にそろえる（今月の取得日を引く）。単位が決まらず `要確認` の年休の日がある人は `仮の値`（問いは入口が出す）。
- `勤怠の始め`（台帳の勤怠が揃っている最初の日）と `出勤率が足りない付与日`（`{NO: [日付]}`）は殻が渡す。

## 始める（新しい会社を型で始める）

過去の答え（前の給与ソフトの明細・一覧表・事務所の手の集計）から逆算した値は、照らし（`道具/答え合わせ/`）で人×項目の差が 0 になった時だけ決まりに書き、出所に `過去の結果 <支給月> <資料の名> <NO>:<項目> 一致` を書く（2026-11-19 オーナーの決定・`docs/設計/確かめと仮.md` §1。`出所を見る` が照らしで確かめ、外れは止める）。一致を示せない過去の答えから読めるのは **見当** まで。ほかの値は書類（規程・契約・通知）か質問と回答で決める。

1. **事務所の設定「会社の一覧」に 1 行**（会社・組・担当・状態＝立ち上げ）。組が無ければ新しい組にする。
2. **`始める.py` を回す**。入力:
   ```json
   {"会社": "…", "組": "…", "最初の支給月": "YYYY.MM支給", "今日": "YYYY-MM-DD", "担当": "…", "選んだ部品": "…",
    "会社の値": {"項目の名": {"値": "…", "書類の名": "書類_<受け取った日>_<元の名>"}},
    "見当": {"項目の名": {"値": "…", "拠り所": "既定・書類の名・過去の答えから読んだ"}},
    "勤務の型": [{"型の名": "…", "項目の名": "…"}],
    "人": [{"NO": "…", "項目の名": "…"}],
    "既にある": [],
    "次の問いの番号": 1}
   ```
   - `既にある` は質問と回答の今の行（列名の dict の並びか、get_values の形＝1 行目が見出しの格子・行が無ければ `[]`）を必ず渡す。問いの番号はその同じ支給年月の次から（渡さないと止まる＝黙って 01 から振らない）。
   - 「会社の値」は書類から読んだ値だけ（書類の名が要る）。書類の無い値は「見当」へ入れる。
   - 出力: `置き場`（作るフォルダ）・`シート`（起こすシート×タブの見出し）・`md`（md 3 枚の本文）・`会社の一覧の行`・`管理表の会社の行`（管理表「会社」へ・型の版つき）・`変更の記録`（会社の値の行・確かめ＝確認済）・`問い`（質問と回答の行）・`知らせ`（`支払.支給の月` が読めない時など）。置き場の `<支給月>` の（M月分）は会社の `支払.支給の月`（無ければ既定 翌月）から確認ページと同じ 1 か所の式で出す。
3. **殻が当てる**: フォルダを作り ID を 事務所の設定「置き場」へ、シートを見出しで起こし、md を置き、管理表「会社」の行と「月の状況」の最初の支給月の行を起こす（`管理表/` の事務所の段の口）。
4. **問いを 1 回で配る**（正本 `docs/設計/設問の作り方.md` §0・§6 ⟦鍵:給与計算/問いは初期設定と毎月に1回で聞き切る⟧）: 最初の支給月の原本で `月次.月を回す` を見当のまま最後まで回し、`設問.種を集める`・`設問.法の線の点検`→`法の線の種`・`設問.型ごとの網` の種に、`始める` の `問い`（`項目.json` で既定が null＝聞く の項目のうち、会社にも全部の勤務の型にも全部の人にも値が無い物を 1 問ずつ・同じ項目の人と型は 1 問）を足して `設問.まとめる` で 1 枚にする。質問と回答に書き、確認ページ（用＝立ち上げ）にして配り、管理表「確認ページ」に載せる。`法の線の点検` の `目で見る` は事務所が書類で見る（先方へ聞かない）。
5. **答えが来るまでは仮**: 答えの無い値を使う人は仮で計算し、出口へ出さない（⟦鍵:給与計算/足りない時は仮で計算し出さない⟧）。答えが来たら答えを出所としてマスタへ入れ、変更の記録に 1 行（問いの番号つき・確認済）。`設問.反映の照らし` が緑（答えが効く設定まで埋まった）になってから 反映済み を 済 にする。
6. **立ち上げの書類** は最初の支給月の `3_月ごと/<支給月>/1_届いた物/` に頭 `書類_` で置く。確認事項のページは `8_確認事項/` に `確認事項_<組>_<支給月>_v<版>.html` で置き、前の版は `9_履歴/` へ（名と置き場は `確認ページ/確認ページ.py` が持つ。1_決まり に HTML を置かない）。

## md の書き方（4 枚とも同じ）

- 見出しは雛形のとおり。足す・消す・名を変えるのは repo の雛形を直してから（版を上げ、直しで全組へ配る）。
- 数を書かない。マスタの項目の名（`分野.名`）や列の名を指す。md とシートで同じ数を 2 か所に持たない。
- 決め事は 1 行に 1 つ。行の終わりに出所を `［出所: 書類の名か 問いの番号］` で付ける。
- 組の中で会社によって違う決まりは、会社を名指しして書く。
- 経緯（前の決まり・取り消した決まり）は `9_履歴/決まりの履歴.md` に書く（md に残さない）。

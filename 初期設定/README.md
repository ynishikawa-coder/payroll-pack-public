# 初期設定 — Drive の型の正本と、会社を始める手順

Drive の給与の DB（マスタ・台帳・質問と回答・事務所の設定・md の雛形）の型の正本はここ 1 か所（`docs/設計/Drive の型.md` §4）。Drive に雛形のフォルダを置かない。Drive のシートと md は、ここから道具が起こす・直す（直すのは `道具/寄せ/`）。

## 置く物

| file | 中身 |
|---|---|
| `型.json` | 型の版・シート×タブの列の名と並びと意味（1 行）・md の雛形の置き場 |
| `項目.json` | 会社の決まりの項目の辞書（`分野.名`・意味・選べる値・既定・法の線・段）。`docs/設計/会社の決まり.md` §2 の機械が読む形 |
| `雛形/` | md の雛形 4 枚（給与のルール・作業のルール・人のルール・事務所のルール） |
| `型の口.py` | 型を読む口（見出し・列の意味・md の見出し・見出しの照らし） |
| `始める.py` | 新しい会社を型で始める時に当てる物を起こす道具 |
| `段の解決.py` | マスタの段（事務所 → 会社 → 勤務の型 → 人）から、その人のその支給月に効く値（芯の `決まり`・`人`）を出す |

## 型の決まり

- タブの列は `型.json` の「列」の順のまま。「項目の列」を持つタブ（社員＝人・勤務の型＝勤務の型）は、`項目.json` の項目のうち、その段に置ける 1 つの値の項目を辞書の順に後ろへ並べる。
- 行の束の項目（`置く所` を持つ物）と優先 B の項目は列にしない。仕組みの段だけの項目（選べない物）も列にしない。
- 会社の段の項目は 03_マスタ「会社」の行（項目・今の値・適用開始）に置く。既定と同じなら行を置かない。事務所の段の項目は 事務所の設定「既定」。
- 列の意味は 1 行（何の値か・値の形・選べる値）。手順・経緯・日付・会社の事情を書かない。
- 型を直したら `型.json` の「版」を 1 上げ、同じ PR で `道具/寄せ/直し/` に直しを 1 つ置く（`docs/設計/寄せる道具.md` §1.2）。見出しの並びの見張り（`tests/初期設定/`）の写しも同じ PR で直す。

## 段の解決（毎月・芯の手前）

芯（`芯/集計`・`芯/計算`）は「この人のこの月に効く値」を受けるだけ（`docs/設計/会社の決まり.md` §1.1）。段の解決は殻ごとに書かず、`段の解決.py` を呼ぶ。Drive を開かない。

- **段**: 事務所の設定「既定」→ 03_マスタ「会社」→「勤務の型」→「社員」の順に重ね、**狭い方が勝つ**（人 > 勤務の型 > 会社 > 事務所）。仕組みの既定は埋めない（芯の 要る値 が埋める）。
- **適用開始**: 事務所・会社・支給控除の項目・人ごとの支給控除は、その支給月以前で最も新しい適用開始の行（空＝前から効く）。社員の行は今の値で、変更の記録に **その支給月より後** に効いた変更があれば、最も早い記録の `前の値` へ戻す（変更の記録は NO で引くので、勤務の型の行は戻さず今の値のまま）。その月に効く値が `確かめ＝仮` の記録から来ていれば `仮の値` に出す（`入口の文脈.給与の関所へ` がその人を関所で仮にし出さない＝下の「入口の文脈」）。
- **1 行の誤りで全体を止めない**（⟦鍵:給与計算/足りない時は仮で計算し出さない⟧）:
  - 支給月の字（`適用開始`・変更の記録の `適用支給月`）は `YYYY.MM支給`・`YYYY.MM`・`YYYY-MM`・`YYYY/MM`・`YYYY年M月`（`支給` つき・全角も）をそろえて読む。そろわない行（`来月`・`2027-13`・空の適用支給月 など）は効かせず、その行の人を `仮の値`＋問い 1 つにする: 人の行（人ごとの支給控除・変更の記録）→その人、会社の行（会社・支給控除の項目）→その会社の全員、事務所の行→全員（項目は `<タブ>.適用開始`・`変更の記録.適用支給月`）。段の誤りで止まるのは呼ぶ側が渡す `支給月` がそろわない時だけ。
  - 変更の記録の `項目` が今の項目に無い名（前の名など＝項目.json・社員の列・社員のタブの見出し・支給控除の項目と人ごとの支給控除の行の名のどれでもない）の行は、`確かめ＝仮` が効くかも分からない＝黙って確定にせず、その行を使わず、その人を `仮の値`＋問い 1 つ（項目 `変更の記録.項目`・知らない名を並べる）。`給与の関所へ`・`有給の関所へ` がその人を出さない。
  - そのほか 1 つのセルの形の誤り（崩れた JSON・数だけの `時間.休憩の表` など）は今までどおり渡さず知らせ（使う人を仮にする項目は仮）。
- **出す形**:
  - `決まり[(会社, NO)]` = 重ねた値 ＋ `勤務の型`（`{型の名: 型の値に人の値を重ねた物}`＝表 A の「勤務の型」の列で引く）＋ `項目.行`（支給控除の項目のタブの行。`項目`→`名`。`給与ソフトの欄`・`足す行` は渡さない＝出口だけが読む）。芯/集計 と 芯/計算 の `決まり` へそのまま。
  - `人[(会社, NO)]` = 社員の行の値（`生年月日`→`人.生年月日`・`入社日`→`人.入社日`・`退職日`→`人.退職日`・`社保の取得日`→`社保.取得日`・`社保の喪失日`→`社保.喪失日`。項目の列はそのまま）＋ `項目.人の額`（人ごとの支給控除）＋ 行の束（`住民税.額` など）。芯/計算 の `人` へそのまま。
  - 住民税: 社員の列 `住民税.6月分`・`住民税.7月以降`（型の版 4）は `住民税.額` の `{"6月分", "7月以降"}` にまとめて渡す（段の解決は月を見ない）。人ごとの支給控除の行 `住民税.額`（優先 B）が在ればそれが勝ち、2 つの列は渡さない。支給月で 1 つを選ぶのは 芯/計算 の 1 か所だけ（特別徴収は 6 月支給分から新しい年度＝支給月が 6 月なら 6月分、7 月〜翌 5 月は 7月以降。前の道具 kyuyo_calc と同じ）。無い方の月は芯が仮にする。7 月以降の額が途中で変われば 変更の記録（項目 `住民税.7月以降`・適用支給月）。
  - `入力[(会社, NO)]` = 台帳「月の変動」の値と `委託.雇用分の出勤時間`（委託の併用の人だけ）。台帳「月の変動」の読み方は `段の解決.その月の変動` の 1 か所（その支給月の行・同じ原本の同じ行は 1 つ）で、下の 2 つが同じ行を読む。
    - 月の変動 → `入力`: 月の変動の `値` は **常に額**（入口/手当控除の一覧 が個数×単価を額で書く・寄せも額と読む）。名が その会社の支給控除の項目で `数量の元`＝`入力の値` かつ `単価の元` が `固定の額`（空も）で額の無い行（段の解決が `項目.行` のその行に 額＝1 を置く＝芯は 1×額）か `委託.出張日数`（日数）の行の値（数の字。`12,000`・`12000円` も）を `{名: 値}` で渡す。`単価の元` が `人の額`・`時間単価`・`日単価`・`回ごとの額` の `入力の値` の行に月の変動の行が在れば、額を数量と読むと単価×額 になるので渡さず仮（下）。会社の `委託.ソフトの出勤時間の欄`・`委託.ソフトの出勤日数の欄` の名の行は渡さない（出勤時間は下が読む）。読めない行（支給月がそろわない・`確認` が 確認済〔空も〕でない・値が数でない・同じ名にその月 2 行以上）・渡せない名（支給控除の項目に無い名・`数量の元` が `入力の値` でない部品の行・`単価の元` が固定の額でない `入力の値` の行）は渡さず、その人を `仮の値`（項目 `台帳.月の変動`）＋問い 1 つにする ⟦鍵:給与計算/足りない時は仮で計算し出さない⟧（`給与の関所へ` がその人を出さない）。社員に居ない NO の行は知らせ。
    - 委託の併用の出勤時間: 会社の `委託.ソフトの出勤時間の欄`（勤怠ソフトの出勤時間の欄の名）で、台帳「月の変動」の 項目＝欄 の行（確認済の行だけ。確認済でない行はその人を上の仮に）（無ければ 台帳「人ごと」の 欄 の列）からその支給月の値を引く（`解く(…, 月の変動=…, 人ごと=…)`）。芯/計算 の `入力` へそのまま（殻が手で写さない）。どちらにも無ければ会社の段の `委託.雇用分の出勤時間`（会社で毎月同じ時間の定数。時間の数か h:mm を h:mm にそろえて渡す・読めなければ渡さずその人を仮の値に）。順は **月の変動 > 人ごと > 会社**。どれも無ければ知らせ（芯が所定で見当し仮）。
  - 委託の所定: `人.区分` が 委託（委託だけ）の人の `時間.日の所定` は、ほかの人と同じく勤務の型の所定（段を解いた値）。それが空なら **前の道具どおり** 8 を `決まり` の `時間.日の所定` に置いて計算し、その人を `仮の値`（`問い`＝勤務の型の 1 日の所定を書く）に出す＝足りない値の見当なので出口へ出さない（前の道具 timecard_tally 318・498 行＝勤務の型の 1日の所定時間、空なら 8:00 を日の所定・委託の日当の境・日給から時給の割る数に使う）。芯/集計 は「時間.日の所定 が無い」を出さず、`委託.日当の境` の既定〔無し＝1 日の所定以上〕もこの値を読む。会社の `委託.所定時間` は `時間.日の所定` へ写さない（前の道具は委託のみなし残業〔563 行〕にだけ使う＝会社の値のまま 芯/計算 へ渡す）。ただし計算が日の所定を使わない人（式が 時給・日給・日ごとに時給か日当〔`委託.日当の境` が決まり、無し・空でない〕で `委託.時給` が在る人＝`委託で日の所定を使うか` が偽）は、8 が結果を変えないので仮にしない（8 は置く＝芯/集計 が「所定が無い」を出さない）。ただ 芯/集計 は定時扱いの日の時間を日の所定で置く（勤怠を見ないとわからない）ので、その人の `決まり` に `見当の値`＝`{"時間.日の所定": 拠り所}` を置き、定時扱いの日がある月は 芯/集計 がその日を仮にする（芯/計算 がその人を仮＋問い）。在る `時間.日の所定`（読めない値も）は上書きしない。委託の併用には置かない（`時間.日の所定` は雇用分の月の所定時間＝時間外・欠勤の単価にも効くので、雇用分の所定が空なら今までどおり仮）。
  - 通勤と割増の基礎（型の版 5）: 社員の列 `手当.通勤の非課税の限度`（人の値・月の額）は 芯/計算 の `人` へ、支給控除の項目の列 `割増の基礎から除く訳` は `項目.行` の行へそのまま渡す（無いと 芯/計算 が通勤の行のある人・割増の基礎から除いた行のある人を仮にし、除く訳が無ければ赤）。
  - `人の休日[(会社, NO)]` = 社員の列 `休日.人の休日`（型の版 4。`YYYY-MM-DD` を 、 で並べるか JSON の `{日付: true／false}`）を、入口の `文脈.人の休日`（人 → 勤務の型 → 会社 の 3 段の人の段・鍵は NO）の形（日付の set か `{日付: bool}`）で。芯/計算 の `人` には渡さない。読めなければ渡さず（会社と勤務の型の休日で見当して数える）、知らせとその人の `仮の値`＋問い 1 つにする（`給与の関所へ`・`有給の関所へ` がその人を出さない・入口の文脈は問わない＝二重にしない）。
  - 勤務の型が空の人は、会社の型が 1 つならその型。2 つ以上なら `知らせ`（型の値は日の列で引く分だけ）。
- **会社のタブの 1 つの値**: 会社のタブの行は `今の値`＝選べる値の 1 つ。並べて全部を渡すのは会社の行の束（`置く所` が 03_マスタ「会社」の行の項目＝`休暇.特別休暇`）だけ。`置く所` がほかのタブの項目（`源泉.報酬` など）を会社のタブに書いた時も 1 つの値（適用開始で一番新しい行）で渡す（並びで渡すと 芯/計算 が字で比べられない＝`源泉.報酬`＝対象でない が効かず法の率で源泉が出た）。同じ適用開始の行に違う値が並べば 1 つに決めず、渡さず `知らせ`＋その人を `仮の値`（`問い` つき）に出す。`源泉.報酬` は 対象・対象でない にそろえ、そろわない字（並び・`対象外` など）は同じく渡さず仮＋問い。
- **値の読み方**: セルの字のまま渡す。`{` か `[` で始まるセルは JSON として読む。`時間.休憩の表` は 2 つの形のどちらか一方で書き、形で芯の 2 つの鍵へ分ける（もう片方は空の並び＝狭い段の形が広い段の形に負けない）:
  - 時間帯の形 `12:00〜13:00、15:00〜15:15` → `時間.休憩の表`（`["12:00〜13:00", …]`）
  - 長さの形 `6:00超45分、8:00超60分`（働いた長さが 6:00 を超えたら 45 分）→ `時間.休憩の長さ`（`[["6:00", 45], …]`＝法の線の `時間.休憩の長さ` と同じ形）
  - 読めないセルは渡さず `知らせ` に出す（止めない）。
  - 時間の値（`時間.日の所定`〔曜日ごとの値も〕・`時間.週の所定`・`時間.月の所定時間`・`有給.1日の時間`・`割増.みなし残業の時間`）は h:mm（`8:00`・`202:30` の 3 桁の時も）・`480分`・`7時間30分`・小数の時間・0 のどれでも読み、読む側の単位の字（多くは 芯/計算 が受ける時間の数＝`7:30`→`7.5`。下の単位を見る）で渡す（h:mm のままだと 芯/計算 が 形の誤り で落ちる）。読めない・時間の数に割り切れない（分が 3 の倍数でない）値は黙って 0 にせず、渡さず `知らせ` に出し、その値を使う人を `仮の値`（`問い` つき）に出す（`給与の関所へ` がその人を出さない）。ただし `時間.週の所定`・`有給.1日の時間` は、値を使う所が無い時に自分で仮と問いを出す（`有給/`〔比例付与の境・時間単位の取得〕と 芯/集計〔変形の週〕）ので、`知らせ` だけ＝無い扱い（締め日を 芯/計算 の 要る値 が問うのと同じ。同じ人×項目に問いを 2 つ出さない）。変更の記録で戻した前の値も同じ（崩れた JSON も知らせ＋仮で止めない）。単位は読む側に合わせる: `有給.1日の時間` は読むのが `有給/有給.py` だけ（int の分）なので **分の数の字**（`7:30`→`450`・`7:20`→`440`）で渡し、ほかは 芯/集計・芯/計算 が読む時間の数で渡す。`時間.週の所定` は 芯 も `有給/` も時間の数で読むので時間の数で渡す＝`有給/` へ渡す殻も時間の数のまま渡す（×60 は要らない。分に直すのは `有給/有給.py` の中だけ）。
  - 芯/集計 が会社の長さ（`時間.休憩の長さ`）を読む（休憩の区間が無い日に、会社の長さで休憩を置く）＝長さの形の人は `仮の値` に出さない。
- **社保**: `社保.標準報酬` は健保の標準報酬月額。健保と厚年の等級が違う人（厚年の下限など）だけ `社保.厚年の標準報酬` に厚年の額を書く（空なら芯が健保の値から厚年の等級表で引く）。
- **委託**: `人.区分` は 委託（委託だけ）と 委託の併用（雇用分と委託分を 1 枚の明細・最低賃金は雇用分で判定）。`委託.*` は 17。会社の段の 13（式・源泉率・社保と源泉の元に入れる・所定時間・みなし残業時間・雇用分・丸め・日当の境・出張日額・法定休日の曜日・法定休日の率・ソフトの出勤日数の欄・ソフトの出勤時間の欄。`委託.式` だけは人の段にも置け、人の値が勝つ）と、人の額の 4（`委託.月給`・`委託.時給`・`委託.日給`・`委託.通勤日額`＝人ごとの支給控除の行。段の解決が 人 の値へ渡す）。`委託.雇用分` は会社の行にも人ごとの支給控除の行にも置け、人の行が勝つ。式は `芯/計算/委託.py` が読む（各項目の `注`）。`委託.源泉率` は `法の表/` の率を下回れない（空＝法の率）。`会社.事業場の都道府県` は芯/計算 が最低賃金を引く名。

## 入口の文脈（毎月・段の解決の後）

殻が手で書いていた繋ぎ（入口の `文脈` と 芯/計算 の `入力` の `委託.日ごとの実働`）をパックの口にした。入口と芯は今の形のまま受けるだけ（入口は初期設定の形を知らない）。

- 呼び順: `月次/README.md`（`月次.月を回す` が回す。殻は部品を手で組まない）。
- **仮は関所へ**（⟦鍵:給与計算/足りない時は仮で計算し出さない⟧）: `給与の関所へ` が、段の解決の `r["仮の値"]`（変更の記録の 確かめ＝仮・時間に直せない時間の値・そろわない `支払.支給の月`／`時間.暦`・委託の所定の見当・委託の雇用分の出勤時間が読めない）と口の `x["仮の値"]`（祝日が引けない・出勤簿が無い の外の値）に出た人の、計算の行を全部 状態＝仮・`人の状態`＝仮 にして渡す（芯が確認済で返した人も関所が外す）。殻が仮を `人の状態` へ写さない。関所と芯の中身は今のまま。問いは足さない（各々の仮の値・問い のまま）。会社の段（と勤務の型の段＝`決まり` の `勤務の型` は会社の全部の型を持つ）の値から来た仮は、段の解決・入口の文脈がその会社の全員に出す＝口は人ごとに見るだけ。
- **期間**: `支払.締め日`（1〜28・末。`20日`・`月末` も読む）と `支払.支給の月`（既定 翌月）から、芯/計算/暦.期間 と同じ式で `期間の始め`・`期間の終わり`。
- **締め日・支給日の字**: 段の解決が `支払.締め日`・`支払.支給日` を `1`〜`28`・`末` にそろえて渡す（`20日`→`20`・`31`・`月末`・`末日`→`末`）。そろわない字（`29`・`30` など）は渡さず知らせ＝無い扱い（芯/計算/暦 は 1〜28・末 だけを読み、ほかの字では落ちる）。
- **支給の月・暦の字**: 段の解決が `支払.支給の月` を 当月・翌月・翌々月 に（空白・全角はそろえる）、`時間.暦` を `{"休みの曜日": [曜日の 1 字], "祝日": "休み"|"出勤", "会社の休み": [...]}` の形にそろえる。そろわない字・崩れた JSON は渡さず知らせ＋その値を使う人（会社・事務所・勤務の型の段なら会社の全員）を `仮の値`＋問い 1 つ（芯/計算 は外れた字で落ち、無ければ既定〔翌月・土日祝〕で黙って数える＝締め日と違い 要る値 が問わないので段の解決が問う）。
- **締め日・支給日が無い**: 03_マスタ「会社」に `支払.締め日` の行が無い・そろわない字なら、期間を末締めで見当して `知らせ` に出す。値は埋めない。仮と問いは 芯/計算 の 要る値 が出す 1 つだけ（締め日・支給日とも。繋ぎで二重に出さない）。`支払.支給日` は入口の文脈に要らないので見ない。
- **休日**: 会社の `時間.暦`（会社の段 → 事務所の段 → 項目の既定 土日祝）で期間の休みの日の set。祝日は 法の表/祝日（芯/計算/暦 の口）。引けない年は知らせ＋全員を仮。書いてあるのに読めない暦（会社・事務所・勤務の型の段）は土日祝で見当して知らせ（仮と問いは段の解決が会社の全員に 1 つずつ出す＝下の「字をそろえる」）。
- **型の休日**: 勤務の型のタブに `時間.暦` がある型だけ、期間の全部の日を `{日付: True=休日／False=勤務日}`（会社の休日より狭い段として全部の日を決める）。
- **人の型**: 社員の `勤務の型`（空で会社に型が 1 つならその型・段の解決と同じ）。**人の休日**: 段の解決の `人の休日`（鍵は NO）。**社員**: `勤怠の表記` → NO。
- **人の区分**: 段を解いた `人.区分`（入口は 委託 を所定の無い人に数える）。**所定の無い人**: 空（`人.区分` のほかに決める項目がまだ無い）。
- **勤怠を取らない人**: 段を解いた `人.区分`＝役員 の人（前に決めた事＝役員は勤怠を取らない。兼務役員は使用人の分の勤怠を取るので入れない）。入口は、その人の空のタブ（どの日も時刻・区分・備考が無い）を表 A に出さず（芯/集計 が勤怠の無い役員を確認済にし、芯/計算 が役員報酬の式で計算する）、書いた日のある時は空の日を 休日（要確認にしない）にする。役員でない人の空のタブは今までどおり要確認。
- **出勤簿が無い**: 段を解いた `時間.出勤簿が無い`（型・人の段）が `無い` の人 → その人の `時間.日の所定` の分。所定が曜日ごと・空なら `None`（入口が空の勤務日を要確認にする）。`ある`・`無い` の外の値は知らせ＋仮（出勤簿がある人として読む）。
- **委託.日ごとの実働**: 芯/集計 の `日ごとの実働`（表 A・B から数えた委託・委託の併用の人の、勤務の日ごとの実働の分）を `計算の入力` が 芯/計算 の `入力` の `委託.日ごとの実働` へ足す。段の解決の `入力`（`委託.雇用分の出勤時間`）は残す。

## 始める（新しい会社を型で始める）

過去の答え（前の給与ソフトの明細・一覧表・事務所の手の集計）から値を逆算しない。過去の答えから読めるのは **見当** まで。値は書類（規程・契約・通知）か質問と回答で決める（`docs/設計/確かめと仮.md` §1）。

1. **事務所の設定「会社の一覧」に 1 行**（会社・組・担当・状態＝立ち上げ）。組が無ければ新しい組にする。
2. **`始める.py` を回す**。入力:
   ```json
   {"会社": "…", "組": "…", "最初の支給月": "YYYY.MM支給", "今日": "YYYY-MM-DD", "担当": "…", "選んだ部品": "…",
    "会社の値": {"項目の名": {"値": "…", "書類の名": "書類_<受け取った日>_<元の名>"}},
    "見当": {"項目の名": {"値": "…", "拠り所": "既定・書類の名・過去の答えから読んだ"}},
    "勤務の型": [{"型の名": "…", "項目の名": "…"}],
    "人": [{"NO": "…", "項目の名": "…"}],
    "次の問いの番号": 1}
   ```
   - 「会社の値」は書類から読んだ値だけ（書類の名が要る）。書類の無い値は「見当」へ入れる。
   - 出力: `置き場`（作るフォルダ）・`シート`（起こすシート×タブの見出し）・`md`（md 3 枚の本文）・`会社の一覧の行`・`管理表の会社の行`（管理表「会社」へ・型の版つき）・`変更の記録`（会社の値の行・確かめ＝確認済）・`問い`（質問と回答の行）・`知らせ`（`支払.支給の月` が読めない時など）。置き場の `<支給月>` の（M月分）は会社の `支払.支給の月`（無ければ既定 翌月）から確認ページと同じ 1 か所の式で出す。
3. **殻が当てる**: フォルダを作り ID を 事務所の設定「置き場」へ、シートを見出しで起こし、md を置き、管理表「会社」の行と「月の状況」の最初の支給月の行を起こす（`管理表/` の事務所の段の口）。
4. **問いを配る**: `問い` は、`項目.json` で既定が null（聞く）の項目のうち、会社にも全部の勤務の型にも全部の人にも値が無い物を 1 問ずつ（同じ項目の人・型は 1 問に並べる）。見当があれば添える。質問と回答に書き、確認ページにして配り、管理表「確認ページ」に載せる。
5. **答えが来るまでは仮**: 答えの無い値を使う人は仮で計算し、出口へ出さない（⟦鍵:給与計算/足りない時は仮で計算し出さない⟧）。答えが来たら答えを出所としてマスタへ入れ、変更の記録に 1 行（問いの番号つき・確認済）。
6. **立ち上げの書類** は最初の支給月の `01_原本/` に頭 `書類_` で置く。確認ページは `20_配る物/<支給月>/` に置く（01_ルール に HTML を置かない）。

## md の書き方（4 枚とも同じ）

- 見出しは雛形のとおり。足す・消す・名を変えるのは repo の雛形を直してから（版を上げ、直しで全組へ配る）。
- 数を書かない。マスタの項目の名（`分野.名`）や列の名を指す。md とシートで同じ数を 2 か所に持たない。
- 決め事は 1 行に 1 つ。行の終わりに出所を `［出所: 書類の名か 問いの番号］` で付ける。
- 組の中で会社によって違う決まりは、会社を名指しして書く。
- 経緯（前の決まり・取り消した決まり）は `90_履歴/決まりの履歴.md` に書く（md に残さない）。
